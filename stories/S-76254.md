## Description

## Acceptance
- [ ] a hook written for a pinned product skips an `asf` that does not carry the dispatcher's marker, with one line on stderr naming the path and the `hooks install --product <p>` remedy
- [ ] the skip falls through: the repository's own `tools/checks/redact.sh` runs when it is there, and only with nothing left to scan with does the standing `REDACTION REFUSED` line fire
- [ ] a dispatcher at the path runs, with argv `redact --<name> --product <p>` — unchanged — proven by tests/test_pin_defects.py
- [ ] at most one warning line per commit or push, when both candidates are the same file
- [ ] a hook written for an **unpinned** product behaves exactly as today — proven by tests/test_pin_defects.py
- [ ] `is_git_hook_ours`, `hook_entry`, `init_hook_upgrade` and `staged_check_upgrade` read the new body as they read the old one
- [ ] `ensure_git_hooks` bakes the guard exactly when `state/<p>/install.json` exists, rewrites an older body onto the new one across a pin being added or removed, and changes nothing on a second run; a foreign hook is still left untouched and refused, a withheld path still skipped
