## Description

## Acceptance
- [ ] [ ] `upgrade.cmd_upgrade` runs `schema.auto_migrate` for every installed product after a successful install and before it prints the per-product table.
- [ ] [ ] With `--skip-pipx` and no install, nothing is migrated: the table stays a read-only view.
- [ ] [ ] `tools/install.sh` and F-0112's auto path inherit the migration by going through `cmd_upgrade`, with no migrate call of their own.
- [ ] [ ] `upgrade.row` renders a `config schema` column beside `record schema`, and its `action` for a pending additive migration reads `none (the next tick migrates)`.
- [ ] [ ] `asf upgrade` prints `upgrade: package <v>, schema <n> (config schema <n>)` after its migration lines and before the table.
