## Acceptance
- [ ] `prices.load()` returns `[]` for an absent `~/.ASF/prices.yaml` and never raises
- [ ] `prices.load` reads the file through `env.load_file`, adding no second yaml parser
- [ ] `rate(table, model, day)` takes the exact `model` match, else the longest `model` ending in `*` whose stem the model starts with
- [ ] among the matching rows, `rate` takes the greatest `from` that is `<= day`, and returns `None` for an unpriced model
- [ ] `cost` is `sum(by_dim[d] / 1e6 * rate[d])` over the dimensions that are not `None`, rounded to 4 decimals
- [ ] `cost` returns `None` when the model is unpriced, and when every dimension is `None`
- [ ] a dimension present in `by_dim` and absent from the rate is a load-time error naming the row, not a silent zero
- [ ] the `sessions` schema carries `usd_source`: `'runtime'` when the result reported `total_cost_usd`, `'priced'` when the table priced it, `None` when neither
- [ ] a measured runtime `total_cost_usd` is never overwritten by the priced value
- [ ] `cost_coverage(sessions)` returns `(priced, total, share)` over the sessions whose `usd` is not `None`; for a fixture of ten sessions, nine priceable and one on an unpriced model, the share is `0.9`
- [ ] `cmd_rollup` prints `cost: 9/10 sessions priced (90 %)`, and the scorecard's `cost coverage` row carries the same numbers with the models seen with tokens and no price as its note
- [ ] `asf doctor` prints one `NEEDS OPERATOR:` line naming the count and `~/.ASF/prices.yaml` when the share is below `conventions.cost_coverage_floor` (default `0.90`), and nothing when it is at or above it
- [ ] `docs/prices.example.yaml` ships the shape, and says the numbers are the operator's and the file is never committed to a product repo
