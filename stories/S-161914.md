## Acceptance
- [ ] [ ] ending a session the beat stalled fetches its last beat, fast-forwards the snapshot onto its branch as a wip commit, and deletes the beat ref
- [ ] [ ] a branch that has moved past the last beat is left as it is, and the line says so
- [ ] [ ] a beat whose tree equals the branch head's adds no commit
- [ ] [ ] ending a session the beat did not stall settles nothing, and its beat ref is left for clear_ended
- [ ] [ ] the dead run's notes and a summary of its last events are written to its ledger row
- [ ] [ ] the next brief for the same item carries a CONTINUE block with the branch head, the notes and the summary
- [ ] [ ] the CONTINUE block says that only the new session's own ASF-Session counts, so a zombie push is never read as its work
- [ ] [ ] the continuation count is incremented on the new row, and a job past max_continues is not relaunched
- [ ] [ ] an item past max_continues goes to Stuck with the operator as owner and the beat's reason as the reason
- [ ] [ ] a beat ref of a run that is no longer live is deleted, and an unreachable origin leaves it for the next tick
- [ ] [ ] a settle that cannot reach origin ends the session anyway and says what it could not do
