## Acceptance
- [ ] [ ] a red check whose log tail names a failing case has that case as its signature key
- [ ] [ ] a red check whose log tail names no case takes its first test file as the signature key
- [ ] [ ] a red check whose failing files hold no test file and whose log tail names no case has no signature at all
- [ ] [ ] a signature carries the job name, the failed step and the key, and a matrix leg counts as its job
- [ ] [ ] a red check with no failed step read still has a signature, with a placeholder for the step
- [ ] [ ] two heads failing different cases of one test file are two signatures
- [ ] [ ] only the test files among a check's failing files become the signature's test files
- [ ] [ ] one tick's sightings hold one row per red required check on an open pull request's head
- [ ] [ ] a red on a check that is not required is no sighting
- [ ] [ ] a red on a merged pull request is no sighting
- [ ] [ ] a sighting carries the pull request, its head, its item, the check, the step, the pull request's changed files and the tick's time
- [ ] [ ] the window holds this tick's sightings without the state file having been written first
- [ ] [ ] a kept sighting older than the window is not counted
- [ ] [ ] a kept sighting whose pull request is no longer open is not counted
- [ ] [ ] two sightings of one signature on one pull request at two heads count as one source
- [ ] [ ] a source's time is the oldest sighting of that signature on that pull request
- [ ] [ ] the signatures of a window come back in sorted order, and each source list oldest first
