## Description

## Acceptance
- [ ] `reslot_closed(run, pr)` is True for a CLOSED unmerged PR whose number the run's own `reslot` record names, and False for a different number, for that same number OPEN, for a MERGED PR (a `merge_sha`), for a run with no `reslot` key, and for a `reslot` record with no `pr`
- [ ] `branch_facts` of the carried branch with the reslot run yields `f['pr'] is None`, the drop happening before `land_requested` and before any later fact is built
- [ ] `next_state` over those facts is `('PUSHED', 'finished')`, where `next_state` over the same branch's facts carrying that closed PR is `STALE`
- [ ] A different CLOSED unmerged PR at the same branch head still reads `STALE`, so the predicate is no blanket excuse for closed pull requests
