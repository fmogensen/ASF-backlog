## Acceptance
- [ ] a Feature whose spec is on the trunk and declares one Story heading with acceptance lines gets one Story card, parent the Feature, with no plan on the trunk at all
- [ ] the minted card carries the declaration's title and every one of its checkbox acceptance lines, in the order the spec wrote them
- [ ] the card's History line names the spec it was declared in
- [ ] a second run of the pass over the same record mints nothing and prints nothing
- [ ] a spec that is not on the trunk mints nothing and prints nothing
- [ ] a Feature the evidence carries no entry for at all mints nothing, raises nothing, and does not stop the Features after it
- [ ] a spec declaring only ids the record already holds mints nothing and prints nothing
- [ ] a Feature the ingest resolved or closed mints nothing, and a retired Feature mints nothing
- [ ] a Feature that already has Task children still gets a newly declared Story minted
- [ ] an undecided Feature whose spec names it nowhere mints nothing
- [ ] an undecided Feature whose spec is named after its id mints, and so does one whose spec declares the id in its own H1 and whose lane evidence entry carries no plan at all
- [ ] two Features whose specs declare the same Story id mint it once, for the first of them
- [ ] the pass loads the record once however many Features mint, and a Feature minting after another still reads the earlier cards as ids the record already holds
- [ ] a spec ref the reader cannot read mints nothing for that Feature, says so in a line naming the Feature and the path, and does not stop the others
