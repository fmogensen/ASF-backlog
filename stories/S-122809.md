## Acceptance
- [ ] [ ] a flake verdict with no open Bug of its class files one Bug
- [ ] [ ] the filed card names a test in its acceptance, so the Definition of Ready finds no gap
- [ ] [ ] the filed card's writes are the signature's test files
- [ ] [ ] a test file that is not on the trunk is left out of the writes
- [ ] [ ] the writes hold every one of the signature's test files when the trunk file list is unread
- [ ] [ ] the filed card carries a signature field, and its symptom class folds the instance tokens away
- [ ] [ ] the filed card carries a severity and is marked decided, so intake asks nothing about it
- [ ] [ ] the filed card's body lists each source with its pull request, head, item, time and changed files
- [ ] [ ] the filed card's body carries the marker line that keeps it filed once
- [ ] [ ] the filed card's title names the failing case, the job and the step, and is cut to the record's title limit
- [ ] [ ] the filed card's rank is the lowest rank on the record, so a main-red Bug still outranks it
- [ ] [ ] a second tick of the same cycle files no second Bug
- [ ] [ ] a signature whose symptom class another filer's open Bug owns is recorded as owned, and is neither quarantined nor filed again
- [ ] [ ] an open Bug of the class that carries no marker line for this signature is not read as this signature's own cycle
- [ ] [ ] the quarantine entry written beside a Bug records that Bug's id
- [ ] [ ] a Bug whose filing failed leaves the entry with no id, and the next tick fills it
- [ ] [ ] a caller that passes none of the new fields writes exactly the card it writes today
