## Description

## Acceptance
- [ ] `asf hooks install` rewrites the bare `asf` of each command line of an `asf init`-written hook to the dispatcher's quoted path — the record's `asf check --staged` and its `asf redact --<name>` both — and leaves every other line byte-identical
- [ ] it rewrites only when the asf it would name **is** the dispatcher, and only a hook carrying `asf init`'s marker: an operator's hook is still left untouched and still refused
- [ ] the rewritten hook reads as the dispatcher's to `is_git_hook_ours` and `hook_entry`, so `hooks.verify` and `asf doctor`'s `redaction hooks` row go green where the remedy they name was a no-op before
- [ ] an older init hook converges in one `ensure_git_hooks` call, and a second run changes nothing; an unpinned product's record hooks are left as they are
- [ ] `plan` reports the row as `upgrade` and `tracked`, so the tracked `.githooks` write is withheld until `touch_security` is answered; `install` and `plan` decide identically, through one `hook_upgrade`
