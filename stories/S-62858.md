## Acceptance
- [ ] rows.correction_cause(items, item_id, occupancy, attempts, product) returns None when no correction is pending on the item
- [ ] CAUSE_PARKED when the correction itself carries parked, and when a branch or job park in occupancy['parks'] holds its run
- [ ] CAUSE_LIVE when a run of the item is live — the item in occupancy['busy'] from lifecycle.inflight
- [ ] CAUSE_LANE for each of the four lane states a correction does not turn back — PUSHED, QUEUED, MERGING and PARKED (P10) — with the state and the PR named in the text
- [ ] CAUSE_CAP when the item is at or past attempt_limit and an adjudication has already ended on this same card
- [ ] The text is one line, operator-facing, and always names the correction's kind and its at
- [ ] rows.pushed_rows renders 'WAITS ON correction: <text>' ahead of its three existing arms, keeps the row non-launching, and sets waits_on to the cause
- [ ] rows.bug_rows asks correction_cause first in its busy arm, so a decided S1/S2 Bug with a held correction names the cause instead of the landing wait
- [ ] No row's action is a bare 'WAITS ON landing' while a correction is pending on that item
- [ ] status.held_corrections_cell renders '<n> — <item> [<cause>]: <text>' with the 'asf next shows the row' pointer, and is registered in render's cell list between Parked and Quota 5h/7d
- [ ] held_corrections_cell is None when every pending correction already has a launching row
