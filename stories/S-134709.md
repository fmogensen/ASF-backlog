## Acceptance
- [ ] [ ] flow_report prints one line per sink, naming the invariant, the item and why it is a sink
- [ ] [ ] flow_report appends one record per sink to the invariants report file, through the state store, carrying the time, the invariant, the mode, the item and the message
- [ ] [ ] the flag unset reads as report, so the law is on by default
- [ ] [ ] the flag set to off prints nothing, writes nothing and returns nothing
- [ ] [ ] the flag set to a yaml off, to None, or to any value that is not a mode, reads as off
- [ ] [ ] there is no refuse mode, and the modes tuple is exactly report and off
- [ ] [ ] a state store that raises on append leaves the lines printed and the findings returned
- [ ] [ ] a rows call that raises costs one line saying the flow check was not run, with the error, and returns nothing
- [ ] [ ] flow_report returns the findings it printed, so a caller can count them without reading the file
- [ ] [ ] flow_report writes no card, changes no item, drops no row and launches nothing
