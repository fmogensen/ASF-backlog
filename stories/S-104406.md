## Description

## Acceptance
- [ ] a bootstrap launchd refuses once is tried a second time and the clock ends loaded
- [ ] the retry prints one line saying it is retrying once, before the second attempt
- [ ] that first line does not carry the word failed, so a host install whose retry succeeded still exits zero
- [ ] a host install whose bootstrap is refused both times exits non-zero on the terminal line
- [ ] a clock loaded by the second attempt says so in a line that marks it as retried
- [ ] a bootstrap refused both times prints a line naming launchd's own message the second time
- [ ] a clock refused both times is not loaded when the install returns
- [ ] the retry waits for the label to leave launchd before it tries again
- [ ] exactly two bootstraps reach launchctl for one clock, never three
- [ ] a clock whose first bootstrap succeeds reaches launchctl once and prints neither retry line
