## Acceptance
- [ ] the `redactout` hook refuses a shell call whose command carries an authorization header, a token-shaped query parameter, or a literal of each of the eight secret shapes `asf.redact` knows
- [ ] it refuses a fetch whose url carries a key-shaped query parameter
- [ ] it allows an ordinary version-control, test and `asf` command, and allows a command whose text merely contains the word token
- [ ] every refusal line carries the pattern name and never the matched text
- [ ] each refusal writes one `refused-secret-output` record, and that record carries no `detail` key
- [ ] a hook body that raises returns 2 naming itself, not the rule
