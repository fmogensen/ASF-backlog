## Description

## Acceptance
- [ ] [ ] a question asking permission to write named paths outside the card's writes is claimed by the write grant class
- [ ] [ ] the paths are read with the same parser the report's needs writes field uses
- [ ] [ ] a question naming no path outside the card's writes is claimed by nothing
- [ ] [ ] a question naming more paths than the rule admits is claimed by nothing
- [ ] [ ] a test path this item adds, matching the configured test globs, absent from the trunk and in no other live item's writes, is granted by rule
- [ ] [ ] the granted answer names the paths and says the card's writes was widened by the kernel
- [ ] [ ] the grant widens the card's writes through the record's own writer, and nothing outside the granted paths
- [ ] [ ] a path that is already on the trunk is not granted by rule and reaches the console
- [ ] [ ] a path another live item writes is not granted by rule and reaches the console
- [ ] [ ] a path outside the configured test globs is not granted by rule and reaches the console
- [ ] [ ] a path matching the high risk globs is routed to the console whatever else holds
- [ ] [ ] the console's reason names the paths and which clause refused them
- [ ] [ ] the three existing needs writes answers are unchanged: a path an unfinished after item writes is held, a path a building or review item writes is granted and serialised, anything else is granted
- [ ] [ ] with the write grant resolver off, the question reaches the console unchanged
