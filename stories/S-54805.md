## Acceptance
- [ ] A product yaml carrying `size:` and `train:` folds both blocks onto their flat `Conventions` fields (the five size fields, `train_lanes`, `train_max_tasks`, `train_max_age_s`)
- [ ] An unknown key inside either block is kept in `extra` rather than silently dropped
- [ ] With both blocks absent every field resolves to its documented module-level default: 3, {docs: 15, copy: 15}, 15, {}, [], [], 6, 7200
- [ ] `size_config()` returns a `SizeConfig` whose `never_small_globs` is `size_never_small_paths` followed by the product's `amendable_paths`, including when `never_small_paths` is absent entirely
- [ ] A yaml carrying `size: {small_max_files: 5}` alone leaves the other four size fields at their defaults — a partial block is not a reset
- [ ] `conv.branch` called for the train lane with `code-20260924-0930` yields that name under the new `train` prefix, and `all_prefixes()` carries that prefix
- [ ] `docs/products.example.yaml` validates clean with both blocks documented in it
