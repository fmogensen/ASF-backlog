## Acceptance
- [ ] both new keys are read through the tunable seam, so the module constant is the default
- [ ] both are typed, which is also what makes them known keys, so neither needs a second registration
- [ ] both are typed with a floor, so a negative or unparsable value keeps the default and is named
- [ ] the poll's floor refuses zero, so no configured value can turn the wait into a hot loop of launchctl calls
- [ ] both are in the example config, in the shape the other scheduler keys have
- [ ] a configured value reaches the wait, and an unset one leaves the constant in force
- [ ] the guide's row for this command says the clock is loaded again before the command returns and that it exits non-zero naming any clock it could not load
- [ ] the troubleshooting table has one row for the new operator line, naming the repair
- [ ] the guide assertions that already pin the installer's operator lines still pass
