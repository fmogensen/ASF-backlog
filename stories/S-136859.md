## Description

## Acceptance
- [ ] [ ] the report counts the milestone's open items and its closed items
- [ ] [ ] the counts are grouped by the Epic above each item, in those Epics' own order
- [ ] [ ] an item with no Epic above it is counted in one trailing row of its own
- [ ] [ ] the totals equal the sum of the rows
- [ ] [ ] an item that inherits the milestone from an ancestor is counted
- [ ] [ ] a card that is retired and done is counted closed
- [ ] [ ] a card that is retired and not done is counted in neither column
- [ ] [ ] the json form carries the same numbers as the text form
- [ ] [ ] the command exits 1 while the milestone still has an open item
- [ ] [ ] the command exits 0 when every item of the milestone is closed
- [ ] [ ] a milestone name the record does not declare is a refusal that names the declared names, and exits 2
- [ ] [ ] the release gate's own criteria, evidence and exit code are unchanged when the flag is absent
