## Acceptance
- [ ] a probe that exits 0 is `valid`, exit 1 is `invalid`, and any other exit code is `broken` — proven by tests/test_credentials.py
- [ ] `expires <ISO-8601>` or `expires never` on the probe last non-empty output line is read into `Result.expires`; an unreadable line leaves it empty and the verdict is `unknown`, never `expiring` — proven by tests/test_credentials.py
- [ ] a probe that outruns `PROBE_TIMEOUT_S` is `broken`, and the call returns well inside the time the probe itself would have taken — proven by tests/test_credentials.py
- [ ] an expiry inside the provider `window_days` is `expiring` and one outside it is `ok`, and `bad()` returns the invalid and expiring results in provider order — proven by tests/test_credentials.py
