## Acceptance
- [ ] an `Edit` of a source file in the worktree under a `review` job returns rc 2 from the `roleguard` hook, the refusal first line naming the role and the surface
- [ ] that refusal writes one `refused-role` record to `approvals.jsonl` with no `hold` key, so nothing parks and nothing is relaunched on it
- [ ] a `Write` of the review file under `reviews_dir` returns rc 0 with empty stderr and records nothing
- [ ] both a trunk push and a branch push are refused for a reviewer, because a reviewer pushes nothing
- [ ] the reviewer rendered settings file carries `Edit`, `MultiEdit` and `NotebookEdit` in its `disallowedTools` argv and keeps `Write`, and its permission mode is `plan`
- [ ] the same three calls under a `coder` job allow the `Edit`, allow the branch push and refuse the trunk push
- [ ] every hook command the installer writes into a fixture account settings file is executable as the runtime would execute it, over the real call JSON on stdin
