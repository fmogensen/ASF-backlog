## Acceptance
- [ ] [ ] the paths a finding names outside the card's footprint are read by the same parser the report's writes request uses
- [ ] [ ] a finding naming only paths the card's footprint covers makes no request
- [ ] [ ] a finding naming a path outside the footprint makes one writes request
- [ ] [ ] a requested path under the test globs, absent from the trunk, and in no other live item's footprint is granted by rule
- [ ] [ ] the by-rule grant says in its answer that the path is a test this item adds and nobody else holds
- [ ] [ ] a requested path that exists on the trunk is not granted by rule
- [ ] [ ] a requested path another live item writes is not granted by rule
- [ ] [ ] a requested path outside the test globs is not granted by rule
- [ ] [ ] a requested path a high-risk glob covers is routed to the operator rather than granted
- [ ] [ ] a path held by an unfinished item the card waits on is held, exactly as the report's request is held today
- [ ] [ ] a path another building or review item writes is granted and serialised, exactly as today
- [ ] [ ] a granted path is added to the card's footprint through the record's own writer
- [ ] [ ] the widening leaves one history line naming the paths and the finding that asked for them
- [ ] [ ] a finding held as a writes request is not briefed on the tick it is requested
- [ ] [ ] a finding held as a writes request charges no round
- [ ] [ ] a finding whose request was granted is briefed once on the next round, against the wider footprint
- [ ] [ ] a finding whose request was routed to the operator is carried in the stuck reason and never briefed again
- [ ] [ ] the same finding is never briefed twice as a finding and once as a request
- [ ] [ ] with the writes resolver off, a finding outside the footprint behaves exactly as it does on the trunk today
- [ ] [ ] the rule reaches no disk and no network, and returns the same answer for the same facts
