## Acceptance
- [ ] [ ] the card path of an id resolves to the json file when one is there
- [ ] [ ] the card path of an id resolves to the markdown file when no json file is there
- [ ] [ ] loading a card returns the flat field map every existing reader indexes
- [ ] [ ] loading a card returns a body rendered as markdown, so a reader that only displays it is unchanged
- [ ] [ ] the canonical text of a card is stable, so writing an unchanged card changes no byte
- [ ] [ ] the canonical text orders keys as the schema declares them
- [ ] [ ] the canonical text ends with exactly one newline
- [ ] [ ] loading the canonical text of a card gives back the same field map
- [ ] [ ] the typed and machine halves come from the schema owner annotation
- [ ] [ ] a key the schema marks machine is in the machine half on every card that carries it
- [ ] [ ] the same key is never typed on one card and machine on another
- [ ] [ ] the split keeps the signature and return shape the old splitter had
- [ ] [ ] the reference fields of a card are read from the schema annotation, not from a list in code
- [ ] [ ] the view of a card renders the description, the acceptance list, the gate block and the history
- [ ] [ ] the view of a card renders the derived children and backlinks sections
- [ ] [ ] the view of a card carries no machine field the schema does not declare
- [ ] [ ] rendering a view twice gives the same bytes
- [ ] [ ] the record scan reads a json card and skips the markdown view beside it
- [ ] [ ] the record scan reads a markdown card that has no json file beside it
- [ ] [ ] the record scan counts a card exactly once when both files are present
