## Description

## Acceptance
- [ ] Two eligible overlapping Bugs put a line `- [ ] B-0034 deliver B-0034+B-0035 —` under `## Deliveries proposed` in the day groom file, with the glob count and the token estimate in its why.
- [ ] With no eligible items the `## Deliveries proposed` section renders `(none)`.
- [ ] A `yes` on the line writes `delivers: [B-0034, B-0035]` on the lead, `delivered_by: B-0034` on the member, and one History line on each card.
- [ ] A second `groom --apply` for the same date leaves both card files byte-identical to after the first run.
- [ ] A member that moved since the proposal skips the whole line with `groom: deliver B-0034+B-0035 skipped — B-0035 is Active` and writes nothing on either card.
- [ ] A `no` declines it: neither card carries `delivers:`, both carry `reshape_declined: [deliver B-0034+B-0035]`, and the next day file has no line for them.
