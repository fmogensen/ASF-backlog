## Acceptance
- [ ] `classify` returns `small` for three literal paths, `medium` for ten and `large` for sixteen, with the boundaries at exactly 3 → small / 4 → medium and exactly 15 → medium / 16 → large — proven by tests/test_size.py
- [ ] A footprint carrying a wildcard entry among two literals is `large`, and `why` names that entry as a glob rather than a file count — proven by tests/test_size.py
- [ ] A footprint entry naming another repository (`record:features/**`) is `large`, and so is an empty footprint, each with its blocker as the `why` — proven by tests/test_size.py
- [ ] An entry matching `never_small_globs` floors a three-file footprint to `medium` with that entry named in `why`, and never lowers a sixteen-file footprint below `large` — proven by tests/test_size.py
- [ ] `kind_of` returns `docs` for an all-documents footprint and `code` for nine documents plus one module, for a footprint no glob matches, and for an empty footprint — proven by tests/test_size.py
- [ ] A fifteen-document footprint is `small` under `small_max_files_by_kind` while fifteen modules at the same count are `medium` — proven by tests/test_size.py
- [ ] `CLASSES` holds exactly (small, medium, large) and `KINDS` exactly (docs, test, config, copy, code) — the names the rest of the repository switches on — proven by tests/test_size.py
