## Description

## Acceptance
- [ ] the predicate returns the labels launchd does not hold, in the order it was given them
- [ ] a label with a pause record is never returned, however unloaded launchd says it is
- [ ] an empty list of labels returns empty and makes no call to launchctl
- [ ] a whole-product install reads back every label it rendered, the undeclared queue and wave clocks included
- [ ] an install given one clock reads back that clock alone
- [ ] a label the install retired is not read back, because the product file no longer declares it
- [ ] the operator line names every label that did not load, once each, with the install command and the doctor command in it
- [ ] a whole-product install, an install that retires a job, one that spares another product's job, a one-clock install and the adoption of an installed-but-undeclared job all still exit zero
- [ ] an install refused for a reason other than a clock, with no launchctl call made, still exits two
- [ ] the installer's step 8 reads a loaded clock, a retried clock, a clock still missing after the retry, an install failure and the no-scheduler case exactly as it does today — proven by tests/test_install.py
