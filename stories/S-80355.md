## Description

## Acceptance
- [ ] one act pass over a mapped kill writes a claim keyed by oom, the box, the kill's time and the pid, carrying kind oom, state oom and the run, before any gh call is made
- [ ] that claim is on disk when the pass returns
- [ ] the run reading completed with conclusion failure on the next pass calls run rerun 77 -R o/r --failed exactly once
- [ ] that re-run moves the claim's state to rerun and stamps rerun_at
- [ ] that re-run is claimed in ci-cancels.json for run 77 with cause infra and by oom-watch, carrying the box, the runner, the task and the kill's time as extras
- [ ] the next three passes over the same journal lines call no further run rerun, which is the same-kill guard
- [ ] a run the stall half already cancelled and re-ran is not re-run again by a kill mapped to that same run, with the stall claim written first
- [ ] that same-run guard holds in the other order too, with the kill claimed first and the stall cancel second
- [ ] a run ci-cancels.json already claims as infra, which is the P7 collision, is not re-run: the claim is written oom-answered naming infra, no run rerun is called, and one line says so
- [ ] a ci-cancels.json claim whose cause is outside HONOURED does not stand the kill down
- [ ] the already-answered guard is applied again in _advance after the wait, so a claim answered while the run was still running becomes oom-answered and is never re-run
- [ ] a run reading completed with conclusion success becomes oom-survived, calls no run rerun, and prints one line saying the run survived the kill
- [ ] a run still in_progress GIVE_UP_S after the kill becomes gave-up, and no run rerun is ever called for it
- [ ] a refused run rerun leaves the claim rerun-failed and is not retried on the next pass under the landed prune
- [ ] report mode prints every kill naming mode report, writes no claim and makes no gh call
- [ ] a kill only reported in report mode is still answered by the next act pass while it is inside the window
- [ ] --apply off writes no claim and makes no gh call whatever the mode file says
- [ ] the operator script's claims.json touched 42 seconds ago forces report for the OOM half too: one report only line naming the operator watchdog, no claim and no gh call
- [ ] a kill mapped to a slot whose repo is not this product's claims nothing and calls nothing
- [ ] a kill mapped to a slot carrying no run id claims nothing and calls nothing
- [ ] a silent idle job past its max is still cancelled, still claimed stall, and its run still re-run once when it completes and not again — proven by tests/test_ci_stall.py
- [ ] report mode and --apply off still cancel nothing in the stall half — proven by tests/test_ci_stall.py
- [ ] ci-cancels.json still reads one cause per run, newest line winning, with stall and infra both intact — proven by tests/test_ci_cancels.py
