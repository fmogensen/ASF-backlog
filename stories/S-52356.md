## Description

## Acceptance
- [ ] `caches.summary_counts` reads either the `execution.{attempted,cached}` shape or the `tasks[].cache` shape from one run summary, and returns None for neither.
- [ ] `caches.hit_rate` sums the newest `summary_max` run summaries under the worktrees' `summary_glob` that fall inside `summary_window_h`, and counts a file it cannot read as unreadable rather than guessing its rate.
- [ ] A summary older than the window is not counted, and a window with no summary inside it reads as no rate at all, not a zero-run rate.
- [ ] The rate appears in the pass's own line, in the `asf status` Caches row and in the doctor's detail — the status cell and the pass's line always agree.
- [ ] No run summaries in the window is said plainly ('no run summaries') and is never treated as a fault.
- [ ] The rate is written into no metric stream — it is read fresh off the worktrees' own summaries each time, never accumulated into a committed record.
