## Acceptance
- [ ] pause.held(product) is None when no state/<product>/paused-launches.json exists
- [ ] pause.pause(name, reason, by, now=...) writes the record, and a following pause.held returns exactly that reason, that author and that at timestamp
- [ ] a truncated, non-JSON or non-dict paused-launches.json makes pause.held return None rather than raise — a pause nobody can read never stops the floor
- [ ] pause.resume(name) removes the record, and resuming a product that is not paused is rc 0 with a line, not an error
- [ ] pause.text(record) and pause.hold_reason(record) each name the reason, the author and the date
- [ ] asf pause with no --reason returns rc 2 and prints the line naming --reason "<why>"
- [ ] asf pause --reason "<why>" writes the record and prints the three lines, each naming which of the two pauses it is; asf resume then leaves no record file
