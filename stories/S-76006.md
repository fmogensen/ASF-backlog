## Acceptance
- [ ] a run cancelled in act, then a pass in report with the run completed, re-runs the failed jobs once and leaves the claim in state rerun — the frozen owed re-run of P7, gone
- [ ] a pass in report mode counts the stall and cancels nothing, and a pass with --apply off cancels nothing either, so report still withholds every new cancel — proven by tests/test_ci_stall.py
- [ ] a cancel-failed claim is cancelled again on the next pass, and on success becomes cancelled with a stall row in ci-cancels.json carrying by stall-watch
- [ ] a cancel-failed claim refused RERUN_TRIES times stops being retried, keeps its state, and carries tries equal to RERUN_TRIES and a given_up_at stamp
- [ ] a rerun-failed claim is re-run again under that same bound, and once it succeeds the claim is rerun and no later pass calls run rerun on it again
- [ ] a gave-up claim is never cancelled again and never re-run
- [ ] a run with the same stall still present is cancelled exactly once across repeated act passes — proven by tests/test_ci_stall.py
- [ ] a cancelled run's failed jobs are re-run exactly once when it completes, and a later act pass re-runs nothing — proven by tests/test_ci_stall.py
- [ ] the run is cancelled exactly once whatever the mode and whatever the claim's state, the bad states this Story adds included
- [ ] the prune drops a claim in state rerun at twice REFRESH_S and holds a cancel-failed, rerun-failed or gave-up claim until BAD_KEEP_S
- [ ] ci_queue.claim_cancel writes exactly one stall cause for a cancelled run — proven by tests/test_ci_cancels.py
- [ ] every other landed case of tests.test_ci_stall is green unchanged — proven by tests/test_ci_stall.py
