## Acceptance
- [ ] `lifecycle.ended_prs(state_dir)` on an hour-old `cache-prs.json` whose only row is `#1046` OPEN is `{}` — the incident's own before-picture
- [ ] `lifecycle.ended_prs(state_dir, landed={1046: <sha>})` is `{1046: {'state': 'MERGED', 'head': <the cached row's headRefOid>}}`, and `lifecycle.pr_ended({'pr': 1046, 'head': …}, that map)` is `'MERGED'`
- [ ] `landed` naming a number no cached row holds at all still ends that PR, and a cached CLOSED row whose number `landed` names reads `MERGED` — the trunk's entry is written last and wins
- [ ] `lifecycle.ended_prs(state_dir, landed=())` is today's answer unchanged — cached MERGED and CLOSED rows still end, and an absent or unreadable cache is still `{}` — proven by tests/test_merge_mode.py
- [ ] `lifecycle.occupancy(path, ended=lifecycle.ended_prs(d, landed={1046: <sha>}), alive=lambda _p: False)` over a ledger whose lane record for `T-0485` is in flight on `#1046` puts `T-0485` in neither `busy` nor `waiting_landing`, sets `landed['T-0485']` to the lane record's sha and `landed_on['T-0485']` to its branch
- [ ] The same `occupancy` call with `landed={}` still holds `T-0485` in `busy` or `waiting_landing` — the hole this card was filed for, pinned
- [ ] `step_wave.trunk_landed(product)` reads `{1046: <sha>}` off a product whose trunk clone carries the queue's commit, and is `{}` both for a product with no `repo_dir` and when `trunk_watch.first_parent` returns None
- [ ] `step_wave.occupancy(product)` passes what `trunk_landed` read through to `lifecycle.ended_prs` as its `landed` argument, reading the trunk with one `git log` and no `gh` call
- [ ] `step_wave.TRUNK_LANDED_DAYS` is the window `trunk_landed` hands `trunk_watch.first_parent`, and a landing older than that window is not in the map
