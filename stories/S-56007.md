## Acceptance
- [ ] The tick summary prints a `WORK since <ts>` block above `IN FLIGHT`, naming the same `since` the `DONE` block names
- [ ] The block's first line is `bugs      +n filed, n fixed`: a Bug at `New` whose `stage_since` is inside the window is filed, a Bug in `DONE_STATES` whose `stage_since` is inside it is fixed, and neither counts a Bug dated before the window nor one that is no longer `New`
- [ ] The block's second line is `features  n landed (<id>), n started`: a Feature at a landed stage inside the window is landed with the newest named, and distinct Features with a ledger run launched inside the window are started — a second run on a Feature already counted does not count it twice
- [ ] Both counts' window is half-open, `since` exclusive and `now` inclusive, asserted at both edges
- [ ] A tick in which nothing moved still prints the block, as `bugs      +0 filed, 0 fixed` and `features  0 landed, 0 started`
- [ ] A first tick on this clock — no stamp, the 24h fallback window — is marked on the `WORK since` block as it is on `DONE`
