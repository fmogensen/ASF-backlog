## Description

## Acceptance
- [ ] `Context.counts` no longer exists, and `Context.events` is the only tally
- [ ] `ctx.tick_counts()` returns the five keys `launches, merges, stalls, refusals, relaunches`, each the count of `COUNTED[name]` among `ctx.events`
- [ ] `tick_line` takes its five counters from `ctx.tick_counts()`
- [ ] `tick_line`'s `refused_files` is derived from the `refusal` events' `fields.path` instead of the literal `{}`
- [ ] for a tick run through the real emitters into a tmpdir record, `ticks[T][name] == len([e for e in events if e['tick'] == T and e['kind'] == COUNTED[name]])` holds for all five counters and every tick of the day
- [ ] that equality needs no window, no regex and no substring match anywhere between the two streams
- [ ] `summary.digest` and `watch.digest_lines` read the same five keys and are unchanged in shape
- [ ] an event raised outside a tick carries `tick: null`, is counted by no tick line, and still renders
