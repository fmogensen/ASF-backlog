## Acceptance
- [ ] [ ] a red check on an open pull request whose every failing id is the spell's is not the pull request's own
- [ ] [ ] such a check charges no fix round and the item's round count is not written
- [ ] [ ] such a check never archives the branch or closes the pull request
- [ ] [ ] such a check leaves one note naming the check, the first red commit and the Bug
- [ ] [ ] a red check naming an id the spell does not hold is still the pull request's, and its finding names only those ids
- [ ] [ ] a red check whose failing ids could not be read is still judged as it is today
- [ ] [ ] the predicate keys on failing test ids and never on the check name
- [ ] [ ] an item already at its round cap is not archived while the only red on it is the spell's
- [ ] [ ] the predicate is read before the on-the-pull-request file comparison
- [ ] [ ] a quarantined flake is still judged by its own path, unchanged
