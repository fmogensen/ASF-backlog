## Acceptance
- [ ] [ ] a job transcript older than the keep window whose run the registry has ended is reapable
- [ ] [ ] a job transcript inside the keep window is not reapable, however its run ended
- [ ] [ ] a job transcript of a session the registry holds without an end is not reapable, however old it is
- [ ] [ ] the keep window is the longest window any reader of a job transcript reads over
- [ ] [ ] a reap without the fix flag removes nothing and names what it would have removed
- [ ] [ ] a reap with the fix flag removes exactly what it named
- [ ] [ ] a reap prints one line naming the count and the bytes, never one line per file
- [ ] [ ] a reap that removed nothing prints nothing
- [ ] [ ] a reap whose directory cannot be read prints that it skipped and raises nothing
- [ ] [ ] a reap never touches a clock transcript, a rotated generation, or any file outside the jobs directory
- [ ] [ ] a reap never touches another product's job transcripts
- [ ] [ ] the health step calls the reap, after the branch sweep
- [ ] [ ] a reap that raises leaves the health step's own result unchanged and the tick running
- [ ] [ ] a scorecard denial row for a job whose transcript was reaped counts zero and does not fail
