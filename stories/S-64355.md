## Acceptance
- [ ] A push to a branch outside `ASF_PUSH_ALLOW` still exits non-zero and still prints `pushes only to factory branches` with the branch named — proven by tests/test_session_push_guard.py
- [ ] That same refused push appends exactly one `push-allow` line to `ASF_REFUSAL_LOG`
- [ ] A product's own `pre-push` hook exiting non-zero appends exactly one `hook refused` line carrying the hook's own output, and that output still reaches stderr
- [ ] An `asf trunk-check --pre-push` refusal appends exactly one `hook refused` line the same way
- [ ] A heartbeat push of `refs/asf/hb/<job>` appends nothing to the ledger
- [ ] A product test fixture's push to a scratch repository appends nothing to the ledger
- [ ] With `ASF_REFUSAL_LOG` unset, and with it pointing at an unwritable path, the hook's exit status is unchanged
- [ ] Whatever a hook printed, the ledger stays one JSON object per line: a backslash and a quote are escaped and control characters are stripped
- [ ] `refusals.env_for(product, job)` is merged into `job.env` at `spawn`, beside `pushlog.env_for`'s `ASF_PUSH_LOG`
- [ ] `refusals.clear(product, job)` runs at `spawn` and at a heartbeat continuation, beside `pushlog.clear`
