## Acceptance
- [ ] [ ] asf archive with no flags writes nothing and says so on its last line
- [ ] [ ] the dry run prints the retention it read, where it read it from, and the floor it was checked against
- [ ] [ ] the dry run prints how many cards and notes would move and how many cards would stay
- [ ] [ ] each card that would move is printed with its path and why it is eligible, naming its closing state and date and its age in days
- [ ] [ ] each card held back is printed with its path and every reference that holds it, naming the holding card, the field and the holder's own state
- [ ] [ ] a parent held back by a child says it is held by its child
- [ ] [ ] the dry run prints the working set's size after the pass as a count and as a share of the cards today
- [ ] [ ] asf archive --why names, for one card, either that it would move and why, or every reference that holds it
- [ ] [ ] asf archive --why on an already archived card says where it is and when it was archived
- [ ] [ ] asf archive --audit prints every reference from a working-set card onto an id the working set does not hold and exits non-zero when there is one
- [ ] [ ] asf archive --audit on a record with no such reference prints nothing and exits zero
