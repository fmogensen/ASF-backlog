## Description

## Acceptance
- [ ] a published channel head resolves to the version tag whose peel line names its commit, and to that commit
- [ ] resolve asks git ls-remote once, with the heads pattern and the tags pattern, in that order, and nothing else
- [ ] an unpublished channel resolves to no tag and no commit, and the listing exits 0 rather than erroring
- [ ] a channel head at a commit no version tag names resolves to that commit with no tag, never to a tag of another commit
- [ ] a tag object sha is never returned for an annotated tag: the peel line is what a tag is read from
- [ ] a stray tag that is not v major minor patch is ignored, as the three existing readers of the newest tag already ignore it
- [ ] two version tags on one commit resolve to the higher one, by the integer tuple of their digits and never lexically
- [ ] a listing that could not be read at all resolves to no tag and no commit, never to a guess
