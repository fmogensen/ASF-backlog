## Description

## Acceptance
- [ ] `chores.record` over a `PostToolUse` `Bash` payload with `ASF_JOB` unset appends exactly one JSON line to `<ASF_HOME>/chores/<today>.jsonl`, carrying `ts`, `cmd`, `cwd`, `product` and `redacted: false`
- [ ] `cmd` is `tool_input.command` whitespace-collapsed and truncated to 400 characters
- [ ] `product` is the product whose `repo_dir` or `backlog_dir` contains `cwd`, and `null` when none does
- [ ] With `ASF_JOB` set, nothing is appended
- [ ] A non-`Bash` tool, a command whose first token is `asf`, and a command matching `chores.ignore` each append nothing
- [ ] A command `redact.scan_text` matches is written as its first token with `redacted: true`, and the matched value is in no byte of the ledger
- [ ] An unwritable ledger directory still returns 0, and the recorder never blocks the call
