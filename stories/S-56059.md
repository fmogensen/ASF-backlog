## Acceptance
- [ ] `owner` is a settable field on a rule card; `load_rules` defaults it to `factory` and reads an unrecognised value as `factory` rather than silencing the rule
- [ ] a violation of an `owner: operator` card carries `"owner": "operator"` in `asf rules check --json`, its printed line is prefixed `NEEDS OPERATOR: `, and the `== RULES` summary counts it as `1 operator`
- [ ] `cmd_file_bugs` over a record whose only violation is operator-owned writes no `bugs/B-*.md` and prints `file-bugs: 0 filed, 0 bumped, 0 unchanged`
- [ ] that run prints exactly one line beginning `NEEDS OPERATOR: R-` and ending in the renew command, and a second run the same UTC day prints none, the day being keyed in `rule-check-failures.json`
- [ ] a run in which the rule is clean drops the key, so the next violation raises the line again
