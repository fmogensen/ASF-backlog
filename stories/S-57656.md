## Description

## Acceptance
- [ ] `log.emit(root, product, kind, key, …)` validates through `metrics.validate('events', …, product=product)`, appends through `metrics.append_event`, and returns the stored event
- [ ] `emit` puts every unrecognised keyword under `fields` and never at the top level
- [ ] a `SchemaError` inside `emit` is printed and swallowed — the step that raised the event still returns normally and raises nothing
- [ ] `Context.event(kind, **fields)` calls `emit` with the tick's product, its record root and its `HHMM` as `tick`, and appends the stored event to `ctx.events`
- [ ] `ingest.write_on_prod_event` calls `emit` with `kind='feature-on-prod'` and `key=<the item id>`, and its hand-rolled dedupe loop is gone
- [ ] a second `write_on_prod_event` for the same item on the same day adds no second line, and the written line's keys are sorted — proven by tests/test_ingest.py
- [ ] an unparseable line already in the day file is skipped, not raised on — proven by tests/test_ingest.py
- [ ] no module under `asf/` other than `asf/metrics/log.py` opens a `metrics/events/*.jsonl` file for writing
