## Acceptance
- [ ] [ ] asf/flow.py exists and imports nothing outside the standard library, asf.views.index_reader and asf.feeder.rows
- [ ] [ ] WORK_TYPES is exactly epic, feature, task and bug, the types the feeder ever opens a row for
- [ ] [ ] CLASSES is exactly done, parked, row, session, subtree and SINK, in that classification order
- [ ] [ ] PARKED has one entry per declared park reason, each carrying the fact that decides it and what ends the park
- [ ] [ ] conserved returns a class from CLASSES and a detail string for every item of an index, never None and never a class outside the tuple
- [ ] [ ] the first class that holds wins, asserted by an item that satisfies two of them at once
- [ ] [ ] done comes before parked and parked before row, so a removed card is counted parked rather than conserved by a row it should not have
- [ ] [ ] an item whose state is Resolved or Closed reads done, and so does an item whose type is not one of WORK_TYPES
- [ ] [ ] row comes before subtree, so an item that has a row of its own has that row named in its detail
- [ ] [ ] a SINK detail names the step the item sits at, as its type, its state and its stage
- [ ] [ ] conserved is pure: called twice on the same input it returns the same answer, and it mutates neither the item nor the item map
