## Acceptance
- [ ] lifecycle.later_operator_ruling(path, item, at) returns the pending operator ruling on the item written at or after 'at', and None when there is none
- [ ] later_operator_ruling ignores a correction that does not carry operator_ruling
- [ ] later_operator_ruling ignores a correction on a run a branch park or a job park holds
- [ ] later_operator_ruling ignores a correction a session run already answered
- [ ] lifecycle.overruling(path, item, head) still answers the adjudicate job with no operator ruling pending — P6's before-picture, unchanged
- [ ] overruling answers None when a pending operator ruling is written at or after the ruling run's 'started'

- [ ] lane.branch_facts sets neither f['overruled'] nor f['ruled'] while an operator ruling is pending, so a CHANGES review never reaches GATE
