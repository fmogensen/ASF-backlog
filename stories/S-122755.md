## Acceptance
- [ ] a required check completed cancelled reads as pending, not red and not green
- [ ] a required check still queued reads as pending
- [ ] a required check still in progress reads as pending
- [ ] a required check the rollup never reported reads as pending
- [ ] a cancelled required check beside a failed one reads as red, so a cancel never hides a verdict
- [ ] a cancelled required check beside a green one reads as pending, so a cancel is never a green
- [ ] a commit whose every required run was cancelled is never a revert and never a Bug
- [ ] a trunk whose newest commit was cancelled over a green commit plans nothing against that green
- [ ] cancelled commits above a red commit leave the red's candidate set exactly the commits from the red back to the last green
- [ ] a cancelled run on a commit is never counted as a red check of that commit
- [ ] a cancelled required check is never rerun by the main safety net
