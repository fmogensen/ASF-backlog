## Acceptance
- [ ] A product with no `debug_toggles` block gets one green `debug toggles` row naming the default globs, the marker count and the waiver
- [ ] A product that narrowed `paths` or extended `markers` gets a green row naming its own globs and its own marker count
- [ ] A product that declared the block with `paths: []` gets a red row naming `conventions.debug_toggles` and saying no branch is checked for a switched-off test, breakpoint or debug flag
- [ ] A marker that does not compile adds one red row naming that pattern, beside the row above
- [ ] The row is labelled `debug toggles`, is not required, and is printed by `asf doctor` — `findings` lands with its reader, so no row ships that nothing prints
- [ ] Every doctor row that exists today keeps its state and its order, `savings` still following `capacity`, with the new row appended beside `customer content` — proven by tests/test_doctor.py
