## Description

## Acceptance
- [ ] `refusals.path(product, job)` answers `<state>/<product>/gates/<job>.refusals`, and a `job` of `../x` cannot leave the `gates` directory
- [ ] `refusals.env_for(product, job)` answers `{'ASF_REFUSAL_LOG': refusals.path(product, job)}` and creates the directory it names
- [ ] `refusals.clear(product, job)` removes the ledger file, and does not raise when there is no file to remove
- [ ] `refusals.ledger(product, job)` answers every `Refusal` the file holds oldest first, drops a line it cannot parse and keeps the rest, and answers `[]` when there is no file
- [ ] `refusals.from_record(run)` turns `run['publish_refused']` into a `Refusal` and a `run['correction']` whose `kind` is in `CORRECTION_KINDS` into a `Refusal`, and ignores a `review` or an `unpushed` correction
- [ ] `refusals.recognise(text)` answers the LAST refusal in a blob of output, and files the push-allow line, a `REF GUARD` line, a `commits do not name` line and a redaction finding each under its own kind
- [ ] `refusals.recognise` files a `REF GUARD` line that also says `push` as `refguard`, not as `pre-push`: the wide `pre-push` pattern is tried last
- [ ] `refusals.last` answers the newest `Refusal` by `at`, sorts a `Refusal` with no `at` oldest, and reads its `text` argument only when the ledger and the record both answered nothing
- [ ] `refusals.clause(None)` is `''`, and a clause is cut to `CLAUSE_MAX = 200` characters and to the refusal's first line
- [ ] `NAMING is lifecycle.NAMING` and `PRE_PUSH is lifecycle.HOOK_REFUSED`: every kind in `KINDS` is the constant that already owns its string, so a rename there follows here
- [ ] `asf/workers/refusals.py` imports none of `cloud`, `health` or `harvest`, so each of them may import it
