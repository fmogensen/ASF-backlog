## Acceptance
- [ ] [ ] a Task that has been parked longer than the minimum age is a candidate
- [ ] [ ] a Bug that has been parked longer than the minimum age is a candidate
- [ ] [ ] a New Task older than the minimum age is a candidate
- [ ] [ ] every New candidate comes before every parked one, whatever their ages
- [ ] [ ] within a class the candidates are ordered oldest first, ties by id
- [ ] [ ] a card younger than the minimum age is never a candidate
- [ ] [ ] a card exactly at the minimum age is not a candidate and one a day older is
- [ ] [ ] a card with no readable created date is never a candidate
- [ ] [ ] a tick whose time is unreadable has no candidates at all
- [ ] [ ] a Story, a Feature and an Epic are never candidates whatever their age
- [ ] [ ] a Ready, Building, Review, Landing, Done or Stuck card is never a candidate
- [ ] [ ] a retired card is never a candidate, since the record reads it as Done
- [ ] [ ] a card a live session of any kind holds is never a candidate
- [ ] [ ] a card already carrying a sweep verdict is never a candidate again
- [ ] [ ] a card whose sweep budget is spent is no longer a candidate
- [ ] [ ] a card the Definition of Ready holds with fills left is not a candidate
- [ ] [ ] a card the Definition of Ready holds whose fills are spent is a candidate
- [ ] [ ] a card still waiting on its intake decision is not a candidate
- [ ] [ ] a card whose age the kernel can read but whose card is in LIMBO is not a candidate
