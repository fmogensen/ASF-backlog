## Acceptance
- [ ] With the ledger and the record both empty, a run log tail holding `asf: push refused — an ASF session pushes only to factory branches, not: main` yields a `push-allow` refusal in the dead reason
- [ ] `actions.Gh.log_tail(run_id)` calls `gh run view <run_id> --log-failed`
- [ ] `actions.Gh.log_tail` falls back to `gh run view <run_id> --log` when the run has no failed step
- [ ] `actions.Gh.log_tail` answers `''` on a rate limit and on a failed call, and never raises, so the dead reason is left bare
- [ ] `actions.Gh.log_tail` answers at most `LOG_TAIL_MAX = 64 * 1024` characters, the tail of the log
- [ ] A fake `Gh` counting calls sees exactly one log read for a dead run
- [ ] That fake sees no log read for a working run and none for a finished one
- [ ] That fake sees no log read when the ledger or the record already answered with a refusal
- [ ] The `claude-remote` leg reads the tail through `remote.run_log_summary(run, s, client)` with no new call shape
- [ ] `cloud._run_log_tail` never raises: no log is no refusal, and the run is still classified dead
