## Acceptance
- [ ] one required check pending whose run concluded failure with that job still queued makes one run rerun, prints the infra red (phantom) line, leaves the branch WAITING_CI, and prints no checks pending wait line claiming nothing was wrong
- [ ] the same pending head on the next pass inside PHANTOM_PROBE_S does not re-read the run, making no actions/runs call and no second run rerun
- [ ] the same pending head past PHANTOM_PROBE_S re-reads the run and the answer is held, never a second re-run
- [ ] a required check pending whose run is itself still queued, nothing concluded, makes no run rerun and prints the ordinary checks pending wait line unchanged
- [ ] the missing branch with every present check green, one required check with no check at all, and the run behind the present checks concluded failure makes one run rerun and prints the phantom line
- [ ] that missing-branch read happens before stalled is consulted and before the landing_checks_missing clock can gate locally, so neither a heavy kick nor a local gate is reached on a phantom
- [ ] the missing branch with no infra red leaves the landing_checks_missing wait clock running exactly as today, naming the missing check and its minutes while it waits — proven by tests/test_harvest.py
- [ ] the missing branch with no infra red still falls back to the local gate once that clock runs out — proven by tests/test_harvest.py
- [ ] a skipped required check with no infra red still never merges and still never becomes a local gate once the clock runs out — proven by tests/test_lane.py
- [ ] the pending probe reads only the runs behind the checks the gate is waiting on, so a run behind a green check is never read
- [ ] the gate's pending and missing calls pass state_dir and are throttled, while the red branch's call passes none and is read on every pass
