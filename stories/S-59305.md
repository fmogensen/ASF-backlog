## Acceptance
- [ ] `asf reservations --heads` exits 0 and prints one tab-separated ref and pull-request-number line per open ref, the trunk first: `main` with `-`, then `worker/T-0100` with `844`, and the branch of a MERGED pull request absent
- [ ] A branch pushed to origin with no pull request at all is in the list, with `-` in the second column — the pre-push case, where a list of open pull requests alone would be empty and would find nothing
- [ ] A branch whose pull request was closed without merging is still in the list, carrying that closed pull request's number
- [ ] An `asf reserve` claim ref under `refs/heads/reservations/<sequence>/<number>` is never printed, because `branch_kind` is `None` for it and `open_refs` has already dropped it
- [ ] `asf reservations` writes nothing in any mode: the state directory's listing is unchanged after a run, no `reservations.json` appears and no ref is created
