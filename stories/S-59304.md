## Acceptance

- [ ] `booked` at `HEAD` returns the numbers a branch's own commits add while that branch is on no remote at all, which is every branch at the pre-push moment
- [ ] With a `reservations.json` on disk naming a stale holding, the verdict `--check` prints is the one the live refs give and not the one that file names
