## Description

## Acceptance
- [ ] [ ] a card whose state is Resolved or Closed, or that is retired, is a candidate and no other card is
- [ ] [ ] a candidate whose closing date is fewer than the retention's days before today does not move
- [ ] [ ] the closing date is read from stage_since, else updated, else the newest date in the card's History, else the card's last touch in git
- [ ] [ ] the git fallback reads every card's last touch in one pass, not one pass per card
- [ ] [ ] a card a live card references does not move, whichever of the schema's ten reference fields names it
- [ ] [ ] a card a parked card references does not move
- [ ] [ ] a card another closed card that is not itself moving references does not move
- [ ] [ ] a card named only by a satisfied entry of a card that stays does not move
- [ ] [ ] a card named only in another card's prose still moves
- [ ] [ ] a parent whose children all move moves with them in the same pass
- [ ] [ ] a parent one of whose children stays does not move
- [ ] [ ] a closed card that is in_progress_by someone, or that carries an open kernel question, does not move
- [ ] [ ] the closure terminates on a record whose candidates reference each other in a cycle, and moves all of them
- [ ] [ ] the audit runs before anything is written and a non-empty audit refuses the whole pass with nothing moved
