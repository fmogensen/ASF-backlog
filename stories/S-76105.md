## Acceptance
- [ ] git's own refusal of a push that would rewrite the branch is a refusal kind of its own, recognised from the lines git prints, filed under no other kind
- [ ] a dead cloud run with no report commit whose only recorded refusal is a correction asking for a rebase has its own log read as well, because that record names what was asked for and only the log holds what stopped the run
- [ ] when the log names git's refusal, that is the refusal the dead reason carries
- [ ] when the log names none, the dead reason falls back to the recorded correction exactly as it does today
- [ ] a run whose recorded refusal is any other kind does not cost the extra log read
