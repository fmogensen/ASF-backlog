## Acceptance
- [ ] [ ] the schema file parses as JSON and declares schema 2 as a constant
- [ ] [ ] every key the record uses today is a declared property with exactly one type
- [ ] [ ] the schema is closed, so a property the schema does not name is an error
- [ ] [ ] a key the schema does not name is accepted under the extra object and nowhere else
- [ ] [ ] every keyword the schema file uses is one the validator implements
- [ ] [ ] a validator keyword list that the schema outgrows fails this test rather than passing silently
- [ ] [ ] a valid card of each of the seven types validates clean
- [ ] [ ] a card missing a required property is one error naming that property
- [ ] [ ] a card whose id does not match the id pattern is one error naming the pointer
- [ ] [ ] a card whose state is outside the state enum is one error naming the value
- [ ] [ ] a writes entry that is not a string is one error naming its index
- [ ] [ ] an acceptance entry with no text is one error naming its index
- [ ] [ ] an acceptance entry with a property the schema does not name is one error
- [ ] [ ] a gate entry that is an empty string is one error
- [ ] [ ] a risk outside the two risk words is one error
- [ ] [ ] a rank below zero is one error, and a null rank is accepted
- [ ] [ ] errors come back in document order, each with a pointer and a message
- [ ] [ ] a card with two separate faults comes back with two errors, not one
- [ ] [ ] the validator raises nothing on any input, however malformed
- [ ] [ ] the schema is readable from an installed package, not only from the checkout
