## Acceptance
- [ ] `spawn` emits one `grant` event per entry of the final `add_dirs` list, `fields.what: 'add-dir'`, keyed `<job>:<label>`
- [ ] `console_perms` emits one `grant` event per rule added to or removed from `allow`/`deny`, `fields.what: 'deny-rule'`, keyed `<scope>:<rule>`
- [ ] `approvals` emits a `grant` event with `fields.what: 'secret'` on both the refusal and the grant of the `secrets` human-now class, keyed `<item>/<target>`
- [ ] every `grant` event carries its `item`, and its `account` as `a<n>` through `metrics.account_index`
- [ ] a grant no session made carries `account: null` and `fields.actor: 'console'`
- [ ] `label` is the granted directory relative to `ASF_HOME` (rendered `<home>/…`) or to the product repo (`<repo>/…`), else its basename — never the absolute path the session was handed
- [ ] `target` is a variable name or a command verb, never a value
- [ ] `asf redact` finds nothing in a record holding a day of `grant` events
- [ ] `cmd_console_permissions` without `--product` prints the grant line and appends nothing, saying the write was not recorded because no product was named
