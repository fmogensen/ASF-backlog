## Acceptance
- [ ] A small Task's launching PLAN → CODE row carries `train` (the open train's id) and `base` (its branch) when the lane is named in `train_lanes` and a train is open for it
- [ ] That row carries neither field when `train_lanes` is empty, when the size is `medium`, when the size key is absent entirely, or when no train is open for the lane
- [ ] The row's own branch stays the code lane's `worker/<id>` in every one of those cases
- [ ] `make_worktree` cuts a new branch from `origin/<base>` when a base is given and from `origin/<main>` when it is not
- [ ] The coder brief renders the train block with the train id, the base branch and the seat count for a train row, and renders none of it for a medium Task
- [ ] Every placeholder in the edited coder template is a key of the brief context
