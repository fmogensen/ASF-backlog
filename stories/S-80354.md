## Description

## Acceptance
- [ ] remote() is one command carrying the heartbeat loop, the marker line, a journalctl -k -n 0 readability probe, and one journalctl -k --since read of the kernel log in short-unix form capped at 40 lines by tail
- [ ] remote(window_s=60) carries 60 seconds ago as that since argument, and ci.stall_watch.oom_window_s set to 60 in the config does the same through tunable
- [ ] fetch on a payload of two heartbeat objects, the marker, journal ok and three OOM lines returns the two heartbeats, a Journal whose readable is true carrying those three lines, and no why
- [ ] fetch on a payload with no marker at all, which is a box whose agent has not been re-read yet, returns the heartbeats, a Journal whose readable is false carrying no lines, and no why, and raises nothing
- [ ] a payload whose journal section reads journal unreadable returns a Journal whose readable is false, and that pass prints one ALARM line naming the box and the kernel log being unreadable and claims nothing
- [ ] an ssh failure prints an ALARM box box-1 unreachable line naming the why — proven by tests/test_ci_stall.py
- [ ] fetch on that ssh failure returns three values, the beats and the journal both absent and the why, so every caller reads the new shape
- [ ] kills reads the cgroup line shape, the one whose task_memcg names a runner service and which carries task and pid, into a Kill carrying the kill's time, the task, the pid and the cgroup
- [ ] kills reads the global line shape, the Out of memory: Killed process line carrying the pid and the task in parentheses, into those same four fields
- [ ] kills skips a line with no readable stamp, a line stamped outside the window, and a line that matched the grep but carries neither shape
- [ ] kills returns its kills oldest first
- [ ] observe writes a slots entry keyed by the box and the runner, carrying the job, the run id, the job id, the repo, started_at, first_seen and last_seen, for every busy fresh beat of the pass
- [ ] that slots entry is updated by the next pass, survives a pass in which the slot is idle, and is dropped once its last_seen is older than SLOT_RECALL_S, which is the P3 probe inverted
- [ ] a busy slot running another repo's job is recorded in slots with that repo, so it is observed before the repo filter rather than after it
- [ ] another repo's job and a dead heartbeat are never judged, and a dead beat prints an ALARM heartbeat dead line naming the runner — proven by tests/test_ci_stall.py
- [ ] map_kill prefers the cgroup: a kill whose cgroup names r-2 maps to r-2 on box-1 with how reading cgroup, even while r-1's observed window also covers that kill
- [ ] map_kill falls back to the window: exactly one observed slot whose started_at is at or before the kill and whose last_seen plus HEARTBEAT_STALE_S is at or after it maps with how reading window
- [ ] map_kill refuses to guess when two observed slots' windows both cover the kill, returning no slot, no job and the reason 2 slots match
- [ ] map_kill returns the reason no slot observed for a kill on a box it has no observation of, and the reason before this watch saw the box for a kill older than every observation of that box
- [ ] every case of tests.test_ci_stall is green with the fetch_fn fake returning the third value
