## Description

## Acceptance
- [ ] [ ] writing a valid card through the one writer writes it
- [ ] [ ] writing an invalid card through the one writer raises, naming the path and the error
- [ ] [ ] a refused write leaves the file on disk exactly as it was, byte for byte
- [ ] [ ] a refused write leaves no temporary file beside the target
- [ ] [ ] a refused write of a card that did not exist leaves no file at all
- [ ] [ ] the error of a refused write names every fault, not only the first
- [ ] [ ] a field-level write that would make the card invalid is refused by the same gate
- [ ] [ ] a machine-block merge that would make the card invalid is refused by the same gate
- [ ] [ ] a typed-field write that would make the card invalid is refused by the same gate
- [ ] [ ] the gate can be waived only by the named argument, never by the environment
- [ ] [ ] a waived write writes the card as given, however invalid
- [ ] [ ] the lint names the two modules allowed to waive the gate
- [ ] [ ] the lint fails when a third module waives the gate
- [ ] [ ] the lint passes on the tree as this Story leaves it
- [ ] [ ] a write of something that is not a card is not validated and is not refused
- [ ] [ ] every existing writer still writes the cards it wrote before, unchanged
- [ ] [ ] a console command whose write is refused exits non-zero with the error on its error stream
- [ ] [ ] a tick whose card write is refused leaves a note and does not crash the tick
