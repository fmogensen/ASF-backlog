## Acceptance
- [ ] [ ] the kernel's session port spawns with the heartbeat on, and with it off only when kernel heartbeat enabled is false
- [ ] [ ] every kernel brief kind carries a HEARTBEAT block naming the beat ref, the interval and the notes file
- [ ] [ ] the brief's beat command names only paths inside the worktree, asserted by matching every path in the block against the worktree root
- [ ] [ ] the brief contains no heredoc, no git rev-parse git-dir and no git rev-parse git-common-dir
- [ ] [ ] the host writes the beat script into the worktree before the session starts, and the script name is one scratch PATHS already matches
- [ ] [ ] the host appends the notes file to the worktree's shared info exclude at worktree creation, through scratch exclude
- [ ] [ ] a worktree whose exclude file cannot be written still launches, with the script written and one line said about the exclude
- [ ] [ ] the beat script writes its index file inside the worktree and calls no mktemp
- [ ] [ ] git add -A in a worktree holding the script and the notes file stages neither
- [ ] [ ] the briefs module no longer rewrites or deletes the floor's heartbeat wording, and its push-rule rewrites are unchanged
- [ ] [ ] the ledger row of a kernel launch carries heartbeat_min, where it carried None before
- [ ] [ ] with kernel heartbeat enabled false, the brief carries no HEARTBEAT block and the row carries no heartbeat_min
