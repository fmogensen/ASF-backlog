## Acceptance
- [ ] `outcome_class('finished')` is `'finished'` and `outcome_class('dead pid')` is `'dead pid'` — proven by tests/test_lifecycle.py
- [ ] `lifecycle.push_gap(ev)` prefixed with `failed: ` classes to `'not pushed'`, matched by prefix so the counts the text carries never change the class — proven by tests/test_lifecycle.py
- [ ] `failed: {EMPTY_BRANCH}` classes to `'empty branch'`, matched on the part before the colon — proven by tests/test_lifecycle.py
- [ ] each CLI failure signature, and `unpushed work`, `pushed after stop`, `token cap`, `run cap` and `overloaded`, classes to its own name and never to `'other'` — proven by tests/test_lifecycle.py
- [ ] `failed: <a failure nobody named>` and a bare `failed` both class to `'other'` — proven by tests/test_lifecycle.py
- [ ] `''`, `running` and `unknown` class to `None`, and so does `stopped` — an operator ending a session is no outcome of the factory's own — proven by tests/test_lifecycle.py
- [ ] classification is case-insensitive and ignores surrounding whitespace — proven by tests/test_lifecycle.py
- [ ] every string `judge` can return classes to a member of `OUTCOME_CLASSES`, and the tuple holds its documented members in their documented order — proven by tests/test_lifecycle.py
- [ ] `FAILING_CLASSES` is `OUTCOME_CLASSES` less `finished` and `nothing to land` — proven by tests/test_lifecycle.py
