## Description

## Acceptance
- [ ] `doctor.check_caches` renders the directory's size, entry count, and what the last pass removed and when, off the state file alone.
- [ ] The row is absent before the first pass has run, and for a product that configures no cache directory.
- [ ] The row is red while a directory is still over its cap, while something could not be removed, or while a directory is refused — and names why.
- [ ] The row stays green for a configured directory that does not exist yet (absent, not a problem), and for a missing hit rate (no run summaries is not a fault).
- [ ] A later pass growing the directory does not change what the doctor already recorded — the row never re-measures and never prunes.
