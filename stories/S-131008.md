## Acceptance
- [ ] [ ] a note whose intake sessions are spent is decided by code, never left in the intake directory
- [ ] [ ] that note is minted as a Feature under the product's declared intake Epic with priority later
- [ ] [ ] the minted card carries the note's title and body, and its history line gives the spent reason
- [ ] [ ] the note file is moved to the done directory with the verdict in its header
- [ ] [ ] a product that declares no intake Epic has the spent note closed with the same reason
- [ ] [ ] a declared intake Epic that is missing from the record or done is treated as declaring none
- [ ] [ ] a card whose sessions are spent is still parked later by code, exactly as it is today
- [ ] [ ] a note with sessions left is still asked, and is not decided by code
- [ ] [ ] no inbox note ever becomes a question on an operator stuck
- [ ] [ ] an undecided note's age comes from its intake file, so the oldest undecided key is never blank
- [ ] [ ] a note whose file cannot be stat'd reads as no age and fails no gate row
- [ ] [ ] the plan reports how many keys are undecided and how old the oldest one is
- [ ] [ ] the per-tick record carries that count and that age, so a window can be read from it
- [ ] [ ] the gate fails when the oldest undecided key is older than the configured age
- [ ] [ ] the gate passes when every undecided key is younger than it, however many there are
- [ ] [ ] a saved plan written before this release has no intake key and reads as information, not a failure
- [ ] [ ] the spent decision reads nothing: the same keys, tries and config give the same verdict
