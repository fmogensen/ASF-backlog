## Acceptance
- [ ] `evidence.landed_proves(product, prs, refused=d)` puts a whole claim in the returned dict and the qualified one only in `d`, carrying `why` beside the same line/test/task/pr/sha/source keys a counted entry has
- [ ] A `Proves:` trailer refused from a trunk commit lands in the refused dict with `source == "commit"` and `pr` None, and the same claim seen from both a merged PR body and that commit appears exactly once, in the refused dict and never in both
- [ ] Both the returned dict and the refused dict sort their per-story lists by (line, task)
- [ ] `landed_proves(product, prs)` with `refused` left at its default drops the refusals and returns exactly what it returns today — proven by tests/test_evidence.py
- [ ] `discover()` publishes the refusals as `ev["proves_refused"]` beside `ev["proves"]`
- [ ] After an ingest pass whose only claim for a Story line is refused, that acceptance bullet is byte-identical `- [ ]` and `proves.proved_lines(body)` does not contain the line — no `proved line <n>` History entry is written
- [ ] The Story `## Evidence` block carries `claim refused, line <n> not proved — partial claim: "only" — <T-id>, PR #<n> (<test>)` on that pass while the Story is still Active
- [ ] `ingest.unproved_of` gives the refused line the `why` `partial claim: "only"` and the other unproved line `no proof`, and `ev_obj.unproved` names both lines
- [ ] A Story whose only claim is refused does not close, and the Feature above it does not close either
- [ ] The same pass with the marker removed from the claim ticks the line, writes the `proved line <n>` History entry, and emits no refusal evidence line
- [ ] A pass whose `ev` carries no `proves_refused` key at all ticks and reports exactly as it does today — proven by tests/test_no_test_no_done.py
