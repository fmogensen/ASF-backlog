## Acceptance
- [ ] `.asf/product.yaml` is tracked in the repository, `env.load_file` parses it, and `env.product_problems` on its text returns `([], [])` while `env.validate_product_text` returns `[]`
- [ ] its top-level keys are exactly `main` and `conventions` — no `product`, `repo_slug`, `repo_dir`, `backlog_dir` or `ci` key is present
- [ ] read as `Product(<name>, data)` the file gives `main == "main"`, `conventions.merge == "auto"`, `merge_factory_only` True, `merge_require_item_id` True and `merge_bot_paths == ["CHANGELOG.md"]`
- [ ] `Conventions` built from the committed file reports `shape_findings() == []`, so the new key is declared rather than making the file misshapen
- [ ] `all_prefixes()` from the committed file equals `all_prefixes()` of `Conventions.from_mapping({})`, so a branch kind added to `DEFAULT_BRANCH_PREFIXES` and not to the file turns the suite red instead of being refused in CI
- [ ] `bash tools/check_generic.sh` stays clean with the new file tracked: it names no product, company, person, account, host or machine path
