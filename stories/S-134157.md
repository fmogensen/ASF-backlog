## Acceptance
- [ ] [ ] the generations of a transcript are its rotated file and its live file, oldest first
- [ ] [ ] the generations of a transcript with no rotated file are just the live file
- [ ] [ ] the generations of a path with no files at all are empty, and reading them raises nothing
- [ ] [ ] reading a transcript yields the rotated file's lines before the live file's
- [ ] [ ] reading a transcript never loads a whole generation into memory at once
- [ ] [ ] a generation holding undecodable bytes is read with replacement, not skipped and not raised
- [ ] [ ] the scorecard's tick transcript reader covers the rotated generation of each transcript it reads
- [ ] [ ] the scorecard's offline count over a rotated transcript equals the count over the same text unrotated
- [ ] [ ] an offline line carried out of a rotated generation is still dated by its own stamp
- [ ] [ ] the release reader's tick transcript entries cover the rotated generation of each transcript
- [ ] [ ] the release reader parses a rotated transcript's lines before its live file's
- [ ] [ ] an upgrade chain split across a rotation reads back with every upgrade and no invented break
- [ ] [ ] an upgrade chain whose oldest links a second rotation dropped under-reports its upgrades and still invents no break
- [ ] [ ] the release reader's return shape is unchanged for a transcript that has never rotated
- [ ] [ ] the grep the troubleshooting guide opens with matches a rotated generation of a tick transcript, not only the live one
