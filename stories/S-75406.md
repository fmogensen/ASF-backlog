## Acceptance
- [ ] asf.record.undeliver exposes undeliver(canonical, member_id, why, product=None, writer='undeliver') returning (lead_id, None) or (lead_id, error), and cmd_undeliver becomes a caller of it with its signature, its refusals and its output unchanged
- [ ] asf undeliver's console behaviour is unchanged by the extraction: the lead's delivers: loses the member, the member loses delivered_by:, one History line on each card, one pushed record commit of the two cards and index.json, asf check clean, delivers: dropped whole when only the lead would be left, and a loose Task, the lead itself or an unknown id refused with nothing written -- proven by tests/test_retire.py
- [ ] step_health.run calls the new asf/tick/strike.py after file_rulings and before rejudge, wrapped like its siblings so a failure in it is one line and the sessions' health still stands
- [ ] an ended adjudicate run whose report carries 'undelivers: T-0002' drops T-0002 from the lead's delivers: and deletes T-0002's delivered_by:, writing a History line on each card with the ruling's job as the why, and asf check is clean after
- [ ] a named id that is not a card, is not open, or whose delivered_by: is not the ruled item is refused by name in one line and changes nothing, while the other ids named by the same ruling are still struck -- per id, not all-or-nothing
- [ ] the pass is once per run: the run is marked struck: <stamp> when anything was written and struck: none when the report carries no undelivers: line, and a second pass over the same run writes nothing and prints nothing
- [ ] an exception anywhere in the pass leaves no struck marker, so the next tick tries the same ruling again
- [ ] the pass re-indexes once through widen_footprint._reindex when anything was written, emits one ctx.event('undeliver', job=, item=, members=[]) line, and leaves the commit to the tick's own commit_and_push
- [ ] a pending lifecycle.INCOMPLETE correction on the lead's run whose finding named only struck members is withdrawn with pool_mod.update_session(product, job, correction=None) and one line; a correction of another kind, or one whose finding names an id that was not struck, stands untouched
- [ ] no id is minted, no Decision card is created and nothing is written to the product repo
