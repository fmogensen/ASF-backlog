## Acceptance
- [ ] [ ] the gate block registers the two lead-time keys the gate already reads, with the defaults it already uses
- [ ] [ ] the gate block gains a seats-busy minimum with a default of seventy per cent and a usable-seats minimum with a default of eight
- [ ] [ ] every one of the four is validated and a malformed value refuses the product load
- [ ] [ ] the occupancy fold reads only the tick rows whose Ready count is above zero
- [ ] [ ] seats busy is the live sessions summed over the seats summed across those rows
- [ ] [ ] usable seats is the median seat count across those rows
- [ ] [ ] the fold is bounded by the gate's own window and reads no other record
- [ ] [ ] the gate renders a usable-seats row and a seats-busy row, each with its value, its threshold and its verdict
- [ ] [ ] a window with no tick row at all reads as information rather than a failure, the way the lead rows already do
- [ ] [ ] a usable-seats figure below its minimum is a failure, because the measurement does not answer the question on a smaller pool
- [ ] [ ] the gate exits zero only when every row passes, the two new ones included
