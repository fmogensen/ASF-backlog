## Description

## Acceptance
- [ ] [ ] connectors KINDS carries identity, and its default is none
- [ ] [ ] the none identity connector returns an empty identity and an unreadable status, so one login behaves exactly as before
- [ ] [ ] the identity protocol declares at_launch and status, and status returns a pair whose first element may be None
- [ ] [ ] a launch records the identity its adapter returned on the session's ledger row, and an empty one with no adapter
- [ ] [ ] the session fact carries that identity back unchanged, and the kernel never parses it
- [ ] [ ] a configured adapter that reports a session not running is a frozen confirmation, never a stall of its own
- [ ] [ ] an adapter that cannot read a status changes no verdict
- [ ] [ ] an identity name that resolves to no implementation is an error, never a silent fall back to none
- [ ] [ ] no module under asf kernel names a runtime, a login, a credential directory or a tool, asserted by scanning those files for the connector names
- [ ] [ ] the forbidden-name check is clean with the adapter naming its tool in the connectors directory
