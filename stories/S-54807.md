## Acceptance
- [ ] `open_train(records, lane)` returns the one record for that lane whose state is `open`, and `None` when the last one is `cut`
- [ ] Two `open` records for one lane return the newest, not a second train
- [ ] `due` is False at five Tasks and one hour, True at six Tasks, True at two Tasks and two hours one second, and False for a train with no `first_commit`
- [ ] Folding an append-only registry file in which one Task's row is written twice leaves one row for that train
- [ ] `new_train(conv, lane, now)` builds its branch from the product's train prefix, carrying the lane and the stamp, with no prefix literal in the module
- [ ] A train branch on origin carrying no session record is not an eligible harvest entry
- [ ] `asf train status` exits 0 with no registry file at all, and `--json` over a two-train registry prints both under `trains`
