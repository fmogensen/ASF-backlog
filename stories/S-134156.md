## Description

## Acceptance
- [ ] [ ] a run whose transcript is over the clock cap rotates it when the run ends
- [ ] [ ] a run whose transcript is under the clock cap rotates nothing
- [ ] [ ] the rotated generation holds the whole of the run that rotated it, not a prefix of it
- [ ] [ ] the live transcript path is recreated by the next run's own writer, not by the rotation
- [ ] [ ] the rotation never truncates the live file in place and never leaves a leading run of NUL bytes
- [ ] [ ] a process with no own transcript variable set rotates nothing
- [ ] [ ] a variable naming a path that is not a regular file rotates nothing and raises nothing
- [ ] [ ] claiming the own transcript path removes the variable from the environment
- [ ] [ ] an asf child of a clock run inherits no own transcript variable and rotates nothing
- [ ] [ ] the smoke strips the own transcript variable from the environment it builds from each clock plist, so no command it runs is given one
- [ ] [ ] a command the smoke runs under a clock plist that names a transcript rotates nothing, and the transcript its parent is writing is neither renamed nor truncated
- [ ] [ ] two clocks of one product whose plists differ only in the transcript path still collapse to one smoke probe
- [ ] [ ] a run that claimed its path still rotates it after the variable is gone from the environment
- [ ] [ ] the scheduler writes the own transcript variable into a product clock's environment, naming that clock's transcript
- [ ] [ ] the scheduler writes it into the host probe clock's environment and into both kernel jobs' environments
- [ ] [ ] the variable is not in the environment a worker session is given
- [ ] [ ] a rotation carries an upgrade line, a skipped upgrade line, a rollback line, a torn tick line and an offline line into the fresh file
- [ ] [ ] a carried line is preceded in the fresh file by the newest stamp line that stood before it in the rotated one
- [ ] [ ] a line matching none of the carried kinds is not carried
- [ ] [ ] every pattern the release reader and the scorecard reader match is still matched by a carried marker
- [ ] [ ] the clock cap is larger than the asf-opened cap, and both are module constants rather than product configuration
