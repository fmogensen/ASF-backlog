## Description

## Acceptance
- [ ] One `asf tick` writes `tables/roadmap.md`, `backlog.md`, `parity.md`, `sessions.md` and `watch.md` into the record clone, and they are in that tick's single commit
- [ ] A second tick over an unchanged record rewrites none of them — `os.stat().st_mtime_ns` unchanged, `filecmp.cmp(shallow=False)` equal — and adds no diff to its commit
- [ ] `tables/status.md`, `prod.md` and `doctor.md` are absent until the probe throttle is due, and present after it
- [ ] A tick whose throttle is not due calls neither `gh` nor the quota command
- [ ] `render_tables(root, product, only=...)` renders only the named views, and `write_changed` returns only the names it actually wrote
- [ ] The throttle is one stamp file holding the last probe's ISO stamp, and a missing or unreadable stamp reads as due
