## Acceptance
- [ ] With an ended adjudicate run and no unparked stamp written since it, the derived park's row still starts with PARKED
- [ ] An unparked stamp written on that adjudicate job at or after the run's start makes the row action == LAUNCH with brief_kind == 'adjudicate'

- [ ] asf unpark <branch> naming a branch of such an item is unchanged: no stalemate release fires at branch scope
