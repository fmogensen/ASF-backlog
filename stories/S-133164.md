## Acceptance
- [ ] [ ] the package schema version is two, and the migration map has an entry for it
- [ ] [ ] the migration converts a markdown card into a json card and its view
- [ ] [ ] the migration lifts the acceptance checkbox bullets of a body into the acceptance field
- [ ] [ ] the migration lifts the test named in an acceptance line into that entry
- [ ] [ ] the migration lifts a gate fenced block of a body into the gate field
- [ ] [ ] the migration lifts the history lines of a body into the history field

- [ ] [ ] the migration drops the children and backlinks sections, because they are derived
- [ ] [ ] the migration lifts a blocked-by string into a one-element list
- [ ] [ ] the migration puts a key the schema does not name into the extra object
- [ ] [ ] the migration round-trips every card and compares it with the original
- [ ] [ ] a card that does not round-trip stops the migration, naming the card and the difference
- [ ] [ ] a stopped migration leaves every card it had not reached untouched

- [ ] [ ] the migration stamps the record and every card at the new version
- [ ] [ ] the migration runs over both the product record and the tick record clone

- [ ] [ ] the repair command converts the record resolved from the working directory and stamps nothing
