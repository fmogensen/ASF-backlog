## Acceptance
- [ ] [ ] a live session whose job log has not moved for kernel.session.quiet_max_min minutes is ended, with that reason and the owner session
- [ ] [ ] a live session past session_bound is ended whatever its beat, because nothing excludes a session from the age rule any more

- [ ] [ ] decide has no judged_by_beat, beat_stalls or beat_stall_reason symbol and Session carries no beat or beats field

- [ ] [ ] kernel.session.quiet_max_min is in the settings spec with a default of 45 and is documented in the config example
- [ ] [ ] an ended session's last snapshot still lands on its branch and its notes still reach the next brief
- [ ] [ ] the kernel's own beat, asf kernel beat and kernel-beat.json are unchanged
- [ ] [ ] the tick summary prints no beats line
