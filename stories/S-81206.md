## Acceptance
- [ ] all four rows met promotes the candidate, and the stable head moves to its commit
- [ ] any one row unmet promotes nothing, and that row evidence names what it is waiting for
- [ ] the cadence row is unmet until the configured days have passed since the last promotion, and says how many are left
- [ ] with no stable release yet the cadence row is met, and its evidence says there is none
- [ ] the dwell row takes the newest tag in the edge log that has been published for at least the configured hours
- [ ] a tag that was never published to edge is never a candidate, however old the tag itself is
- [ ] the rehearsal row is met only when the named check succeeded on the candidate commit
- [ ] a missing rehearsal check is unmet, never n a, so a renamed or deleted job cannot open the gate
- [ ] the rehearsal setting off makes the row n a and its evidence names the setting
- [ ] an S1 bug whose stage since or updated falls inside the window is unmet, and the evidence names the card
- [ ] an S1 bug raised before the window and closed before it does not block
- [ ] an open S1 of any age blocks, whatever the candidate did, and the evidence names the card
- [ ] an S2 or S3 inside the window does not block
