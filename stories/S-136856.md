## Description

## Acceptance
- [ ] [ ] a declaration file with a header, prose and two bullets parses to exactly those two milestones, in file order
- [ ] [ ] a milestone name may hold letters, digits, dots, hyphens and underscores, and must start with a letter or a digit
- [ ] [ ] an em dash, an en dash and a hyphen are all accepted as the separator of a declaration line
- [ ] [ ] a declaration whose state word is neither open nor closed is one finding at that line
- [ ] [ ] the same milestone name declared twice is one finding at the second line
- [ ] [ ] a bullet shaped like a declaration whose name is not a name is one finding at that line
- [ ] [ ] a record with no declaration file declares no milestone, and the absent file is not itself a finding
- [ ] [ ] a card naming a declared milestone is clean
- [ ] [ ] a card naming a milestone nothing declares is one finding on that card's own milestone line
- [ ] [ ] a card whose milestone is a list rather than one name is one finding
- [ ] [ ] the declaration file is read once per check, whatever the card count
- [ ] [ ] the paths the staged check lays out include the declaration file
- [ ] [ ] a commit adding a card and the declaration it names together is not refused
- [ ] [ ] a commit adding that card without the declaration is refused, naming the card and the milestone
- [ ] [ ] a commit deleting a declaration that cards still name is refused at every one of those cards
- [ ] [ ] a check restricted to one card path still reports a declaration file finding
