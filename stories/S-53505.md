## Acceptance
- [ ] A built review brief contains the asf review-checks command, the review path the brief told the reviewer to write, --card with the item id, and --kind with exactly one of spec, plan or code
- [ ] A spec/ branch renders --kind spec, a plan/ branch --kind plan, a worker/ branch --kind code, a fix/ branch --kind code, and a branch of no recognised prefix --kind code
- [ ] The pre-review command is rendered in review.md only, and in no other brief template
- [ ] The review template's final-message line names the pre-review's last line
- [ ] review.md's verdict block keys, its six check rows and its rounds rule are byte-for-byte what they were, and verdict: approved still appears in no template
- [ ] The golden review.md fixture matches the built brief and every other golden brief is unchanged — proven by tests/test_briefs.py
- [ ] Every placeholder in every template is a context key and no placeholder survives into a built brief, so --kind is never rendered empty — proven by tests/test_briefs.py
