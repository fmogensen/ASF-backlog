## Acceptance
- [ ] a fix lane branch whose card is found_in prod, carrying both a test file and a non-test change, is gated
- [ ] the same branch whose card is found_in ci is not gated, and the reason returned names found_in ci
- [ ] a branch of the code, plan, spec or direct lane is not gated whatever its card says
- [ ] a card carrying no found_in field at all is gated: an absent field is not a licence
- [ ] a fix branch whose whole diff is test files is not gated, and the reason says there is no change to be red against
- [ ] test_files picks the test paths out of a mixed diff in order and leaves a fixture data file alone
- [ ] failing_cases reads unittest FAIL and ERROR case names, and still reads the node, vitest and TAP shapes
- [ ] verdict returns proved when a case is red before and absent from the failing cases after
- [ ] verdict returns not-red when the pre-fix run exits zero and names no failing case
- [ ] verdict returns inconclusive when the pre-fix run exits non-zero and names no failing case
- [ ] verdict returns red-both when every case red before the fix is red after it as well
