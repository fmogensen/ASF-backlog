## Description

## Acceptance
- [ ] [ ] asf reopen on an archived id moves the card and its view back into its item folder before it derives anything
- [ ] [ ] a card moved back is byte for byte the card that was archived, before the reopen's own write
- [ ] [ ] the card's manifest entry is gone once it is back, and its index.json entry is there
- [ ] [ ] the card carries one History line recording that it was unarchived and why
- [ ] [ ] asf set on an archived id brings the card back and then writes the field
- [ ] [ ] asf untick on an archived Story brings it back and then clears the tick
- [ ] [ ] asf undeliver on an archived delivery member brings it back and then writes both cards
- [ ] [ ] the record's resolver brings an archived target back before it resolves an edge onto it
- [ ] [ ] an id neither the working set nor the archive holds still reports not found, unchanged
- [ ] [ ] a card brought back closes and ages again and is archived again by a later pass
- [ ] [ ] a card brought back whose shape is below the record's schema is converted as it comes back
