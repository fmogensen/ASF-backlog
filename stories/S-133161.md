## Description

## Acceptance
- [ ] [ ] the incoming edges of a card are every field on every card that names it
- [ ] [ ] the incoming edges of a card with none is an empty set
- [ ] [ ] closing a card marks every incoming edge satisfied in place
- [ ] [ ] a satisfied edge keeps the id it pointed at, for history
- [ ] [ ] a satisfied edge records which field and which id it was
- [ ] [ ] the satisfied field is a declared property of the schema, so a resolved card passes the write gate
- [ ] [ ] retiring a card marks its incoming edges satisfied and says retired in the history line
- [ ] [ ] superseding a card re-points its incoming edges at the superseding card
- [ ] [ ] superseding a card keeps the id that was re-pointed in the satisfied record
- [ ] [ ] deleting a card removes the edges onto it and leaves a history line on each dependent card
- [ ] [ ] every card the operation rewrites is written in one record commit
- [ ] [ ] the commit carries the derivation the rewrites imply
- [ ] [ ] the operation is idempotent, so running it twice rewrites nothing the second time
- [ ] [ ] an operation that cannot write one of its cards writes none of them
- [ ] [ ] a card whose incoming edge was satisfied is no longer held by that edge
- [ ] [ ] a card whose incoming edge was re-pointed is held by the superseding card instead
- [ ] [ ] the retire command, the close path and the supersession path all go through the one operation
