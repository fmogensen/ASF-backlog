## Description

## Acceptance
- [ ] a worktree holding an uncommitted work file and an untracked notes file commits the work file alone
- [ ] the notes file is still in the worktree after the commit, with its contents unchanged
- [ ] the commit subject still names the branch and the leftover-work mechanism, and is still signed off
- [ ] a worktree whose only dirty path is the notes file commits nothing and returns ok, not a refusal
- [ ] the line returned for that case says the scratch was left in the worktree and names it
- [ ] the branch head is unchanged when nothing but scratch was dirty, and no empty commit was made
- [ ] a notes file that is already tracked and modified is left unstaged, and the work file beside it is still committed
- [ ] a top-level scratch file matching the session-scratch glob is excluded, and so is one nested in a subdirectory
- [ ] a work file nested in a subdirectory is still staged, so the pathspec did not narrow the add to the root
- [ ] a staging run whose working directory is a subdirectory of the worktree still excludes a scratch file sitting at the worktree root
- [ ] a commit the repo's own hooks refuse is still returned as a refusal and still leaves the files a hold
