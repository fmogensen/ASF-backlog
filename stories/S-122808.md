## Acceptance

- [ ] [ ] a sighting inside a live entry's life never moves its expiry

- [ ] [ ] a signature whose own Bug is still open and whose cap is spent gets no second entry

- [ ] [ ] that signature's record line says the cap is spent and names the Bug it waits on

- [ ] [ ] a signature whose Bug is Done and whose sources reappear starts a fresh cycle with a fresh expiry
- [ ] [ ] a fresh cycle after a Done Bug files a new Bug, because its key carries the cycle's start

- [ ] [ ] a cap of zero quarantines nothing and files nothing
