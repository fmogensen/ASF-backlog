## Acceptance
- [ ] closing.Ev carries ref_evidence (str, default "") and ref_proven (bool, default False), and every existing Ev(...) construction in asf/ and tests/ keeps the state it decides today
- [ ] closing.state_of("story", Ev(ref_evidence="test", ref_proven=False, children=("Closed",), in_prod=True)) is Resolved / ref-untested
- [ ] the same Ev with ref_proven=True is Closed / ref-tested
- [ ] the same Ev with ref_evidence="merge" is Closed / tasks-closed — the legacy matrix_path reference keeps legacy closing
- [ ] with ref_evidence="" every pre-existing story rule decides exactly as it does today, so a product declaring no reference sees no change
- [ ] the any/reconciled rule still closes a reference Story carrying a typed landed: sha with green CI, whatever ref_proven says
- [ ] the closing totality sweep still lands a known rule and a known state for every Ev, with the two new fields added to SAMPLE as one GROUPS entry — proven by tests/test_closing.py
- [ ] ingest.derive fills ref_evidence from the reference its Story typed reference: resolves to, and leaves it "" when the card carries no reference:, when the id resolves to no declared reference, or when derive was called with product=None

- [ ] ingest still chooses no state of its own — no task_state/story_state/feature_state/bug_state/epic_state call appears in asf/record/ingest.py — proven by tests/test_ingest.py
