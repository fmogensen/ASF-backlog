## Acceptance
- [ ] every file under `asf/briefs/templates/` carries `<!-- row -->` exactly once
- [ ] `load_template` raises `BriefError` when the marker is missing, and when the stable half holds a `{placeholder}`
- [ ] `stable_text(kind)` holds no `{`, and is a pure function of the kind — the same two briefs built in either order give the same text
