## Description

## Acceptance
- [ ] a cached result younger than `probe_every` is not re-probed, while `--fresh` and a stale cache entry each probe again
- [ ] the window is recomputed from a cached expiry, so a credential ticking into its last three days reads `expiring` with no new probe
- [ ] the default output is a counts header and one row per provider sorted by name, exiting 0 when every verdict is ok or unknown, 1 when any is invalid or expiring, and 2 when any probe is broken
- [ ] `--json` carries one object per provider with `provider`, `state`, `verdict`, `expires`, `days_left`, `probed_at` and `detail`
- [ ] `--quiet` prints nothing and exits 0 on a pass, exits 1 with one line per bad provider each ending in its renew command, and exits 2 with the reason on stderr when any probe is broken
- [ ] `asf.views.header` titles the `credentials check` command as the `CREDENTIALS` table
