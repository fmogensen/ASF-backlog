## Acceptance
- [ ] [ ] the transcript census groups a clock transcript with its rotated generation as one group
- [ ] [ ] the transcript census groups one product's job transcripts as one group, and another product's separately
- [ ] [ ] a transcript group reports its file count, its bytes, its oldest and newest times, counting its rotated generation in each
- [ ] [ ] a transcript group judges over cap on its live file alone, so a group whose rotated generation is over the cap and whose live file is under it is not over cap
- [ ] [ ] a group that has no cap reports no cap and no over-cap verdict, rather than reporting zero
- [ ] [ ] the stream census has one group per directory under the record clone's metrics directory
- [ ] [ ] the stream census reports a stream that is on disk and not in the declared stream tuple
- [ ] [ ] the stream census of a record clone with no metrics directory is empty and raises nothing
- [ ] [ ] the logs doctor row is ok when nothing is over its cap and nothing is past the keep window
- [ ] [ ] the logs doctor row reports the tree's groups, files and bytes whether it is ok or warning
- [ ] [ ] the logs doctor row does not warn on the tree's total size alone, however large it is
- [ ] [ ] a root log the package never opens is reported as a group with no cap and no over-cap verdict
- [ ] [ ] the logs doctor row counts a group with no cap in neither its over-cap count nor its warning, and stays ok on its account however large that group is
- [ ] [ ] the logs doctor row names the groups with no cap, with their bytes, on every pass including an ok one
- [ ] [ ] the logs doctor row warns when any group is over its cap, naming how many
- [ ] [ ] the logs doctor row warns when job transcripts past the keep window are still on disk
- [ ] [ ] the streams doctor row warns when a stream on disk is not declared, naming it
- [ ] [ ] the streams doctor row is skipped entirely for a product whose record clone has no metrics directory
- [ ] [ ] both rows are advisory, so neither can redden the doctor
- [ ] [ ] both rows warn by returning the warn value the table renders as warn, never by returning false
- [ ] [ ] neither row reads the operator's home directory for anything but the tree the env helper names
