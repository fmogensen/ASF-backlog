## Acceptance
- [ ] `touched_files` twice for one branch runs one `git diff` and two `git rev-parse`s, and returns equal lists
- [ ] A new commit pushed to the branch makes the next `touched_files` run a second `diff` — the key moved, nothing was invalidated
- [ ] A second branch is a separate cache entry
- [ ] `already_on_trunk` for the same branch with a different `item` is a separate cache entry, because its answer depends on the deliverable
- [ ] `own_commits` twice for a branch carrying a merge runs its five processes once and returns the same `(base, shas, why)` triple, refusal included
- [ ] A branch name that does not resolve is answered uncached, with today's return value, as many times as it is asked
- [ ] `clear_facts()` empties the store
