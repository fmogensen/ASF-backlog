## Acceptance
- [ ] a real repo with a real annotated tag: resolve_ref returns the commit, and the fixture asserts first that the commit and the tag object differ
- [ ] the argv is exactly git ls-remote <url> <ref> <ref> with the peel suffix, both patterns, in that order, one call
- [ ] a lightweight tag, a branch and HEAD each resolve to the commit they already resolved to, with one line in the answer
- [ ] a ref that matches nothing on the remote resolves to None, and git exits 0 rather than erroring on the peel pattern
- [ ] a ref that already ends in the peel suffix is asked for once, not twice, so it never resolves to the unpeeled line
- [ ] resolve_target with the factory checkout absent reaches the commit through the remote, which is the host run the card reports
- [ ] resolve_target with a checkout that carries the tag reaches the commit without any remote read, under a run that raises if one is attempted
- [ ] a 40-hex sha still resolves offline, with no ls-remote call at all
