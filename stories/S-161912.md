## Acceptance
- [ ] [ ] one tick over four live sessions makes exactly one ls-remote call, asserted on the Beats call counter
- [ ] [ ] every live session fact carries beat, quiet_min, beat_min, beats and identity
- [ ] [ ] a session launched without a beat carries beat_min 0 and beat empty, and is never judged
- [ ] [ ] a branch head that moved since the last pass is movement, and so is a beat ref that moved
- [ ] [ ] an unreadable origin leaves every session's beat unknown and sets the facts' beats_unread
- [ ] [ ] the movement state is written once per tick and holds session, shas, moved, seen, tree and same_tree per job
- [ ] [ ] a new session of a job whose state file holds the old one starts from a fresh record
- [ ] [ ] the same-tree counter is only read for a run whose branch head has not moved for loop_beats times interval_min, asserted by counting fetches
- [ ] [ ] a failed read of the beat tree leaves the counter as it was and the verdict alive
- [ ] [ ] a push carrying the stalled session's own ASF-Session trailer is logged as a zombie push and is not movement
- [ ] [ ] a read-only session kind carries no beat and is judged as it is today
