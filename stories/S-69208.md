## Description

## Acceptance
- [ ] [ ] `env.deprecated_reads(data)` returns `(old, new)` for every old name still present in a file, read from `CONFIG_MIGRATIONS`'s `renames` and not from a hand-written list.
- [ ] [ ] An old name is still honoured after its migration landed, and the new name wins when both are set.
- [ ] [ ] `capacity.deprecations(cfg)` reads the same table, and `doctor._capacity_deprecations` is gone: one copy of those lines, not two.
- [ ] [ ] A still-present old name is named with its new home in the doctor's `capacity` findings without turning the row red — proven by tests/test_doctor.py
- [ ] [ ] Every `renames` entry whose migration landed within the current minor line is still honoured by the reader, so a rename stays readable for at least one minor version.
