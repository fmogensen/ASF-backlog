## Acceptance
- [ ] `log.needs_operator(out, text, *, product, root, item, key)` prints the line to `out` and appends a `needs-operator` event, `key` defaulting to the text's first 120 characters
- [ ] `log.needs_operator` with no product, or no resolvable record root, prints the line and appends nothing — the line is never lost to a failed append
- [ ] `log.needs_operator_text(what, fix=None)` is the pure formatter, and `cli.needs_operator_line` is a call into it
- [ ] `NoOtherWriterTests` parses each `asf/**/*.py` with `ast` and inspects only `Constant` strings that are not a module, class or function docstring, plus the first piece of each `JoinedStr`
- [ ] the test fails on such a string that **starts with** `'LAUNCH '`, `'MERGE: '`, `'RELAUNCH: '`, `'REFUSED '`, `'WAVE '` or `'NEEDS OPERATOR:'` outside `asf/metrics/log.py`
- [ ] the exemption table has exactly two entries — `asf/briefs/**` for all six prefixes, and `asf/approvals.py` for `'REFUSED '` only — each carrying its reason in the source
- [ ] `'NEEDS OPERATOR:'` is not exempt in `asf/approvals.py`, and that site composes through the helper
- [ ] docstrings, comments, constant names, the `asf/groom/digest.py` report regex, and the mid-string forms `'snapshot: REFUSED — …'` and `'… DISPATCH REFUSED — …'` raise no finding
- [ ] the test is clean over the whole tree, and fails when a `print('NEEDS OPERATOR: …')` is added back to any module outside `asf/metrics/log.py`
