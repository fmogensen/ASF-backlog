## Acceptance
- [ ] `work.bugs(items, runs, now)` returns `open_by_sev` carrying every one of `S1`, `S2`, `S3`, `S?` including zeros, and a Bug with no `severity` is counted in `S?` and never silently as `S3`
- [ ] `work.bugs(...).fixed_today` counts a Bug in `DONE_STATES` whose `stage_since` falls on the injected `now`'s local day, and not one whose `stage_since` is a minute before that local midnight
- [ ] `work.bugs(...).in_fix` holds a Bug with two live runs once, excludes a run `lifecycle.is_live` rejects, and excludes a live run whose `item` is not a Bug in the index; `in_fix_s1` is its S1 subset
- [ ] `work.bugs(...).oldest` is the open S1 or S2 with the earliest `stage_since`, ties breaking to the lower id, and is `()` when no S1 or S2 is open
- [ ] `work.features(items, runs, now, window_days)` counts `building`, `spec_plan` over all six spec/plan stage words, `decided_waiting`, `undecided` for both an absent `decided` and `decided: false`, and `landed_today` for a Feature at `landed` and one at `on-prod`
- [ ] `work.features(...).median_to_land` is the median from a Feature's first ledger run to its `stage_since` over the Features landed inside `window_days`, skipping one the ledger never saw, taking the mean of the two middles on an even sample, `None` with nothing measurable, and `measured` reporting the sample size
- [ ] every function in `asf/views/work.py` returns the same value when called twice with the same arguments and opens no subprocess, asserted with `subprocess.run` patched to raise
