## Acceptance
- [ ] [ ] after booting the new jobs in, install checks that both labels are loaded, not only the ones it changed
- [ ] [ ] a label that is not loaded afterwards makes install roll back every plist it replaced and bootstrap it again
- [ ] [ ] install returns non-zero when it rolled back, and its last line names the labels that were not loaded
- [ ] [ ] a rollback that itself fails prints the exact launchctl bootstrap command for each label still down
- [ ] [ ] a refused shadow preflight leaves both plists and both loaded jobs exactly as they were, asserted on the files and the bootstrap calls
- [ ] [ ] a refused tick lock leaves both plists and both loaded jobs exactly as they were
- [ ] [ ] a launchd refusal from the scheduler leaves both plists and both loaded jobs exactly as they were
- [ ] [ ] an install where both labels are loaded afterwards rolls nothing back and returns 0
- [ ] [ ] a dry run writes nothing, boots nothing and checks nothing
- [ ] [ ] the venv prune still runs after a successful install and never after a rollback
