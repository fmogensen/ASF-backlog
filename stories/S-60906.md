## Description

## Acceptance
- [ ] `sync_operator_checkout` returns a `Sync` record carrying `moved`, `why`, `behind`, `paths` and `detail` instead of a bool, and `why` is `None` or one of `off-trunk`, `local-changes`, `merge-refused`
- [ ] Each of the three refusal lines keeps the literal `not fast-forwarded` and carries the drift and the reason, as in `record: the record checkout is not fast-forwarded — 28 behind, local changes: groom/2026-10-06.md`
- [ ] No refusal line carries the checkout's filesystem path: the paths it names are the record-relative ones `git status --porcelain --untracked-files=no` already prints, sorted and capped at `SYNC_PATHS_MAX`
- [ ] `behind` is the number of `origin/<trunk>` commits the checkout lacks, and every refusal line prints that number
- [ ] A refused sync raises exactly one `NEEDS OPERATOR:` line naming the record checkout, its drift, the record-relative paths that block it, and a read-only command in backticks
- [ ] That `NEEDS OPERATOR:` line is printed again on the next tick over the same unchanged checkout — pure over the checkout's state, with no ledger file and no marker to suppress it
- [ ] A refused sync writes exactly one `record_checkout_stale` event, with `why`, `behind` and `paths` as its fields and no machine path anywhere in its JSON
- [ ] A tick whose sync refused still prints `[step:record]` with `ok=yes`, and the steps after `record` still run — a dirty operator checkout never stops the rest of the factory
- [ ] `commit_and_push` keeps the `Sync` the call returned on the tick context instead of discarding it, which is what the line, the event, the health file and the row all read
- [ ] A clean checkout on the trunk is still fast-forwarded to `origin/<trunk>`, and such a tick prints neither `not fast-forwarded` nor any `NEEDS OPERATOR:` line — proven by tests/test_operator_checkout_sync.py
- [ ] A checkout carrying local changes is left exactly as it was — same `HEAD`, the hand edit still in the file — and named rather than cleared — proven by tests/test_operator_checkout_sync.py
