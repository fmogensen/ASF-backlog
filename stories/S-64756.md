## Description

## Acceptance
- [ ] asf ci class prints the class alone on one line on stdout, and exits 0 for FACTORY_ONLY and for FULL alike
- [ ] the command always writes a reason line to stderr naming how many paths changed, how many matched, and the paths that forced FULL
- [ ] --paths-from - reads the path list from stdin and runs no git command
- [ ] --globs-from FILE is used in place of the resolved product's ci.factory_only_paths
- [ ] a --base of forty zeros, and a --base that does not resolve, each yield FULL with the reason on stderr and no traceback
- [ ] a --base ending in ... diffs against the merge base, a plain --base diffs the two-point range
- [ ] --json prints one object on stdout carrying class, paths, unmatched, globs, base and head
- [ ] a bad invocation or an unreadable repository exits 2 through the ConfigError path, never 1 and never a traceback
