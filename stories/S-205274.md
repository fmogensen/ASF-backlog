## Acceptance
- [ ] [ ] a tick that leaves a question writes the class of every question it left, counted by class
- [ ] [ ] the classes counted are exactly the questions the record counts as left, so the counts sum to the left figure
- [ ] [ ] a question no matcher claims is counted as a judgement and still reaches the console
- [ ] [ ] a tick that leaves nothing writes no such counts and no empty record
- [ ] [ ] the window's share folds the left classes the same way it folds the resolved ones
- [ ] [ ] a ledger record written without the left classes is folded as none, and reading it raises nothing
- [ ] [ ] the questions command prints the left classes as a table ordered by count, most frequent first
- [ ] [ ] a window that left nothing prints the share line alone
- [ ] [ ] the console share figure the gate row reads is unchanged by any of this
