## Acceptance
- [ ] [ ] a question saying a Gate command runs in no CI job, naming exactly one backticked command, is claimed by the gate class
- [ ] [ ] the same question with two backticked commands is claimed by nothing
- [ ] [ ] the same question with no known branch is claimed by nothing
- [ ] [ ] a pre push check step is admitted by the probe exactly as it is today
- [ ] [ ] a read only command that is not a pre push check step is admitted when the read only grant grants it
- [ ] [ ] a command the read only grant refuses is refused by the probe, with a reason naming both rules
- [ ] [ ] a command naming a path outside the probe's own worktree is refused
- [ ] [ ] the command runs on a fresh detached worktree of origin's branch head and its result is cached by command and head sha
- [ ] [ ] the answer is the command, the branch, the head sha and the command's last line, green or red, in the form the gate class already uses
- [ ] [ ] the run counts against the per tick test run budget, and a tick with none left leaves the question for the next tick
- [ ] [ ] with the read only widening off, only pre push check steps are admitted
