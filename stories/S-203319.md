## Acceptance
- [ ] [ ] a finding is stamped with its key and the head it was found on, and parses back to the same three parts
- [ ] [ ] a finding written before this change, with no stamp, parses with an empty head and a key derived from its own text
- [ ] [ ] two findings wording the same defect over the same file and line have the same key
- [ ] [ ] two findings over the same file and line asking for different things have different keys
- [ ] [ ] the same defect found again on a later head keeps its key and carries the new head
- [ ] [ ] a red finding, a rebase finding, a shared-files notice and an operator answer marker each keep their own meaning once stamped
- [ ] [ ] a finding whose key the card records closed is dropped before the brief
- [ ] [ ] a finding whose key the card records closed charges no round
- [ ] [ ] a finding whose key an operator ruling settled is dropped before the brief
- [ ] [ ] a finding whose key an operator answer settled is dropped before the brief
- [ ] [ ] a ruling that names a file and line, rather than a key, settles the keys over that line
- [ ] [ ] a re-raised finding is logged once and noted on the card once, however many times it is raised
- [ ] [ ] a changes verdict whose every finding is a re-raise neither sends the branch back nor charges a round
- [ ] [ ] a changes verdict carrying one finding no ruling and no closed key covers still sends the branch back
- [ ] [ ] a key a later review of the same pull request did not raise is recorded closed at that later head
- [ ] [ ] a key closed at a later head can never be raised again
- [ ] [ ] two findings over the same file and line whose earlier key is already closed are read as a contradiction
- [ ] [ ] a contradiction escalates to a stuck item owned by the operator rather than opening another round
- [ ] [ ] the escalation names the file and line, both findings, both heads, and the one question to answer
- [ ] [ ] the same file and line escalates at most once while that escalation stands
- [ ] [ ] a second contradiction on a different file and line escalates on its own
- [ ] [ ] the answer to an escalation puts its key in the ruled set, so neither side is raised again
- [ ] [ ] two findings over different lines are never read as a contradiction
- [ ] [ ] the drop, the re-raise and the contradiction are pure functions of the findings and the card
