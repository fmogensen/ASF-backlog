## Acceptance
- [ ] [ ] the acceptance of a card is a list of entries, each with its text
- [ ] [ ] an acceptance entry carries the test it is proved by when there is one
- [ ] [ ] an acceptance entry carries whether it is done
- [ ] [ ] the line number a proves trailer names is the one-based index of the acceptance list
- [ ] [ ] the gate of a card is a list of command strings
- [ ] [ ] the risk of a card is one of the two risk words
- [ ] [ ] the definition of ready finds a test in the typed acceptance of a card
- [ ] [ ] the definition of ready finds a test in the typed gate of a card
- [ ] [ ] the definition of ready reads no prose body on a json card
- [ ] [ ] a card with an empty acceptance and an empty gate is still held by the definition of ready, with the same reason as today
- [ ] [ ] the groom-fill applier writes its verdict acceptance into the field
- [ ] [ ] the groom-fill applier writes its verdict writes into the field, as it does today
- [ ] [ ] a verdict that raises risk high sets the field and still leaves the note it leaves today
- [ ] [ ] minting a story from a spec declaration writes its checkbox lines into the field

- [ ] [ ] ticking an acceptance line twice changes nothing the second time
