## Acceptance
- [ ] a local session's brief says liveness comes from the runtime and tells it to start no detached or background process
- [ ] that brief carries none of the loop: no nohup, no heartbeat script, no instruction to run a first command in the background
- [ ] the brief still tells the session to commit and push as each piece stands, and still names the notes file a continuation starts from
- [ ] an actions session's brief keeps the loop exactly as it is today, text for text, because its beat ref is its only movement signal
- [ ] a remote session's brief is unchanged
- [ ] a local run with no beat ref on origin is still judged: the branch standing still past the grace and the limit is a stall
- [ ] a local run whose job log is streaming events is alive by that log and is not stalled, with no beat anywhere
- [ ] a stalled local run is still stopped and continued, from the worktree's head and the worktree's notes file
- [ ] a local run still records the heartbeat interval it was launched with, so the stall rule still judges it
