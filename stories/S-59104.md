## Description

## Acceptance
- [ ] `load_pool` reads a pool entry's `exclude_labels` map into `PoolEntry.exclude` with every label normalised through `_norm` and every reason kept verbatim, and `PoolEntry.excluded(label)` returns that reason for an excluded label and the empty string for any other
- [ ] `load_pool` yields an empty `PoolEntry.exclude`, without raising, when the entry's `exclude_labels` value is not a mapping
- [ ] `exclude_labels` is in `POOL_FIELDS` and not in `POOL_REQUIRED`, so a pool entry carrying it draws no 'is not a field of a pool runner' problem from `pool_problems`
- [ ] `pool_problems` reports `ci.pool[N].exclude_labels` with 'must be a map of label to reason' for a string value and for a list value
- [ ] `pool_problems` reports `ci.pool[N].exclude_labels.<label>` for a label that fails `LABEL_RE`, for an empty reason, and for a reason that is not a scalar
- [ ] `pool_problems` reports `ci.pool[N].exclude_labels.<label>` when the excluded label is the entry's own `role`, when it is the entry's own `class-<cls>` label, and when it is in `DEFAULT_LABELS`; a well-formed exclusion yields no problem
- [ ] `PoolEntry.labels()` returns the same label set for an entry carrying an `exclude_labels` map as for the same entry without one
- [ ] `env.loads` of a pool entry whose `exclude_labels` is written in the block form, and of the same entry as a single-line flow mapping, both yield the same label-to-reason map; the same entry wrapped over two lines raises `env.ConfigError` naming 'an unbalanced flow-style value'
- [ ] `docs/products.example.yaml` gains a new `ci-3` pool entry whose `exclude_labels` is written in the block form -- that line carries no brace -- and the shipped `ci-1`, `ci-1b` and `ci-2` entries are byte-identical afterwards
- [ ] `docs/products.example.yaml` still validates clean under `env.validate_product_text` with that entry in it -- proven by tests/test_env.py
- [ ] `docs/guide/ci-runner-pool.md` documents `exclude_labels`: the block form, the required reason, and that a label the entry itself derives may not be excluded
