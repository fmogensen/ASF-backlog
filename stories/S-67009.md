## Description

## Acceptance
- [ ] `classify` returns `covered`, `repeated` and `own` lists plus an `ignored` count, and the three lists and the count add up to the ledger's length
- [ ] A `gh pr list` is `covered` and names `asf prs / asf status`, and a `tail` over a path under `env.log_dir()/jobs/` is `covered`
- [ ] The same normalised command appearing `chores.repeat` times or more (default 3) is `repeated`, and a one-off nothing covers is `own`
- [ ] Normalisation replaces quoted strings, numbers and absolute paths, so two `tail` calls over different logs with different line counts are one chore
- [ ] A command matching `IGNORE` is counted as `ignored` and appears in none of the three lists
- [ ] `chores.covered:` in the config replaces a built-in entry by name, appends a new name, and drops one with `off`
- [ ] A regex that does not compile raises `ChoresError` naming it, and the whole call refuses rather than silently matching nothing
- [ ] `asf chores --json` prints `day`, `days`, `total`, `covered`, `repeated`, `own`, `ignored`, `window_pct` and `account`, and `--days N` widens the window
