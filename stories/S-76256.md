## Description

## Acceptance
- [x] `dispatch.reassert()` replaces a pipx-style link at the path with the dispatcher and keeps the link as `<path>.pipx-link`
- [x] it is a no-op, writing nothing, on an absent path, on a symlink whose target is itself a dispatcher (an agent home), and on a dispatcher that is already current
- [x] it refuses a foreign file with the `NEEDS OPERATOR` line and leaves it byte-identical, and it never raises
- [x] `cmd_tick` calls it once before taking the lock, prints nothing when there was nothing to do, prints the detail when there was, and runs the tick either way
- [x] the `--dry-run`, `--shadow` and `--manifest` flags do not call it
