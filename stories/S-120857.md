## Acceptance
- [ ] [ ] a call that passes an environment runs with exactly that environment, whether or not an App is configured
- [ ] [ ] a call that passes none, with no App configured, runs with exactly the environment it runs with today
- [ ] [ ] a call that passes none, with an App configured and a token minted, runs with the minted token over the ambient environment
- [ ] [ ] a call that passes none, with an App configured and no token minted, runs with the ambient environment unchanged
- [ ] [ ] the default makes no mint, no product load per call and no network call: the ambient product is resolved once per process
- [ ] [ ] a product that cannot be resolved or loaded leaves the call on the ambient environment and raises nothing
- [ ] [ ] the harvest shim's calls carry the minted token
- [ ] [ ] the forge clean-up's calls carry the minted token
- [ ] [ ] the upgrade reader's calls carry the ambient login, because it reads the factory's own repository and passes its environment explicitly
- [ ] [ ] the git hook variables are still stripped from the environment the default builds
