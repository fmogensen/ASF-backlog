## Acceptance
- [ ] a window whose five red jobs all failed on the same step yields exactly one cause
- [ ] two failing-step names differing only in digits or hex fold into that same one cause class
- [ ] a red job the forge named no failing step for keeps its `ci-job:<name>` cause key and is a cause of its own — proven by tests/test_scorecard.py
- [ ] a red gate keeps its `gate:<class>` key, folding the digits of its first failing line into the class — proven by tests/test_scorecard.py
- [ ] a window whose CI jobs are all green yields no CI cause
- [ ] each `ci_causes` row names the distinct job names it folded, and its red counts sum to the window's red jobs
- [ ] `rank`'s `by_ci_job` keeps its per-job `ci-job:<name>` rows, with its minutes and red counts unchanged — proven by tests/test_scorecard.py
- [ ] `metric` answers a `ci-step:` key from the grouping and a `ci-job:` key from the whole job's red count, so a cause filed before this change verifies against the number it was filed at
- [ ] `asf scorecard` prints a CI-red-cause row naming each cause and how many jobs it folded
