## Acceptance
- [ ] a pass that read at least one journal prints exactly one oom summary line giving the kill count, how many were mapped, how many are owed a re-run, and the window in seconds
- [ ] a pass over a box whose journal is unreadable prints the ALARM and no summary line claiming it looked
- [ ] watch still returns a pair, the stall count and the cancel count — proven by tests/test_ci_stall.py
- [ ] asf ci stall-watch is still registered, still runs cmd_stall_watch and still takes --apply — proven by tests/test_ci_stall.py
- [ ] the subcommand still ends with the one ci stall line naming how many stalled and how many were cancelled
- [ ] ci.stall_watch.oom_window_s is in config_keys.KEYS as a number with a floor of 1 and no ceiling
- [ ] ci.stall_watch.oom_window_s is in docs/config.example.yaml beside the other five stall_watch keys, so tests.test_config_keys is green
- [ ] ci_stall.TUNABLES maps OOM_WINDOW_S to ci.stall_watch.oom_window_s
- [ ] tunable of OOM_WINDOW_S reads 1800 with no config and the config's value with one
- [ ] ci_cancels.CAUSES is exactly the tuple P9 measured and GROUPS still partitions it exactly, so the port mints no cause — proven by tests/test_ci_cancels.py
- [ ] asf/doctor.py gains no stall-watch row, and asf doctor's row count for a product with no CI pool is unchanged
- [ ] the module docstring names the OOM half beside the stall half, the one mode governing both, the yield to the operator script while it still writes claims.json, and the operator's one remaining step
- [ ] a case-insensitive grep for oom over asf/ci_stall.py is no longer 0, which is P1 inverted
