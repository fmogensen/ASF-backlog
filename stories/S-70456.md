## Acceptance
- [ ] asf coverage --help answers, "coverage" is a declared key of surface.COMMANDS and header.TITLES["coverage"] is "COVERAGE"
- [ ] surface.RENAMED["parity"] is "coverage", and every RENAMED value is still a declared command while no RENAMED key is — proven by tests/test_surface.py
- [ ] every header.TITLES key first word is still a registered command, and plugin_build.VIEWS is still a subset of TITLES — proven by tests/test_views_header.py
- [ ] for a source: stories reference the table lists the union of every Story whose parent Epic is the reference epic and every Story carrying reference: <id>, deduped by Story id, ordered by parity.area_key(section) then by row
- [ ] each row state is missing (no Story for the row, or a Story with no Task), built (a Story with a Task, not Closed) or tested (the Story is Closed), and each one equals what index.json already records for that Story, so a table that recomputed a state fails
- [ ] the GAPS FIRST block prints every missing row before every built row, each with its section, row, Story id or an em dash, state and title
- [ ] the BY SECTION block prints built / tested / missing / total per section with a % that is tested/total, and a totals row that sums the sections
- [ ] the MISMATCHES block names, by class, a Story whose reference: names no declared reference, a ref_row matching no row of a source: file reference, and a row claimed by two Stories; an empty MISMATCHES block is not printed
- [ ] --reference naming nothing the product declares exits non-zero with a reason naming the id; a product declaring no reference prints one line and exits 0
- [ ] asf parity renders the first declared reference coverage, and on a product declaring no reference returns views.parity.render(root) byte for byte with asf/views/parity.py unedited
- [ ] the whole table renders from a hand-written index.json and a product dict alone — no git repository, no gh and no network in the fixture
