## Acceptance
- [ ] With the default retry, a run whose one red module sits among green ones starts exactly one more attempt, over that module alone
- [ ] A module red on its first attempt and green on its second leaves the run's exit status 0
- [ ] That module's second result replaces its first in results: the summary prints OK and no red: line names it
- [ ] The summary's module count stays the number of modules the suite ran, and Ran N tests counts the retried module once — its final attempt's count
- [ ] A retry: <modules> line naming every module of the second pass is printed before the summary
- [ ] The second attempt's ASF_TESTS_HOME is a path the first attempt did not use
- [ ] Acceptance test: python3 -m unittest -v tests.test_run_tests.RetryPassTests
