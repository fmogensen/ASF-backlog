## Acceptance
- [ ] [ ] load_items is unchanged, and given a record with an archive it returns the working-set cards only
- [ ] [ ] load_items opens no file under the archive, counted on its own reads
- [ ] [ ] the kernel's record port returns the working-set cards only and reports no archived card as unreadable
- [ ] [ ] asf index writes an index.json holding the working-set cards only, with no archived entry carried over
- [ ] [ ] an archived card whose entry index.json still held is dropped by the next asf index
- [ ] [ ] asf check reports no finding for any archived card and opens no archived card file
- [ ] [ ] asf check --staged lays out the item folders only and does not refuse a commit that moves cards into the archive
- [ ] [ ] asf check --staged still refuses a commit that deletes a card another card references
- [ ] [ ] no record invariant sees an archive path, because an archive path is two levels down
- [ ] [ ] the staged record step's snapshot does not walk the record's top-level archive
- [ ] [ ] the staged record step's snapshot still walks a folder named archive that is not at the record's root
- [ ] [ ] the archive writer stages exactly the paths it moved and the manifest, and a bad move is put back without touching another writer's output
