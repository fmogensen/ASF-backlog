## Acceptance
- [ ] classify() returns FACTORY_ONLY when the path list is non-empty and every path matches one of the globs — proven by tests/test_ci_class.py

- [ ] unmatched() returns exactly the paths that forced FULL, in first-seen order — proven by tests/test_ci_class.py
