## Acceptance
- [ ] [ ] a signature with fewer sources than the configured minimum is watched, and its count is in the reason
- [ ] [ ] a signature with the minimum number of sources sharing no changed file is a flake
- [ ] [ ] a signature with more than the minimum number of sources sharing no changed file is a flake
- [ ] [ ] a signature whose sources all change one file in common is a defect, and the verdict names that file
- [ ] [ ] a signature whose sources share two files is a defect, and the verdict names both in sorted order
- [ ] [ ] a signature where only two of three sources share a file is a flake, because the third shares nothing
- [ ] [ ] a signature whose sources' changed files are unread is a flake on the count alone
- [ ] [ ] a signature a trunk commit is red on is the trunk's red, and the verdict names that commit
- [ ] [ ] a signature red on the trunk and on sources that share a file is reported as a defect, the shared file first
- [ ] [ ] the verdict vocabulary is closed, and every verdict the judge returns is one of its four names
- [ ] [ ] a watched signature produces no action and no record line
- [ ] [ ] a defect produces a record line and no action
- [ ] [ ] a trunk red produces a record line and no action
- [ ] [ ] the judge returns nothing at all while the knob is off
