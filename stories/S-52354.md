## Description

## Acceptance
- [ ] An entry past `max_age_days` is removed whole — its archive and its `-meta` sidecar together, grouped by stem; a young entry stays.
- [ ] While the directory is over `max_size_gb`, the oldest remaining entries are removed, and only as many as it takes to fit.
- [ ] An entry used within `min_age_min` is never taken, whatever the cap says — a live session's own archive is not pulled out from under it.
- [ ] An entry's age is `max(atime, mtime)`, so an archive read today but written weeks ago survives the age rule.
- [ ] A directory that is not an absolute path, or that resolves outside the product's own state dir, is refused, named and left untouched — nothing in it is unlinked.
- [ ] A product that configures no cache directory gets no line, no state file and no doctor/status rows.
- [ ] A dry pass (`fix=False`) measures but removes nothing; `per_pass` bounds one pass and counts the rest as left for the next.
- [ ] A child of the cache directory that is itself a directory is counted and skipped, never recursed into and never removed.
- [ ] The `cache_prune` conventions block validates its keys and defaults sanely; a malformed block is a shape finding, never a silent default.
- [ ] The health step calls the pass last and swallows any exception, printing one line, so a prune never stops a tick.
