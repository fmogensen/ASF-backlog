## Description

## Acceptance
- [ ] `asf reslot` is registered in `build_parser` and declared in `asf.surface` as (`mint a fresh sibling that carries a wedged item's branch, and retire the item`, RECORD, None): `surface.apply` raises no `SurfaceError` and `tests/test_surface.py` asserts `len(COMMANDS) == 59`
- [ ] Each of the eight refusals of the spec's §1 table — empty `--why`, no item id, no card, not a Task, already `removed:`, a session running, parked by hand, branch not on origin — exits 2 with its own single stderr line, and the parked and running-session cases print that line verbatim
- [ ] After any one of those refusals the old card still carries no `removed:`, no new card file exists, the registry has not grown a line, and the forge was not called
- [ ] One `cmd_reslot` over a wedged Task writes a sibling card whose `parent`, `writes`, `stories` and `after` equal the old card's, with `links.branches == [<branch>]`, `links.supersedes == [<old>]`, `state: New`, and a `## History` line naming the carry
- [ ] The same run leaves the old card carrying `removed: retired: <why> (reslot → <new>)`, its own `## History` line, and its pending correction read as dropped (`correction: null` with `dropped` and `drop_why`)
- [ ] The registry's last line is the hand-over: `lifecycle.by_branch(path)[<branch>]['item']` is the new id with `lane_of` empty and `occupies` False, `rounds_of(<new>)` is 0, and `rounds_of(<old>)` is unchanged
- [ ] The whole command leaves the record exactly one commit longer, signed off, carrying both card files and the derived index, with no second commit and no dirty tree
- [ ] The fake forge records one `close_pr(<number>, reason)` whose reason names the new id and the branch; with `--keep-pr` it records none; with no number to close the command still succeeds and says so; a forge answering `(False, 'no pull requests on this forge')` is not a failure and the record writes still stand
- [ ] With the mint made to fail nothing is retired and no registry line is written; with the retire made to fail the command names the sibling and the hand-over as standing; a second `asf reslot` on the same id is the already-removed refusal
