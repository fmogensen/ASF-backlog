## Acceptance
- [ ] after one pass ci-stall.json carries a pass block whose at is the pass's now, and whose mode reads report or act as the pass actually ran
- [ ] that pass block's stalls, cancels, boxes and unreachable counts match what the pass returned and printed
- [ ] a pass held back by the legacy script records legacy as the integer age it printed, and mode as report — the degraded mode, not the mode file's word
- [ ] a pass that acts records legacy as None
- [ ] load on a file written before this change, carrying no pass key, returns an empty mapping for pass and raises nothing
- [ ] load on a file whose pass is a list, not a mapping, returns an empty mapping for pass too
- [ ] registry.spec for ci-stall.json is a Spec whose owner is asf.ci_stall, whose kind is json and whose ttl_days is None
- [ ] registry.spec for ci-heartbeat.json is a Spec whose owner is asf.ci_heartbeat
- [ ] store.reap over a state directory holding ci-stall.json, ci-heartbeat.json and ci-cancels.json returns an empty list, so neither name is an orphan any more
