## Acceptance
- [ ] the footer is a blank line, then one `NEEDS OPERATOR:` line per open `needs-operator` event of the window, oldest first
- [ ] a `needs-operator` event whose `key` carries a later `hold-resolved` or `needs-operator-cleared` event is left out
- [ ] a window with no open `needs-operator` event renders no footer and no trailing blank line
- [ ] two `needs-operator` events sharing a `key` in the window render one line, the oldest
- [ ] the footer reads the events stream and parses no prose
- [ ] the footer's lines are part of the fixture day's expected bytes
