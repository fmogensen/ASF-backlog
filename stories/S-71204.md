## Acceptance
- [ ] A decided, open S1 Bug held by a live session is one non-launching WAITS ON session row at tier 0, never absent from NEXT — proven by tests/test_feeder.py
- [ ] A decided, open S1 Bug blocked by an open item is one WAITS ON <blocker-id> row naming that id in both its action and its waits_on — proven by tests/test_feeder.py
- [ ] A decided, open S1 Bug in state Active with no branch row speaking for it is one WAITS ON branch row — proven by tests/test_feeder.py
- [ ] A decided, open S1 Bug past the attempt limit is one WAITS ON operator row whose reason names the attempt count — proven by tests/test_feeder.py
- [ ] A decided, open S1 Bug whose work is pushed and waiting to land is one WAITS ON landing row whose reason contains 'waiting to land' — proven by tests/test_feeder.py
- [ ] The live-session row carries the sentence an operator reads and not a bare field: for an in-flight record carrying job=fix-bug-b-0001 the reason equals 'S1 open, decided: session fix-bug-b-0001 running'
- [ ] The Active-with-no-branch-row row's reason names both 'Active' and 'fixer branch'
- [ ] A WAITS row takes no scheduling slot and holds no tier, so a tier-2 card ranked behind it still launches — proven by tests/test_feeder.py
- [ ] An S1 Bug held by a live session is shown in NEXT even when no free slot remains — proven by tests/test_feeder.py
- [ ] An S3 Bug and an undecided Bug mint no BUG to FIX row at all, so neither gains a WAITS row — proven by tests/test_feeder.py
- [ ] A Bug with a correction in flight gets the correction row alone and no second WAITS row — proven by tests/test_feeder.py
