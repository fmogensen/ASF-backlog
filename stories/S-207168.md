## Acceptance
- [ ] [ ] the clock module is the only file under asf that reads the wall clock, and it answers now, an ISO stamp, a day and epoch seconds
- [ ] [ ] every one of those answers takes an optional instant and reads no clock at all when it is given
- [ ] [ ] the shift variable moves the clock the module answers with, by whole and by fractional days
- [ ] [ ] an unset, empty or unparsable shift variable is no shift, and never an error
- [ ] [ ] monotonic time is passed through unshifted
- [ ] [ ] each of the dozen named clock helpers still answers what it answered before, and holds no raw read of its own
- [ ] [ ] each of those helpers takes an optional instant and passes it through
- [ ] [ ] the lint counts a raw clock read per file and fails when a file rises above its baseline line
- [ ] [ ] a file absent from the baseline has a ceiling of zero
- [ ] [ ] the lint exempts the clock module itself and any line carrying the clock-exempt comment
- [ ] [ ] the lint does not count monotonic reads
- [ ] [ ] a count below its baseline passes and prints that the baseline can be lowered
- [ ] [ ] the lint takes an against-a-ref mode in which only the reads a change adds can fail it
- [ ] [ ] the lint takes a write-baseline mode, and the baseline it writes from this tree makes the check pass
- [ ] [ ] the baseline committed in this Story matches the tree it was written from
- [ ] [ ] the continuous integration workflow runs the lint beside the client ratchet step
