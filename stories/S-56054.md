## Acceptance
- [ ] `providers(cfg)` reads `credentials.providers` with its defaults (`window_days` 3, `probe_every` 1h), and a missing or misshapen section is no providers, never a raise — proven by tests/test_credentials.py
- [ ] `config_problems` names, by dotted key, a provider with no `probe:`, one with no `renew:`, a non-positive `window_days`, a `probe_every` that is not `<n>s|m|h|d`, an `account:` no `worker_pool` entry names, and a secret-shaped `renew:` — proven by tests/test_credentials.py
- [ ] `credentials: [a, b]` in a product file loads as `product.credentials == [a, b]`, while a mapping or a duplicate name is one refusal naming `credentials` — proven by tests/test_env.py
- [ ] `for_product` returns the providers in the product own order and raises `env.ConfigError` naming a provider `config.yaml` does not define — proven by tests/test_credentials.py
- [ ] `probe_env` sets `GIT_TERMINAL_PROMPT=0`, builds the named account own session environment, and raises when no `worker_pool` account carries that name — proven by tests/test_credentials.py
