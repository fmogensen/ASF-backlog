## Acceptance
- [ ] [ ] an item that carries a milestone reports its own, whatever its ancestors carry
- [ ] [ ] an item with no milestone reports the milestone of the nearest ancestor that has one
- [ ] [ ] a Task under a Story under a Feature reports the Feature's when neither it nor the Story carries one
- [ ] [ ] a Story that carries a milestone shadows its Feature's, for itself and for its own children
- [ ] [ ] an item with no milestone anywhere above it reports none
- [ ] [ ] a card with no parent reports its own milestone, or none when it carries none
- [ ] [ ] the items of a milestone are every item whose effective milestone is that name
- [ ] [ ] a parent cycle returns an answer rather than walking for ever
- [ ] [ ] a chain broken by a retired ancestor stops at the break, as the walk to the Epic already does
- [ ] [ ] the mint command takes a milestone and refuses one the record does not declare
- [ ] [ ] the set command takes a milestone, refuses an undeclared one before it writes, and writes a declared one
- [ ] [ ] a milestone written on a card reaches that card's entry in the index with no other entry changing
