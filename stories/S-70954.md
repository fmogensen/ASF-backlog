## Description

## Acceptance
- [ ] a session whose `item` is a Bug parented under an Epic, and whose own text names a live Feature carded no later than it, is charged to that Feature in `rank`'s `by_feature`
- [ ] a Bug whose text names two live Features is charged to the newest-carded of them
- [ ] a Bug whose text names a Feature carded after the Bug is charged to neither, and its spend stays unattributed
- [ ] a session on an Epic or a Decision whose text names a Feature is not charged to that Feature
- [ ] a session with no `item` whose branch names a Task under a Feature is charged to that Feature, and a branch id that is unknown or removed falls through to the next id the branch names
- [ ] a session whose `item` already reaches a Feature up its parent chain is charged to the same Feature it is charged to today
- [ ] `rank` returns `unattributed` carrying `usd`, `sessions` and `share`, with `share` 0.0 on an empty window and no division by zero
- [ ] the window's total session `usd` is the same before and after the ladder — no dollar is created, lost or double-counted
- [ ] `asf scorecard` prints an `unattributed` row in the "where the last N days went" table, and prints `none` in it when nothing is unattributed
- [ ] every card id a branch names is read out of it by `ids_in` alone, prefix-free and wherever in the string it sits — proven by tests/test_scorecard.py
