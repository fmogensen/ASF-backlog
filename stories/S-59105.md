## Acceptance
- [ ] `ci_pool.Backend.queued_jobs()` returns `()` on the base class, and `ci_pool.doctor_rows` with a backend that does not override it returns rows byte-identical to today's
- [ ] `GitHubBackend.queued_jobs()` returns an empty list with no host call when the backend has no slug, otherwise asks for queued runs first and a run's queued jobs only once per run that query returned, and returns the records sorted oldest-first by `created_at`
- [ ] `label_gap` returns exactly one `(False, detail)` row naming the runner, the missing label and the queued job, for one required job queued past `wait_min` and one idle runner of a class that already serves that job missing only that label
- [ ] `label_gap` returns exactly one `(True, detail)` row carrying 'held: <reason>' and not carrying 'asf ci reconcile', when the candidate's pool entry excludes the missing label
- [ ] `label_gap` returns `[]` for an idle runner whose class is not one of the classes already serving the job -- a `light` runner one label short of a heavy job
- [ ] `label_gap` returns `[]` when the candidate is missing two or more of the queued job's labels
- [ ] `label_gap` returns `[]` when no live runner carries all of the queued job's labels
- [ ] `label_gap` returns `[]` when the candidate runner is busy, and `[]` when the job has been queued fewer than `wait_min` minutes
- [ ] `label_gap` returns `[]` when the single missing label satisfies `is_default` -- a `DEFAULT_LABELS` label, or one the runner's own fixed set already holds
- [ ] `label_gap` skips a queued job whose `deploy.job_key` name is not in `required`, takes every queued job when `required` is empty, and matches a queued 'gate (ubuntu)' against a required 'gate'
- [ ] `label_gap` admits a live runner absent from `ci.pool` only by a `class-<name>` label the pool declares, and that row says 'not in ci.pool'; the same runner carrying only a role label yields `[]`
- [ ] `label_gap` reports a runner-and-label pair once, against the oldest queued job that wants it, when two queued jobs want the same label
- [ ] `label_gap` ignores a queued job whose labels do not contain `self-hosted`
- [ ] The class a candidate is judged by is `ci_queue.class_key` -- the declared `class:` else the `role`, provider-blind -- so an idle runner whose only gap is the provider label is a candidate for a job the runners of another provider serve
- [ ] Every row `label_gap` returns suffixes its minute figures with 'm' and carries no bare seconds token
