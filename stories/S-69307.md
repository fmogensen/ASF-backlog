## Acceptance
- [ ] [ ] Under notify, a newer tag prints the UPGRADE AVAILABLE line naming the old and the new release in the tick log, and the channel reports notified
- [ ] [ ] That same line reaches the tick digest, after the record-stale line
- [ ] [ ] A later tick that sees the same tag prints nothing and reports none; a tag newer than the stamped one notifies again
- [ ] [ ] Under off, a newer tag notifies nothing, installs nothing and writes no channel state
- [ ] [ ] With no newer release the channel reports none and prints no upgrade line, under every policy
