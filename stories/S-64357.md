## Acceptance
- [ ] `cloud.classify`'s existing table is unchanged, and `classify(done, None, 5, 240, '9')[1]` is still exactly `run 9 ended failure without the report commit` — proven by tests/test_cloud.py
- [ ] `cloud.classify(..., refusal=r)` on the `without the report commit` arm answers `... without the report commit — last ASF refusal (naming, 3m before): commits do not name ...`
- [ ] `cloud.classify` stays pure with a refusal given: it reads no file, runs no `gh` and reads no clock, and answers for a product whose state directory does not exist
- [ ] A `timed out` reason, a `stalled` reason and a never-appeared reason each take no clause
- [ ] `cloud.REPORT_MISSING` is the module constant naming that one arm, and the call site branches on it rather than on a sentence fragment
- [ ] `cloud.sync` passes `refusals.last(product, job, run)` into `classify`
- [ ] `cloud-sessions.json`'s `why` for the run holds the composed sentence, and the file's shape is otherwise unchanged
- [ ] The tick log's existing `cloud <job> dead: <why>` line prints the composed sentence, and no new line is printed
