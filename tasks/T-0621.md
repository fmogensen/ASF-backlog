   ```python
   def check_amendable_bundles(canonical, warn, find_line, amendable_globs=()):
       """F-0232: a Task whose ``writes:`` mixes the amendable set with paths outside it sends the
       whole footprint to the console — a human then hand-writes code a coder should have. A
       warning, not a finding (D5): the footprint is the planner's to split, and a Task wholly
       inside the set is correctly served by the console today."""
       if not amendable_globs:
           return
       for iid, rec in canonical.items():
           meta = rec['meta']
           if not is_open(rec) or meta.get('type') != 'task':
               continue
           writes = meta.get('writes') or ()
           inside, outside = amendable.partition(None, list(writes), glob_set=amendable_globs)
           if not (inside and outside):
               continue
           warn(rec, find_line(rec, 'writes'), <the PD10 message>)
   ```

   `from asf import amendable` at the top of the module (`asf/record/check.py` has none today,
   P9) — a plain import, no cycle: `asf/amendable.py` imports `os`, `fnmatch` and
   `asf.conventions` only. `product` is `None` because the pair is given (PD5). The default `()`
   is the "nothing declared → check nothing" contract `shared=()` already has (D9).
