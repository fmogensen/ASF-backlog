The spec's design §1, whole — `NOTES_FILE`, `PATHS`, `add_pathspec()` and `exclude()` — plus D-0007's
glob, D-0008's tracked ignore entry and S-91158's invariant. It lands first because the other four
Tasks import it, and it lands green alone because nothing imports it yet (**PD1**). `exclude()`
ships here rather than with Task 4 so that `asf/workers/scratch.py` stays in one Task's footprint;
that is why S-91157 is on this line as well as Task 4's (**PD1**).

**Files**

- `asf/workers/scratch.py` — new. Module-level imports `os` and `subprocess` and **nothing from
  `asf`** (D-0009, **PD5**). `NOTES_FILE = 'NOTES.asf.md'` — the literal's home, moved here from
  `heartbeat.py:73` by Task 3. `PATHS = (NOTES_FILE, '.b[0-9][0-9][0-9][0-9]_*')`.
  `add_pathspec()` returns `['-A', '--', ':/', ':(exclude,top)NOTES.asf.md',
  ':(exclude,top,glob)**/.b[0-9][0-9][0-9][0-9]_*']`: the whole-tree magic first, then one exclude
  per name, a literal as `:(exclude,top)<name>` and a name holding a glob character as
  `:(exclude,top,glob)**/<name>`. Every exclude carries `top` — **PD3** measured both entries being
  swept in without it. `exclude(wt)` appends each name of `PATHS` that is not already a line of
  `<git-common-dir>/info/exclude` to that file, creating `info/` if needed (D-0004), and returns the
  names it added; it reads and writes under `try`/`except OSError` and returns "added nothing" on
  failure, never raising — it is a hardening step and a worktree that cannot be hardened still has
  to run.
- `tests/test_scratch.py` — new. `ScratchPathsTests` over `PATHS` and `add_pathspec()`, including
  the agreement assertion (below) and the both-orders import of **PD5**. `ExcludeFileTests` over
  `exclude()` in real throwaway repositories, covering S-91157's eight lines about the exclude file.
- `.gitignore` — `NOTES.asf.md` added to the block that already holds
  `.b[0-9][0-9][0-9][0-9]_*` at line **13**, the last line of the file, under the comment P11
  quotes (D-0008). Its reason is the same one that comment already gives, so it belongs in that block
  rather than a new one.
- `tests/test_invariants.py` — `FactoryScratchIgnoredTests`: every name in `scratch.PATHS` is a
  line of the repository's **tracked `.gitignore`**, and `.gitignore` names no factory scratch path
  `PATHS` has forgotten. It reads `.gitignore`, never `info/exclude` and never a bare
  `git check-ignore` in whatever checkout it runs in — **PD7** is why.

**Steps**

1. Write `asf/workers/scratch.py`. Derive the exclude form from the name: a name containing any of
   `*?[` takes `:(exclude,top,glob)**/<name>`, anything else `:(exclude,top)<name>`. Do not
   hand-write the two strings — S-91158's second and third acceptance lines are about the
   derivation, and D-0007 exists so the list can grow.
2. Write `ScratchPathsTests`. Beside the shape assertions, assert the pathspec's first three
   elements are `['-A', '--', ':/']` (the fifth acceptance line) and that **every** element
