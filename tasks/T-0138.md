§2.4: the fifteen-line page is replaced by the three parts, the spans are filled by `--refresh`
against the record (PD8), and the four checks that hold it — byte-identity, no typed number, no dead
link, one page — run against the real file from here on. This is the Task that deletes the two
directory names that do not exist.

**Files**

- `README.md` — rewritten: `## The argument`, `## The mental model`, `## The manual`, in that order,
  with the `scoreboard`, `cost_per_feature` and `commands` block spans and the inline `n` spans the
  argument's sentences carry. The quickstart block is written here as a fenced `sh` block between
  `<!--asf:quickstart-->` and `<!--/asf:quickstart-->`; Task 5 is what makes it run.
- `docs/readme-numbers.json` — **new**, written by `asf readme --refresh`, never by hand.
- `tests/test_readme.py` — `CommittedPageTests`, `ProseTests`, `LinkTests`, `OnePageTests`,
  `CommandsBlockTests`.

**Steps**

1. `## The argument` — what ASF is in three sentences, then the `scoreboard` block. The numbers are
   the argument: sessions run over the window, Features shipped, spend per Feature, and the record
   that says so is public. The status line (0.1 in construction) and the link to the record
   repository stay; `0.1` is in `LITERALS`, so it is prose, not a measurement.
2. `## The mental model` — eight to twelve lines, one idea each, each linking the one place it is
   specified: the record is typed intent; state is derived from evidence, never typed
   (`docs/CONSTITUTION.md`, `asf/evidence/`); the tick is the loop — groom, wave, harvest
   (`docs/design/lane-state-machine.md`); a lane is a branch with a session on it; rules are checks,
   not prose (`asf/rules/`); multi-product from day one — every path and vendor name lives in
   `~/.ASF`, none in this repo. Where the section would explain a mechanism, it links (§1.2).
3. `## The manual` — install (the current block, kept); the quickstart block; the `commands` block;
   where things live, as a table whose every path is link-checked; `~/.ASF` as the operator's
   configuration; the license; the credit paragraph per PD11. The "Not the Apache Software
   Foundation" disambiguation stays. The bullet naming `rules/` and `evals/` goes — those two paths
   are why this card exists.
4. The budget (PD9): 41 lines are the `commands` block, so the prose fits in the other 109. Cut
   prose to fit; do not move it into `docs/`, do not trim a generated block, do not raise
   `MAX_LINES`. If the three parts cannot be carried in 109 lines, say so in the session report
   rather than adjusting the budget.
5. `asf readme --refresh` against the factory's own record writes `docs/readme-numbers.json` and
   fills every span (PD8). No span is hand-filled and no value from §2.2's illustrative JSON is
   copied — those are the spec's shape, not a reading.
6. `bash tools/check_generic.sh` is run **after** the refresh (PD13): the Feature titles the
   `cost_per_feature` block renders are record data reaching a tracked file for the first time.
7. `CommittedPageTests` per §3.3: read the real `README.md` and the real facts file, re-render,
   assert byte-identity. A number edited by hand in either file fails here.
8. `ProseTests` and `LinkTests` per §3.4: every digit run in the real page is in a span, in inline
   code, in a link target or in `LITERALS`; every relative path resolves under the repo root, in both
   of PD6's forms. `LinkTests` carries the regression case §3.4 names — a page naming `rules/` and
   `evals/` when neither exists must fail, asserted against a fixture page, not against the real one.
9. `OnePageTests` per §3.5: ≤ 150 lines, ≤ 10 000 bytes, and exactly the three `##` headings, present
   and in order.
10. `CommandsBlockTests` per §3.7: the `commands` block names exactly the subcommands
    `asf.cli.build_parser()` registers — no
