**Files**

- `asf/doctor.py` — `scheduler_rows`.
- `tests/test_doctor.py` — `TestSchedulerSection`.

**Steps**

1. `scheduler_rows(cfg, product, jobs=None)`, before the kind check: if
   `(cfg.get('scheduler') or {})` has `interval_s`, add a YELLOW row `config
   scheduler.interval_s is set but no longer read — clocks live in products/<p>.yaml` (spec D10).
2. After the kind check (P3), call `scheduler.clocks(product)`.
   - On `SchedulerError` whose text starts `NEEDS OPERATOR:` (no `clocks:`), add one RED row
     with that line.
   - On any other `SchedulerError`, add one RED row per refused clock, with the text as given.
   - Otherwise, for each declared clock whose `label_for(product.name, clock.name, cfg)` isn't
     among the loaded labels, add a RED row `<label>  declared in products/<p>.yaml but not
     loaded — asf scheduler install --product <p>`.
3. Keep the per-job rows, the D11 never-ran check Task 1 put in, the log tail and the yellow
   legacy-dir rows as they are.
4. `tests/test_doctor.py`: `TestSchedulerSection`'s product gains a `clocks:` block whose
   labels match the jobs its tests load, so the existing healthy-job assertions stay OK. Add
   the four tests in Acceptance.
