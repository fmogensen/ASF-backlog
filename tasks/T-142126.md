asf/flow.py, asf/feeder/rows.py, tests/test_flow_conservation.py

**Steps**

1. In `asf/feeder/rows.py`, add `BUG_SEVERITIES = ('S1', 'S2')` beside the module's other
   constants, with a docstring naming it as the bar the feeder opens a fix row above, and use it
   at the three sites: `:849` (the `BUG → FIX` gate), `:2010` (`undecided_rows`' roots) and
   `:2282` (the Epic budget exemption). The value does not change. Leave `asf/feeder/idle.py`
   alone — its fourth copy is dead code and outside this footprint.
2. Create `asf/flow.py`, stdlib-only and pure: no git, no gh, no filesystem, no clock. Its only
   product imports are `asf.views.index_reader` for `subtree` and `asf.feeder.rows` for
   `is_open`, `inflight_ids` and `BUG_SEVERITIES`. Module docstring, `WORK_TYPES`, `CLASSES` and
   `PARKED` exactly as §2.1 of the spec writes them, including the comments.
3. `conserved(item, by_item, busy, items)` → `(class, detail)`: the first class of `CLASSES` that
   holds, per §2.1's table. `done` when `state` is in `invariants.DONE_STATES` or `type` is not
   in `WORK_TYPES`; `parked` when a `PARKED` entry's fact holds, in table order; `row` when
   `by_item` has a row with this `item_id`; `session` when the id is in `busy`; `subtree` when
   some item of `ix.subtree(items, item)` is in `by_item`; `SINK` otherwise, its detail the step
   it sits at as `f"{type} {state}/{stage or '—'}"` plus `waited on by <id>` when a row's
   `waits_on` names it. Mutate neither the item nor the item map.
4. `sinks(items, rows, inflight=(), occupancy=None)` → `[(item, detail)]` in id order. Build
   `by_item`, `busy` (`rows.inflight_ids(inflight)` together with occupancy's `busy`,
   `waiting_landing` and `corrections`) and the `waits_on` back-index once each per call. An
   item map that is empty, that has no rows, or whose `children` name ids it does not hold must
   return without raising.
5. Read the wait chain forward (§1.3 C10): a row whose `waits_on` is an item id with no row of
   its own makes the **target** the finding, never the waiter. A `waits_on` that is a keyword
   (`decision`, `landing`, `build slot`) is never a sink; nor is a target that is `removed`,
   `Resolved` or `Closed`. A target the item map holds no entry for is not read as done.
6. Create `tests/test_flow_conservation.py` with `TheLaw`, `SinksInTheFixture`, `TheWaitChain`
   and a class for the severity bar, over `tests/fixtures/feeder/index.json` and
   `rows.candidates(..., decision_limit=0)`, plus hand-built items for the shapes the fixture does
   not hold. The fixture's one sink is `T-0004`; `B-0003` is parked on severity, `F-0008` parked
   on `removed`, `E-0001` conserved by its subtree (§1.2 P2). Assert *which* class took each.
   Assert that `conserved` agrees with `invariants.waits_on_without_a_row` on the pair, so the
   tick check and the test that states the same property cannot drift. Assert
   `rows.BUG_SEVERITIES == ('S1', 'S2')` and that no literal tuple of the two is left in
   `asf/feeder/rows.py` (K6).
