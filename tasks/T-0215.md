§2.10. The card's fourth acceptance is a fortnight's reading, and today it cannot be taken at all:
nothing prints minutes per small Task. One scorecard row over the `ci` stream the rollup already
reads — no new stream, no new event, no new collector.

**Files**

- `asf/metrics/metrics.py:454` — `scorecard_rows` gains the `runner-minutes per small Task` row.
- `tests/test_metrics.py` — §3.8.

**Steps**

1. `scorecard_rows` keeps its signature exactly — `(ci, sessions, ticks, conv=None, events=())`
   (PD10) — so `asf/views`, the rollup and every existing test are untouched. The row is appended
   beside the `runner-minutes` row it refines.
2. The number is `sum(minutes of runs naming a small Task) / count(small Tasks merged)`, with the
   comparison drawn against the same figure for the window before trains were switched on. The
   `ci` stream holds both windows, so the fortnight acceptance is a `rollup` run rather than a new
   collector.
3. A run's minutes reach its Tasks through the machinery that already exists: `compute_costs`
   splits a run's minutes evenly over the items it names (`:358`), and Task 7 writes every Task id
   into the train's pull request body, which `asf/record/match.py` rule 1 turns into the event's
   `items` list. Nothing in the `ci` schema changes, and `compute_costs` is not edited.
4. With no merged small Task in the window the row reads `—`, not `0` — a factory that merged no
   small Task has nothing to report, and a printed zero would read as an achievement.
5. `tests/test_metrics.py` per §3.8: `scorecard_rows` returning the row over a synthetic `ci`
   stream — one train run of 12 minutes naming six small Tasks against six single-Task runs of 12
   minutes each, the row reading `2.0 (was 12.0) — 83 % down`; the row reading `—` with no merged
   small Task in the window; and `compute_costs` splitting a train run's minutes over exactly the
   Tasks its event names, unchanged.
6. Then, for the operator, after two weeks of trains — §3.8's second fence, which is acceptance
   row 4 read twice, the fortnight before the lanes were named and the fortnight after.
