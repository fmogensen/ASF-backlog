if Task 1 shipped without the `os.devnull` condition.

**Files**

- `tests/__init__.py` — `hermetic.confine_hooks_to_temp(os.environ)` after the `CALLER_IDENTITY` loop
  (`:38-39`), with the spec's three-line comment
- `tests/test_00_home.py` — the same call inside `hermetic_home()`, beside its `strip_git_config`
  (`:32`)
- `tests/test_hermetic.py` — the fourth probe key and the fourth assertion in
  `test_both_of_the_suites_entry_points_are_hermetic` (`:230-266`); the matching case on
  `HomeIsHermetic`'s side is **in `tests/test_00_home.py`**, above

**Steps**

1. `tests/__init__.py`: after the `for _var in hermetic.CALLER_IDENTITY:` loop (`:38-39`), add the
   spec's comment byte for byte — the review-b-0111 sentence and the "both entry points set it;
   tests/test_hermetic proves neither twin is without it" sentence — then
   `hermetic.confine_hooks_to_temp(os.environ)`. `hermetic` is already imported at `:24` and `os` at
   `:7`. It goes into `os.environ`, so every subprocess a test starts inherits it (P11, reproduced in
   PD11).
2. `tests/test_00_home.py`: the same call inside `hermetic_home()`, beside `strip_git_config`
   (`:32`), with a one-line comment naming F-0143 and pointing at its twin. `hermetic` is already
   bound in that function (`from asf import env, hermetic`, `:24`) and `os` at `:8`. The twin can
   import no sibling in `tests/` (P18, re-verified), which is exactly why the call is duplicated
   rather than shared — D6 and D7.
3. Do **not** add a `GIT_HOOK` strip to `tests/test_00_home.py`. It is missing there (PD10) and that
   is a real asymmetry, but it is out of this card's scope and the strip that matters for this defect
   is inside `git_hooks_dir` itself (P4), where it covers both entry points already.
4. `tests/test_hermetic.py`, in `test_both_of_the_suites_entry_points_are_hermetic`: the probe dict
   (`:246-251`) gains the spec's fourth key byte for byte —
   `'"confine": os.environ.get(hermetic.HOOKS_CONFINE),'` — and the `for entry in (…)` loop
   (`:252-262`) gains the spec's fourth assertion byte for byte, with its F-0143 comment:
   `self.assertEqual(os.path.realpath(got['confine'] or ''), os.path.realpath(tempfile.gettempdir()), entry)`.
   Add `import tempfile` to the module if it is not already there. The `or ''` matters: a missing
   variable must compare unequal rather than raise a `TypeError` inside `realpath`, so the failure
   reads as the assertion it is.
5. `HomeIsHermetic` in `tests/test_00_home.py` gains the matching case — that class is what the
   `discover -s tests -p test_00_home.py` half of the same test runs (the loop above cannot reach the
   twin, since both its entries import `tests/__init__.py` first and the package guard masks it; the
   existing comment at `tests/test_hermetic.py:263-266` says exactly this). One assertion:
   `os.environ[hermetic.HOOKS_CONFINE]` realpaths to `tempfile.gettempdir()`'s realpath. Import
   `hermetic` inside the method, as the neighbouring case imports `env` (`:41-42`) — the module's
   top level must stay stdlib-only (P18).
6. Prove the property rather than assume it, before the Gate: delete the
   `confine_hooks_to_temp` line from each twin in turn and confirm one of the two commands goes red.
   The spec's S-34601 fence has the exact script; run it as written. It restores both files in a
   `finally`, so check `git status` is clean afterwards.
