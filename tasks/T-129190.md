**Files**

- `asf/feeder/rows.py`
  - `LANDING_MIN_DEPENDANTS = 1` beside `ROOTS_MIN_DEPENDANTS` (`:467`) and deliberately not it,
    with the spec's own comment: one, not five, because "a landing nobody owns is already a stall
    at the first row that waits on it (the incident had three), and unlike a park there is no
    person to wait for" (`D2`, `P6`).
  - `class Row` (`:247`): two fields appended **after** `ruling` (`:273`), so every positional
    construction in the module is unaffected — `pr: str = ''` and `ownerless: bool = False`, each
    with the `#: a PUSHED → LAND row only:` comment the spec gives, in the shape `review_round`,
    `amend`, `groom_date` and `ruling` already use (`D4`).
  - `pushed_rows` (`:2731`): `ownerless = False` bound after `back = …` (`:2745`), set `True` in
    the `else` arm alone (`:2753-2754`), and `pr=number, ownerless=ownerless` added to the
    `Row(…)` at `:2755-2757`. The `waiting[iid]` arm and the `back` arm are **not** marked: each
    names a real owner (harvest, and the lane's BACK re-read). `:2758` is unchanged — a blocked
    pushed item still goes through `blocked_row`, which is a `dataclasses.replace` (`:1528-1533`),
    so both new fields ride along on the wrapped row.
  - `surface_stale_landings(rows, product, least=LANDING_MIN_DEPENDANTS)` beside
    `surface_stale_parks` (`:2463-2502`), with the spec's docstring. Body: the gate first
    (`if not product.conventions.merge_queue(): return rows`), then `surface_stale_parks`' own
    body with the park's `since`/`days` test replaced by the dependant count, the same
    `dataclasses.replace`, and the same reinsertion of each surfaced row at the first row whose
    tier is at least its own (`s.tier <= r.tier`, `:2497`).
  - `stalled_landings(rows)` beside `orphaned_pushed` (`:2762`), the spec's body verbatim:
    `{item: (pr, n)}` over rows that are `ownerless`, carry a `pr`, and whose action
