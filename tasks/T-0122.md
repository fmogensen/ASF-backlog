§2.6 and §2.7's first and third bullets. The operator's window into the decision: one flag that
prints the message the tick would send, or the one line saying why there is none. Plus the
transition written into the state machine and the limit written into both sample configs, so
`heartbeat_min` is discoverable without reading the source (PD15, PD16).

**Files**

- `asf/briefs/build.py` — `register` gains `--continue` (`:293`); `cmd_brief` honours it
  (`:269`).
- `docs/design/lane-state-machine.md` — the `held ─► continued ─► running` transition with its
  one-line rule, and the `runtime_session` row beside `stop_tip`.
- `docs/products.example.yaml:120` — `heartbeat_min: 6` in the `stage_limits` block, with the
  comment distinguishing it from `silent_min`.
- `sample/product.yaml` — a `stage_limits:` block holding `heartbeat_min: 6` (PD16).
- `tests/test_continuation.py` — `SurfaceTests` (§3.7).
- `tests/test_sample_product.py` — the sample product's new key.

**Steps**

1. `p.add_argument('--continue', dest='continue_', action='store_true', …)` — `continue` is a
   keyword, so the dest is named; the help says what it prints.
2. `cmd_brief`, when the flag is set, asks `continuation.target` for the row it already selected
   (`--item` selects it as today) and, on a session id, prints
   `continuation.prompt(...)` to **stdout** and returns 0. With no continuation it prints
   `no continuation for <item>: <reason>` to **stderr** and returns 0 — the split `asf new` and
   `asf stale` already use, so a caller can pipe the prompt without catching the reason. Exit 0
   either way: "there is no continuation" is an answer, not a failure.
3. The state machine gains the transition in its own table, with the rule in one line — *a held
   run's findings go into its own session; a dead one's go into a new one* — and
   `runtime_session` beside `stop_tip` in the run-fields row.
4. Both sample configs carry the limit with the comment that separates the two clocks:
   `silent_min` (30) asks whether a live session is worth an operator's look; `heartbeat_min`
   (6) asks whether findings may be put into this conversation. One number cannot be both.
5. `SurfaceTests` per §3.7: `asf brief --continue` printing the prompt on stdout for a
   continuable row; the reason on stderr, exit 0, for one that is not; and `--item` selecting a
   row. `tests.test_env` and `tests.test_sample_product` are run beside it because
   `stage_limits` is a free-form map (P7) and the new key must cost neither a schema change nor
   a refused product.
6. `check_conventions.sh` is run as its own Gate line, per §3.7's last paragraph:
   `asf/workers/continuation.py` derives every path from `conventions` and owns only
   `DEFAULT_HEARTBEAT_MIN` (PD12).
