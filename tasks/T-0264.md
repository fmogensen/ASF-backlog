**Steps**

   existing section byte-identical (PD13). It holds the launch notes as bullets: what 0.1 is, the

   not replace the per-release `## v0.1.<n>` sections the existing machinery writes.
2. `docs/release-0.1.md` — new: the reading that justified the release. Run
   `asf release-readiness --json` in this worktree and write its eight criteria, one line each with
   `key`, `name`, met/unmet and the evidence string the command printed, plus the tag, the commit and
   the day it was read. Nothing composed (PD12). If the record does not resolve, the page's shape
   lands with the reading empty and `NEEDS OPERATOR: docs/release-0.1.md needs its reading — asf

4. `docs/products.example.yaml`: the commented `release:` block already lists `requires` and

   the Feature ids 0.1 will not ship without, `requires` as the ids each criterion depends on — so
   the gate is legible from the example file instead of only from `asf/release.py`. Every key stays
   commented: the block is an example, not this operator's configuration.
5. Print the release step rather than take it (§2.5, D7, P8):
   `NEEDS OPERATOR: cut the 0.1 release — asf release-readiness must read eight of eight met, then
   publish the line's newest tag as a GitHub Release with the ## v0.1 notes`. Nothing in this Task
   pushes a tag, publishes a Release or announces anywhere.

**Gate**

```bash
python3 - <<'EOF'
import re, sys
from asf import release
text = open('README.md', encoding='utf-8').read()
heads = release.readme_headings(text)
missing = [s for s in release.DEFAULTS['readme_sections']
           if not any(s.lower() in h.lower() for h in heads)]
if missing:
    sys.exit('README lacks ' + ', '.join(missing))
changelog = open('CHANGELOG.md', encoding='utf-8').read()
# `release.changelog_notes` matches a tag as a prefix, so 'v0.1' is satisfied by any `## v0.1.<n>`
# section that already exists. The launch section is the exact heading, and it must carry notes.
lines = changelog.splitlines()
at = next((i for i, ln in enumerate(lines) if re.match(r'^##\s+v0\.1(?![.\d])', ln)), None)
if at is None:
    sys.exit('CHANGELOG.md has no "## v0.1" launch section (a "## v0.1.<n>" release section is not it)')
body = []
for ln in lines[at + 1:]:
    if ln.startswith('## '):
        break
    body.append(ln)
if not any(b.strip().startswith(('-', '*')) for b in body):
    sys.exit('the "## v0.1" section carries no notes')
print('ok')
EOF
```
