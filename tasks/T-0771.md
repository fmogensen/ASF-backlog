**Files**

- `tests/test_retired_derived.py` — new; one `RetiredDerivedSectionsTests`

**Steps**

1. New file, module docstring naming the sentence it holds: a card with `removed:` or `moved_to:`
   gets an empty `## Children` and an empty `## Backlinks`, the four words inside the `if` at
   `asf/record/core.py:301-302` that no test has covered since they landed in `b191575fd`.
2. `RetiredDerivedSectionsTests(unittest.TestCase)` over a `tests.test_groom.make_repo` root, with
   `self.addCleanup(shutil.rmtree, self.root, True)`. A `build(retire_line, body=…)` helper writes
   four cards through `tests.test_groom.write_item`:
   - an Epic;
   - a live Feature whose Description **names the retired Feature's id** (PD5);
   - the retired Feature, `typed_lines=[retire_line]`, whose body carries a Description that
     **names the live Feature's id** (PD5) and both derived sections already filled — a
     `## Children` listing the Story and a `## Backlinks` listing the live Feature;
   - a Story parented to the retired Feature.
3. `test_a_retired_card_is_stale_on_both_headings`: `findings, _warnings, _index_wrong =
   record_findings(self.root)` (PD3) and assert that `('features/F-0002.md', line,
   '## Children section is stale (run `asf index`)')` and its `## Backlinks` twin are both among
   them, matched on the `(relpath, message)` pair so the line number is not pinned. Do **not**
   assert anything about the live card here (PD4).
4. `test_a_refresh_empties_the_retired_sections_and_keeps_the_live_one`: `refresh(self.root,
   create_index=True)`, then read both card files off disk. The retired card's `## Children` and
   `## Backlinks` are empty; the live card's `## Backlinks` carries
   `- [F-0002](../features/F-0002.md) Retired feature` — the folder-relative link `rel_link`
   renders (PD5). The record still records that the link existed, on the side that is not retired.
5. `test_the_record_converges_after_one_refresh`: `refresh(...)` then `record_findings(self.root)`
   again, and assert **no** finding whose message is one of the two stale messages remains, for any
   relpath. This is PD4's stable form of §1's "reports neither against the live one"; a
   `make_repo` record keeps its unrelated findings (missing layout folders, missing
   `schema_version`, and before the refresh a missing `index.json`), so never assert the list is
   empty.
6. `test_moved_to_reads_exactly_as_removed`: the same fixture built with
   `moved_to: other:F-0049` in place of `removed: …`, asserting the same two stale findings and
   the same two empty sections. Measured here: identical.
7. `test_a_card_retired_before_its_sections_were_written_is_byte_identical`: the same retired card
   with a body that has **no** `## Children` and no `## Backlinks`. Read its bytes, run
   `refresh(self.root, create_index=True)`, read again, `assertEqual`. Also assert neither stale
   message names that card's relpath — `expected_body` rewrites the sections a body already has
   and adds none, so the rule removes and never adds a finding of its own.
8. `test_the_retired_cards_graph_is_kept_on_purpose`, with the reason in its own docstring citing
   P13 and P14 so the divergence reads as the rule's boundary and not as a second defect:
   `compute_derived(canonical)['F-0002']` still equals `{'children': ['S-0001'], 'backlinks':
   ['F-0001']}`, and `build_index_data(canonical, derived)['items']['F-0002']` still carries both
   lists — asserted **positively**. The docstring says why: `close_exact_duplicate`,
