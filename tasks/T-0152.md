## Description
stories: S-17302

after: none

§2.4 and §2.6: the two things both cells need before either can be written — a duration renderer that
is not an age off the wall clock, and the window the median is measured over. No count and no row
here; `age` comes out behaving exactly as it went in (PD15).

**Files**

- `asf/views/index_reader.py` — `span(seconds)` added above `age` (§2.4's fence), `age` reduced to
  `parse_ts` + `span((now - t).total_seconds())` with `'—'` for an unparseable `ts`. The bucket
  expression moves; it does not change.
- `asf/conventions.py` — `DEFAULT_LAND_WINDOW_DAYS = 7` with the other `DEFAULT_*` ints and the
  comment §2.6 gives it, and `land_window_days: int = DEFAULT_LAND_WINDOW_DAYS` on `Conventions`
  beside `prs_per_tick` (`:148`) — PD4, PD5.
- `docs/products.example.yaml` — the one commented line from §2.6's fence in the `conventions:`
  block (PD12).
- `tests/test_views.py` — `SpanTests` (new, §3.5): the eight buckets, the negative, and `age`'s
  agreement with `span` over a known timestamp.
- `tests/test_conventions.py` — `DefaultsTests.test_every_documented_default_is_what_the_card_says`
  grows `land_window_days` in the tuple it already asserts; `ModuleConstantsTests` grows
  `self.assertEqual(conv_mod.DEFAULT_LAND_WINDOW_DAYS, c.land_window_days)` (`:260`, PD5).

**Steps**

1. Add `span(seconds)` to `asf/views/index_reader.py` exactly as §2.4's fence has it: `max(seconds, 0)`
   then the three buckets, `25m` / `5h` / `3d`.
2. Rewrite `age(ts)` as `parse_ts`, `'—'` when it fails, else `span` of the difference from
   `dt.datetime.now(dt.timezone.utc)`. Nothing else in the module moves.
3. Declare `DEFAULT_LAND_WINDOW_DAYS = 7` in `asf/conventions.py` and the `land_window_days` field on
   `Conventions`. This is the only literal `7` for the window in the tree (PD4).
4. Document the key in `docs/products.example.yaml`'s `conventions:` block, one line, §2.6's comment.
5. Write `SpanTests` in `tests/test_views.py`: `0 → 0m`, `59 → 0m`, `60 → 1m`, `3599 → 59m`,
   `3600 → 1h`, `172799 → 47h`, `172800 → 2d`, `-5 → 0m`; then `age(ts)` over a timestamp three days
   back equals `span` of the same difference, and `age(None) == '—'`.
6. Extend the two `tests/test_conventions.py` assertions.
7. Run the Gate.

`SpanTests` covers `span`: 0s → `0m`, 59s → `0m`, 60s → `1m`, 3599s → `59m`, 3600s → `1h`,
172799s → `47h`, 172800s → `2d`, a negative → `0m`; and that `age(ts)` over a known timestamp is
what `span` gives for the same difference, with `age(None)` still `—`. The tick's existing bucket
test is named as the regression for the module that keeps its own.

`check_conventions.sh` is named because §2.6 adds one config key: it must be read through
`Conventions.get` with a default and never spelled a second time at a call site.
