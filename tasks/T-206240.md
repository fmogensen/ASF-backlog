**Steps**

1. Create `asf/kernel/findings.py`, pure — it imports `asf.reviews` and `asf.evidence.rulings`
   for two readers and nothing from `asf.kernel.decide` (circular). A module docstring in the
   house voice naming what a finding's identity is for: the closed set, the ruled set and the
   contradiction.
2. `stamp(text, head)` → `'[%s@%s] %s' % (key_of(text), head[:7], text)`, and `parse(line)` →
   `(key, head, text)`. A line with no stamp parses as `(key_of(text), '', text)` — every finding
   written before this change. `stamp` is idempotent on an already-stamped line: it re-stamps the
   parsed `text`, never the stamp, so the same defect on a later head keeps its key and carries
   the new head.
3. `key_of(text)` — eight hex characters of `sha1` over
   `line_key(text) + '\x00' + normalize(rest)`, with `normalize` imported from `asf.reviews`
   (`asf/reviews.py:145`, D-0004) and `rest` the text with its `path:line` token removed.
   `line_key(text)` is the first `path:line` token the text names, normalized — the handle a
   contradiction is detected on, and `''` when the text names none.
4. The typed prefixes keep their meaning once stamped, because every predicate reads the parsed
   text and not the line: add no predicate here, and assert in step 11 that
   `decide.rebase_finding`, `decide.shared_finding`, `RED`, `ANSWERED` and `ESCALATED`
   (`asf/kernel/decide.py:243`, `:246`, `:415`, `:348`, `:422`) each still match their own line
   after a stamp — through `parse`, which is the one call a predicate's caller gains.
5. `closed(it)` and `ruled(it)` read the card's two key sets off the item.
   `drop_known(findings, it)` → `(kept, reraised)`: a finding whose key is in either set is
   dropped and returned as a re-raise, order preserved, each key once.
   `contradiction(findings, it)` → `(line_key, earlier, later)` or `None`: one is found when a
   finding's `line_key` matches a key over the same line in `closed(it)` **whose text key
   differs**, and the line is not already in the card's escalated set. At most one per
   `(item, line_key)`.
6. `ruled_by(text)` — the keys an operator answer or a card ruling settles: the keys the text
   names outright, and every closed-or-raised key whose `line_key` the text names. The
   `## History` ruling line is read with `asf.evidence.rulings.HISTORY_RULING_RE`
   (`asf/evidence/rulings.py:26-29`) — the regex reused as a reader, never the lane gate
   (`reraised_only` at `:146` is not touched, §1.1 Out).
7. `asf/kernel/ports.py`: three machine-block keys beside the others at `:67-68` —
