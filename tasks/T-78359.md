## Description
stories: S-76259
writes: asf/hooks.py, tests/test_hooks_recognise.py, tests/test_install.py, tests/test_hooks.py
after: Task 1, Task 5

The spec's §6. Last on `asf/hooks.py`: it replaces the three-alternative upgrade chain in **both**
`ensure_git_hooks` and `plan` with one `hook_upgrade`, so it should not run while another Task is
editing the same two call sites. `init.PRE_COMMIT` and `init.PRE_PUSH` are **not** edited (C14),
and `hook_entry`'s rule for a bare name is not edited either (P19) — after the rewrite there is no
bare name left in the line to read.

**Files**

- `asf/hooks.py` — a new `init_cli_upgrade(text, name, asf_path)` and a new
  `hook_upgrade(text, name, asf_path, product_name, pin_required)` (**PD5**: five parameters, not
  §6's four), with §6's docstrings; `ensure_git_hooks`' chain (`:370-371`) and `plan`'s
  (`:477-478`) both replaced by one `hook_upgrade` call.
- `tests/test_hooks_recognise.py` — `init_cli_upgrade` over both init bodies, the recognisers over
  the rewritten text, and the three None arms.
- `tests/test_install.py` — `ensure_git_hooks` over a pinned product whose record hooks are init's,
  and over an unpinned one; the `_git_hook_body` call at `:3544` updated for Task 1's arity if
  Task 1 left it.
- `tests/test_hooks.py` — `plan` reporting the row as `upgrade` and `tracked`, and `install` and
  `plan` agreeing row for row through the one `hook_upgrade`.

**Steps**

1. `init_cli_upgrade(text, name, asf_path)`: None unless `init.INIT_MARKER` is in `text`; None
   unless `dispatch.is_ours(asf_path)` (C15 — a hook is moved onto the pin, never off it); None
   when `shlex.quote(asf_path) != asf_path` (**PD2**); else `text` with each command line's bare
   `asf` replaced by `shlex.quote(asf_path)`, and None when that changes nothing.
2. The match is `re.compile(r'(?m)^([ \t]*(?:exec[ \t]+)?)asf(?=[ \t])')` — the command word at the
   start of a line, `exec` allowed before it, only the bare name. Measured over both real bodies:
   it rewrites exactly `asf check --staged || exit 1` and `exec asf redact --pre-commit` in
   `init.PRE_COMMIT` (2 of 16 lines) and exactly `exec asf redact --pre-push` in `init.PRE_PUSH`,
   leaving `top="$(git rev-parse --show-toplevel)"`, the `ASF_HOOK_RUNNING` guard, the `cd`, and
   every `#` comment — `asf init`'s own, which carry the `INIT_MARKER` — byte-identical.
3. **PD2 is not optional.** Measured, without the `shlex.quote(asf_path) != asf_path` condition
   and with a dispatcher path that needs quoting (a HOME with a space), the rewrite yields
   `exec '/…/My Op/.local/bin/asf' redact --pre-push`, for which `is_git_hook_ours` is **False**
   and `hook_entry` is **None** — `_ENTRY_TOKEN`'s path prefix (`[^\s"'\n]*/`, `asf/hooks.py:194`)
   cannot span a space. `ensure_git_hooks` would then write that file and, on every later run,
   refuse it: `NEEDS OPERATOR: <path> is not asf's — add the line: …`, with `verify` calling it
   `is not asf's` and the doctor row calling it `foreign`. Today's `_git_hook_body` with the same
   path is still `is_git_hook_ours` True (measured), so this would be a regression, not an
   inherited limit. With the condition, such a host keeps bare `asf` and the honest red row it has
   today. Pin both halves in `tests/test_hooks_recognise.py`: the rewrite happens for an ordinary
   path, and `init_cli_upgrade` returns None for one needing quotes.
4. `hook_upgrade(text, name, asf_path, product_name, pin_required)`:

   ```python
   up = (init_hook_upgrade(text, name) or staged_check_upgrade(text, name)
         or _own_upgrade(text, name, asf_path, product_name, pin_required))
   return init_cli_upgrade(up if up is not None else text, name, asf_path) or up
   ```

   Composed, not a fourth `or` — that is what makes one pass enough (C16), and §6's four-parameter
   signature cannot call Task 1's five-parameter `_own_upgrade` (**PD5**). Measured against a real
   dispatcher on disk, all five arms: a current own body → None; a stale own bod
