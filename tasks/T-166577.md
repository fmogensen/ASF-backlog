**Files**

asf/kernel/ports.py, asf/kernel/briefs.py, asf/kernel/decide.py, tests/kernel/test_beat_settle.py

**Steps**

1. `asf/kernel/ports.py`: `RealSessions.end(session, free_worktree)` gains a settle step, and only
   for a session the beat ended (`session.beat` in frozen, looping, no-first-beat): stop it
   through the paths `end` already uses, then `heartbeat.last_beat`, then
   `heartbeat.land_snapshot(worktree, branch, beat)` so the work in progress becomes a `wip:`
   commit on the branch, then `heartbeat.delete_ref`, then `heartbeat.clear_ended(product)` for
   any ref whose run is over.
2. A branch that has moved past the last beat is left as it stands and the line says so; a beat
   whose tree equals the branch head's adds no commit; a settle that cannot reach origin ends the
   session anyway and says what it could not do. Ending a session the beat did **not** stall
   settles nothing and leaves its ref for `clear_ended`.
3. The dead run's notes and `heartbeat.summarize_events(heartbeat.log_records(log))` are written
   to its ledger row as `beat_notes` and `beat_summary`, and `resumes` is incremented.
4. `asf/kernel/briefs.py`: `RealBriefs` appends a `CONTINUE` block to the next brief for the same
   item when its last run ended on a beat verdict and carries `beat_notes` — the shape of
   `heartbeat.continue_text`, fed from the ledger rather than a file on disk, and saying that only
   the new session's own `ASF-Session` counts, so a zombie push is never read as its work.
5. `asf/kernel/decide.py`: an item past `kernel.heartbeat.max_continues` is not relaunched — it
   goes to Stuck with `owner: operator` and the beat's reason, through the Stuck path that already
   exists. The count is read off the ledger's `resumes` on the session fact (`beats`).
6. The kernel calls neither `heartbeat.sweep` nor `heartbeat.launch`: the continuation is the
   kernel's own next tick, so one wave owns the seat.
7. Create `tests/kernel/test_beat_settle.py` with one case per acceptance line, over a temporary
   bare origin and a real worktree, with the fake ports of `tests/kernel/fakes.py` for the
   relaunch half.
