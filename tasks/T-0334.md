§2.2's eighth row, and §3's `NoOtherWriterTests` — the test that *is* Acceptance 1. Eighteen
modules, one line each: a wide Task with a shallow diff, cut this way because the test is
tree-wide and a half-routed tree fails it.

**Files**

- `asf/metrics/log.py` — two functions (PD13):
  - `needs_operator_text(what, fix=None) -> str` — the pure formatter, `NEEDS OPERATOR: <what>`
    with ` — <fix>` when a fix is given. The one place the literal is composed.
  - `needs_operator(out, text, *, product=None, root=None, item=None, key=None)` — prints `text`
    on `out` **and** appends a `needs-operator` event through `emit`, `key` defaulting to the
    text's first 120 characters. No product, or no resolvable root: it prints and appends
    nothing. Never raises.
  - `NEEDS_OPERATOR = 'NEEDS OPERATOR: '` as the module constant, so a site that must test a
    string (`asf/workers/wave.py:91`, `asf/groom/digest.py:139`) compares against it instead of
    re-typing it.
- The printing sites — one call each, the line's text unchanged byte for byte so no operator's
  eye has to relearn it: `asf/doctor.py:794`, `asf/init.py:288`, `asf/schema.py:137`,
  `asf/scheduler.py:298,404`, `asf/upgrade.py:198,552,562`, `asf/console_perms.py:136`,
  `asf/tick/tick.py:388` (which already raises the event and now stops composing the string
  itself), `asf/tick/step_health.py:55`, `asf/tick/file_bugs.py:297,407,533`,
  `asf/tick/flaky.py:372`, `asf/workers/wave.py:96`, `asf/groom/digest.py:122`,
  `asf/approvals.py:1022`.
- The **returning** sites take `needs_operator_text` and nothing else (PD13):
  `asf/hooks.py:165,168,192,207,329`, `asf/scheduler.py:414,458,460`, and
  `asf/cli.py:358`'s `needs_operator_line`, which becomes a two-line wrapper over it — the one
  site that by construction has no product (it is `main`'s `except env.ConfigError`).
- The **reading** sites take the constant: `asf/workers/pool.py:66`'s `REASON_NO_QUOTA` and
  `asf/workers/wave.py:91`'s `reason.startswith(...)` are two halves of one contract and must name
  the same string; `asf/groom/digest.py:139`'s `s.startswith(...)` likewise.
  `asf/groom/digest.py:20`'s `NEEDS_OPERATOR_ID_RE` parses a *session's* report, not the factory's
  log, and keeps its own pattern — built from the constant, so the two cannot drift.
- `tests/test_log_render.py` — **new**, `NoOtherWriterTests` only (the renderer's classes are
  Task 4).

   and is excluded outright. Assert the exemption table itself is exactly those two entries, so
