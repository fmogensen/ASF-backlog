The same verdict as a periodic check, so `asf rules check` can carry the rule card — and the
constitution line that has been recited since the record began stops being a recitation. Runs after
Task 1 (`asf/cli.py`) and Task 6 (`asf/harvest/refine.py`, `tests/test_refine.py`).

**Files**

- `asf/harvest/refine.py` — `cmd_refine_check` (PD8).
- `asf/cli.py` — the `refine-check` subparser beside `harvest` (`asf/cli.py:114`).
- `rules/refine-not-rewrite.sh` — new, and with it the repo's core rules directory, which
  `rules.core_rules_dir()` and `hooks.RULES_DIR` already point at (`asf/rules/rules.py:43-51`,
  `asf/hooks.py:38`).
- `docs/CONSTITUTION.md` — directive 1's TRIGGERS line (`docs/CONSTITUTION.md:47-48`), the tally row
  (`docs/CONSTITUTION.md:265`) and the closing count (`docs/CONSTITUTION.md:275`).
- `tests/test_refine.py` — `RefineCheckCommandTest`.
- `tests/test_cli.py` — `idea` and `refine-check` in the subcommand list.

**Steps**

1. `asf refine-check [--product P] [--branch B] [--json]`: `refine_refusal` over every `spec`/`plan`
   lane branch on the product repo's origin, using the existing remote-tracking refs — it fetches
   nothing, so it stays inside the rule runner's 10 s. One line per rewriting branch,
   `spec/F-0023 docs/specs/f-0023.md: 3 anchor(s) the document on main carries are gone: "## Records", …`,
   and exit 1 when there is one; silence and exit 0 when there is none.
2. `rules/refine-not-rewrite.sh`, three lines, `exec asf refine-check --product "${ASF_PRODUCT:?}"`,
   executable. It names no path and no id — `tools/check_generic.sh` is the gate on that.
3. `docs/CONSTITUTION.md`: directive 1's TRIGGERS line becomes ``**TRIGGERS: checked.** The
   interrogator is `asf idea` ([[F-0023]]); the harvest holds a spec or plan branch that drops an
   anchor of the document already on the trunk, and `asf refine-check` is the rule's check.`` The
   tally row for directive 1 becomes `checked`, and the closing "Four of ten are decoration today"
   becomes three.
4. The rule **card** is not minted here (D10): `R-nnnn` comes from `asf new rule` in the record when
   this work lands, and the report's `NEEDS OPERATOR` line carries the command.
