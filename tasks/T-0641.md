The spec's `## The design` §1 and §2 in full, and nothing else. After this lands there is one
module that answers *is this Task's work already on the trunk?*, the minter asks it before a plan
section becomes a card, and `closing`'s `reconciled` rule — live since it was written and never
once reached — finally decides a Task by the sha in its own frontmatter.

**Read PD1 first.** This Task carries the hunk the measurement indicts (`asf/record/plan_tasks.py`,
the `found = …` / `state = 'Closed'` block). Build it as the spec writes it; do not add a fourth
guard, do not soften it, and do not skip it — but do not be surprised if the ruling on the
`NEEDS OPERATOR` line removes it, because that hunk is deliberately a single contiguous block so
it can be removed without touching anything else in this Task.

Three things are load-bearing. `satisfied_on_trunk` has **one** `return` that is not `None` and
every branch before it returns `None` — the timid default is structural, not remembered (C4);
write it that way even where an early `return None` looks redundant. The mint writes `state:
'Closed'` **and** typed `landed:`, and it needs both for different reasons: `do_index` runs after
`plan-tasks` in the same record step and the wave plans off that index, so a Task left `New` for
one tick is a seat spent (C5) — while `landed:` is what every *later* tick reads, so the close
derives from `reconciled` rather than being held by `sticky`'s *"held Closed; planned would say
New"*. And `plan_order.backfill(only=ids)` on the line after already skips a card in `DONE_STATES`
(`asf/record/plan_tasks.py:96-99`), so a closed-by-trunk Task gets no `after:` and needs no guard
of its own.

Read **PD4 before writing `close_by_trunk`'s signature** (it takes `product=None` and passes it
down; nothing wraps it), **PD5 before writing `card_body`**, **PD6 before writing
`_completing_commit`**, **PD7 before adding any string literal to the new module**, **PD10 before
building a fixture**, and **PD14 before putting a test method anywhere but on a leaf class**.
