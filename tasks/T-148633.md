**Steps**

1. In `asf/views/index_reader.py`, add `milestone_of(items, item)` and `in_milestone(items,
   name)` exactly as §3 writes them, beside `epic_of` (`:106-115`): the item's own `milestone`
   first — so the card's own value wins — else the nearest ancestor's up the `parent` chain, else
   None, with `epic_of`'s `seen` set so a parent cycle returns rather than hangs. Keep the module
   **stdlib-only and importing nothing from `asf.record`** (Precondition 5): both are dict walks,
   and that contract is what lets `asf.release` call them without pulling the record package into
   a view. No derived key is added to any `index.json` entry (D-0004) — the resolution is on read.
2. `new._COMMON_SET` (P7) gains one entry, `milestone`, which opens both `asf new --set
   milestone=v0.3` and `asf set <id> milestone=v0.3` at once (D7) — `setfield.parse_assignments`
   falls through to the same `_parse_sets` (`setfield.py:152-158`). Do **not** put it in
   `SET_ONLY` and do **not** validate it in either parse half: neither `_parse_sets(type_, pairs)`
   nor `parse_assignments(type_, pairs, canonical=None)` takes a record root (P10, re-measured),
   and reading `milestones.md` needs one.
3. Validate in the two commands, which both have the root and both already resolve and refuse
   before the first card is written (`setfield.py:213-222`): `cmd_new(args, root)` and
   `cmd_set(args, root)` each read `milestones.declared(root)` and refuse an undeclared name with
   the spec's wording — `error: milestone=v0.4 — not declared in milestones.md (declared: v0.2,
   v0.3)` — writing nothing.
4. Extend `tests/test_work_item_model.py` with `EffectiveMilestone`. Over the spec's index
   fixture — an Epic with `milestone: v0.3`, a Feature under it with none, a Story under the
   Feature with `milestone: v0.2`, a Task under the Story with none, and a parentless Decision
   with none — `milestone_of` returns `v0.3`, `v0.3`, `v0.2`, `v0.2`, `None`;
   `in_milestone(items, 'v0.3')` is the Epic and the Feature and `in_milestone(items, 'v0.2')` is
   the Story and the Task. So a Story that carries one shadows its Feature's for itself and its
   own children, and a Task under a Story under a Feature reads the Feature's when neither it nor
   the Story carries one. Add: a two-card parent cycle returns rather than hangs; a chain broken
   by a retired ancestor stops at the break, as the walk to the Epic already does; a card with no
   parent reports its own, or none when it carries none.
5. Then the commands, in the same class: `asf set <id> milestone=` refuses an undeclared name
   before it writes and writes a declared one; `asf new --set milestone=v0.3` does the same; and
   a milestone written on a card reaches that card's entry in `index.json` **with no other entry
   changing** — which is P8's derivation doing it with no code, and the fence on D-0004.
