§1.1's last bullet and §3/T6: the card's second acceptance holds today — a relaunch's worktree is
created at `origin/<branch>` and rebased onto the trunk (P10), and the launch line records
`launch_head` (P9) — and has no test. It gets one. Tests only; no product code changes, and if one
looks necessary the assumption is wrong and the finding belongs in a report, not in a widened Task.

**Files**

- `tests/test_workers.py` — `RelaunchHeadTests`

**Steps**

1. Build on the existing `Home` fixture (`tests/test_workers.py:74-99`): a temp `ASF_HOME`, a product
   whose repo is a clone of a bare origin, `hooks.ensure_git_hooks` already patched.
2. Push a branch to origin with two commits, then make a worktree for a second run of the same job
   through `spawn.make_worktree(self.product, <job>, branch, kind=…)` — the path the other
   worktree tests already take (`:951`, `:971`).
3. Commit in it, then assert the old head is `git rev-parse HEAD~1`, **or** that
   `lifecycle.rebase_of(wt, worktree_head(wt), old_head, main)` is true when the trunk moved under it
   (P11) — the two readings of "on top of the old head", and the second is the one a moved trunk
   leaves.
4. Assert the launch line records `launch_head` equal to the sha origin held at launch: call
   `spawn._launch_head(self.repo, branch)` (`asf/workers/spawn.py:750-756`) against
   `git rev-parse origin/<branch>` after `make_worktree` has fetched it.
5. Assert a worktree reused while behind origin is caught up before the commit rather than diverging:
   move origin's branch forward, reuse the worktree, and assert its HEAD contains origin's sha
   (`merge-base --is-ancestor`) — `spawn._catch_up` (`:440-467`) is what does it.
6. No `asf/**` file is touched by this Task. If a case cannot be made to pass without one, stop and
   report it rather than editing product code from here — the writes line is the footprint.
