**Steps**

1. Create `asf/logs.py`. Module-level imports: the stdlib and `asf.env`, nothing else of the
   package — it is called from the installer, the hook and a clock's exit path. The docstring and
   the constants of §1 as the spec writes them, comments included: `LOG_MAX_BYTES = 4 << 20`,
   `CLOCK_LOG_MAX_BYTES = 16 << 20`, `GENERATIONS = 1`.
2. The path accessors of §1: `tree()` returning `env.log_dir()` (`asf/env.py:1078-1081`), never a
   second definition of the path; `path(*parts)`; `clock_path`; `host_clock_path`; `kernel_path`;
   `jobs_dir`; `job_path`. Each renders the name its current minter renders, character for
   character — `tick-<product>-<clock>.log`, `<clock>.log`, `kernel-<p>.log`,
   `kernel-watch-<p>.log`, `jobs/<p>/<job>.jsonl` — and creates the parent directory.
3. `cap_for(name)` — the cap of the log this module *rotates* under that basename:
   `CLOCK_LOG_MAX_BYTES` for a transcript the scheduler or the kernel renders (`tick-*`,
   `kernel-*`, `kernel-watch-*`, `net-probe`); `LOG_MAX_BYTES` for the two asf rotates per write
   (`approvals-hook.log`, `harvest-gate-red.log`) and for a detached child's (`harvest-*`,
   `product-checks-*`, `rebuild-check-*`); `None` for every other name — the installer's ledger
   and a log with no asf opener alike. No exception list: a name it does not rotate has no cap.
4. The seven hand-built paths delegate, each function keeping its name and signature:
   `asf/scheduler.py:242` → `logs.clock_path`, `:728` → `logs.host_clock_path`,
   `asf/kernel/host.py:69` and `:74` → `logs.kernel_path`, and one `logs.path(...)` each at
   `asf/install.py:763`, `asf/harvest/product_checks.py:124` and
   `asf/harvest/rebuild_check.py:131`.
5. The two job-transcript spellings become one: `asf/workers/runtime.py:101-105` and
   `asf/metrics/metrics.py:1943-1945` both return `logs.job_path(...)`; the two callers that
   recovered the directory with a fake job name (`asf/metrics/metrics.py:2126`,
   `asf/improve/measure.py:156`) call `logs.jobs_dir(name)`.
6. `asf/install.py` gets its path from the module and nothing else: the `open(path, 'a')` two
   lines below `:763` is left exactly as it stands, and it gets no rotation here or later (`K11`).
7. Create `tests/test_logs_tree.py` with `PathTests` — the path half of `S-134155`, one case per
   acceptance line, down to the grep of §6 that says the tree has one owner and the line that
   holds the ledger's own open. Every case runs over a temporary `ASF_HOME` with `env.ASF_HOME`
   patched, never the operator's home.
