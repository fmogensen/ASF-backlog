## Description
stories: S-18801
writes: asf/conventions.py, docs/products.example.yaml, tests/test_conventions.py, tests/test_env.py
after: Task 1

§2.2. Two nested blocks folded onto flat fields by the mechanism `harvest:` already uses, every
field with a documented module-level default, and both blocks documented in the example product —
which `tests/test_env.py` makes a checked artifact rather than a comment. This is also where the
`train` branch prefix is minted, and therefore where `train/` becomes a literal the package may
never write again (PD7).

**Files**

- `asf/conventions.py` — `DEFAULT_BRANCH_PREFIXES` gains `'train': 'train/'` (`:40`);
  `SIZE_KEYS` and `TRAIN_KEYS` beside `HARVEST_KEYS` (`:90`); the seven module-level defaults of
  §2.2; seven `Conventions` fields; the fold in `_from_mapping`'s nested-block pass (`:197`); and
  `size_config()`.
- `docs/products.example.yaml` — the `size:` and `train:` blocks under `conventions:`, beside
  `area_depth`/`batch_max_globs`, with §2.2's two comment paragraphs verbatim.
- `tests/test_conventions.py` — the fold, the defaults, the union, the new prefix.
- `tests/test_env.py` — the example product still validating clean with both blocks
  (`tests/test_env.py:264`).

**Steps**

1. `SIZE_KEYS` and `TRAIN_KEYS` exactly as §2.2 fences them, and the same treatment `HARVEST_KEYS`
   gets in `_from_mapping`: a key inside the block that the map does not name is kept in `extra`
   rather than dropped, so a product yaml is never silently narrowed.
2. The seven defaults, each on its own documented line: `DEFAULT_SMALL_MAX_FILES = 3`,
   `DEFAULT_SMALL_MAX_FILES_BY_KIND = {'docs': 15, 'copy': 15}`, `DEFAULT_MEDIUM_MAX_FILES = 15`,
   `DEFAULT_KIND_PATHS = {}`, `DEFAULT_NEVER_SMALL_PATHS = []`, `DEFAULT_TRAIN_LANES = []`,
   `DEFAULT_TRAIN_MAX_TASKS = 6`, `DEFAULT_TRAIN_MAX_AGE_S = 7200`. Two of them are empty
   containers on purpose: no product's tree is known here, and no train opens until an operator
   names a lane (D15).
3. `Conventions.size_config()` → `size.SizeConfig(...)` with
   `never_small_globs = list(self.size_never_small_paths) + list(self.amendable_paths)`. The union
   is built here, once — neither the classifier nor the cutter remembers it (D6), and a product
   that lists a path in both gets it once, deduplicated in order.
4. `'train': 'train/'` in `DEFAULT_BRANCH_PREFIXES`. Three consequences to hold in the same diff:
   `all_prefixes()` gains it, so `harvest.remote_branches` now *sees* train branches (PD14, safe —
   they carry no session record); `conv.branch('train', name)` yields `train/<name>`; and
   `python3 -m asf.conventions --forbidden` now emits `['"]train/`, so `check_conventions.sh` in
   this Task's own Gate is the proof that no package file writes it (PD7).
5. `docs/products.example.yaml` gains both blocks with the comments §2.2 gives, unedited — they
   are the operator's only documentation of what `never_small_paths` is for and why
   `amendable_paths` joins it for free.
6. `tests/test_conventions.py`: `size:` and `train:` folded onto their flat fields; an unknown key
   inside either kept in `extra`; every field at its documented default with both blocks absent;
   `size_config()` unioning `never_small_paths` with `amendable_paths`, and doing so when
   `never_small_paths` is absent entirely; `train_lanes` defaulting to `[]`; `conv.branch('train',
   'code-20260924-0930')` → `train/code-20260924-0930`; and `all_prefixes()` containing `train/`.
7. `tests/test_env.py`: the example product validates clean with both blocks, and a product yaml
   carrying `size: {small_max_files: 5}` alone resolves the other four to their defaults —
   a partial block is a partial block, not a reset.
