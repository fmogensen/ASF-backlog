§2.6. "Already filed today" becomes "filed inside this signature's own window", with
`DEFAULT_REFILE_DAYS = 1` as the default that reproduces the old guard exactly. A source that
wants a slower cadence says so in the dict it already returns. Nothing asks for one yet — Task 4
does — so this Task changes no card the filer writes today, which is what makes it provable on
its own.

**Files**

- `asf/tick/file_bugs.py` — `DEFAULT_REFILE_DAYS = 1` with §2.6's comment; `_too_soon(last_filed,
  date, refile_days)`; `_file_or_bump_bug`'s guard (`:164-165`) calling it with
  `info.get('refile_days', DEFAULT_REFILE_DAYS)`; the module docstring's sentence about the
  same-day no-op (`:8-9`) gains the window.
- `tests/test_file_bugs.py` — `RefileWindowTests` (new), beside `FileBugsIntegrationTests`
  (`:219`).

**Steps**

1. `DEFAULT_REFILE_DAYS = 1`, with §2.6's comment: 1 is "not again today", which is what the guard
   has always meant.
2. `_too_soon(last_filed, date, refile_days)` → True when `last_filed` is inside the window:
   `(date - last_filed).days < refile_days` over two `datetime.date.fromisoformat(str(...))`, and
   string equality when either end will not parse (P15). A missing `last_filed` is never too soon.
3. `_file_or_bump_bug`'s `if typed.get('last_filed') == date:` becomes
   `if _too_soon(typed.get('last_filed'), date, info.get('refile_days', DEFAULT_REFILE_DAYS)):`,
   still returning `'skipped'`. Nothing else in the function moves: the title stays as first
   filed, and only `count`, `last_filed` and `links` are rewritten.
4. The module docstring's third paragraph says the guard is the signature's own window and that
   the default is the day, so the one place a reader learns the rule states it once.
5. `RefileWindowTests`: `_too_soon` over the matrix — same day / one day back / six back / seven
   back at `refile_days` 1 and 7; a `last_filed` that will not parse skipped only on an exact
   string match; a `None` never too soon. Then through `_file_or_bump_bug` with a hand-written Bug
   card: a CI-failure Bug filed yesterday still bumps today and one filed today is still
   unchanged — the default `refile_days` of 1 is the old guard exactly — and an info dict carrying
   `refile_days: 7` is skipped at six days back and bumps at seven, bumping `count` 1 → 2, setting
   `last_filed` to today and appending one `## History` line with the title untouched.
