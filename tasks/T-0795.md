Read **PD3** (`plan_inputs`, not a hand-rolled `adjudications` — the overlay is the whole point) and
**PD5** (the Bug's reason prefix, which Task 3 will produce, is not a defect) before starting.

**Files**

- `asf/feeder/rows.py` — one string. `_capped`'s PARKED reason (**:2212-2215**) ends
  `` …, on this same card: a card edit, a ruling (`asf correct {row.item_id} --why …`) or `asf
  unpark {row.item_id}` moves it `` in place of today's `a card edit or a person's decision moves
  it`. The action (**:2217**) and the `waits_on` (**:2219**) are unchanged; D7 is why both commands
  are named and not only one. Nothing else in `_capped` is touched in this Task.
- `asf/views/status.py` — `parked_cell` gains an optional trailing `root` (D6: two existing callers
  pass `None` meaning *product*, and an optional trailing argument keeps both correct), plus one
  helper and one block:
  - `_stalemate_parks(product, root)` — `{}` when `root` is falsey or carries no `index.json`
    (`os.path.isfile(os.path.join(root, 'index.json'))`), never `not_configured(…)` (**PD3**);
    otherwise `{item: adj for item, adj in step_wave.plan_inputs(product, root)['adjudicated'].items()
    if adj.get('same_card') and not (adj.get('ruling') and not adj.get('carried'))}` — a park is
    listed only when it is really parked, never when a ruling is on its way to a session. The
    import is function-local, the idiom `build_cell` (**:419**) and `decisions_cell` (**:440**)
    already use.
  - `parked_cell(product, root=None)` — after the two existing comprehensions (**:457-462**) and
    before the `if not parked:` (**:463**), one more: `parked += [(iid, 'item', f"adjudicated
    {adj.get('runs') or 1} time(s), last {str(adj.get('at') or '?')[:16]}, on this same card")
    for iid, adj in sorted(_stalemate_parks(product, root).items())]`. The count, the three-entry
    truncation, the `(+N more)` suffix and the trailing
    `` · `asf unpark <item|branch|job>` releases one `` are all unchanged.
  - the table's call site (**:759**) becomes `parked_cell(product, root)`; `root` is already in
    scope there. Every other caller keeps working unchanged.
- `tests/test_cli.py` — `ParkedCellTests`, new: `parked_cell(product)` with no `root` reads exactly
  as it does today (P9, D6); given a `root` whose `index.json` and ledger carry an over-limit item
  adjudicated on this same card, the cell counts it, scopes it `item`, names the run count and the
  stamp, and still ends with the release line; an item whose adjudicate ruling is uncarried is
  **not** listed, because a session is about to act on it; a `root` with no `index.json` adds
  nothing and raises nothing. `ScopedParkTests` (**:335**) and its `parked_cell(None)` call
  (**:477**) are **not** edited and must stay green.
- `tests/test_hidden_work.py` — `RulingLiftsParkTest` (**:237**) gains **one** assertion on the
