The spec's §3 and the card's own named test. The `reword_refused` memo, merged onto the branch's lane
record **without a state transition**, read against `f['head']` before any git call, and cleared by a
reword that pushes. This is the change that turns 48 lines a branch into one.

Read **PD8** (`memo_refusal` must leave `state`, `head`, `head_at` and **`reason`** alone, and
`test_a_second_lease_race_defers_with_no_session` is the pin on it) and **PD1** (P9: `record`'s
non-`None` filter is how `None` clears the field) before starting.

**Files**

- `asf/harvest/lane.py` — `Lane.memo_refusal` beside `record`/`write` (`:1706-1738`); the memo read at
  the top of `_repair_naming` (`:1989`); the memo write in the deferral block (`:2048-2053`); the
  clear on the pushed tail (`:2055-2069`)
- `tests/test_lane.py` — A2's two tests, added to Task 1's class

**Steps**

1. `memo_refusal`, in the `# ---- writing ----` section beside `record` and `write`
   (`asf/harvest/lane.py:1704-1738`), byte for byte from the spec's §3:

   ```python
   def memo_refusal(self, f, **fields):
       """Merge fields onto the branch's lane record, leaving its state and head alone."""
       rec = dict(f.get('prev') or {}, **fields)
       self.write(f, rec)
       f['prev'] = rec
       return rec
   ```

   It builds on `f['prev']`, **never** on `self.record(f, …)` — a `record` call would rewrite
   `reason` and redden `tests/test_lane.py:1789` (PD8). `write` mints the synthetic adopted run when
   none owns the branch (P9), so a memo survives on a branch with no session.

   **before** the `kind` and `live` checks — a memoed branch must not print the `live session` line
   either. `DEFERRED` is right: no session is started and no hold is written, which is exactly what
