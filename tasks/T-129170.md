## Description
stories: S-102505
writes: asf/feeder/rows.py, tests/test_feeder.py
after: none

Design §1 and nothing else. One constant, one predicate, and `replan_branch` minting from the
constant — **read by nothing but its own test**, which is the point of landing it first: Task 2's
three readers find it already on the trunk, and this diff cannot break a reader because it has none
(**PD1**).

**Files**

- `asf/feeder/rows.py` — `REPLAN_SUFFIX = '-replan'` beside `REPLAN_KIND` (`:160`), with the spec's
  two comment lines; `is_replan_branch(product, branch)` beside `replan_branch`, which is
  `:1676-1680` and **not** the `:1657-1661` the spec cites (**PD3** — grep for
  `def replan_branch`); `replan_branch`'s body becomes
  `branch_for(product, 'plan', f'{fid}{REPLAN_SUFFIX}')`.
- `tests/test_feeder.py` — new `ReplanBranchTests`, the seven acceptance lines of S-102505.

**Steps**

1. Add `REPLAN_SUFFIX = '-replan'` beside `REPLAN_KIND` (`:160`) with the spec's comment as
   written: the suffix `replan_branch` adds and the one string `is_replan_branch` reads back.
2. Change `replan_branch`'s return to `branch_for(product, 'plan', f'{fid}{REPLAN_SUFFIX}')`. Its
   docstring already says why the name is what it is; leave it, and add
   `:func:`is_replan_branch`` as the inverse it now has.
3. Add `is_replan_branch(product, branch)` after it, exactly as §1 writes it:
   `conv = _conventions(product)` (`:358` — it falls back to a default `Conventions()` for a `None`
   product, which is what makes the `None` and `''` acceptance lines answerable), then
   `conv.branch_kind(b) == 'plan' and conv.strip_prefix(b).endswith(REPLAN_SUFFIX)`.
   `branch_kind` is `asf/conventions.py:1304-1316` and `strip_prefix` `:1317`; **neither is
   touched** (D-0002), and the last acceptance line of S-102505 is the assertion that says so.
   Read the prefixes through those two methods and never a literal `'plan/'` — `check_conventions.sh`
   refuses the literal (**PD8**).
4. Write `ReplanBranchTests`. The seven lines, in order: `replan_branch(product, 'F-0002')` equals
   `branch_for(product, 'plan', 'F-0002' + REPLAN_SUFFIX)` for the fixture product **and** for a
   product whose plan prefix is nested, so neither assertion depends on the prefix; the predicate is
   `True` for exactly `replan_branch(product, 'F-0002')`; `False` for
   `branch_for(product, 'plan', 'F-0002')`, `branch_for(product, 'spec', 'F-0002')`, a code branch,
   the trunk, `''` and `None`, raising nothing on the last two; `False` for a plan branch of a card
   whose id merely ends in the suffix letters with no suffix of its own — build that one as
   `branch_for(product, 'plan', 'F-0002replan')`, which `strip_prefix` returns without a leading
   `-`; and `branch_kind` answering `'plan'` for both branches, unchanged. Use the module's existing
   `product()` helper for the fixture product and build the nested-prefix one with
   `Conventions(branch_prefixes=…)` in the shape the module already uses.
5. Run the Gate.

**Gate**

