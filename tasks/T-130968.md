**The preconditions, re-measured** — P1-P10, the facts the design is built on.

```bash
python3 - <<'PY'
import inspect, re
from asf import installs, scheduler, upgrade
from asf.kernel import host, loop, settings

K = ['/v/bin/python -m asf.cli kernel tick --product alpha',
     '/v/bin/python -m asf.cli kernel watch --product alpha',
     '/v/bin/python -m asf.cli tick --product alpha --steps prs']
print('P1', [bool(re.search(upgrade.MOVE_PATTERN, s)) for s in K])
print('P2', len(re.findall('kernel', inspect.getsource(upgrade))))
print('P3', re.findall(r"'([a-z.]+\.lock)'", inspect.getsource(upgrade.floor_busy)),
      'kernel' in inspect.getsource(upgrade.floor_busy), loop.LOCK_FILE,
      hasattr(loop, 'locked'))
print('P4', re.search(r'clock=\w+', inspect.getsource(upgrade.MoveOps.install_clocks)).group(0))
print('P5', scheduler.clock_of_plist('asf.alpha.kernel',
      {'ProgramArguments': K[0].split(), 'StartInterval': 120}, 'alpha', {}))
print('P6', [scheduler.noop_command(s.split()) for s in K])
print('P7', inspect.signature(scheduler.smoke),
      [l.strip() for l in inspect.getsource(scheduler.smoke).splitlines() if 'product_labels' in l])
print('P8', scheduler.SMOKE_TIMEOUT_S, host.SHADOW_TIMEOUT_S)
print('P9', inspect.signature(host.jobs), host.TICK, host.WATCH, installs.interpreter('/V'))
print('P10', sorted(settings.read(None)), [n for n in dir(host) if 'on_kernel' in n])
PY
```

**S-124906 — the kernel's two jobs are re-rendered at the new pin.**

```bash
python3 -m unittest tests.test_upgrade_kernel_floor.PinMovesTests
```

- [ ] a product with a kernel tick job definition on disk reads as on the kernel
- [ ] a product with no kernel tick job definition on disk reads as not on the kernel
- [ ] a kernel block in the product file alone does not make a product read as on the kernel
- [ ] a kernel product whose jobs are booted out still reads as on the kernel
- [ ] the kernel job names the move routes on are the two names the kernel host module declares
- [ ] a move of a kernel product writes both kernel job definitions
- [ ] both written kernel jobs name the pinned venv interpreter, not the moving process interpreter
- [ ] both written kernel jobs carry the intervals of the product file kernel block
- [ ] both written kernel jobs are loaded at the end of the move
- [ ] the kernel jobs are rendered by the kernel host renderer, not by a renderer in the move
- [ ] the pin the kernel jobs are rendered from is the one on record at that moment
- [ ] a move that only quiesced the kernel tick writes only the kernel tick
- [ ] a move of a product that is not on the kernel installs its 0.1 clocks exactly as it does today
- [ ] a move prints one line naming the kernel floor it found
- [ ] the dry run step list names the kernel renderer for the kernel half and one per clock install for the 0.1 half
- [ ] the dry run of a kernel product writes no plist and loads nothing

**S-124907 — a retired 0.1 floor is not written, not loaded and not retired.**

```bash
python3 -m unittest tests.test_upgrade_kernel_floor.RetiredFloorTests
```

- [ ] a move of a kernel product writes no plist for a paused 0.1 clock
- [ ] a paused 0.1 clock plist is byte for byte what it was before the move
- [ ] a paused 0.1 clock is not loaded by the move
- [ ] a paused 0.1 clock keeps its pause record through the move
- [ ] a move of a kernel product whose product file declares no clocks succeeds
- [ ] a move of a kernel product never asks the operator for a clocks block
- [ ] a move prints one line naming the retired 0.1 clocks it is leaving alone
- [ ] a move with no retired 0.1 clocks prints no such line
- [ ] each 0.1 clock the move quiesced is installed by its own per clock call
- [ ] the move makes no whole file scheduler install call
- [ ] a 0.1 clock the move did not quiesce is not written by the per clock calls
- [ ] the retire candidates of a product never include the kernel tick job
- [ ] the retire candidates of a product never include the kernel watch job
- [ ] the retire candidates still include a loaded 0.1 label the product file does not declare
- [ ] a kernel product with a loaded 0.1 clock refuses the move with an operator line naming the pause command
- [ ] that refusal pauses nothing, writes no pin, installs no venv and exits two
- [ ] that refusal is printed by a dry run too

**S-124909 — a refusal, a failed install and a failed smoke leave the floor on the pin that was running.**

```bash
python3 -m unittest tests.test_upgrade_kernel_floor.RollbackTests
```

- [ ] a failed floor install puts the pin back and says so with an operator line
- [ ] a failed floor install re-renders the kernel jobs from the pin it put back
- [ ] a failed smoke puts the pin back and re-renders the kernel jobs from it
- [ ] a failed smoke leaves both kernel jobs loaded
- [ ] a first pin whose floor install fails removes the install record and leaves the floor loaded
- [ ] a rollback re-renders the kernel jobs from the previous pin
- [ ] a rollback never prunes the venv the next rollback would need
- [ ] the move resumes exactly the jobs it paused, on every exit
- [ ] a drain that times out boots nothing out and leaves every kernel job loaded
- [ ] a signal mid drain resumes the kernel jobs it paused
- [ ] a killed move leaves pause records the next move lifts, for the kernel jobs too
- [ ] a move that has nothing to move touches no plist
- [ ] the hooks install and the host clocks step are unchanged by this card
