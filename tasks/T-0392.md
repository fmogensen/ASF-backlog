§2.1's second half and §2.2. One optional keyword on `wave()`, the ready-row derivation lifted out
of `left_out` into a function of its own, the count by subtraction, and four lines in `launch()`.
After this Task the card's first acceptance has its numerator and its denominator on every tick
line.

Three things this Task does **not** do, each for a reason the spec gives: it does not widen `wave()`'s
return (D3 — two production callers and a dozen test unpackings read a 2-tuple); it does not pass the
pool in from the step (D3 — that would flip `sample` and silently stop the headroom history the wave
records at the end of every tick, P8); and it does not read a wait reason (D2, and the whole of
§1.2's *"No wait reason becomes an interface"*).

**Files**

- `asf/workers/wave.py` — `wave(..., stats=None)`, filled beside the headroom samples
- `asf/tick/step_wave.py` — `ready_rows`, `ready_waiting`, `left_out(..., ready=None)`, and the
  stamping in `launch()`
- `tests/test_quota_pressure.py` — `TickLineTests` gains the wave cases; `WaitingTests`
- `tests/test_tick_steps.py` — the wave step's own case: a `_wave` double that fills `stats`

   the docstring with §2.1's sentence copied as it stands — *"``stats`` (a dict, or None): what this
   wave measured, for a caller that records it — ``banded_seats`` and ``pool_caps`` from
   :meth:`asf.workers.pool.Pool.banded_seats`. A caller that passes none is unchanged in every
   respect."*
2. The fill goes immediately before `if sample:` at `:349`, exactly as §2.1 writes it: when `stats`

   are set. It is **after** `if raised is not None: raise raised` in source order but must run

   and say so in a one-line comment: *a wave that launched nothing because every account is stopped
   is precisely the wave whose number matters* (§2.1's own sentence). A `stats` that stays empty
   because the wave raised is a measurement lost on the tick that needed it most.
