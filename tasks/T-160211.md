**Steps**

1. `docs/products.example.yaml`: document the block beside `launch:`, with the spec's §2.6 comments
   — `enabled: true` ("a Task whose one open after: edge names an item that has pushed starts on
   that item's branch instead of waiting for its merge; false: it waits") and `max_depth: 1` ("how
   many levels deep a stack may go; 1 = never on a stacked branch").
2. `ports`: a new `write_event(self, kind, **fields)` on the record port — declared on the protocol,
   implemented on `RealRecord` as an append of one JSON line to
   `<root>/metrics/events/<day>.jsonl`, modelled on `asf.record.ingest.write_on_prod_event`
   (`K2`). An `OSError` is logged and swallowed: the tick stays green, the launch unchanged.
3. `apply`: `NoteStack` writes one event — `stacked-start` when the action carries a base,
   `stacked-land` when it clears one — each naming `item`, `predecessor`, `base` and `fork`. The
   record write stays the handler's result line.
4. `loop`: nothing new to decide. Both lines are already in `Plan.notes` and `plan_notes` prints
   them. The dry-run arm runs under `mutation_guard.active()` and never calls `apply`, so it writes
   no card field, no event and no pull request; `blind_plan` returns only `EndSession` actions, so a
   blind tick starts no stack. Assert both rather than change them.
5. Extend `tests/kernel/test_stacked_builds.py` with `class KnobsAndRecords`: one case per
   acceptance line on `S-135960`'s card, all 16, in three groups — the knobs (both keys with their
   defaults, a wrong type refusing the load and naming the key, an unknown key a warning,
   `docs/products.example.yaml` validating clean, `config_for` filling both fields); the floor, with
   `enabled: false` (the card stays New, nothing launches, no base on any `Launch` or `OpenPR`, and
   one fixed set of facts yielding a plan equal in actions, states and notes to the knob-off plan);
   and the records (both actions in `ORDER`, the `NoteStack` before its `Launch`, the two tick
   lines, the two events with their four fields, the dry run writing none of the three, the blind
   tick starting none, an unwritable state directory leaving it green).
