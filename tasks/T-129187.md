## Description

after: Task 1

The spec's §5 — D-0006. The refusal keeps its first line and gains a second: a landing that stands is
not undone by hand, so push the follow-up on the product's fix branch cut from the trunk and
ingest derives `Active` by `refixing`; `asf reopen` is for a close no evidence supports. Exit
code stays 2 and nothing is written.

Two decisions bind it: **PD10** (the reopen-to-`Active` case needs no `reopen.py` code at all —
it arrives with Task 1 through `ingest.derive`, and this Task writes the test for it) and **PD7**
(`product.conventions.branch('fix', iid)` guarded on `product is not None`, never
`rows.branch_for`, and never a `fix/` literal — `tools/check_conventions.sh` refuses it).

**Files**

- `asf/record/reopen.py` — the refusal at `:155-159` gains a second `print(..., file=sys.stderr)`
  under the existing one, conditional on `type_ == 'bug' and c.rule in ('fixed', 'quiet',
  'reconciled')`. `type_`, `iid`, `product` and `c` are all in scope there. The first line is
  untouched: `'; '.join(c.lines)` of whatever path wrote the evidence (P6). `return 2` stays, and
  no write happens on a refusal.
- `tests/test_reopen.py` — new `ASecondFixTests(ReopenTestCase)` (`:58`).
  `TaskFalselyClosedTests.test_refuses_when_current_evidence_still_lands_it` (`:126`) and
  `RefusalTests` (`:180`) are untouched — a Task's refusal gets the first line only, which is the
  third new case asserting it.

**Steps**

1. Add the route line. The branch parenthesis only when a product resolved:
   `conv = getattr(product, 'conventions', None)`, then
   `where = f" ({conv.branch('fix', iid)}-…)" if conv is not None else ''`, and the sentence
   without it otherwise — `product` is a plain parameter of `reopen()` and the suite passes
   `product=None` (`test_reopen.py:64`), so the `None` arm is reached in the tests and must read as
   a sentence, not as a stray empty parenthesis. The string carries no `fix/` literal (**PD7**).
2. `ASecondFixTests`: a `Closed` Bug (the quiet rule) whose fresh evidence carries `refix` gives
   `rc == 0`, state `Active`, `rule: refixing` in `evidence`, one `reopened:` entry and the History
   line — the sticky hold lifted for the one id, which is reopen's own job, where P4 makes the
   `Resolved` case need no command at all. This case is a regression on Task 1 (**PD10**).
3. The same Bug with no refix in its evidence gives `rc == 2`, stderr still carrying
   `current evidence still says Resolved (rule: fixed)` and now also `rule: refixing` and the fix
   branch the product's conventions name; and the card is **byte-identical** afterwards — read the
   file before and after and compare, since "nothing is written" is the half of the refusal that
   regresses silently.
4. A Story refused by `tasks-resolved` gets the first line only. And `product=None` gives the
   sentence without the branch parenthesis, `rc == 2`.
5. Run `tests.test_reopen` whole (11 tests before this Task, PD8), then the two modules whose
   derivation this path shares.
