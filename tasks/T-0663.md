## Description
stories: S-36754
writes: asf/evidence/evidence.py, asf/record/ingest.py, tests/test_evidence.py
after: none

The `DocCarriers` half of the spec's `## The design` §5, and nothing else. After this lands, the
ingest makes one `cat-file --batch-check` process where it made one per card.

**Read PD1 before writing the warm.** D12 says to warm *"from the `links.spec` and `links.plan` of
every card in `canonical`"*. Measured at this record's real scale that is 226,782 requests, **6.39 s
and 12.5 MB in one process** — more than the 8 s the whole §5 item is worth, and most of it asking
about refs nothing will ever read, because `_spec_home` and `_plan_home` are called from one loop
that skips every card that is not a live Feature (`ingest.py:865-866`). Warm from the typed
`links.spec` and `links.plan` of the **non-retired Feature** records only: 25,198 requests, **0.73
s**, measured. `DocCarriers.carriers`' own fallback to a single `doc_carriers` call is what makes
the narrowing safe — a path the scope misses costs exactly today's one process.

**Files**

- `asf/evidence/evidence.py` — `class DocCarriers` with §5's docstring. `warm(paths, branches)`
  asks for the whole path × branch cross product in **one** `resolve`; `carriers(path, branches)`
  answers `(on_trunk, [branches])` from that and falls back to one `doc_carriers` call for a path it
  was never warmed with. The answer must be identical to `doc_carriers`' in both limbs, including
  the ordering: `others = sorted(b for b in branches if b != product.main)` and the returned list is
  those branches in that order (`:182-191`). A warm with no paths makes **no** process at all —
  `_batch` already returns `[]` for an empty request list (`:99-100`), so do not build the args.
  `doc_carriers` itself is **not** changed: it is the fallback and the single-path API.
- `asf/record/ingest.py` — `derive` builds one `DocCarriers` and warms it before the Features loop,
  from the typed `links.spec` and `links.plan` of the non-retired Feature records of `canonical`
  (PD1), deduplicated, against `['origin/<main>'] + ev['branches']`. `_spec_home` (`:536`) and
  `_plan_home` (`:556`) gain an optional argument defaulting to `None` → today's per-card
  `doc_carriers` call, and are passed the instance at `:927` and `:929`. Every guard above their
  `doc_carriers` line is untouched, so a Feature whose spec the lane already placed still costs no
  lookup at all. Nothing else in `derive` moves.
- `tests/test_evidence.py` — one new class, `DocCarriersBatch`, with `evidence._batch` counted. The
  cases §3.5 names: `warm` over ten paths and four branches makes **one** `--batch-check` process,
  and `carriers()` for each of the ten then makes none and answers exactly what ten `doc_carriers`
  calls answer — on the trunk; on one branch; on several, in the same order; nowhere. A path that
  was never warmed falls back to one `doc_carriers` call. A warm with no paths makes no process at
  all. Assert the answers against `doc_carriers` itself rather than against literals: it is the
  function this class must not differ from.

**Steps**

1. **`DocCarriers`**, warm and fallback. Build the request list the way `doc_carriers` does
   (`:188-190`) so the two cannot drift, and handle `product is None` and an empty `path` the way it
   does (`:186-187`).
2. **The new test class**, before touching `ingest.py`. Assert equality with `doc_carriers` for all
   four placements; that equality is the contract the ingest then relies on.
3. **The two optional arguments** in `_spec_home` and `_plan_home`, defaulting to `None`. Then run
   `python3 -m unittest tests.test_ingest` and confirm **120**, `OK` (PD12) — the default must
   change nothing, and this is where you prove it before the warm exists.
4. **The warm in `derive`** (PD1). Scope it to non-retired Feature records. Count the requests you
   build and keep the number in the commit message: if it is in the hundreds of thousands, the
   scope is wrong.
5. Run the Gate
