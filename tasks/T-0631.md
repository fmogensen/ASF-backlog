The spec's `## The design` §1, §2, §3's `DEFAULTS`/`settings`/`enabled`/state file/`cut`, and §5's
two edits. After this lands, a product that writes `harvest: {gate_where: ci}` gets a landing pass
that builds the combined head, pushes it once as `gate/<stamp>-<sha9>`, leaves every member
`WAITING_CI`, and **starts no test process on this host** — a fact about control flow, because
`gate_one_set` returns before `confirmed_group`, `red_on_trunk`, `push_set` and every path to
`H.product_gate` are reached. A product that writes nothing behaves exactly as it does today.

Three things are load-bearing. `gate_where` must be **orthogonal** to `harvest.gate`: the taken key
keeps its two words and `per-branch` + `ci` has to parse as a legitimate pair (D1) — the switch
reads at `gate_one_set`'s top, which is downstream of `gate_set`'s `harvest_gate` branch at `:2741`,
so both are already true if the edit goes where §5 puts it. The **slug** is the one thing a
fast-forward lane does not have: `lane.slug` is None off `self.mode == 'pr'` (P5), so every forge
read here starts `slug = lane.slug or lane_mod.repo_slug(lane.product)`. And the gate's cross-tick
memory is the **file**, never the lane record (D13): `wait()` keeps three named fields and drops
everything else (P7, measured), so a ref remembered on a `WAITING_CI` record is a ref forgotten on
the next pass.

Read **PD4** before the conventions edit, **PD5** before putting a ref prefix anywhere near
`asf/conventions.py`, **PD6** before adding an import to `asf/harvest/lane.py`, and **PD7** before
touching `held_by_host`.

- `asf/conventions.py` — `DEFAULT_GATE_WHERE = 'local'` and `GATE_WHERE_VALUES = ('local', 'ci')`
  with §1's comment block verbatim; `HARVEST_KEYS` gains `'gate_where': 'gate_where'` (`:182-183`);
  `Conventions` gains `gate_where: str = DEFAULT_GATE_WHERE` beside `harvest_gate` (`:669`);
  `MAP_CONVENTIONS` gains `'ci_gate'` (`:321-322`); and the enum check — **two** edits, the
  validation beside `merge`'s and `delivery`'s and one `want` branch in `shape_findings` (PD4).
- `asf/ci_gate.py` — **new**. A module docstring in `asf/merge_queue.py:1-60`'s shape saying what
  the gate is, what it writes and what a product on `local` never touches; `DEFAULTS =
  {'ref_prefix': 'gate/', 'run_wait_min': 10, 'timeout_min': 120}`; `settings(conv)` over
  `conv.map_of('ci_gate')` per key, copied from `merge_queue.settings` (`:89-105`);
  `enabled(conv)`; `STATE_FILE = 'ci-gate.json'` with `path`/`load`/`save`
  (`merge_queue.py:107-131`); `cut(lane, group, cls, st)`; and `pass_for(lane, group, cls)`, the
  seam's entry. Nothing else — `judge`, `land`, the sweep and the `NEEDS OPERATOR` causes are
