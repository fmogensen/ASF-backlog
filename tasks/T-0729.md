The spec's §1 and §2 in full, plus the read half of §4. After this Task `asf center` prints the
machine's shared block and one row per product file on the machine, every cell with its age and
every missing cell naming the file that would have filled it, and `asf center --json` is the
`{at, machine, products}` seam C1 names. A product whose file does not validate is one row holding
the first line of its `ConfigError`; a product with no state directory at all is a row of dashes.

`asf center` is registered here with optional sub-parsers (`dest='center_command'`, **not**
required) so `command_key` keys the bare form as `center` (P13) and Tasks 3 and 4 have a parser to
hang `follow`, `ask` and `thread` on. Its `help=` text matters beyond the terminal:
`plugin_build.command_help()` reads it straight off this subparser and Task 5's generated skill
description is that string (P11).

Read **PD1** (the three readers are safe as of Task 1, and why), **PD2** and **PD3** (the quota
band: the key the cached sample must be given, and the window it cannot see), **PD4** (do not call
`head()`), **PD6** (the tick renderer arrives as a callable) and **PD13** (compose `<root>/record`;
never `shadow.record_dir`).
