## Description
stories: S-80806

after: Task 1

The land path's pending probe asks the checks a question the run itself answers better: it stands
down whenever any waiting check is `in_progress` (P6), though such a run is still a phantom (P2).
A real head usually has something running, so the guard fires on the card's own incident. One
clause goes.

**Files**

- `asf/merge_queue.py` — the condition of the `state != 'green'` branch (`:2726-2727`) only.
  `_land_infra` (`:2753`), the red branch's `_land_infra` call (`:2703`), the annotation-based
  `lost` path behind it (`:2704-2715`), `_lost_runner` (`:1200`) and `_nonverdict` (`:1221`) are
  not touched — the batch path has its own per-job budget and its own escalation (P11, C8).
- `tests/test_merge_queue.py` — `AnInfraRedIsReRunNotRed` (`:1510`) gains two cases.

**Steps**

1. Delete `not any(c.get('status') == 'in_progress' for c in waiting) and` from the condition,
   leaving `if waiting and _land_infra(lane, n, head, waiting, required, probe=True):` on one
   line, with its `continue` kept. The run's own `completed`/`failure` is the phantom test (P2)
   and `PHANTOM_PROBE_S` is what keeps the read cheap (C4).
2. Reword the trailing comment to name a running job beside a queued one: the spec's §4 reads
   "its jobs queued or running under a run that failed", where the landed one says "queued" alone.
3. Add the two cases S-80806 names for this path: the card's phantom with one waiting check
   `in_progress` instead of `queued` makes one `run rerun` and the line
   `infra red (phantom): re-run queued` (the P6 probe, inverted), and that same phantom beside a
   second workflow's queued check makes one `run rerun` (the P7 probe, inverted — and the reason
   this Task waits on Task 1).
4. `test_a_queued_run_is_waited_on_as_before` (`:1563`) is not edited and must stay green: a run
   that has not concluded is no phantom, which is `classify_red`'s last branch (`:295-296`) and
   never was this guard's work. `test_a_lost_runner_on_the_head_is_re_run_never_red` (`:1532`) and
   `test_a_phantom_run_under_queued_checks_is_re_run` (`:1548`) are the three remaining proven
   lines of S-80806 and are not edited either.
