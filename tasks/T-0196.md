## Description
stories: S-18752
writes: asf/harvest/harvest.py, tests/test_harvest.py
after: Task 1, Task 2

§2.5 whole. One more kind in `lane_refusal`, in the one place this factory decides a landing — above
`mark_session(harvest='pr')` and above both `land_ff` and `land_combined` — so a claimless Task
branch is never handed to a merge queue and never fast-forwarded onto the trunk. Waits on Task 2
because §1.3 says so: refusing a coder for a trailer its brief never asked for is a correction
round bought for nothing.

**Files**

- `asf/harvest/harvest.py` — `lane_refusal`'s signature and its third check (`harvest.py:800-814`);
  the one call site's argument list (`harvest.py:1297`); `import` of `asf.proves`.
- `tests/test_harvest.py` — `ProvesRefusalTests`.

**Steps**

1. `lane_refusal(repo, trunk, branch, item, conv=None, items=None, root=None)`, the three new
   arguments keyword-defaulted so every existing four-handed call keeps working (**P9**), and
   §2.5's docstring sentence appended to the existing one.
2. After the `merge` and the `naming` checks — their order is load-bearing and §3.3 asserts it:

   ```python
   card = (items or {}).get(item) or {}
   if not (root and card.get('type') == 'task' and card.get('stories')):
       return None
   ```

   No `items`, no `root`, an item that is not a Task, or a Task listing no Story: **no refusal**
   (D4, D5). A missing index must never stop every landing in the factory, and a Task card outside
   the coder's `writes:` must never be the subject of a correction the coder is forbidden to make.
3. Then the claims, the tree and the verdict, as §2.5 fences them: `proves.claims_on_branch` with
   the `sh(...)`-backed callable, `git ls-tree -r --name-only origin/<branch>` for the tree, and
   `proves.validate(claims, card, items, root, tree)`. `problems` non-empty returns
   `('proves', <the correction>)`.
4. The correction text is §2.5's, verbatim in shape: the Story the Task lists, its bullets numbered
   through `proves.card_bullets`, the exact trailer to write with a real line number in it, and the
   closing *"then push; the factory publishes the rewritten branch"*. Where `validate` returned
   specific problems, they are named before the numbered list — a claim naming a Story the Task
   does not list is a different mistake from writing no claim at all, and the session cannot fix
   what it is not told.
5. The call site becomes
   `lane_refusal(repo, trunk, branch, item, conv, items, product.backlog_dir)` — every argument a
   local of `run_product_harvest` already (`harvest.py:1233-1240`). `hold_with_correction` is
   unchanged: the `kind` it records is `proves` and the round counter and `correction` field of
   `asf.workers.lifecycle.hold` carry it as they carry the other two.
6. `ProvesRefusalTests`, over the git fixture (`tests/gitfixture.py`): a Task branch whose commits
   carry no trailer refused with kind `proves`, reaching neither `land_ff` nor the `harvest: pr`
   mark; the correction naming the Story and its numbered bullets; the same branch with a valid
   trailer landing; a claim naming a Story the Task does not list, a line past the end of the list,
   and a test path absent from the branch's tree each refused with their own reason; a branch whose
   item is a Bug, a branch whose Task lists no Story (D5) and a call with `items=None` (D4) each
   **not** refused; and the `merge` and `naming` refusals still firing first.
