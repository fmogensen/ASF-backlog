§2.2, §2.3 and §2.7: the built-in `Stop` hook, its bound, its convention, the `spawn` clear, and the
half-sentence that makes the standing rule true rather than hopeful. Nothing in this Task is wired
to the runtime yet — `BUILTIN` and `install` are Task 3 — so the gate is provable here as a
function, which is how T2 and T3 drive it. It refuses and it names commands; it never commits and
never pushes (§1.3: a hook that commits from inside a live session would race the session's own git,
and the session is the one that knows what its commit message should say).

**Steps**

1. `asf/conventions.py`: `DEFAULT_STOP_GATE_ROUNDS = 2` with a `#:` comment saying what it bounds
   and why there is a bound at all (§1.3: an unbounded Stop gate turns one stuck session into an
   infinite one; `0` disables the gate for the product and is the operator's escape hatch); the
   field `stop_gate_rounds: int = DEFAULT_STOP_GATE_ROUNDS` beside `repeat_failure_n` (`:652`); and
   the key in the docstring's yaml example beside `idle_wave_ticks` (`:54`). It is a plain top-level
   `conventions:` key, so `from_mapping` picks it up through `field_names()` with no `*_KEYS` entry
   (`HARVEST_KEYS`/`GIT_KEYS`, `:173-177`, are for nested blocks only).
2. `asf/workers/stopgate.py`, module docstring first: what the hook is, the rc contract it answers
   to (0 lets the stop through, 2 blocks it and feeds stderr back to the model), that it is bounded
   and why, and that it measures nothing itself but asks `lifecycle.unpublished`. Stdlib imports
   plus `from asf import env`; everything else is local to the function that needs it (the hook runs
   at every session's stop and must not import the feeder to say "you are fine").
3. The bound, written before the hook so the hook reads top-down:
   - `GATES_DIR = 'gates'` with a `#:` comment: factory scratch under `env.state_dir(product)`,
     never committed, one integer per job.
   - `counter_path(product, job)` — `os.path.join(env.state_dir(product), GATES_DIR, f'{job}.stop')`.
     `job` reaches this from `ASF_JOB`; pass it through `os.path.basename` so no environment can
     make the path escape the directory.
   - `refusals(product, job)` — the integer in the file, or `0` for a file that is missing,
     unreadable or not an integer. Never raises.
   - `bump(product, job)` — writes `refusals(...) + 1`, creating the directory; returns `True` when
     the write reached disk and `False` on `OSError`. §2.3: the counter is written **before** the
     refusal is printed, so a gate that dies between the two refuses one time fewer, never one more.
   - `clear(product, job)` — removes the file, ignoring a missing one and any `OSError`.
   - `spent(product, job, conv, payload)` with the spec's docstring byte for byte, its body to PD4

     `DEFAULT_STOP_GATE_ROUNDS`; true when `refusals() >= bound`, or when the last `bump` could not
     be written and `payload.get('stop_hook_active')` is true.
