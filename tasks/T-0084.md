## Description
stories: S-15003
writes: asf/workers/lifecycle.py, tests/test_lifecycle.py

§2.3, whole. Pure: no git, no clock, no product — a ledger path and an item id in, a number or a
fields dict out, exactly as `rounds_of` and `attempts` already are.

**Files**

- `asf/workers/lifecycle.py` — `EMPTY`, `EMPTY_CAP`, `empty_ends`, `park_text`, and `hold()`'s new
  first branch and its `empty_cap=EMPTY_CAP` parameter.
- `tests/test_lifecycle.py` — `EmptyEndsTests`.

**Steps**

1. `EMPTY = 'empty'` and `EMPTY_CAP = 2` beside `UNPUSHED` (`lifecycle.py:589`), each with the
   one-line comment §2.3 fences — `UNPUSHED` is work not on origin, `EMPTY` is no work.
2. `empty_ends(path, item)` over `item_runs(path, item)`, counting `end_reason ==
   f'failed: {EMPTY_BRANCH}'`. `0` for a falsy item (P12). It folds over every job of the item,
   the way `rounds_of` does.
3. `park_text(n)` verbatim from §2.3 — the sentence names the count, the three things the operator
   can do, and `asf unpark <item>` by name.
4. `hold(path, run, kind, text, now, empty_cap=EMPTY_CAP)`. The new branch goes **first**, ahead of
   `prev >= ROUND_CAP` (P10): `kind == EMPTY and empty_ends(path, item) >= empty_cap` returns the
   correction with `parked: True` and its `reason`, plus `operator_flagged: 1`, and **no** `rounds`
   key — the round counter does not move, because a park is not a round. Its line is
   `f'parked {branch}: {reason}'`.
5. Every existing caller passes five positional arguments (`health.py:278,310,317`,
   `step_health.py:91,173`, `harvest/harvest.py:865`); the new parameter has a default and none of
   them moves.
6. `derive()` is not touched and must not be: a parked correction has no `at_cap` and leaves
   `rounds` at 1, so `derive` reports `HELD`, not `ADJUDICATE`. That is an assertion in
   `EmptyEndsTests`, not a change.
7. `EmptyEndsTests` over a hand-written ledger, in this module's idiom: the count across jobs and
   what it ignores (`failed: not pushed: …`, `finished`, a live run); the first hold; the second;
   `empty_cap=3`; a `not pushed` hold at the same item still spending rounds and never parking;
   and `derive()` over the parked run.
