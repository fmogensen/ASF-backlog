asf/workers/heartbeat.py, asf/kernel/settings.py, tests/test_heartbeat_verdict.py

**Steps**

1. In `asf/workers/heartbeat.py`, the five answers as module constants in the precedence
   `verdict` applies — `ALIVE, UNKNOWN, NO_FIRST_BEAT, FROZEN, LOOPING = ('alive', 'unknown',
   'no-first-beat', 'frozen', 'looping')` — with the comment §2.1 gives them.
2. `Observation`, a frozen dataclass with §2.1's seven fields and its docstring: `now`,
   `started`, `moved`, `branch_moved`, `beat_seen`, `unknown`, `same_tree`. Epoch seconds, `None`
   where not known.
3. `Settings` gains `loop_beats: int = 4` beside its four existing fields; `limit_min` keeps its
   meaning (`interval_min` times `missed`). Add `DEFAULT_LOOP_BEATS = 4` beside the module's
   other `DEFAULT_*` constants, and a `kernel.heartbeat`-shaped entry in `KEYS`' neighbourhood
   only if the floor's own reader needs it — it does not, so leave `KEYS` alone.
4. `verdict(obs, s)` → `(one of the five, minutes quiet, why)`, pure, in §2.1's order: `unknown`
   first with `'origin unreadable: not judged'`; then no beat ever seen past
   `grace_min + limit_min` → `NO_FIRST_BEAT`; then `judge`'s own arithmetic for `FROZEN`, by
   calling `judge` — not by restating it; then `same_tree >= s.loop_beats` **and**
   `now - branch_moved > loop_beats × interval_min` → `LOOPING`; else `ALIVE`. Frozen outranks
   looping. Read no clock, no file, no remote, no product.
5. `kernel_settings(block)` → `Settings` from a read `kernel.heartbeat` block, each key absent
   from the dict falling back to this module's own `DEFAULT_*` constant (`K7`).
6. In `asf/kernel/settings.py`, add the `heartbeat` section to `SPEC` with §1.4's eight keys and
   defaults: `enabled` (True, bool), `interval_min` (3, int), `missed` (3, int), `grace_min`
   (10, int), `loop_beats` (4, int), `max_continues` (2, int), `max_age` (`'6h'`, the seconds
   form `SPEC` already uses for a duration), `kernel_stale_after_s` (600, int).
7. Create `tests/test_heartbeat_verdict.py` with one case per acceptance line of the Story,
   including the two that are not about `verdict` itself: `judge` keeping its signature and its
   answer for every landed case, and `kernel_settings` of a fully-defaulted read block equalling
   `kernel_settings({})`.
