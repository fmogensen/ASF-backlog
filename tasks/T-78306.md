## Description
stories: S-76258
writes: asf/workers/githooks.py, tests/test_session_push_guard.py
after: none

The spec's §5. A footprint no other Task touches, so this runs in wave 1 beside Tasks 1 and 2.
The `prepare-commit-msg` and `commit-msg` halves of the shim are not touched — they run
`git interpret-trailers` and `awk`, never asf, so no build can be the wrong one.

**Files**

- `asf/workers/githooks.py` — `ASF_HOOK`'s `pre-push` branch, the trunk-check block at
  `:182-195`. `ensure` (`:292`) is unchanged: `ASF_HOOK` stays a verbatim write (PD8).
- `tests/test_session_push_guard.py` — three new arms beside `PrePushAllow`'s fixture, plus the
  marker-prefix assertion of PD8.

**Steps**

1. Delete `[ -x "$cli" ] || cli=$(command -v asf 2>/dev/null)` (`:185`) — P7, C12. The unpinned
   build, named outright, is the only thing that line can resolve to.
2. Replace `if [ -n "$cli" ]; then` with §5's two-branch form: a first branch for
   `[ -x "$cli" ] && ! head -n 3 "$cli" 2>/dev/null | grep -qF '# asf dispatcher'` that echoes
   §5's message naming the path and `asf hooks install --product $ASF_PRODUCT`, calls
   `asf_refused "hook refused" "$msg"` (the helper the branch already defines) and sets `rc=1`;
   and an `elif [ -x "$cli" ]` branch holding the existing `trunk-check` call unchanged. With no
   file at that path the trunk check is skipped exactly as today — a cloud session has no
   `$HOME/.local/bin/asf` and is unaffected (C12).
3. Keep §5's literal `'# asf dispatcher'` rather than interpolating `dispatch.MARKER` — **PD8**:
   `ASF_HOOK` is written verbatim while its sibling `_SHIM` goes through `.format`, and the shim's
   `awk` program is full of literal braces, so routing it through `.format` would mean doubling
   every one of them in the file whose job is byte-stability.
4. `tests/test_session_push_guard.py`, over the shim `githooks.ensure` writes, driven by a real
   `git push` to a local clone as `PrePushAllow` already does: `command -v asf` appears nowhere in
   `githooks.ASF_HOOK`; a dispatcher at `$HOME/.local/bin/asf` → the trunk check runs and the push
   is allowed; a non-dispatcher file there → the push is refused, the stderr line names the path
   and `asf hooks install --product <p>`, and **one** `hook refused` object is appended to
   `ASF_REFUSAL_LOG`; no file there → the trunk check is skipped and the push is allowed; a
   heartbeat push (`refs/asf/hb/<job>` only) still exits 0 before any of this.
5. Add PD8's one assertion: `dispatch.MARKER.startswith('# asf dispatcher')`. It is what buys C2's
   "one source of truth" for a shim that cannot interpolate — a rename of the marker's head turns
   this test red instead of leaving the grep silently matching nothing.
6. Build the dispatcher fixture from `dispatch.render(...)` (or `dispatch.install`), never a
   hand-written marker line, for the same reason.
