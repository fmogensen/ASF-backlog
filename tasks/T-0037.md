stories: S-8000
writes: asf/env.py, docs/products.example.yaml, tests/test_env.py

**Files**

- `docs/products.example.yaml` — the new keys (PD7).
- `tests/test_env.py` — three new cases.

**Steps**
1. `Product.conventions` folds three more values, each `setdefault`, each only when present, in
   the shape `test_command` already set (`asf/env.py:337-341`):
   ```python
   if isinstance(ci, dict):
       for src, dst in (('workflow', 'ci_workflow'), ('dev_job', 'ci_dev_job')):
           if ci.get(src):
               data.setdefault(dst, ci[src])
   deploy = self._get('deploy_sha')
   if isinstance(deploy, dict) and deploy.get('workflow'):
       data.setdefault('deploy_workflow', deploy['workflow'])
   ```
   `ci: none` and `deploy_sha: none` are strings and fall through untouched, as today. The
   docstring's "plus three values that live at the top level" becomes six, named.
2. `CI_FIELDS` gains `'dev_job': _STR`. `deploy_sha` is not shape-checked today and stays so.
3. `docs/products.example.yaml`: under `conventions:` add `matrix_path`, `decisions_file`,
   `reports_dir`, `report_pattern`, `intake_dir`, each with one comment line saying that leaving
   it out means the product has no such thing and nothing looks for it. Under `ci:` add
   `dev_job:`. One comment on `ci.workflow` and `deploy_sha.workflow` saying they are read as
   `conventions.ci_workflow` / `conventions.deploy_workflow`.
4. Tests: `test_workflow_names_fold_into_conventions`, `test_a_conventions_key_wins_over_the_fold`,
   `test_ci_none_folds_nothing`, exactly the three cases the spec names.
