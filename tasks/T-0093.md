§2.5: the `Undecided > 3 days` section becomes `Undecided` with threshold zero, asked once per
file, and `Undecided > 14 days` is left exactly as it is because it is `close_on_starvation`'s
section and not a second question.

**Files**

- `asf/groom/groom.py` — `GROOM_SECTIONS`' second entry (`:465`); `build_groom_sections`' call
  (`:512`); `_SECTION_BY_TITLE` keeping the retired title on read (`:526`, PD8); the `exclude` set
  widened to the auto-filed Bugs already asked.
- `tests/test_groom.py` — `UndecidedFromFirstGroomTests` (new, §3/T6);
  `GroomSectionCoverageTests:293`'s section list.
- `tests/test_groom_policy.py` — the `undecided14`/`close_on_starvation` binding asserted unchanged.

**Steps**

1. `GROOM_SECTIONS[1]` becomes `('Undecided', 'undecided')`. `_SECTION_BY_TITLE` maps both
   `'Undecided'` and the retired `'Undecided > 3 days'` to `undecided`; only the new title is ever
   written (PD8).
2. `build_groom_sections`: `'undecided': groom_undecided_section(canonical, now, 0,
   exclude=asked_elsewhere)` where `asked_elsewhere = origin_ids | {the id of every line in
   sections['auto_bugs']}` — so an inbox-origin card and an auto-filed Bug are asked once, in the
   section whose reason is the one that matters. The `auto_bugs` section is therefore built before
   this one.
3. `groom_undecided_section` keeps its `days` parameter and its `decision`/`rule` exclusion
   untouched — `undecided14` still passes 14 and still excludes `origin_ids` only. With `days=0`
   the `age > threshold` test admits every open item whose `decided` is not `true` from the first
   groom after `stage_since`.
4. The reason text stays `undecided <age>`, frozen at first asking by Task 2's merge (§1.4).
5. `UndecidedFromFirstGroomTests` per §3/T6: a Feature created a minute ago appears in `Undecided`
   on the very next groom; an inbox-origin card and an auto-filed Bug appear once, not twice; a
   `decision` and a `rule` item appear in neither; `Undecided > 14 days` holds only the 14-day set
   and `close_on_starvation` answers there and nowhere else.
