## Description
stories: S-37150

after: none

The spec's `## Decisions → In` bullet 1 and `## The design` §1 in full: `wrote_a_result`,
`outcome_text`, and the two text producers rewritten to branch on them. This is the half of the
card that stops the ledger lying — the hold that quoted the record it said did not exist.

Nothing the factory *does* changes when this lands. The same run is held, in the same pass, for the
same round, with the same `correction.kind` of `died`; `ran_to_its_end` and B-0150's skip are not
touched, so a correction that wrote a *clean* result still holds nothing at all. Only the sentence
moves. That is why this Task can land beside the other two and be proven on its own.

Read **PD3** (the hold stays — do not try to make the card's "nothing is held" true here),
**PD4** (`tests/test_tick_steps.py` is expected to need no edit, and why), and **PD14**
(`outcome_text`'s three branches, and which one B-0123 actually takes) before starting.

**Files**

- `asf/tick/step_health.py` — `wrote_a_result` and `outcome_text`, new, beside `log_tail` (`:30`)
  and above `error_text`; `error_text` (`:40`) and `died_text` (`:46`) rewritten. `runtime_mod` is
  already imported at `:20` — add no import. The two call sites (`handle_dead`'s at `:112`,
  `hold_failed_corrections`'s at `:266`) are **not** edited.
- `tests/test_quota_headroom.py` — `AResultIsNeverADeathTests`, a new class subclassing `HomeCase`
  (`:172`), placed after `TestExhaustedRun` (`:185`)
- `tests/test_tick_steps.py` — in `writes:` for safety; expected diff **none** (PD4)

**Steps**

1. `wrote_a_result(session)` in `asf/tick/step_health.py`, with the spec's body and docstring byte
   for byte: `return runtime_mod.read_result(session.get('log')) is not None`. The docstring is the
   invariant's only home — it says this is the presence of the record and never its verdict, names
   B-0123's two logs, and points at `ran_to_its_end` as the reading that let an `is_error` result
   through. Do not weaken it to a summary.
2. `outcome_text(session)` beside it, the spec's body byte for byte: the ledger's `end_reason`
   first, `runtime_mod.failure_reason(runtime_mod.read_result(session.get('log')))` second,
   `'no failure declared'` last (PD14).
3. `error_text` (`:40`) keeps its `log_tail` line and its `; the last lines of its log:` /`.` tail
   exactly as they are, and branches only on its claim: `wrote a result and then failed:
   {outcome_text(session)}` when `wrote_a_result(session)`, else today's `died before it wrote a
   result` sentence, verbatim.
4. `died_text` (`:46`) takes the spec's shape: bind `last` from `error_text(session)`'s last
   stripped line (today's `tail[-1]` with the same `'no log lines'` default, written as the spec
   writes it), then branch — `the retry ended with a result, not a death: {outcome_text(session)}
   — {last}` when the log holds one, else the existing `died twice: …` string **byte for byte**.
   That string is asserted at `tests/test_tick_steps.py:244`; retyping it is how it breaks.
5. Its docstring gains the spec's second sentence — that the phrase "without a result" is never
   written about a log that holds one — because the invariant lives in this function and a third
   caller must read it here.
6. `AResultIsNeverADeathTests(HomeCase)` in `tests/test_quota_headroom.py`. Copy `TestExhaustedRun`'s
   `ledger` helper (`:207-212`) into it rather than subclassing that class: subclassing re-runs its
   eight tests under a second name (P8). The class drives the **real** `hold_failed_corrections`,
   the way the existing tests do at `:246`/`:266`/`:288`/`:302` —
   `step_health.hold_failed_corrections(ctx, lifecycle.latest(path), out=…)` — never a stub.
7. Its central case is B-0123's shape: a ledger with an original adjudicate run (started, then
   ended `dead pid`, `corrected: 1`) and a `<job>-correction` started after it and ended on an
   `is_error`
