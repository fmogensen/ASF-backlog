The spec's fourth **In** bullet and `## The design` §2's reader table. One compiled pattern, one more
source of rounds, one more branch in `read`, and one argument threaded through `review_at`. The
default path — every call site that exists today — is byte for byte what P10 does now, so no branch
the factory pushed changes its reading.

**Files**

- `asf/evidence/review.py` — `legacy_rx(conv, slug)`; `rounds(conv, paths, slug, legacy_prefixes=(),
  legacy=False)`; `read(text, legacy=False, required=(), conv=None)`;
  `review_at(repo, conv, ref, item, required=(), legacy=False)`
- `tests/test_review_reader.py` — the reader's cases for the new form and for the default path

**Steps**

1. `legacy_rx(conv, slug)`: `None` when `conv.get('legacy_review')` is not a map with a non-empty
   `glob`; else `pattern_rx`'s body (`:107-115`) over that glob — `re.escape` the literal, then
   substitute `{reviews_dir}` with `_dir_of(conv)`, `{slug}` with the lower-cased slug and `{n}` with
   `(?P<n>\d+)`, compiled `re.I`. The three placeholders are `review_pattern`'s, so the operator
   learns one substitution and not two (D7). A glob with no `{n}` is legal and matches at round `1`.
2. `rounds` grows `legacy=False`. With `legacy` false it is unchanged, line for line. With it true and
   `legacy_rx` not None, a path the legacy regex fullmatches is a third source: `(n, path, 'product')`
   — the string, not `True` (PD10) — appended before the sort. The existing sort key
   `(round, not legacy)` keeps the pattern form winning a tie; `'product'` is truthy, so a product
   file loses a tie to an ASF review of the same round, which is the right way round: the factory's
   own form is the one a session writes.
3. `pick` passes `legacy` through. Its return shape is unchanged — `(round, path, legacy)` — with
   `legacy` now one of `False`, `True`, `'product'`.
4. `read(text, legacy=False, required=(), conv=None)`: `legacy == 'product'` → `approved` when
   `conv.get('legacy_review')['verdict_regex']` **searches** the text and `changes` when it does not
   (D8), with `head_of(text)` as today; `legacy is True` → today's `legacy_verdict_of`; otherwise
   today's `verdict_of(text, required)`. `'product'` with no `conv`, or a regex that will not compile
   at read time, is `changes` and never `approved` — a file that cannot be judged is not an approval,
   which is the same shape as no review, and it waits (D6, D8). The regex is searched against the
   whole body the caller passes, not a prefix, so a marker below `READ_CHARS` is still found.
5. `review_at(repo, conv, ref, item, required=(), legacy=False)` passes `legacy` into `pick` and into
   `read`, and passes `conv` into `read`. Every existing call site keeps today's behaviour by not
   passing it; `newest` (`:161`) is not given the argument in this Task and keeps its signature.
6. `tests/test_review_reader.py`: `legacy_rx` is `None` for a product declaring nothing and for a
