The spec's third `## In` bullet and `## The design` §4: the one command that tells the operator what
to run, read-only, idempotent, exiting 1 when any connector needs a human. Plus the one line of
`connectors.findings` that PD16 held back until the command it names exists.

Read **PD8** (`tests/test_surface.py:49` holds the count as a literal, and P13's fence claim is
wrong), **PD12** (`README.md` is in no footprint and why), **PD16** (the `findings` hint line is
this Task's) and **PD17** (both fences) before starting.

**Files**

- `asf/connect.py` — **new module**: `cmd_connect`, `register(subparsers)`, and the three checks
- `asf/cli.py` — one local-import `register` call in `build_parser`, in the block at `:292-300`
- `asf/surface.py` — one `COMMANDS` row
- `asf/connectors/__init__.py` — `findings` gains the *"declare one"* line (PD16)
- `tests/test_connect.py` — **new module**
- `tests/test_surface.py` — the count literal at `:49`, 49 → 50 (PD8)

**Steps**

1. `asf/connect.py`, with the spec's usage: `asf connect [<name>] --product P [--template <t>
   --print]`. Per connector — all of them when `<name>` is omitted, in the product file's own order
   — run the spec's three checks **in order, stopping at the first that fails for that connector**
   and printing one line for it.
2. Check one, **installed**: `shutil.which(check[0])`. On failure,
   `NEEDS OPERATOR: <name> is not installed — <the catalogue's install line>`. A connector with an
   empty `check:` is skipped, not failed: it declares no probe, so there is nothing to answer.
3. Check two, **secret reachable**: for `file:`, the file exists and is non-empty; for `env:`, the
   variable is set in the operator's own environment; for `keychain:`, the service name is
   non-empty. **Never the value, never a byte of it** — for `file:` that means `os.path.getsize`,
   never a read; for `env:` `name in os.environ`, never the value; for `keychain:` no lookup is
   performed at all. On failure,
   `NEEDS OPERATOR: <name>'s secret is not readable — <the location, not its content>`.
4. Check three, **authenticated**: `credentials.run_probe(connectors.as_provider(c),
   credentials.probe_env(...), now)` (D1 — no second probe runner). `valid` prints the probe's own
   scrubbed last line as the identity. `invalid` or `broken` prints
   `NEEDS OPERATOR: <name> is not authenticated — run: ! <shlex.join(login)>`. The `! ` prefix and
   `shlex.join` are both asserted by the spec's fence, so build that line from `shlex.join(c.login)`
   and never by hand.
5. Then one line per connector naming what it provides and its session policy, so the operator sees
   the product's whole external surface in one screen. Exit **1** if any connector printed a
   `NEEDS OPERATOR:` line, else **0** (D10).
6. `--template <t> --print` skips all of it and writes the catalogue entry's body to stdout as the
   yaml block to paste under `connectors:`. The spec's fence asserts the emitted block **then
   loads**, so emit it in the shape `env.loads` reads back (PD9) and test the round trip rather than
   the string.
7. The command **runs no `login:`, edits no product file and installs no tool** (the spec's `## Out`,
   first two entries). It prints. No `subprocess` call in this module but the probe's, which is
   `run_probe`'s and is read-only by contract.
8. `register(subparsers)` shaped on `approvals.register` (`asf/approvals.py:1386-1397`): a positional
   `name` with `nargs='?'`, `--product`, `--template`, `--print`, and `set_defaults(run=cmd_connect)`.
   Called from `cli.build_parser` with a local import, in the block at `:292-300`.
9. `surface.COMMANDS` gains, byte for byte from the spec's design:
   `'connect': ("check each declared connector's auth and print what the operator must run", None, None)`
   — effect `None`, because it writes nothing.
