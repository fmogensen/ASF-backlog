**Files**

asf/logs.py, asf/doctor.py, tests/test_logs_tree.py

**Steps**

1. `asf/logs.py` gains the census of §4, with that section's comment block:
   `Group = collections.namedtuple('Group', 'tree name files bytes oldest newest cap over_cap')`.
   `files`, `bytes`, `oldest` and `newest` cover the whole group, rotated generations included;
   `cap` comes from `cap_for` (Task 1) and is `None` for a group that has none — a worker
   session's transcript, a stream's day files, a root log no module in the package opens;
   `over_cap` is judged on the group's **live file alone** and is `None` when `cap` is, so a
   correctly rotated log never warns for ever and a capless group is never counted as zero.
2. `transcripts()`: one `Group` per log in the tree, read from disk — a clock transcript and its
   generations one group, each product's job transcripts one group.
3. `streams(root)`: one `Group` per directory under `root/metrics`, read from disk and never
   enumerated from `metrics.STREAMS`; that constant is imported **inside the body** and read only
   to *name* the streams it is missing. `census(product=None)` returns both trees in one call.
4. `asf/doctor.py` gains `check_logs()` and `check_streams(product)` as §5 writes them.
   `check_logs` always reports what the tree holds and returns `'warn'` only on a condition the
   factory can clear: a group over its cap, or job transcripts past the keep window still on disk.
   Never on the total bytes, and never on a capless group — that group is named with its bytes and
   its newest time on every pass, including an `ok` one. `check_streams` warns on a stream on disk
   that `metrics.STREAMS` lacks or a newest day file older than yesterday, and is `None` when the
   record clone holds no `metrics` directory.
5. `run()` appends them after the two network rows (`asf/doctor.py:1845-1848`) and before `drift`
   (`:1850`), both `required=False`, the `streams` row only when `check_streams` is not `None`.
   `'warn'` is the one value a non-required row shows as `warn` (`asf/doctor.py:2367-2380`), and
   neither row can redden the doctor (`is_red`, `:2383`).
6. `tests/test_logs_tree.py` gains `CensusTests` and `DoctorRowTests` — one case per acceptance
   line of `S-134159`, over a temporary `ASF_HOME` and a temporary record clone, so neither reads
   the operator's home for anything but the tree the env helper names. `CensusTests` takes the two
   census readers; `DoctorRowTests` the two rows, down to the `logs` row staying `ok` on a capless
   group's account however large it is.
