## Description
stories: S-120855
writes: asf/ghapp.py, tools/check_clients.py, tools/clients-baseline.txt, tests/test_ghapp.py
after: none

The spec's design §1 whole, and nothing else: one new module that reads the App's declaration,
signs a JWT with `openssl`, mints an installation token, caches it with its expiry and refreshes
it inside a 15-minute margin — plus `openssl` as a new kind in the client ratchet with
`asf/ghapp.py` as its only owner. It is the first wave by itself because every other Task imports
a name from it and it imports nothing from them: at this head `grep -rn 'app_id\|installation_id\|installations' asf | wc -l`
is `0` (`P8`), so no existing reader is extended and no existing test can go red from this Task —
a red in its Gate is its own. It writes no `asf/env.py`, no `asf/github.py` and no doctor row:
those are Tasks 2, 3 and 4.

**Read this Task from `docs/plans/f-0333.md`, not from this card.** The record cuts a Task card's
description at 4000 characters (`PD16`), so the card stops inside the Steps and neither the
**Gate** nor the **Acceptance** below reaches it; the card's `links.plan` is this file. Four
decision rows bind this Task and are on no card: `PD7` (the one exception `refresh` raises, and
why `except BaseException` breaks an acceptance line), `PD9` (`app_id` is an **int** — check for a
non-empty scalar, never `isinstance(v, str)`), `PD11` (`token_path`/`meta_path` must not call
`env.state_dir`, because it makes a directory) and `PD6` (the ratchet needs no baseline line, and
the `urllib` grep that looks right and is not).

**Files**

- `asf/ghapp.py` — **new**, and the whole of §1. Implement exactly the surface the spec fences:
  `App` (`app_id key_file installation_id`), `settings`, `configured`, `token_path`, `meta_path`,
  `token`, `expires_at`, `signing_input`, `sign`, `jwt`, `installation`, `mint`, `refresh`, plus
  `TOKEN_VAR` (`'GH_TOKEN'`, the variable Task 2 writes into the map and the one that also gives a
  session's git its HTTPS credential — `asf/workers/runtime.py:363`) and `REFRESH_MARGIN_S = 900`.
  Module scope may read `from asf import env, gh_limit, mutation_guard`: all three are
  cycle-free from here (`PD5`). `settings` reads `product.conventions.get('github_app')` — an
  unknown `conventions:` key kept verbatim in `Conventions.extra` and returned by
  `Conventions.get` (`asf/conventions.py:1009`, `:1469-1473`; measured in `PD10`) — and expands
  `key_file` with `os.path.expanduser`. `token_path`/`meta_path` build their path from
  `env.ASF_HOME` directly, **not** through `env.state_dir` (`PD11`); `mint`, which writes, calls
  `env.state_dir(product)` for the directory. `refresh` is the only entry another Task calls.
- `tools/check_clients.py` — one entry in `PATTERNS` (`:44-51`) and one in `OWNERS` (`:54-60`):
  `'openssl': re.compile(r"""['"]openssl['"]""")` and
  `'openssl': frozenset({'asf/ghapp.py'})`, matching the shape of the existing `launchctl` and
  `systemctl` rows. `KINDS` is `tuple(PATTERNS)` (`:52`) and derives itself; the module docstring's
  own list of kinds gains `openssl`.
- `tools/clients-baseline.txt` — **expected untouched** (`PD6`): `count_text` skips a kind for its
  owner file, and `openssl` sites elsewhere in `asf/` are `0` at this head. If
  `--write-baseline` wants to add an `openssl` line, a second call site was written.
- `tests/test_ghapp.py` — **new**, and the whole of S-120855's 23 lines. Every case injects `run`
  (for `openssl`) and `http` (for the one `urllib.request.urlopen`), so the module's whole proof
  runs with no key, no App and no network — which is what makes this Task's Gate hermetic.
