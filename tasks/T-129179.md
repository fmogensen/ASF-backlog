## Description
stories: S-91155
writes: asf/workers/lifecycle.py, tests/test_lifecycle.py
after: Task 1

The spec's design §2 — D-0001's pathspec and D-0002's new middle return. The second half is the delicate
one: excluding the notebook turns "the session left only its notes dirty" into a `git commit` that
exits 1, and `publish_gap` reads a `(False, line)` as a hold (`health.py:501-502`), so the fix
without that return is a new way to strand a branch (P8, **PD3**).

**Files**

- `asf/workers/lifecycle.py` — `commit_leftovers` (`:1863`, **not** the `:1838` the spec cites —
  **PD2**). Its `git add -A` at `:1871` becomes `_git(['add', *scratch.add_pathspec()], wt)`; a new
  `if _git(['diff', '--cached', '--quiet'], wt).returncode == 0:` returns
  `(True, f"nothing to commit on {branch} but the factory's own scratch "
  f"({', '.join(scratch.PATHS)}) — left in the worktree")`. The subject (`:1873-1874`), the `-s`
  sign-off, the hook behaviour and the refusal return are all unchanged. `scratch` is imported the
  way this module imports its siblings.
- `tests/test_lifecycle.py` — `LeftoverScratchTests`, the eleven lines of S-91155.

**Steps**

1. Add the import and replace the `add` arguments. Leave `_git`'s `wt` cwd exactly as it is: `top`
   is what makes the pathspec independent of it (**PD3**), not the caller.
2. Add the middle return above the `commit` call. Reach it by the **exit code** of
   `diff --cached --quiet`, never by matching git's refusal text (**PD13**).
3. Phrase the returned line as the spec's Records table fixes it, and assert on that line in the
   test rather than on anything git printed.
4. Write `LeftoverScratchTests`: the work file alone is committed; the notes file is still in the
   worktree with its contents unchanged; the subject still names the branch and `B-0094` and is
   still signed off (`git log --format=%B` carries `Signed-off-by:`); the only-notes-dirty case
   returns `(True, …)` and the line names the scratch; the branch head is unchanged in that case
   and no empty commit exists; a **tracked and modified** notes file is left unstaged while the work
   file beside it is still committed; a top-level and a nested glob-matching scratch file are both
   excluded; a nested work file is still staged; a staging run whose cwd is a **subdirectory** still
   excludes a scratch file at the worktree root — that is the `top` case, and **PD3**'s control
   shows what it catches; and a commit the repo's own hooks refuse is still a refusal that leaves
   the files a hold, which is the one line here that pins existing behaviour.
5. Run the Gate whole. `tests.test_lifecycle` is `Ran 281 tests` / `OK (skipped=2)` at this base
   (**PD6**), so any failure is this Task's.
