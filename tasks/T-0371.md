## Description
stories: S-33105
writes: asf/probe/stream.py, asf/init.py, tests/test_probe_stream.py
after: Task 1, Task 3

§2.8's first half: `metrics/probes/<day>.jsonl` — the writer that is idempotent per `(sha, journey)`
and the two readers ingest will call. This is the line shape Tasks 5, 7 and 8 all read, which is
why it lands before the fan.

**Files**

- `asf/probe/stream.py` — `PROBE_KIND`, `Verdict`, `append(root, product, target, sha, run,
  artifact, results, owed, now)`, `verdicts(root, sha)`, `standing(root, sha)`
- `asf/init.py` — `'metrics/probes'` in `STREAM_FOLDERS` (l. 28)
- `tests/test_probe_stream.py` — T5's stream half

**Steps**

1. `append` writes §2.8's line, one per `Result`, with `customer_facing` taken from the matching
   `Owed` at probe time — written down when it was computed, never recomputed from a tree that
   has moved on (§2.9) — and `origins_ok` from the judged result.
2. The append is idempotent per `(sha, journey)`: the day file is read first and an existing line
   for the pair writes nothing, the rule `ingest.write_on_prod_event` (`asf/record/ingest.py:41`)
   already follows, including its tolerance of an unparseable line in an unvalidated stream.
3. The writer makes its own directory (PD14): `os.makedirs(os.path.dirname(path), exist_ok=True)`
   before the append, because `STREAM_FOLDERS` reaches only records that `asf init` creates from
   here on.
4. `verdicts(root, sha)` returns `{item: Verdict(...)}`: an item's verdict is its own try-it
   journeys' — `fail` if any failed, `unrunnable` if any was unrunnable and none failed, else
   `pass`. `standing(root, sha)` returns the sha's standing journeys folded the same way.
5. An item that owed no journey of its own has no entry of its own; the caller (Task 7) falls
   back to `standing`. An item at an unprobed sha is absent from both, and nothing changes for it.
6. `tests/test_probe_stream.py`: writing the same run's results twice appends each `(sha, journey)`
   line exactly once; the three folds over two try-it journeys of one item; `standing` over a sha;
   an unprobed sha yielding nothing; and the directory created on a record that has none.
