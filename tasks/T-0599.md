`asf/reservations.py` whole, and `tests/test_reservations.py` whole — the spec's `## The design`
§1 in full, both its halves. Nothing outside these two new files moves, and nothing in the factory
behaves differently when this lands: the module has no caller yet. That is exactly why it can go
first and be proven alone, and why it must — C1's argument is that one predicate serves four call
sites, and a predicate three parallel Tasks each reach for is the defect this card closes.

Read **PD5** (the `prs` map's shape is the lane's, and `open_refs`/`rank` take it as an argument),
**PD6** (`conv.get('reservations')` finds a product's command before Task 4 types the field),
**PD9** (nothing here calls the forge; the fixture hands in its pull-request numbers), **PD10**
(the two globs that book nothing) and **PD13** (the forbidden tokens, in a new module that is not
one of the exceptions) before starting.

**Files**

- `asf/reservations.py` — **new module**: the docstring, `Booking`/`ADDED`/`WRITES`/`COMMAND`/
  `FILE`/`BRIEF_LIMIT`, `sequences`, `open_refs`, `rank`, `added_files`, `added_bookings`,
  `writes_bookings`, `command_bookings`, `holdings`, `holder`, `clashes`, `next_free`, `refusal`,
  `snapshot`, `save`, `load`, `brief_lines`
- `tests/test_reservations.py` — **new module**: `Bookings`, `Holdings`, `AgainstGit`, `Refusal`,
  `Snapshot`

**Steps**

1. `asf/reservations.py` opens with the spec's module docstring byte for byte (§1) — the three
   readers and why no one of them sees a whole booking. It names `asf.harvest.lane.landing_class`
   as the reason a plan cannot book by adding a file. Every branch in it is `worker/`- or
   `plan/`-prefixed (PD13).
2. The vocabulary, byte for byte from the spec: `Booking = collections.namedtuple('Booking',
   'sequence number ref source')`, `ADDED, WRITES, COMMAND = 'added', 'writes', 'command'`, the
   `#:` comment pointing the correction kind at `asf.workers.lifecycle.RESERVED` (*spelled once
   there* — this module defines no kind string of its own; Task 2 adds the constant and this
   comment is the pointer to it), `FILE = 'reservations.json'`, `BRIEF_LIMIT = 12`.
3. `sequences(conv)` → `{name: (dirname, regex, width)}` over `conv.map_of('sequences')`, each
   pattern through `reserve.split_pattern` and `reserve.pattern_regex`. A pattern that raises
   `ValueError` (no `N` run) is **skipped, not raised** — the spec's docstring says so and the
   reason is a lane pass: one misdeclared sequence must never stop the pass for every other. Reuse
   `asf.reserve`'s two readers; do not write a second pattern parser (C1, one level down).
4. `open_refs(product, heads, prs)` → the trunk first, then every open lane branch, sorted. A head
   is a lane branch when `conv.branch_kind(b)` names it — **every** prefix the product declares,
   `legacy` included — and it is open when its entry in `prs` has no `MERGED` state. This is the
   one definition B-0151 split in two (P2); its docstring says so and names `asf.reserve.
   open_branch_trees` as the caller that joins it in Task 4. `prs` is `{branch: {'number',
   'state'}}` (PD5).
5. `rank(ref, trunk, prs)` → `(-1, '')` for the trunk, `(0, <number>)` for a ref with a pull
   request, `(1, ref)` for one without, with the spec's docstring byte for byte. Name C5's
   consequence in a comment: two ref-less branches are ordered by name, deterministic and
   arbitrary, and the loser re-books.
6. `added_files(repo, trunk, ref)` → `git diff --name-only --diff-filter=A
   origin/<trunk>...origin/<ref>`, through `asf.harvest.harvest.sh`. Its docstring names
   `asf.harvest.lane.touched_files` (`asf/harvest/lane.py:351-354`) as its sibling and
   `--diff-filter=A` as the one flag between them, with C3's reason: `touched_files` lists edits
   too, so a branch fixing a typo in a landed `0201_*.sql` would book `0201` and be refused for a
   file it never claimed. Import
