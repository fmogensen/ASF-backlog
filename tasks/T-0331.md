**Files**

- `docs/research/sandboxed-worker-shell.md` — completed.
  - **Three settings blocks** (item 4): the minimal working file per role — the real one, the
    union of the `grant-<n>` legs that flipped a row and nothing more — with every host and path
    written generically (`<the code host>`, `<state>`, `<repo>`) and no account name and no machine
    path anywhere (PD4). A grant that no pair proved necessary does not appear in a block; it
    appears in a table row with the `not needed` verdict.
  - **The adoption list** (item 5, §2.8): one row per change the measurements show is needed, each
    naming the file and the function and citing the probe that showed it — a settings file per role
    rather than per pool (`asf/workers/spawn.py:598-606`, `:721`); the permission mode the fence
    survives (`asf/workers/runtime.py:27`, `asf/workers/spawn.py:715-716`); the grants the fence
    needs that `job_grants` does not carry (`asf/workers/spawn.py:703-708`); the names a proxied
    egress needs in the environment (`asf/hermetic.py:63-66`, `worker_pool.env_passthrough`); and
    the hook's behaviour when the fence refuses its own ledger write (`asf/hooks.py`,
    `asf/approvals.py`). **Nothing in that table is minted as a card by this session** (§1.2,
    PD10) — each row is a line for the launch-path card's author, who mints it from their own range.
  - **The deletion** (item 6): the one line saying `tools/spike/f-0065/` is throwaway, naming the
    card that removes it.
  - The stamp is finalised: the session count and the unpaired count as the collector reports them.
- `tools/spike/f-0065/**` — `--check-doc` is exercised here for the first time against a complete
  document, and any gap it finds is a collector defect fixed here.

**Steps**

1. Write the three settings blocks from the pairs, not from the templates: a block is the set of
   grants that were *measured* to flip a row for that role. Generic paths only.
2. Write the adoption list, one row per §2.8 line, each with the probe id behind it. Where a
   measurement came back `error` rather than a verdict, say so in the row instead of leaving it
   out.
3. Write the deletion line.
4. `collect.py --check-doc` and fix what it finds — every table row matching a paired result, every
   table opening with its two control rows, the stamp's unpaired count equal to the collector's.
5. `bash tools/check_generic.sh` and `python3 -m asf.redact --tree` over the whole tree. This is the
   last gate before the branch is publishable, and the document is the file most likely to carry a
   path someone pasted out of a terminal.
