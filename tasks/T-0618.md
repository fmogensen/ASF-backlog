The spec's §5 whole. `i9_events` stays a pure fold over the append-only history — it is the
read-only audit's reader too (P12) and is unit-tested as one — and the *saying* half gets a ledger
of the branches already said, beside the session ledger the events are folded out of. The tick says
each foreign merge once for the life of the product; `asf check --invariants` keeps listing every
one, every run.

Read **PD2** first — the one-line reordering without which the quiet tick can swallow the I8
findings, and which the suite already exercises — then **PD3** (a path that cannot be derived is
noise, not silence) and **PD10** (where each test's ledger lands, and why the two existing
`lane_report` tests stay green for two different reasons).

**Files**

- `asf/invariants.py` — `I9_SEEN`, `_i9_path`, `i9_seen` and `i9_unseen` under `i9_events`
  (`:663-683`); one line of `lane_report` (`:881`) and one clause of its docstring (`:876`).
- `asf/record/check.py` — one clause of `invariant_findings`' docstring (`:544`).
- `tests/test_invariants.py` — a **new plain `unittest.TestCase` class**
  `R12AnI9EventIsSaidOncePerBranch` beside `R12I9IsAnEvent` (`:219`).

`i9_events` itself is **not** edited (C9), and neither is the `EVENT I9:` line, the
`event('foreign-merge', …)` call, `metrics`, or anything that reads `metrics/events/<day>.jsonl`
(P11).

**Steps**

1. `asf/invariants.py`, under `i9_events`: `I9_SEEN = 'i9-seen.json'` with the spec's comment, then
   `_i9_path`, `i9_seen` and `i9_unseen` — §5 byte for byte, docstrings included, with the two
   corrections below and nothing else. `json` is imported per function, as `lane_history` does
   (`:719`); `os` is already imported at the module top (`:21`), so `_i9_path` needs no import.
2. `_i9_path` returns `None` rather than raising (PD3):
   `try: return os.path.join(os.path.dirname(_sessions_path(product)), I9_SEEN)` /
   `except OSError: return None`, and say so in its docstring — *no ledger, and every event is said
   again (C11)*. `i9_seen` opens with `path = _i9_path(product)` / `if not path: return {}` above
   its existing `try`.
3. `i9_unseen` opens with `if not events: return []`, **before** `seen = i9_seen(product)` (PD2) —
   the quiet tick derives no path, reads no file and cannot darken the report. Its write becomes
   `path = _i9_path(product)` / `if path:` / the spec's `try: … except OSError: pass`. Everything
   else is the spec's: the `new` filter on `ev.get('branch') not in seen`, the early
   `if not new: return new`, the `at` stamp, `seen.update({ev['branch']: {'pr': ev.get('pr'), 'at':
   at} for ev in new})`, `.tmp` + `os.replace`, `sort_keys=True`. Extend the docstring's *Never
   raises* sentence to name both arms.

   driven by `events`, so both happen exactly once per branch. The docstring's
   `per merge from outside the lane` becomes
   `per merge from outside the lane not recorded before`.
