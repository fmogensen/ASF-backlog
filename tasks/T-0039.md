## Description
stories: S-8004
writes: asf/briefs/preamble.py, asf/briefs/build.py, tests/test_briefs.py

**Files**
- `asf/briefs/preamble.py` — the four `DEFAULT_*` go; `conventions()` returns an object.
- `asf/briefs/build.py` — `context`'s three `or preamble_mod.DEFAULT_*` fallbacks go.
- `tests/test_briefs.py` — two new `PreambleTest` cases.

**Steps**
1. `preamble.conventions(product)` returns `product.conventions` when there is a product, else
   `Conventions()` (`from asf.conventions import Conventions`). It still answers `.get()`, so
   `max_lines` and `rules_block` are unchanged — `rules_tail` is an extra key, `.get()` finds it
   or returns `None`, and `preamble_max_lines` comes back as its documented int.
2. Delete `DEFAULT_SPECS_DIR`, `DEFAULT_PLANS_DIR`, `DEFAULT_REVIEWS_DIR`,
   `DEFAULT_REVIEW_PATTERN` (lines 31-34). `DEFAULT_MAX_LINES` and `DEFAULT_RULES` stay (PD6).
3. `review_path_for(product, slug, n)` → `conventions(product).review_path(slug, n)`.
   `doc_path_for(product, key, slug)` → `f'{conventions(product).doc_dir(key)}/{slug}.md'`.
   `convention_lines` (line 369) reads `conv.specs_dir`, `conv.plans_dir`, `conv.reviews_dir`
   straight off the object — no `or` fallback, because the object has no empty value to fall
   through.
4. `asf/briefs/build.py:202-208`: the three `or preamble_mod.DEFAULT_*` become the object's
   `specs_dir` / `plans_dir` / `reviews_dir`.
5. Tests: `PreambleTest.test_the_document_dirs_come_from_the_object` and
   `PreambleTest.test_no_product_means_the_defaults`, exactly the two cases the spec names — the
   second asserting with `hasattr` that `asf/briefs/preamble.py` has no `DEFAULT_SPECS_DIR`.
   The existing golden-brief fixtures are built from the default product and do not move.
