**Steps**

1. Write `check_tracked_scratch`. `git ls-tree -r --name-only origin/<product.main>` in
   `product.repo_dir` through `asf.gitops.git`, matched against `scratch.PATHS` — the literal by
   name, the glob entry with `fnmatch` on each path's basename, so it is the same membership test
   `PATHS` means everywhere else. Clean trunk → `(True, 'no factory scratch tracked on
   origin/<main>')`.
2. For a dirty trunk, name each path, the commit that first added it
   (`git log --reverse --format=%h --diff-filter=A -1 origin/<main> -- <path>`), how many origin
   refs descend from it (`git branch -r --contains <sha>`, counted), and the exact removal command,
   copy-pasteable and unparaphrased.
3. Make unreadable distinct from clean: a `product.repo_dir` that is absent, or a `ls-tree` that
   fails, returns `(False, …)` saying it could not be read — never `(True, 'no factory scratch…')`.
   That is S-91159's seventh line and the one way this row could lie.
4. Keep it read-only: no `fetch`, no write, no `rm`. S-91159's eighth line asserts the trunk is
   byte-identical afterwards, so the test compares `git rev-parse origin/<main>` and the tree sha
   before and after (**PD10**).
5. Add the row and the docstring paragraph, then write `TrackedScratchTests` over throwaway
   products: a clean trunk, a trunk tracking the notebook, a trunk tracking a glob-matching file,
   an unreadable repo, and the row's presence in `doctor.run('<product>')`'s table under `tracked-scratch` marked
   required.
6. Run the Gate whole. `tests.test_doctor` is `Ran 165 tests` / `OK` at this base (**PD6**).
