## Description
stories: S-39050
writes: asf/views/status.py, asf/tick/tick.py, tests/test_tick.py
after: none

The writer, and the format every later Task reads. `render`'s output does not change by a byte.

**Files**

- `asf/views/status.py` — `rows()` lifted out of `render()`; `SNAPSHOT`, `STAMP_FORMAT`,
  `_HEADER_RE`, `snapshot_path`, `snapshot_text`, `write_snapshot`.
- `asf/tick/tick.py` — `write_status_snapshot(ctx)`, called after `summary.run` at `:499`.
- `tests/test_tick.py` — `StatusSnapshotTests(TickTestCase)`.

**Steps**

1. Lift `rows(root, product, cfg=None)` out of `render` exactly as §1 gives it: the 21-pair literal
   tuple, the `cfg = env.load_config() if cfg is None else cfg` line, the `try/except Exception`
   with its `# noqa: BLE001` comment, and the `if text is None: continue` drop, all moved
   unchanged. `render` keeps its signature and becomes the four header lines plus
   `[f"| {name} | {text} |" for name, text in rows(root, product, cfg)]`. Run
   `tests.test_views.StatusViewTests` **before** going further: its 15 assertions are the pin that
   the markdown is byte-identical, and they are cheap (PD1's 104-test command is 3.7s).
2. Add the format block — `SNAPSHOT`, `STAMP_FORMAT`, `_HEADER_RE` — as *The fences* above gives it.
3. `snapshot_path(product)` → `os.path.join(env.state_dir(product), SNAPSHOT)`. `env.state_dir`
   creates the directory (P7), so nothing else needs to.
4. `snapshot_text(root, product, cfg=None, now=None, stale_after_s=None)` per §2: the header from
   `product.name`, `now.strftime(STAMP_FORMAT)` and
   `int(stale_after_s if stale_after_s is not None else 2 * _record_period_s(product))`, then one
   `f"{name}: {' · '.join(text.splitlines())}"` per `rows()` entry. The `splitlines()` fold is
   defensive — no cell produces a newline today (PD1, P2) — and it is what fence 3.2 injects one to
   prove.
5. `write_snapshot(root, product, cfg=None, now=None)` per §2: write `f'{path}.{os.getpid()}.tmp'`,
   then `os.replace(tmp, path)`, return the path. **It does not clean up on failure** — that is the
   caller's, and fence 3.1 asserts the temp file is what a failed `os.replace` leaves (PD8).
6. `write_status_snapshot(ctx)` in `asf/tick/tick.py` per §3, with two changes PD8 requires: the
   `except` clause removes the leaked temp file under `contextlib.suppress(OSError)` before it
   prints its one line (`contextlib` is already imported, `:32`), and it still never touches the
   tick's exit code. The root is `ctx.record_root() if ctx.has_record else (product.backlog_dir or
   None)` — `ctx.has_record` is a property and `record_root()` clones on first call
   (`asf/tick/tick.py:171-178`), so a `--steps wave` tick never clones a record to draw a line. No
   root, or a root that is not a directory: print `tick: status snapshot not written (no record to
   render)` and return, leaving the previous snapshot and its honest age (D10).
7. Call it on the line after `summary.run(ctx, chosen, ran=ran)` (`:499`), before `return rc`. Do
   **not** add it to the early return at `:415-418` (PD14).
8. `StatusSnapshotTests(TickTestCase)`: a stubbed-steps tick leaves `status.txt` under
   `env.state_dir('sample')` with a header `_HEADER_RE` matches and `len(rows(...))` body lines —
   count `rows()`, never 21 (PD13: seven rows drop as `None`); `status.write_snapshot` called
   **directly** with `os.replace` patched to raise leaves no `status.txt` and one `.tmp`; a second
   tick replaces the file in place with a fresh `ts=`; a render that raises prints
   `tick: status snapshot not written (…)`, returns the tick's rc unchanged **and leaves no `.tmp`
   behind** (PD8); a tick with neither a record nor a `backlog_dir` leaves an existing snapshot
   byte-for-byte as it was.
