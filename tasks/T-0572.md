The spec's `## The design` §4 whole, in one commit. After it lands, an undecided Feature that parents
a reference row whose reference declares `decide: need` is decided by code, with
`by: rule:decide_reference_gap` and a why naming the reference and the row; it crosses no approval
class (P16); and the decided Feature with `stage: card` gets the ordinary `CARD → SPEC` row,
"decided card, no spec", with no operator step in it. **The feeder is not edited** — C8 and C9 are
the argument, and this Task's second half is a test that the existing lane already does the right
thing.

**Read PD10 before the edit.** The index is **5**, between `decide_on_approved_doc` (4) and
`decide_or_close_ci_red` (5 today), `POLICIES` goes 9 → 10, and `groom.POLICY_NAMES` takes the same
name at the same index in the same commit or `test_policy_names_match_groom_POLICY_NAMES` is red on a
diff that looks finished. Its other half is a direction: `policy.py` must not import `groom.py`.

   with `decide: need`; and that Story's coverage is a gap — no Task, or a Task set that is not all
   Closed. Otherwise `None`. It computes the gap from `canonical`/`derived`, never from a view and
   never from a state Task 2 derives (PD4) — which is why this Task does not wait on Task 2.
