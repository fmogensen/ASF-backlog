The spec's design §1, and its `## In` row 1. `held_feature_row` stops guessing from occupancy keys
and reads the rows already drawn: `spoken`, threaded from `_candidates` through `feature_rows` and
`_one_feature_rows`. The `corrections` key it deferred to can never be a row for a Feature that
reaches this path — `correction_rows` drops every correction whose item is busy (`:1022`), and the
held path is only ever reached *because* the Feature is busy (`:1556`) — so the guard fired exactly
when the row it deferred to had already stepped aside, and the Feature left `asf next` in silence
with every one of its open Tasks (P3, P5). The `review`/`landing` keys go with it: unreachable for a
Feature (P6) and never backed by a `lane_rows` row anyway (P8, **PD8**).

The `gate` arm beside the call is **not touched** (P15, C12): a Story-less Feature in build whose own
`spec-amend` runs keeps drawing its Task rows, which is the card's one stated exemption.

**Read this Task from `docs/plans/f-0274.md`, not from this card** — the record cuts a Task card's
description at 4000 characters and this section is longer. Three decisions bind it and the last of
them will not reach the card: **PD3** (every line anchor here was re-read at `080cdf5a6`; the
spec's are 40-55 lines stale), **PD4** (P3's total silence needs the fixture's delivery cut out —
step 5) and **PD5** (an all-Active held Feature gains the held row beside its Tasks' own rows:
correct, and step 6's last case pins it).

**Files**

- `asf/feeder/rows.py` — five edits, all in the two functions and their one call site.
  `held_feature_row` (`:1638`) gains `spoken=()` and its three-key guard (`:1645`) becomes one
  `fid in set(spoken or ())` test, with the spec's own docstring in place of the present one.
  `feature_rows` (`:1507`) and `_one_feature_rows` (`:1536`) gain `spoken=()` with the same
  default; both `_one_feature_rows` calls inside `feature_rows` pass it on, the blocked branch's
  included (`:1520`, `:1522-1523`). The one `held_feature_row` call (`:1563`) passes `spoken`. The
  `_candidates` call site (`:2635-2636`) passes `{r.item_id for r in rows}`. Nothing else in the
  module moves — the row's own body, `holder_of`, `task_rows`, `correction_rows`, `lane_rows` and
  `pushed_rows` are all untouched (`## Out`).
- `tests/test_held_feature.py` — new file, the fixture of **PD4** and one case per acceptance line
  below. The module is new because `tests/test_replan.py` owns the replan pass and holds the landed
  half's 13 tests; this card's cases are about the held row, and the spec's fence names a file of
  its own.

**Steps**

1. Rewrite `held_feature_row`'s docstring to the spec's design §1 text, which says what `spoken`
   is (the `item_id` of every row drawn before `feature_rows` — a correction's, a lane's, a
   branch's, a groom's), why the occupancy is not consulted (the `corrections` key cannot be a row
   on this path, P5), and why `review`/`landing` need no test (`docs_waiting` subtracts such a
   Feature before `feature_rows` sees it, and `pushed_rows` draws its `PUSHED → LAND` row).
2. Replace the guard body: `if fid in set(spoken or ()): return None`, in place of the
   `any(fid in (occ.get(k) or {}) for k in ('review', 'landing', 'corrections'))` test. Everything
   after it — the `held` list, the no-open-Task return, `holder_of`, the `Row(...)` — stays byte
   for byte, so the row's text and `waits_on` do not change for any Feature that already had one.
   `occ` stays bound: `holder_of(occ, fid)` still reads it.
3. Add `spoken=()` to `feature_rows` and `_one_feature_rows`, and pass it at both
   `_one_feature_rows` calls and at the one `held_feature_row` call. Leave the `gate` arm's
   `task_rows(items, product, f, busy, running, landed_shas)` call exactly as it stands (C12).
