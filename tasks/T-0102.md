## Description
stories: S-15559
writes: asf/evidence/evidence.py, asf/record/ingest.py, tests/test_evidence.py, tests/test_ingest.py

§2.5's last paragraph and §1.2's one named exception: the typed `landed:` sha arrives through the
same `{id: evidence}` map a commit subject would have produced, so the `reconciled` rule is the
ordinary `landed-green` with a different source, and nothing about reconciliation is a special
path through closing.

**Files**

- `asf/evidence/evidence.py` — `merge_landed(ids, landed, product, green=None)`; `id_evidence`
  gains `landed=None` and calls it (`:740`); the five `*_state` functions gain one docstring line
  each pointing at `closing.RULES` as the live rule (P5). Nothing is deleted.
- `asf/record/ingest.py` — `cmd_ingest` collects `{iid: typed['landed']}` from the canonical record
  and calls `evidence.merge_landed(ev['ids'], landed, product)` after `evidence.load` (P14); the
  Task/Story/Bug/Feature `Ev` fills gain `landed=`.
- `tests/test_evidence.py` — beside `DiscoverIdEvidenceTests` (`:457`) and `IngestIdEvidenceTests`
  (`:526`), which already drive a real product repo fixture.
- `tests/test_ingest.py` — `ReconciledTests` (new).

**Steps**

1. `merge_landed(ids, landed, product, green=None)`: for each `{iid: sha}`, set that id's `commit`
   when it has none, and compute `green` with the same `ancestor_of` walk over the same green runs
   `id_evidence` uses — one function, so a reconciled item's map entry is indistinguishable from a
   commit-subject one.
2. `id_evidence(product, branches, prs, commits=None, green=None, landed=None)` calls it last, so
   a sha a commit subject already carried is never overwritten.
3. `cmd_ingest` reads the typed `landed:` values out of `canonical` and calls `merge_landed` on
   `ev['ids']` immediately after `evidence.load`, before any per-type block — the cache can never
   serve an `ids` map that predates an answer applied in the same tick (P14).
4. `Ev.landed` is filled from the typed field, so the `any/reconciled` rule (`ev.landed` and
   `ev.green`) fires and the evidence lines are `id_state`'s ordinary ones —
   `commit <sha> names <id>` and `CI green on main at or after it`.
5. `ReconciledTests`: an item carrying `landed:` closes at the next ingest with rule `reconciled`
   and those lines, and its file carries no typed state anywhere.
