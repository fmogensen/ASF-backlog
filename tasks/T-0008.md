stories: S-7309
writes: asf/doctor.py, tests/test_doctor.py

**Files**
- `asf/doctor.py` — `check_capacity(cfg, product)`, appended in `run()`
- `tests/test_doctor.py` — new class `Capacity`

**Steps**
1. `check_capacity(cfg, product)` → a list of `(ok, detail)`; empty findings → one ok row naming
   the resolved numbers. Findings, one line each (§2.5):
   - the sum of every product's `capacity.sessions` (each product file under
     `~/.ASF/products/`, via `asf.capacity.product_sessions`) above `capacity.total.sessions`;
   - `capacity.total.sessions` above the sum of `worker_pool.accounts[].cap`;
   - each `asf.capacity.deprecations(cfg)` line, prefixed `capacity: ` (§4.2's text).
   A product file that fails to load is skipped, not raised — the `config` row already reports it.
2. `run()`: append each as `('capacity', False, ok, detail)` after `one-factory` (PD6) — never
   required, so `is_red` is unchanged by any capacity finding.
3. `tests/test_doctor.py`: `Capacity` with the three tests of §3.5, each asserting the finding's
   line appears and `is_red(rows)` is false.
