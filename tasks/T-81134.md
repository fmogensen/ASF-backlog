sixty-day window holds — is on **no** Task's Acceptance, on purpose. It passes today (PD3), it
proves the mechanism rather than the code, and a Gate built on one commit is a Gate that goes red
when that commit leaves the window or its module is renamed. It stays what the spec makes it:
evidence, run by hand, re-measured in this session and quoted in PD3. Each Task proves itself on
its own fixture instead (PD11).

acceptance bullets, and any judgement of the test's quality beyond "fails before, passes after".

(PD1) are not fixed here: the deliverable is one file, and the headings are in a doc this job may
not edit. The operator line below asks for the record to be read first; the repair, if the record
confirms it, is an amend of the spec's frontmatter and headings under its own card, not a
