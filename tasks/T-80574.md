The spec's design §2, the `record` row of the acts table: a groom pass and a replan over the
laid-down record, each committed through the record's own pre-commit (`asf redact --pre-commit`,
which runs `staged_guard.check`) with **the index read at the commit's parent and the tree at its
head** — a stale index over a record of real size, the shape the 2026-10-08 regression had — and
once more over an intake note whose `done/` copy is not a byte-for-byte superstring of it.

`tests/rehearsal/record/**` is in this Task's `writes:` for one reason: S-79606's fifth acceptance
line is a claim about the **snapshot**, and if Task 1's builder did not produce all three intake
states this Task fixes the builder and rebuilds rather than reporting `needs writes:`. **PD8**
binds it: the guard's own two modules are already green and must stay green — what is new is the
guard driven at real record size, which no existing test does.

**Files**

- `asf/rehearsal.py` — the `record` act, appended to `ACTS` after `ids`. A red act prints the input
  and the answer on one named line, never a traceback (S-79606's fourth line), and names the blobs
  the guard compared in the non-superstring case. The escape `staged_guard.ALLOW_VAR` is **never**
  set: P4 is that nothing in the product sets it, and an act that set it would test nothing.
- `tests/test_rehearsal_record.py` — **new**. The stale-index commit shape; the act's reporting of
  what the guard answered; the non-superstring case naming both blobs; a red act's one-line output.
- `tests/rehearsal/record/**` — only if the builder's three intake states need correcting.

**Steps**

1. Re-read the guard before writing against it: `asf/record/staged_guard.py` — `ALLOW_VAR` `:33`,
   `check` `:129`, `kept` `:145`, the substring escape `:151` (PD9: the spec's line numbers moved).
2. The act: groom pass, replan, each committed from a stale index through the pre-commit.
3. The third run: the intake note whose `done/` copy is not a superstring of it.
4. One named line per failure. No traceback reaches the act's `detail`.
