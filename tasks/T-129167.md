The spec's design §5 (D-0008, D-0009; P7). One fact read where the lane already reads its neighbours, and
one clause appended to the string the lane both prints and records — so the waits line and the
row's recorded reason cannot disagree about what the factory did, and a review that was written
and thrown away is never reported as "no review" without saying so.

**Read this Task from `docs/plans/f-0313.md`, not from this card.** **PD3** binds it and reaches
no card: **`tests.test_harvest.HarvestLane` does not exist and this Task creates it.** The
acceptance fence names `tests.test_harvest.HarvestLane.test_an_unfiled_review_is_named_in_the_waits_line`;
`tests/test_harvest.py` has no such class, and the two waits-line assertions the spec cites
(`:1878`, `:1939`) live in `ProductHarvestTests` (`:543`). Adding the new method to
`ProductHarvestTests` instead would make the fence collect zero tests and exit 0 — a green gate
proving nothing. `HarvestLane` is new, on the same fixture, and `ProductHarvestTests` is not
touched.

**Files**

- `asf/harvest/lane.py` — two edits. In `branch_facts` (`:1770`), beside the block that already
  reads `review_answered` (`:1924`) and `corrected_on`, the one fact: `if f['review_required'] and
  not (rv and rv.get('current')): f['review_unfiled'] = lifecycle.unfiled_review(self.path, item,
  head)` — asked only for a head with no current review, so a filed review costs nothing. And in
  `review_reason` (`:1450-1460`) the clause, appended after the existing `why`, with the spec's
  docstring. `incomplete` (`:1442-1448`) is untouched; so is the printed line's shape at

  reaches both the printed line and the recorded reason.
- `tests/test_lane.py` — `UnfiledReviewInTheWaitsLine` added after `Transitions` (`:52`), the
  pure-transition class that owns `:82`'s `round 1 wanted: no ASF review yet` assertion (PD9).
  `Transitions` and the module's other thirty classes are untouched: `:82` is exactly the
  byte-for-byte assertion D-0009 promises stays green when no review was dropped.
- `tests/test_harvest.py` — a new `HarvestLane` class (**PD3**) holding
  `test_an_unfiled_review_is_named_in_the_waits_line` and S-84459's last acceptance line: the whole

  through `lifecycle.unfiled_review`, so no health pass is needed in this Task's fixture, which is
