§2.3: the five private helpers with five failure conventions and the three inline calls all go
through `ctx.git` or a `Git` built from the product. Every public function keeps its name, its
signature and its return value — `widen_footprint.tracked_paths`' `None` for "no repo" included.
`Context` gains `git` and `record_git`, lazily, in `record_root()`'s shape (D9). Also §2.6's one
duplicate default: `step_prs.DEFAULT_PRS_PER_TICK` is a second copy of a field that already
exists, and this is the Task that owns the file.

**Steps**

1. `Context` gains two lazy properties beside `record_root()` (`asf/tick/tick.py:164`), each
   memoised on a `self._git = None` / `self._record_git = None` set in `__init__`:
   `git` is `gitrun.Git(self.product.repo_dir)` — **None** when the product has no `repo_dir`, so
   a step that reads no git starts no process and builds nothing; `record_git` is
   `gitrun.Git(self.record_root())` for the record clone, the one other root the tick reads
   (`fresh_index`, `shadow.push`, the operator-checkout fast-forward). Both carry §2.3's
   docstrings. No step signature changes anywhere: every step already takes `ctx` and nothing else.
2. `step_wave`: `_git` (`:416`) deleted. `repo_facts(product, branch, git=None)` builds
   `git or gitrun.Git(product.repo_dir)` after its existing no-repo guard and calls
   `git.out(['ls-remote', …])` then `git.out(['log', …])` — the two reads unchanged, `''` still the
   failure, so `heads.split()[0] if heads else ''` stands. The no-repo shape is returned before any
   runner is built. `run` passes `ctx.git`.
3. `step_wave.fresh_index(root)`: the two inline calls (`:548`, `:552`) become one
   `g = gitrun.Git(root)`, then `if not g.ok(['fetch', '-q', 'origin']): return None` and
   `raw = g.out(['show', f'origin/{branch}:index.json'])`. `''` from `out` falls into the existing
   `except (ValueError, KeyError, TypeError, AttributeError): return None`, so the `returncode`
   check goes and the three `None` returns stay three `None` returns. `shadow._default_branch(root)`
   is unchanged (step 7 moves its runner, not its answer). The function takes a `git=None` too, so
   a test reaches it with a `FakeGit`.
4. `step_prs`: `_git` (`:21`) deleted. `card_link(root, relpath, git=None)` calls
   `(git or gitrun.Git(root)).out(['remote', 'get-url', 'origin'])` — `out` already strips, so
   `:70`'s trailing `.strip()` goes and the `if root else ''` guard stays. Then §2.6's duplicate:
   `DEFAULT_PRS_PER_TICK = 6` (`:14`) deleted and `prs_per_tick(product)` becomes
   `product.conventions.prs_per_tick`, the field that has existed at `asf/conventions.py
