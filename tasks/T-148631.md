**Steps**

1. Create `asf/record/milestones.py`, §1's parser: `NAME_RE` (`[A-Za-z0-9][A-Za-z0-9._-]*`, D-0003),
   `parse(text)` → `[(line_no, name, state, title)]` in file order, `declared(root)` →
   `{name: state}` and `{}` when the file is absent, `problems(text)`, and the `MILESTONES` header
   constant Task 6 and Task 7 both write, so a migrated record and a fresh one get the same file.
   A declaration is a top-level bullet: `NAME_RE`, a separator (em dash, en dash or hyphen — all
   three, D-0002), a word. Every other line is prose and ignored. No declarations is not a problem.
   **Read-only, stdlib only: never open a file for writing here** —
   `tools/check_record_writers.sh:18-20` greps `asf/record/` for exactly that and exempts only
   `writer.py` (Precondition 1).
2. `problems(text)`: three findings, each at its own line, in the spec's wording — a state word
   that is neither `open` nor `closed` → `a milestone is open or closed, not 'opne'`; the same
   name declared twice → at the second line; a declaration-shaped bullet whose name is not one →
   `'v' is not a milestone name`.
3. In `record_findings`'s pass over `canonical` (`check.py:269-361`), beside the parent and
   `BOOL_FIELDS` blocks: a set `meta.get('milestone')` must be a string `declared(root)` holds. A
   non-string or a list → `milestone: ['v0.2', 'v0.3'] is not one milestone name` at
   `find_line(rec, 'milestone')`; an undeclared name → `milestone 'v0.9' is not declared in
   milestones.md`.
4. Once per record, outside the card loop: each `problems(text)` entry as
   `('milestones.md', line, why)`. Read `declared()` **once** per check and pass it in — parsed
   once per check, not once per card.
5. `tree.record_paths(prefix)` (`tree.py:14-16`) gains `prefix + 'milestones.md'`, so
   `cmd_check_staged`'s two layouts each carry the declarations the cards on that side are judged
   against: a commit adding `milestone: v0.4` *and* declaring it is clean, one adding only the
   card is refused, one deleting only the declaration is refused at every card that named it.
6. `cmd_check`'s path filter (`check.py:187-190`), whose condition is
   `f[0] in restrict or f[0] == 'index.json' or f[0] in LAYOUT`, gains `milestones.md` — else
   `asf check features/F-0001.md` drops the declaration finding that explains it.
7. Extend `tests/test_work_item_model.py` with `MilestoneDeclaration`, covering S-136856's
   acceptance lines in three groups. The parser: file order, the three separators, `declared` with
   the file and without it (an absent file is not itself a finding), `problems`' three findings at
   their lines, `NAME_RE` against `v0.3`, `0.3`, `v 0.3` and the empty string. The card rule: a
   declared name clean, an undeclared one a single finding on that card's own `milestone:` line, a
   list a single finding, the file's own problems reported at `milestones.md`, and the file parsed
   once per check — count the parse, do not time it. The staged form: `record_paths('')` holds it; a
   card-plus-declaration commit is clean; the same commit without the declaration is refused,
