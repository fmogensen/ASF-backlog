§2.5, less the stall half of it (Task 4): `asf sessions`, `asf status`'s Agents row and the tick
digest's IN FLIGHT table each stop deriving a word and start printing the classifier's.

**Files**

- `asf/views/sessions.py` — `live_rows` returns three lists (`:60-72`); the header line and the
  table loop (`:122-135`); `LIVE_COLUMNS` gains the two per-group columns; the module docstring's
  four groups become five.
- `asf/views/status.py` — `agents_cell` unpacks three and drops a zero clause (`:108-113`).
- `asf/tick/summary.py` — `inflight_rows` sets `row['status']` from the classifier (`:84-91`);
  `IN_FLIGHT_COLUMNS`' `status` cell widens (`:124-135`).
- `tests/test_lifecycle.py` — the ratchet loses `asf/views/sessions.py`, `asf/views/status.py`
  and `asf/tick/summary.py`.
- `tests/test_views.py` (`SessionsViewTests:57`, `StatusViewTests:85`), `tests/test_tick_summary.py`
  — §3.4's cases.

**Steps**

1. `live_rows(product, alive=None, session_source=None)` returns `(working, ended_awaiting, dead)`,
   splitting on `state_of(product, run, alive=alive)` and keeping each row's `Status` on it so the
   renderer needs no second call. `alive` resolution is unchanged (`health.alive_for`, F-0076
   D10/D11).
2. `render`'s header becomes
   `**SESSIONS** — 2 working · 1 ended, awaiting tick · 0 dead · 14 ended · 0 other`, and the three
   live tables are driven by `lifecycle.LIVE_GROUPS` (P11). The `Ended, awaiting tick` table carries
   one extra column, `Result` (the derived result); `Dead` carries `Why` (`status.reason`). An empty
   group still prints `<Heading>: none`, so `Dead: none` is what an all-ended registry shows.
   The `Other` and `Ended` groups, and the unreadable-observation path, are untouched.
3. `views.status.agents_cell` prints `2 working, 1 ended (awaiting tick), 1 dead` from
   `LIVE_GROUPS`' count words, dropping any clause whose count is 0 and keeping the
   `no session registry yet` line exactly as it is (`asf/views/status.py:111-112`).
4. `tick.summary.inflight_rows(product, alive)` sets `row['status'] = state_of(...).label`; the
   IN FLIGHT `status` column widens to fit the longest label. `done_rows` is untouched.
5. The ratchet loses this Task's three modules.
