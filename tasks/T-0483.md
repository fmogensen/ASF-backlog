**Steps**

1. `import json` into the module's list (`asf/workers/spawn.py:29-34`), in alphabetical place. No
   `datetime`: `pool_mod.now_iso()` is already this module's way to stamp a UTC time, and `spawn`
   stamps `started` with it (`:765`).
2. `SETUP_MARKER = 'asf-setup'` beside `WORKTREE_SETUP_TIMEOUT_S` (`:668`), with the spec's comment
   block byte for byte — that the marker is in the **git admin dir** and never in the tree, that an
   untracked file in the tree would read as uncommitted work for ever
   (`asf.workers.worktrees.safety`), and that `git worktree remove` / `prune` delete the admin dir
   with the tree, which is what makes a recreated path count as fresh (D1/D2). The literal is the
   factory's own state name inside git's own directory, not a product convention (PD8).
3. `setup_marker_path(worktree)` → `os.path.join(_admin_dir(worktree), SETUP_MARKER)`, or `''` when
   `_admin_dir` is `''`. Through `_admin_dir` (`:181-192`) and never by joining the tree's basename
   onto `<repo>/.git/worktrees/`: git suffixes an admin dir whose name is taken, and `_admin_dir`
   reads the tree's own `.git` file, so a suffixed one resolves to its own (P9). This is the reader
   `_reclaim` already uses for `rebase-merge` and `MERGE_HEAD` (`:311-317`).
4. `setup_done(worktree, command)` — the spec's function, byte for byte, with its docstring: the
   marker parses as JSON and its `command` equals `command` exactly (D3 — the text the operator
   wrote, not a hash and not a flag). `except (OSError, ValueError, AttributeError): return False`
   covers an absent file, a truncated or non-JSON one, and a JSON scalar that has no `.get`. No
   admin dir is **not** set up (D8): the case is unreachable, because `make_worktree` returns only
   linked worktrees git made, and on an unreachable path running an idempotent command again beats
   handing a session a tree that may hold no dependencies.
5. `_record_setup(worktree, command, took_s)` — the spec's function, byte for byte: one JSON object,

   the path or `''`. `except OSError: return ''` and nothing raised: a marker that cannot be written
   is not a failed launch (D7) — the setup ran, the tree is good, and the only cost of a lost marker
   is one repeat of an idempotent command on the next launch in that tree.
