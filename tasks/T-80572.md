The spec's **In** 1 and its design §1, plus the `--build` half of §3. A new module's builder half
reads a real record and a real code repo and writes `tests/rehearsal/` — shapes kept, every prose
run cleared to deterministic filler — with a `manifest.json` stating what it wrote; `manifest_holds`
reads the snapshot back against those claims; and `asf rehearse --build --from-product <p>` is the
command that does it, because S-79604's fourth acceptance line names that command. The runner,
`lay` and the acts are **Task 2's** and are not written here.

**Read this Task from `docs/plans/f-0306.md`, not from this card** — the record cuts a Task card's
description at 4000 characters and this section is longer, so the card stops before the Gate and the
Acceptance. Four decisions bind this Task and reach no card: **PD5** (the surface count bumps 59 →
60), **PD6** (the plugin needs no regeneration), **PD10** (the manifest's five-digit claim is proved
on the digit run in the test module, not by the spec's own `len(str(v))` fence) and the size table
above (the record is reachable from a session on this host — no operator hand-off).

**Files**

- `asf/rehearsal.py` — **new**, the builder half only: the module docstring; `filler(n, seed)`,
  seeded by a hash of the cleared run's length so two builds of one source sha are byte-identical;
  `build(record_dir, repo_dir, out, product=None)` returning the manifest it wrote; and
  `manifest_holds(snapshot)` returning `[]` or one line per broken claim. Stdlib plus `asf` only.
  It hardcodes **no** record path, **no** branch prefix and **no** item id: the record's layout
  comes from the product's own conventions and from the manifest (P19 — `python3 -m asf.conventions
  --forbidden` generates thirteen anchored patterns, among them `'worker/`, `'spec/`, `'plan/`,
  `'fix/`, `'docs/specs`, `'docs/plans`, `'docs/reviews` and `\bE-[0-9]{4}\b`; `tests/rehearsal` is
  not one of them, so the default snapshot directory may be spelled).
- `asf/cli.py` — `rehearse` registered beside `release-readiness` (`:448-455`), with `--snapshot`
  and, for this Task, `--build` and `--from-product`. It is **not** a record view: it takes no
  `resolve_record`, so the dispatch is its own `if args.command == 'rehearse':` branch, not a line
  inside the view block at `:710-745`. `rehearse` is free across all 76 subcommands (P14).
- `asf/surface.py` — one row keyed `rehearse`, scope `REPO`, with the spec's own help text.
- `tests/test_surface.py` — `:50`'s `59` becomes `60`, its trailing comment extended (PD5).
- `tests/test_rehearsal_snapshot.py` — **new**. `manifest_holds` on the committed snapshot and on
  each of the three breakages S-79604's third line names (a card removed, an id narrowed to four
  digits, a tag's `annotated` flipped); the manifest's keys; the five-digit claim read off the
  **digit run** of each `widest_id` value, not its string length (PD10); the three intake states of
  §1 present in `tests/rehearsal/record/`; and `BuilderIsDeterministic`, the class the spec's fence
  names, building twice from one synthetic source and comparing bytes. Every test builds from a
  **synthetic** source record it writes itself — the suite reaches no real record and no network.
- `tests/rehearsal/**` — the artefact: `README.md` (what it is, what it must preserve, how to
  refresh it, what never goes in it), `manifest.json`, `record/` and `repo/`.
