drift a contributor never notices becomes a `doctor` row and, past a week, a Bug. Nothing here writes
the trunk — the tick checks and files; a session on a branch fixes (§1.2).

**Files**

- `sample/product.yaml` — `conventions.readme: README` and `conventions.readme_facts:
  readme-numbers.json`, both relative to the sample's repo dir.
- `sample/repo/README` — two spans, one inline and one block, added to the line it already carries.
- `asf/doctor.py` — `check_readme(product)`; the `readme` row in `run()`, after `drift` and before
  `capacity`.
- `asf/tick/file_bugs.py` — `readme_signatures(root, now, conv)`; `README_STALE_DAYS = 7`; the fourth
  `signatures.update(...)` in `cmd_file_bugs` (`asf/tick/file_bugs.py:234-237`) and the source named
  in the module docstring's list of three.
- `tests/test_sample_product.py` — `ReadmeRenderTests`.
- `tests/test_doctor.py` — `ReadmeRowTests`.
- `tests/test_file_bugs.py` — `ReadmeStaleTests`.

**Steps**

1. The sample's two conventions keys and its README's two spans. A path this repo's own layout
   hard-codes fails here, which is why the sample's README is named `README` and its facts file sits
   at the repo root rather than under `docs/`.
2. `ReadmeRenderTests` in the sample product's existing end-to-end pass: `asf readme --refresh
   --product sample` fills both spans from the sample record's own cards, and `--check` is green
   afterwards. The rendered file and the facts file live in the temp copy only — nothing is committed
   into `sample/repo/` but the spans.
3. `check_readme(product)` — one `doctor` row from `asf readme --check --json`: `ok`, or
   `n complaints — <the first>`. Required, so a drifted page is RED; skipped entirely (`ok=None`) for
   a product whose README carries no span, and for one whose repo dir does not resolve.
4. `readme_signatures` — signature `readme/stale`, produced when `--check` is red **and** the
   committed facts' `day` is more than `README_STALE_DAYS = 7` behind the record's newest event day.
   A page merely a day old files nothing. One signature, so `_file_or_bump_bug`
   (`asf/tick/file_bugs.py:160`) bumps rather than duplicates on the next tick — the mechanism that
   is already there, unchanged.
5. `ReadmeRowTests`: the row is `ok` for a sound page; RED naming the first complaint for a page
   whose span was hand-edited; absent-or-skip for a spanless README; the table still formats.
6. `ReadmeStaleTests`: eight days behind and red files one Bug with signature `readme/stale`; a
   second run bumps `count` and `last_filed` and mints no second Bug; six days behind files nothing;
   red with no facts file files nothing rather than crashing.
