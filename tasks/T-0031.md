## Description
stories: S-7950, S-7951
writes: asf/groom/shape.py, asf/groom/inbox.py, tests/test_inbox_shape.py

**Files**: `asf/groom/shape.py` (new), `asf/groom/inbox.py` (only the move of
`infer_parent_epic`, PD2), `tests/test_inbox_shape.py` (new: `ShapeRulesTest`,
`ShapeQuestionTest`).

**Steps**
1. `shape.py`: `Shape`, `Question`, `Card`, `SIZE` (the spec's five texts, verbatim),
   `RULES`, `SHAPE_LINE_RE`, and
   `DEFECT_WORDS_RE = re.compile(r'\b(broken|red|fails?|failing)\b', re.IGNORECASE)`.
2. Move `infer_parent_epic` into `shape.py` unchanged. `inbox.py` then does
   `from asf.groom.shape import infer_parent_epic`. The rest of `inbox.py` does not change in
   this Task.
3. `derive(card, canonical, default_bug_parent=None)`, in the order PD3 sets:
   - Both `signature` and `writes` in `card.headers` → `Question('A card is one thing: signature: makes it a Bug, writes: makes it a Task — drop one.')`.
   - `parent` given and not in `canonical` → the PD3 text.
   - `signature` → bug. The parent is `parent:` if its type is in `PARENT_TYPES['bug']` (otherwise the PD4 text), else `default_bug_parent`, else `Question('Which item is this Bug under? Add a `parent: <id>` line.')`.
   - `writes` → task. The parent must be a Feature or a Story, otherwise `Question('A Task hangs under a Feature or a Story — add parent: <id>.')`.
   - `features-list`: `len(card.features) >= 2` → epic with parent `None`. If a `parent:` is present → `Question('An Epic has no parent — drop the parent: line, or it is a Feature under that Epic.')`.
   - `parent-feature`: the parent's type is `feature` → story if `card.acceptance` has items, otherwise `Question('A Story is one PR with one acceptance list — add an ## Acceptance checklist.')`.
   - The parent's type is `story` → `Question('Under a Story only a Task hangs — add a writes: line, or parent the card to the Feature.')`.
   - `DEFECT_WORDS_RE` matches title + description and `card.acceptance` is empty → the D5 text, verbatim from the spec.
   - `default` → feature. The parent is a `parent:` naming an Epic. A `parent:` of any other type → `` `parent: X` is a <type> — a Feature hangs under an Epic. ``. With no `parent:`, the parent is `infer_parent_epic(canonical, tokenize(card.title))`, and if that finds nothing → `Question('Which Epic is this under? No open Epic shares a title word with it.')`.
   - Then D4: if `card.headers.get('type')` is present and is not `shape.type` (compared lower-case) → `Question(f"`type: {t}` is not read — the card's shape reads as {type} ({rule}: {SIZE[type]}). Remove the line, or change the shape.")`.
4. `tests/test_inbox_shape.py`: a module docstring, the `card(title, headers=None, description='',
   features=(), acceptance=())` helper, and `seeded_canonical()`. `seeded_canonical()` builds the
   spec's record (E-0001 `Factory billing`, decided; F-0001 `Billing plans` under E-0001; S-0001
   under F-0001) in memory from `frontmatter.parse` of the card texts, with no temp dir. Then
   every `ShapeRulesTest` and `ShapeQuestionTest` case the spec lists, with the names and asserted
   substrings exactly as there.
