**Steps**

1. Create `asf/kernel/proof.py`, pure, with exactly the three things §2.1 names.
   `needed_ids(it, items)` is `asf.kernel.needed.test_ids` (`asf/kernel/needed.py:66`) and
   nothing else — one parser for "the tests this card names", reused, so the ids are the card's
   and never its plan's (P3) and are at most `resolvers.MAX_IDS`.
2. `Proof` — one value per `(item, base_sha, head_sha)`: `{test: {'base': …, 'head': …}}`, each
   side one of `red`, `green`, `absent`, `error`, with the two shas beside it.
3. `judge(proof)` → `(state, reasons)`, `state` one of `proved`, `failed`, `pending`, exactly
   §2.1's table: `red`/`absent` base with a `green` head is proved; a `green` base is failed
   ("it passes on the base, so it proves nothing about this change"); a `red` head is failed
   ("the head is red on a test the checks called green"); an `absent` head is failed, naming the
   missing id; any `error` side is **pending**; and `judge(None)` is pending. One `green` base
   among otherwise proved tests still reads failed — the state is the worst of the rows, not a
   majority. `reasons` is one line per failing test, in id order, so the same proof renders the
   same reasons twice. `proof.findings(reasons, head)` stamps each one through
   `asf.kernel.findings.stamp` (Task 1).
4. `asf/kernel/trunk.py`: one new probe class whose target carries the sha and the ids, so the
   run is at a **given** sha rather than `_trunk_sha()`'s tip (K9, D-0002). It reuses `_in_worktree`
   (`:249`) and `_unittest` (`:289`) unchanged, counts one against `test_runs_per_tick` per run
   like `TRUNK_TESTS` does (`:146-148`), caches by its own probe key, and is skipped — not
   guessed — when the budget is spent (`:136`) or a dry run is active (`:113`). Add its bullet to
   the module docstring's class list (`:4-27`), in the voice the other four use.
5. `asf/kernel/resolvers.py`: the class constant beside `TRUNK_TESTS` (`:52-53`), added to
   `PROBED` (`:56`) and to its comment. No `match` rule and no `answer` rule: this class is never
   matched out of a session's question — the proof probe asks for it directly, which is why it is
   in `PROBED` and in no `match` branch.
6. Create `asf/kernel/proof_probe.py`, the host half, shaped on `asf/kernel/needed_probe.py`
