## Description
stories: S-14855
writes: asf/workers/lifecycle.py, tests/test_lifecycle.py
after: Task 2, Task 3

The spec's `asf/workers/lifecycle.py` section. `judge` gains one clause, after the result's own
failure and after the push checks (D6), so a run that failed for a real reason is judged on that
reason. `report_spent` is the registry read the caller resolves, exactly as `landing` is, and
`report_text` is the correction D9 describes. Nothing holds yet — Task 5 does the holding.

**Files**

- `asf/workers/lifecycle.py` — `RUN_FIELDS` gains `'report'` (B-0041); `REPORT = 'report'` beside
  `UNPUSHED`/`EMPTY`; `BAD_REPORT = report.BAD_REPORT` re-exported for health's prefix test;
  `report_spent(path, run)`; `judge(run, ev, landing=None, report_done=False)` with the clause
  last, before `FINISHED`; `derive` passes `report_done=report_spent(path, run)` beside its
  `landing=lands(run, path)`; `report_text(kind, why, tail)`.
- `tests/test_lifecycle.py` — `BadReportJudgeTest` and `ReportTextTest` (new, the spec's cases).

**Steps**

1. `RUN_FIELDS`, `REPORT`, `BAD_REPORT`.
2. `report_spent`: True when any run on this run's branch carries a `correction` of kind `report`
   or a `report` field of its own; the branch, not the job (D8). `False` for a run with no branch.
3. `judge`'s clause, verbatim from the spec, reading `ev.result and ev.result.get('result')`;
   `report.check(None, …)` is `None`, so a run whose kind names no schema is not judged on its
   report.
4. `derive` passes `report_done`; every other caller of `judge` keeps its two arguments and so
   keeps today's behaviour until Task 5 gives it the third.
5. `report_text`: the sentence, "your work is pushed and is not being re-done — print the report
   again, in this shape", `contract(kind)`, then the last 20 lines of the result under "what you
   said".
6. The two test classes, then the suite.

- `BadReportJudgeTest`
  - `test_a_pushed_run_with_no_typed_report_fails`: an ok result with prose only, a pushed branch
    with commits → `judge(run, ev)` is `failed: bad report: …` naming `asf-report`.
  - `test_a_pushed_run_with_a_good_report_finishes`: the same run with
    `report.render('coder')` appended → `FINISHED`.
  - `test_the_report_is_judged_last`: an unpushed branch *and* no report → the verdict is
    `failed: not pushed: …`, not the report's (D6).
  - `test_a_run_whose_kind_has_no_schema_is_not_judged_on_its_report`: `kind: None` and
    `kind: 'preflight'` with no report → `FINISHED`.
  - `test_report_done_skips_the_clause`: no report, `report_done=True` → `FINISHED`.
  - `test_report_spent_reads_the_branch_not_the_job`: a registry with a `report` hold on run A of
    branch `worker/T-1` → `report_spent(path, {'branch': 'worker/T-1'})` is True for a *different*
    job on that branch, and False for another branch (D8).
  - `test_report_is_a_run_field`: `'report' in lifecycle.RUN_FIELDS`, and a fold over
    `launch, report=unreadable, launch` leaves the second run without it (B-0041).
- `ReportTextTest`

    `report_text('spec', 'no ```json asf-report block…', tail)` contains the sentence, every
    field name of the `spec` contract, the words `not being re-done`, and the tail's last line.
