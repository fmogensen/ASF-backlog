## Description
stories: S-80458
writes: asf/conventions.py, tests/test_conventions.py, tests/test_regression_gate.py
after: Task 1

Off by default is the point: a product that takes this release does not have its incident lane
start holding branches nobody asked it to hold (PD9).

**Files**

- `asf/conventions.py` — four dotted names in `KNOWN_FLAGS` (`:403`), and the malformed-value
  checks beside `pre_push_check`'s own validation (`:600`).
- `tests/test_conventions.py` — the registry and the two malformed cases.
- `tests/test_regression_gate.py` — `FlagsTest`.

**Steps**

1. Add `regression.check`, `regression.exempt_found_in`, `regression.command` and
   `regression.fail_re` to `KNOWN_FLAGS`, which today holds 36 names and no name matching
   `regress` — so each is unregistered and the doctor would call a product setting it unread.
2. `regression.check` defaults to `off`; `exempt_found_in` to `['ci']`; `command` unset falls back
   to `conventions.test_command` with `{base}` substituted either way; `fail_re` unset falls back
   to the built-in shapes Task 1 wrote.
3. `asf check` / `doctor` **says** a malformed one rather than acting on it — a `command` that is
   not a string, an `exempt_found_in` that is not a list of strings — as the `pre_push_check`
   validation at `:600` already does, and the value never reaches the runner.
4. Write `FlagsTest` to the five acceptance lines of S-80458, and the registry and malformed cases
   into `tests/test_conventions.py` where that module already holds the flag-registry assertions.

**Gate**

```bash
python3 -m unittest tests.test_regression_gate.FlagsTest tests.test_conventions -v
for m in test_regression_gate test_conventions test_config_keys; do
  echo "== $m"; python3 -m unittest tests.$m 2>&1 | tail -3
done
bash tools/check_generic.sh && bash tools/check_conventions.sh \
  && python3 tools/run_tests.py --touched origin/main --shards 2
```

**Acceptance** (the spec's S-80458 fence, byte for byte)

```bash

```
