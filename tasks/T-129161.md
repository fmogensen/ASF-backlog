## Description
stories: S-74456
writes: asf/tick/rejudge.py, tests/test_rejudge.py
after: Task 2

The four rows the card names are parked now, and a park is a pending correction: no session is
launched on it until a card edit or `asf unpark` lifts it. Task 2 makes `needs_input` `None` for
such a run, which is already the whole condition `release_answered` releases on (P9) — so this
Task adds no condition. It makes the reason truthful, so the tick log does not claim the report
asked nothing when it plainly printed a `NEEDS OPERATOR:` line (C5).

**Files**

- `asf/tick/rejudge.py` — `release_answered` only: the `why` line (`:81`). No new condition, no
  change to `asked`, `judged`, `_text` or the hold that follows.
- `tests/test_rejudge.py` — `ReleaseAnsweredTests` gains the refusal park's cases; its existing
  cases stay as they are.

**Steps**

1. `release_answered` (`asf/tick/rejudge.py:81`): replace the one `why` assignment with

   ```python
   why = ('its only question was a heartbeat-start refusal (re-judged)'
          if report_mod.heartbeat_refused(text) else 'its report asks no question (re-judged)')
   ```

   `report_mod` is already the module's import, and `heartbeat_refused` is on it after Task 2's
   C6 move — this is the edge in `after:` (**PD11**). Everything downstream is unchanged: the
   same `unparked`/`unpark_why` fields, the same `ctx.event('unparked', …)`, the same
   `out(f'unparked …')` line, the same `judged(run, text)` and the same unpushed hold.
2. `tests/test_rejudge.py`, `ReleaseAnsweredTests`: a `blocked` park whose run's report declares
   only a refusal is released — `correction` `None`, `unparked` stamped, and `unpark_why` exactly
   `its only question was a heartbeat-start refusal (re-judged)`; the tick prints one
   `unparked <item> (job <job>): its only question was a heartbeat-start refusal (re-judged)` line
   and raises an `unparked` event; the released run is judged on its own report (an empty branch
   with `status: done` → `nothing to land`, unpushed work → a correct round); and a park for a
   real question still stands, with `its report asks no question (re-judged)` still the reason for
   a report that genuinely asks nothing.
