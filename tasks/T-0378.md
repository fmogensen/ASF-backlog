**Steps**

1. The constants, beside `PHANTOM_RED_S` (`:313`): `DEFAULT_STEP_SILENCE_MIN = 10`, and
   `MOVING, STEP_SILENCE, BUDGET, UNKNOWN = 'moving', 'step-silence', 'budget', 'unknown'`, each
   with the `#:` comment §2.2 gives it.
2. `step_silence(job, now, limit_s)` — `(class, step name, since)` for one job, §2.2's docstring
   verbatim. The body is the spec's table and nothing else: take the job's `steps` (absent, not a
   list, or empty → `(UNKNOWN, None, None)`); parse each `started_at` and `completed_at` through
   the module's `_parse` (`:325`); the *newest parsed start* is the step it is inside, ties broken
   by the later position in the provider's own order, never by name; `(UNKNOWN, None, None)` when
   no step has a parsable start; `(MOVING, name, start)` when any step's parsed `completed_at` is
   at or after that start, or when `(now - start).total_seconds() <= limit_s`; else
   `(STEP_SILENCE, name, start)`. No clock, no host, no configuration, no import.
3. `_minutes(v, default)` — the duration grammar at this module's level (D11, P17): a bool is the
   default, an int or float is minutes, a string matching `^\s*(\d+(?:\.\d+)?)\s*([smhd]?)\s*$`
   scales by `{'s': 1/60, 'm': 1, '': 1, 'h': 60, 'd': 1440}`, anything else is the default. The
   same table as `asf/workers/stall.py:52-60`, which `ci_queue` may not import.
4. `step_silence_seconds(product)` — §2.2's docstring: `_qcfg(product).get('step_silence_min')`
   (`:350`) through `_minutes` with `DEFAULT_STEP_SILENCE_MIN`, as seconds. `0`, and the strings
   `off`, `none`, `false` (case- and space-insensitive), and a literal `False`, all return `0` —
   the watch off (D12). A negative number returns `0` too: a limit below zero is not a shorter
   watch, it is no watch.
5. `JudgeTests` in `tests/test_ci_step_silence.py`, one case per row of §2.2's table, named exactly
   as §3.2 names them:
   - `test_a_step_started_past_the_limit_with_no_completion_since_is_step_silence`
   - `test_the_named_step_is_the_newest_started_one`
   - `test_a_completion_after_the_newest_start_is_moving`
   - `test_a_step_under_the_limit_is_moving`
   - `test_a_job_between_steps_is_moving_not_stalled` — §2.2's fourth row: `build` completed 12 min
     ago and `test` has not started, so the newest *start* is `build`'s and `build` completed at or
     after it. `moving`, named `build` (§1.2).
   - `test_no_steps_is_unknown_and_claims_nothing` — `steps: []`, `steps` absent, and `steps: None`.
   - `test_steps_with_no_start_are_unknown`
   - `test_an_unparsable_stamp_is_unknown_never_stalled`
   - `test_a_tie_on_started_at_names_the_later_step_in_provider_order`
   - `test_the_limit_is_read_from_the_product_and_defaults_to_ten_minutes` — the product built in
     memory (`env.Product('p', {...})`, as `tests/test_ci_queue.py:27-36` builds one), so the judge
     is tested with no file and no `config_problems` in the way.
   - `test_zero_and_off_turn_the_watch_off` — `0`, `'0'`, `'off'`, `'none'`, `'false'`, `False` and
     a negative all give `0`.
   - `test_the_duration_grammar_matches_stall_silent_minutes_over_one_table` — one table of inputs
     (`45`, `'45'`, `'45m'`, `'1h'`, `'30s'`, `'2d'`, `'nonsense'`, `''`, `True`) asserted equal
     against `asf.workers.stall.silent_minutes` over a product carrying the same value in
     `stage_limits.silent_min`, so the two grammars cannot drift apart silently (D11). The off
     words are asserted as this module's own extension and are not put to `silent_minutes`.
