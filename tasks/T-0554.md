## Description
stories: S-37255
writes: asf/approvals.py, tests/test_connectors.py
after: Task 1

The spec's fifth `## In` bullet and `## The design` §5: four lines inside `signals`, and a database
CLI's `migrate` stops reading as an ordinary command.

Read **PD14** (the local import, and why it is what makes the direction safe) and **PD17**.

**Files**

- `asf/approvals.py` — `signals` (`:199-221`) only
- `tests/test_connectors.py` — `ConnectorActionsTests`

**Steps**

1. `signals(product)` gains the spec's docstring sentence byte for byte — *"A connector's `actions:`
   are merged in first, under the class each action names (F-0185 D3); the product's own
   `approval_signals` are appended after, so a product can always add to what a connector declares
   and never has to fight it."*
2. `out = connectors.approval_signals(product)` through a **function-local** `from asf import
   connectors` (PD14 — `connectors` reads `CLASSES_BY_NAME` from this module), and the existing loop
   **appends into `out[cls]`** rather than assigning, so a class both name keeps both sets of
   patterns and the product's come second. Every existing refusal, including a product that declares
   no connectors at all, is byte-identical: `approval_signals(product)` is `{}` for it.
3. **Nothing else in the module changes** — `_command_matches` (`:487-496`), `_classify_command`
   (`:499-509`), `classify`, `merge_class`, `_COMMAND_PATTERNS`, `CLASSES` and every class in it are
   untouched (the `## Out` list's fourth entry). `recognisers(product)` (`:1306-1318`) picks the
   merged patterns up for free and lists them as `signal command: …`, which is D3's whole argument
   for this seam: one function feeds the classifier, the doctor's approvals row **and** the printed
   matrix, where a branch in the matcher would have fed the first and silently skipped the other two.
4. `ConnectorActionsTests`: a connector's `actions:` entry refuses the command it matches, at the
   class it names, **through the real hook path** (not by calling `_command_matches`) — copy
   `tests/test_approvals.py`'s own hook-path idiom; a connector action for `touch_customer_data`
   refuses a command that today matches nothing at all, since `_COMMAND_PATTERNS` names that class
   nowhere (P7); `recognisers` lists it as a `signal command:` line; and a class that a connector
   **and** `approval_signals` both name carries both patterns with the product's second.
5. Re-run `tests.test_approvals` whole. The spec names it in this Story's fence precisely because
   *"every existing classification is unchanged"* is the assertion that matters more than the new
   one, and a merged-in empty dict is what makes it true.
