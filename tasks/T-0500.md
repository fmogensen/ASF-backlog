**Steps**

1. `apply_list` — replace `asf/record/setfield.py:56-64` with `## The design`'s version byte for
   byte: the `covers=False` keyword, the docstring (which names `norm_writes`, D2, D3 and what
   `changed` means), the function-local `from asf.feeder import widen` with its `(D3, D4)` comment,
   `have = widen.norm_writes(_as_list(current))`, `want = widen.norm_writes(value)`, and the three
   branches returning `(list, bool)`. Note what each branch's `changed` is computed against: `+` is
   `bool(add)`, `-` is `kept != have` where `have` is the **normalised** current (so a `-=` of a
   packed entry's inner path is `changed=True`, which is the first defect), and `=` is
   `want != have` (so `writes=[a b]` on `writes: [a, b]` is `changed=False` and rewrites nothing
   the operator can see).
2. `_why_not_removed` — add `## The design`'s function directly below `apply_list`, byte for byte:
   the docstring naming D5, the function-local `widen` import, the `next((w for w in have if w != v
   and widen.covered(v, [w])), None)` search, the two message shapes, and `'; '.join(dict.fromkeys(out))`
   so a `-=[a, b]` where both are covered by the same glob says it once.
3. `cmd_set`'s fold — add `idempotent = []` beside `updates = {}` (`:79`), that is PD1(a). Then
   apply `## The design`'s diff to the list-field branch: `updates[top], changed = apply_list(base,
   op, value, covers=(top == 'writes'))`, the `op == '-' and not changed` refusal printing
   `f"error: {top}-={' '.join(value)} removes nothing — " + _why_not_removed(top, args.id, base,
   value)` to stderr and returning 2, and the `op == '+' and not changed` branch appending
   `(top, value)` to `idempotent`. Keep the existing empty-`writes:` refusal exactly where it is,
   **below** both new branches — PD6 has why, and `test_emptying_writes_is_refused` is what breaks
   if it moves.
4. The print — PD1(b) and PD4. After `err = set_typed(...)` returns None and before today's `set`
   line (`:101-103`), emit one line per `idempotent` entry in D6's exact wording:
   `f"{args.id}: {top}: already covers {' '.join(widen.norm_writes(value))} — footprint unchanged"`.
   Then print today's `set` line **unless** every assignment in `sets` was a list-field op that
   returned `changed=False` — track that with a single flag set in the fold; the line's body is
   unchanged. The one `widen` import this needs is function-local like the other two (D4).
5. The module docstring — its last paragraph (`:7-8`) already names the three forms. Add the two
   rules this card puts under them: that both sides are flattened first, so a plan's packed entry is
   the paths it names; and that on `writes:` an add the footprint already covers adds nothing while a
   remove that would remove nothing is refused. Two sentences, no worked examples — those are the
   guide's, which is Task 2.
