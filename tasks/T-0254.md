## Description
stories: S-29403
writes: asf/init.py, tests/test_install.py
after: Task 7

§2.6 and D9. `tools/install.sh:147` is one of two adoption paths; `pipx install` + `asf init` is
the other, and it is the one the CHANGELOG's upgrade line teaches. An adopter who never sees the
two `/plugin` lines has a factory with no console.

**Files**

- `asf/init.py` — `cmd_init`'s tail, after the console-permissions offer (`:320`–`:323`), and a
  `_marketplace_slug()` helper
- `tests/test_install.py` — the plugin block, and the three slug cases

**Steps**

1. After `console_perms.offer_text(product)` and the `run one to write it:` line, print §2.6's
   block verbatim in shape: the `console:` sentence, the two indented `/plugin` lines, and the
   skills line — `15 skills: /asf:status, /asf:next, /asf:ci, /asf:health, /asf:performance, …`
   with the names from `plugin_build.skill_names()` and the count from `len()` of it, neither
   retyped (PD15). Init's return code and every earlier step are unchanged.
2. `_marketplace_slug()` (PD15): `cli._direct_url().get('url')` reduced to `<owner>/<repo>`
   first; when there is no `direct_url.json` — a checkout rather than a pipx install — the
   checkout's `git remote get-url origin`, reduced the same way; and when neither resolves, the
   literal `<your ASF remote>`. It writes no repo, owner or host name into the module: all three
   branches derive their value or print a placeholder.
3. `tests/test_install.py`, §3.8: `asf init --product p --repo <fixture> --backlog <tmp>` ends
   with the console-permissions offer it ends with today *and* the plugin block; the fifteen
   `/asf:*` names in the output equal `plugin_build.skill_names()`; the slug comes from
   `direct_url.json` when there is one, from `origin` when there is not, and is
   `<your ASF remote>` when neither resolves; and in none of the three cases does a repo, owner
   or host name appear in a tracked file — `asf/redact.py`'s scanner over the tree, beside
   `tools/check_generic.sh`, is the standing check. Everything the file already asserts about
   init's earlier steps is unchanged.

**Gate**

```sh
python3 -m unittest -v tests.test_install tests.test_sample_product tests.test_redact tests.test_check_generic
python3 tools/run_tests.py 2>&1 | tail -3
bash tools/check_generic.sh && bash tools/check_conventions.sh && python3 -m asf.cli plugin check
```

**Acceptance**

```bash

```
