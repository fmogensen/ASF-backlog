`## The design` §4, whole. One defaulted keyword on the function that mints every card this product
writes — `new`, the groom's inbox intake, `file-bugs`, `flaky` and the plan's own Task cards all go
through it. It lands alone, before anything uses it, so that the one Task touching the shared path
is the one Task whose whole job is proving it changed nothing.

**Files**

- `asf/record/ids.py` — `write_new_item`'s signature and its `meta['state']` line (`:59`, `:73`)
- `tests/test_new_publish.py` — one case

**Steps**

1. `asf/record/ids.py:59` — append `state='New'` to `write_new_item`'s parameter list, **after**
   `shape=None`. Last, not inserted: the two positional callers in the suite stop at `why`, and the
   five keyword callers in `asf/` name everything after it (PD13).
2. `:73` — `meta['state'] = 'New'` becomes `meta['state'] = state`. Nothing else in the function
   moves; in particular the line keeps its position **after** the `typed_fields` copy, so a `state`
   in `typed_fields` is still overwritten, which is P8 and is what every existing caller relies on.
3. Add one sentence to the function's behaviour where it is documented. `write_new_item` has no
   docstring today; give it none — add the reason as a trailing comment on the parameter line or
   beside `:73`: the state a card is *born* in, `New` unless the writer is recording something that
   is already true. Keep it to one line; this is not a docstring-adding Task.
4. `tests/test_new_publish.py` — one case in the existing class beside the `:29` seed: call
   `write_new_item(self.root, {}, 'decision', 'D-0001', {'title': 'A decision'}, '', '2026-01-01',
   'seed', state='Closed')` into a scratch root and assert the written file's frontmatter carries
   `state: Closed`; and assert the existing positional call at `:29` still yields `state: New`. Two
   assertions, no new class, no new fixture — the file already builds a record with a git origin in
   `setUp` and that is all this needs. `'decision'` is used rather than `'feature'` because it is
   the type this keyword exists for and needs no `parent`.
5. Change no caller. `grep -rn 'write_new_item(\|_write_new_item(' asf/ tests/` must show the same
   five `asf/` call sites and the same two positional test call sites after this Task as before it,
   all unchanged.
