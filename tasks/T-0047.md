Depends on T-9450: `observe` parses the id with `lifecycle.parse_session`.

**Files**

- `asf/workers/observe.py` (new): `Observed`, `ObserveError`, `SessionSource`, `ProcessSource`,
  `CommandSource`, `FakeSource`, `source_from_config`, `read`, `identity_alive`.
- `tests/test_session_identity.py`: `ObserveTest`, plus a `fake_ps(directory, table)` helper that
  writes an executable `ps` stub printing `table`, or exiting 1. This is the `fake_launchctl`
  pattern (`tests/test_scheduler.py:63`). Tests put its directory first on `PATH` through
  `mock.patch.dict(os.environ, …)`.
- `docs/config.example.yaml`: the three `worker_pool` keys, commented.

**Steps**

1. `Observed = namedtuple('Observed', 'pid ppid account session product job owner cwd')`. `cwd` is
   None from every source here. The spec names the field and no source can read it with one `ps`
   call, so it stays None and nothing reads it.
2. `ProcessSource(binary, match)`: one `subprocess.run(['ps', 'axeww', '-o', 'pid=,ppid=,command='])`.
   `FileNotFoundError` or a non-zero exit → `ObserveError(<why>)`. Each line is `pid ppid rest`.
   It is a candidate when `re.search(match, rest)`, with `match` defaulting to
   `^(\S*/)?<binary>(\s|$)`. Drop a candidate whose ppid chain through the *full* table reaches
   another candidate, and guard the walk against cycles. The env comes from the `KEY=VALUE`
   tokens of `rest` for the five keys, and the last occurrence wins.
3. `CommandSource(cmd)`: `shlex.split`, run, one JSON object per non-empty line
   `{"pid", "ppid", "env": {…}}`. Non-zero exit or unparsable output → `ObserveError`.
   `FakeSource(entries)` returns those entries as they stand (D3).
4. `source_from_config(cfg)`: `worker_pool.sessions` (`process` default | `command` | `fake`).
   `command` with no `sessions_command` → `ObserveError` at read time, which is D10, not a crash
   at config load. `binary` = `worker_pool.binary` or `runtime.DEFAULT_BINARY`.
5. `read(cfg, accounts, source=None) -> ([Observed], why)`. The account is assigned by spec D7,
   in that order, with realpath on both sides (D11). `owner` is `asf` iff `ASF_SESSION` is
   set. `product`/`job` come from `parse_session`, else None. An `ObserveError` → `([], str(e))`,
   never raised.
6. `identity_alive(observed, runs)` exactly as the spec's bullet (D11 of the spec). Nothing calls
   it yet. T-9453 wires it in.
7. `docs/config.example.yaml`: under `worker_pool:`, after `accounts`, add the three keys commented
   out, with one comment line each: `sessions: process   # process | command | fake`,
   `sessions_command: …   # prints one JSON object per session: {"pid", "ppid", "env"}`, and
   `session_match: …   # default: the runtime binary as argv[0]`. Nothing else in the file moves.
8. `ObserveTest` as below.
