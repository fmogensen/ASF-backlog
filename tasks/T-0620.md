   A default, and last, so no positional `Row(...)` construction anywhere moves.

2. `console_amend_row`: keep the `hit`/`if not hit: return None` head byte for byte, then

   ```python

   reason = (f'writes: {hit} is in the amendable set — no worker session edits it; the '
             f'console makes the edit on {branch}')
   if outside:
       reason += SPLIT_CLAUSE.format(globs=', '.join(outside),
   ```

   ```python
                                   verb='is' if n == 1 else 'are',

   out(f'NEEDS OPERATOR: {row.item_id} writes {row.amend} (amendable set) — no worker'
   ```
