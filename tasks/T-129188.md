## Description
stories: S-91405, S-91406, S-91407

after: none

A session told that its work is already on the trunk under another commit is told, in as many
words, to make one empty signed commit naming its item and push it. That commit changes no file, so
the lane's trunk test — "every file the branch touched is identical on the trunk" — ran over an
empty list and held vacuously: the branch was declared already on main, its PR closed, the ref
deleted, and the record stamped at a trunk tip the branch never reached. The one commit that could
have closed the card was the one deleted, so the card stayed open and the row launched again, and
the next session's proof was deleted the same way. This Task makes the branch's own commits its
deliverable.
