1. `hosts_ci(product)` — `(sum of slots, 'ci.hosts: ci-1 2, ci-2 1')`, `(None, None)` with no

2. `product_ci`'s fall-through and PD5's derived wording. Verify the pool product's string is

   every existing `tests/test_capacity.py` assertion green.
3. `ci_runs_in_flight`'s clause at the top. `_pick_ci_source` (`:557`) needs **no** change: it
   already returns `CiRuns()` for any non-empty `ci` dict, so a vm product reaches this function,
   and the clause answers before a `gh` process could be built. `VmCapacity` asserts it with a
   `run` that fails the test if called.

   PD7 — and, advisory, a run directory with no `running` row. Never raises: any exception is one
   unknown row, the shape `check_ci_runners` already uses at `doctor.py:1049-1050`.
