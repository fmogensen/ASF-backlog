The spec's design §3: one function in the one `gh` client, so that the 30 call sites which name no
environment at all (`P3`) stop running as the operator's login. It is the Story past the card's
literal words (`D6`) and it stands alone so a reviewer can cut it without touching anything else —
which is also why it is its own Task rather than folded into Task 2. The Story is bounded by its
own first acceptance line: a caller that passed an `env` already chose its identity and is not
touched, and that is every one of the ten readers of `P2` and every test that already pins one.

**Read this Task from `docs/plans/f-0333.md`, not from this card.** The record cuts a Task card's
description at 4000 characters (`PD16`), so the card stops inside the Steps and neither the
**Gate** nor the **Acceptance** below reaches it; the card's `links.plan` is this file. Two
decision rows bind this Task and are on no card: `PD5` (import `ghapp` locally inside `identity`,
and why `asf/github.py`'s module-scope set is left where it is) and `PD2`/`PD3` (the 30 sites and
the counts, re-measured at this head).

**Files**

- `asf/github.py` — one new function, `identity(env)`, and one changed line. `_spawn` (`:126-130`)
  becomes `'env': hermetic.git_env(identity(env))`. `identity` returns `env` **unchanged** when
  the caller passed one; otherwise it returns `os.environ` with the cached App token over it,
  from a per-process memo of the ambient product (`$ASF_PRODUCT`, which every session and the host
  already set), and `None` when there is no App, no token file or no readable product — so the
  call runs exactly as it does today. No product load per call, no mint, no network on this path:
  the memo is resolved once per process. `from asf import ghapp` goes **inside** `identity`
  (`PD5`). The module docstring gains a clause naming the default.
- `asf/upgrade.py` — `_gh` (`:534-543`) passes `env=dict(os.environ)` on its one
  `github.gh(args, json=json, timeout=timeout, run=run)` at `:540`, with a comment naming the
  reason: it reads the **factory's own** repository, which the product's installation is not
  installed on (`D6`). `os` is already imported (`:51`). This is the one site in the package that
  opts out by name, and `_gh` already turns a `RateLimited` into an Unknown of its own.
- `tests/test_github.py` — the new class `AmbientIdentity` for S-120857's ten lines. The module
  also runs `Ratchet` (`:209`) and the rest of the one client's own suite, which the Story's
  command runs whole.

   `runs` and `api` all reach `gh`/`call` through `**kw` — so this one line is every call in the
   module, which is what the client ratchet keeps true (`tools/check_clients.py:42`).
