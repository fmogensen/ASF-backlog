**Steps**

1. `asf/record/archive.py`: `plan(root, product, now=None)` — the whole decision as data, written
   once and read by every surface below: the retention and the floor, the candidates, the closure,
   the held-back cards each with every `(holder, field, index, holder state)` that holds it, the
   relpaths that would move, and the working-set size after. Pure: it opens no file for writing and
   is what `--apply` must have **before** the writer runs, because `stage.guarded` needs
   `only=paths` up front (**PD6**).
2. `asf/record/archive.py`: `render_plan(plan)` → §2.3's table byte for byte — the
   `archive: retention 30d (conventions.archive_after_days), floor 14d — ok` line, the
   `would move … ; … stay` line, the rows with path and reason, the `… N more (--why <id> for one)`
   elision, the `held back (N):` block naming the holder, the field and the holder's state, the
   `working set after: …` line with the count and the share, and `nothing written — rerun with
   --apply` last. A parent held back by its own child says so in the card's words — *"its child — a
   parent moves after its children"* — because the holder it names **is** a child (D-0004).
3. `asf/record/archive.py`: `apply(root, plan, product)` — §2.3's six steps in that order and no
   other (**PD13**, D-0022): the floor (a refusal writes nothing), the load and the closure as `plan`
   computed them, `audit` over the record **as it will be** with a non-empty result refusing the
   whole pass and printing each miss as a finding, the moves, the manifest, `index.refresh(root)`.
   It writes and returns relpaths; it does not commit — the tick's writer does (Task 6), and a pass
   run by hand leaves the operator a change to read. `index.refresh` needs no code to drop the
   archived entries: `build_index_data` builds from the loaded cards alone (P3).
4. `asf/record/archive.py`: `why(root, product, iid)` → §2.3's `--why` for one card: that it would
   move and the reason, or every reference that holds it with the holder's state, and for an
   already-archived id where it is and when it was archived.
5. `asf/cli.py`: `cmd_archive` wires the four flags Task 1 parked. No flag is the dry run; `--apply`
   prints the same table then `moved <n> cards, <m> notes` and the paths; `--why` and `--audit` are
   the two above, `--audit` exiting non-zero when it finds one and printing nothing and exiting zero
   when it does not. A floor refusal exits non-zero before a card is read.
6. `tests/test_record_archive_dryrun.py`: assert each of S-211570's eleven lines against real
   command output on a record built in `setUp`, including the exact first line and last line of the
   dry run, that the dry run writes nothing (compare a full `stage.snapshot` of the record before
   and after), the parent-held-by-child wording, the share after, `--why` in both of its answers and
   on an already-archived id, and `--audit`'s two exits. Assert `apply` with an audit made non-empty
   by hand moves **nothing** — the record's snapshot is unchanged — and prints each miss.
