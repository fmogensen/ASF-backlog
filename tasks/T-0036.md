## Description
stories: S-8000, S-8002
writes: asf/conventions.py, tests/test_conventions.py

**Files**
- `asf/conventions.py` — nine `DEFAULT_*` constants, nine dataclass fields, `forbidden_patterns()`,
  a `__main__` block.
- `tests/test_conventions.py` — `DefaultsTests.test_the_new_fields_default_to_none`, a new
  `ForbiddenPatternsTests`.

**Steps**
1. Nine module constants, each with the spec's documented comment, all `None`:
   `DEFAULT_BRIEFS_DIR`, `DEFAULT_MATRIX_PATH`, `DEFAULT_DESIGN_SPEC_NAME`,
   `DEFAULT_DECISIONS_FILE`, `DEFAULT_REPORTS_DIR`, `DEFAULT_REPORT_PATTERN`,
   `DEFAULT_CI_WORKFLOW`, `DEFAULT_CI_DEV_JOB`, `DEFAULT_DEPLOY_WORKFLOW`.
2. The matching dataclass fields, beside the existing ones and before `stage_limits`/`extra`.
   `field_names()` and `as_dict()` pick them up with no change; `from_mapping` already drops a
   `None` value, so a yaml key set to nothing keeps the default.
3. `forbidden_patterns()` (D4, D5, PD9): walk the string values of `DEFAULT_BRANCH_PREFIXES`
   (skipping `legacy`, a list) and every module-level `DEFAULT_*` string; keep the ones containing
   `/`, `{` or `#`; return `"['\"]" + re.escape(value) + (r'\b' if value[-1].isalnum() or
   value[-1] == '_' else '')`. Stable order. `import re` at module top.
4. A `__main__` block at the bottom: `--forbidden` prints the patterns one per line; any other
   argv prints `name = value` for each `DEFAULT_*`; exit 0 either way.
5. The module docstring's `conventions:` example gains one of the new keys so the block a reader
   copies is current. **Do not** touch the "second and last exception" sentence — that is Task 7
   (PD8), which owns the three-adapter wording in all three files.
6. Tests: `DefaultsTests.test_the_new_fields_default_to_none` (all nine `None` on `Conventions()`,
   all nine in `field_names()`); `ForbiddenPatternsTests` with
   `test_one_pattern_per_path_shaped_default` (nine entries; contains `['"]worker/`,
   `['"]docs/specs\b`, `['"]\{reviews_dir\}/\{n\}-\{slug\}\.md`, `['"]### Task\b`; no pattern
   matches the bare words `main` or `inbox`), `test_a_copied_default_matches_and_prose_does_not`
   (`re.search` hits `X = 'docs/specs'`, `default="fix/"`, `f'worker/{iid}'`; misses the unquoted
   prose `the worker/ prefix` — PD3), and `test_the_module_prints_them` (`python3 -m
   asf.conventions --forbidden` → exit 0, the same nine lines).
