**Files**
- `asf/views/capacity.py` — new (PD5)
- `asf/views/status.py` — the **Capacity** row; `ready_cell` passes the product (PD3)
- `asf/cli.py` — `asf capacity [--product <name> | --all] [--json]`, registered and dispatched
- `asf/plugin_build.py` — `'capacity'` joins `VIEWS` (PD1)
- `plugin/**`, `.claude-plugin/marketplace.json` — regenerated by `asf plugin build`, committed
- `tests/test_views.py` — new classes `CapacityTable`, `StatusRow`
- `tests/test_cli.py` — `asf capacity --json` parses and dispatches

**Steps**
1. `asf/views/capacity.py`: for each product (one with `--product`, the default product with
   neither flag, every `~/.ASF/products/*.yaml` with `--all`) call `asf.capacity.resolve` and
   render the table of §2.4 verbatim in shape — header `CAPACITY — operator total: sessions <n>,
   ci <n>`, columns `product  sessions  in flight  free  bound by  ci  runs  free  batch`, `?` for
   an unknown count, the batch cell `<per_run> per run × <parallel> parallel on <runners>
   runners` (a missing key drops its clause), then one `deprecated: …` line per
   `asf.capacity.deprecations(cfg)` entry. The table is script-generated (R-0109). `free` is
   `max(0, ceiling - inflight)`, `?` when the count is unknown.
2. `--json` prints the list of §2.4: `{product, sessions: {ceiling, inflight, free, bound_by},
   ci: {ceiling, inflight, free, bound_by}, batch: {per_run, parallel, runners}, deprecated:
   [...]}`, `null` where the table prints `?`.
3. `asf/cli.py`: `sub.add_parser('capacity', help='the CAPACITY table: sessions and CI runs per
   product')` with `--product`, `--all` (mutually exclusive) and `--json`; dispatch to
   `asf.views.capacity.cmd_capacity(args)` outside the record-view branch.
4. `asf/views/status.py`: a `('Capacity', lambda: capacity_cell(cfg, product))` row —
   `sessions <inflight>/<ceiling> (operator total <n>), ci <inflight>/<ci>` (drop the clauses that
   do not resolve), or `not_configured('capacity')` when neither file has a `capacity:` block and
   no deprecated key is set. `ready_cell` calls `capacity(product)`.
5. `asf/plugin_build.py`: add `'capacity'` to `VIEWS`. Run `asf plugin build` and commit
   `plugin/skills/capacity/SKILL.md` plus whatever else it rewrites (P6).
6. `tests/test_views.py`: `CapacityTable` (`test_one_row_per_product_with_the_bound_by_column`,
   `test_json_shape`) and `StatusRow` (`test_capacity_row_says_not_configured_when_nothing_is_set`)
   on a temp `ASF_HOME`. `tests/test_cli.py`: a case that `asf capacity --json --product <p>`
   exits 0 and prints a JSON list.
