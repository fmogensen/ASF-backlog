§2.8, and the two fixture sessions of §3's T5 and T6 that are this Feature's only real boundary.
Constitution §3 is explicit that a capability list is not a boundary; Tasks 1–4 shipped the list, and
this Task ships the thing behind it. Both hooks are `BUILTIN` entries, so both are installed into
every worker account's own settings by the `hooks install` that already runs (P15), and neither
needs `rules/` to exist — which it does not, at this head.

**Files**

- `asf/guards.py` — **new** (**PD9**, the one file this plan adds to §2.13's footprint). A
  top-level leaf beside `asf/approvals.py`, holding the two hook bodies and nothing else. Both
  follow `approvals.run_hook`'s four rules exactly (`asf/approvals.py:847-863`): `ASF_JOB` unset
  returns 0 before any import that reads a config file; a clean call returns 0 silently; a refusal
  returns 2 with the reason on stderr and one ledger record with **no `hold` key**; any exception
  returns 2 naming the hook and not the rule, through `approvals._log_traceback`.
  - `roleguard(stdin_text, environ, out)` — `PreToolUse`, every tool; returns 0 for anything that is
    not a `Write`/`Edit`/`MultiEdit`/`NotebookEdit` as its first statement after the `ASF_JOB`
    check. Resolves the job's row from the session registry (`pool`), its kind and role, then
    `launch_for` and `resolve_writes`, then refuses a write whose `file_path` falls outside the
    surface. An empty `writes` means the role's own worktree and nothing above it. The refusal is
    §2.8's four-part shape, ending with the literal line `This is not a question for a person: do
    not print NEEDS OPERATOR for it.` One `refused-role` record: `{event, role, item, job, tool,
    detail, ts}`, `detail` the relative path, scrubbed.
  - `redactout(stdin_text, environ, out)` — `PreToolUse`, `Bash` and `WebFetch` only. Refuses a
    command or url whose *argument* is key-shaped — an `Authorization:` header, a `?key=`/`?token=`
    query, an inline key-shaped literal — and any text that `redact.scan_text` matches against
    `redact.default_patterns`, because a command that contains a secret prints it merely by being
    echoed. One set of secret shapes in this factory, not two. One `refused-secret-output` record:
    `{event, rule, job, tool, ts}` — **no `detail`**, because the detail is the secret — and the
    refusal line carries the pattern name and never the matched text.
- `asf/hooks.py` — three changes:
  1. `BUILTIN` gains `'roleguard': ('PreToolUse',)` and `'redactout': ('PreToolUse',)`.
  2. `cmd_hook` dispatches on the name instead of sending every `BUILTIN` name to
