The spec's design §5 and `D5`. One constant, one row in `LANES`, one branch in `rows` — the
module's own documented way to add a lane (P8). The view makes no network call and reads no repo,
so this Task needs nothing Task 1 or Task 2 writes: its fixture is a lane registry written by
hand. It runs beside Task 1 — its `writes:` intersects no other Task's.

This is the one Task that fits on its card whole, Gate and Acceptance included (`PD19`). One
decision binds it: **`PD16`** — the landed assertion
`test_the_vocabulary_is_exactly_two_lanes` (`tests/test_pr_hygiene.py:117-118`) goes red the
moment `LANES` gains a third pair, and this Task lands the third pair *and* renames that test.

**Files**

- `asf/harvest/pr_hygiene.py` — `CLOSED_DECIDE = 'CLOSED → DECIDE'` beside the two constants
  (`:24-25`); a third `LANES` row (`:30-33`); one `elif` in `rows`, after the
  `BACK kind=conflict` branch (`:51-54`). The module docstring's lane list (`:11-12`) gains its
  third line. `_entries` (`:58-66`), `lanes` (`:69-77`), `render` (`:80-82`) and `main`
  (`:85-108`) are **not** touched — `_entries` reads `LANES[r['kind']]` and picks the new pair up
  for free, and a `decide` mark with no PR number is left out of the listing by the rule already
  there (F-0119, `D4`).
- `tests/test_pr_hygiene.py` — a new class `ClosedDecideRows`, and the one landed assertion
  `PD16` names.

**Steps**

1. `asf/harvest/pr_hygiene.py`: add `CLOSED_DECIDE` after `CONFLICT_REBASE` (`:25`), and
   `CLOSED_DECIDE: ('closed', 'decide'),` as the third `LANES` row — the spec's §5 fence verbatim.
2. Add to `rows`, after the `elif state == lane.BACK and reason == 'kind=conflict':` branch
   (`:51-54`), the spec's §5 fence verbatim: `elif rec.get('decide'):` appending `kind`
   `CLOSED_DECIDE`, `branch`, `item`, `pr`, `why` from `rec['decide'].get('why') or ''`, and
   `since` from `rec['decide'].get('at') or rec.get('at')`. `since` is the **mark's** own time,
   not the record's — the question is how long the decision has waited (`D5`). Keep it an `elif`
   on the existing chain: a record that is both `STALE` and marked gives one row, the `STALE` one.
3. Add the third line to the docstring's lane list (`:11-12`), in the shape of the two above it.
4. `tests/test_pr_hygiene.py`: rename `test_the_vocabulary_is_exactly_two_lanes` (`:117-118`) to
   name three, and assert the third pair — then widen it to S-84508's eighth bullet: every kind
   `rows` can emit is a key of `LANES` and every key is a kind `render` can print (`PD16`).
5. Add `ClosedDecideRows(unittest.TestCase)` beside `LaneListing`, with `LaneListing`'s own
   `setUp`/`run_` shape, one test per bullet of the spec's **S-84508** block. The fixture is
   `self.run_('a', 'T-0999', 'worker/T-0999', 'PR_OPEN', 'PR #880', pr=880, decide={'state':
   'Closed', 'at': '<iso>', 'why': '<text>'})` — `run_`'s `**extra` lands the key on the record
   as-is. Assert the row's `kind`, `why` and `since`, `render`'s one line, `lanes`' entry
   (`lane` `closed`, `action` `decide`, exactly five keys), a marked record with no `pr` in `rows`
   but absent from `lanes`, and the landed `STALE`/`BACK` rows unchanged.
