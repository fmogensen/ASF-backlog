**Steps**

1. `asf/schema.py`: `SCHEMA_VERSION = 2` (`:40`), and the entry as the `Migration` NamedTuple the
   table holds (`:69`, `:98`) — `MIGRATIONS[2] = Migration(_migrate_to_2, additive=False,
   note='the card is JSON; machine fields are typed')`. **`additive=False` is load-bearing**: it
   makes `blocking()` (`:208`) record the step as a gap and `require()` (`:242`) exit 3 with the
   operator line, so every writing command refuses a schema-1 record (K8).
2. `_migrate_to_2(record_dir)` walks every `*.md` card and does §2.8's six steps in order: parse
   with `frontmatter.parse`; lift the body's machine meaning into fields (`## Acceptance` bullets
   into `acceptance`, with `test` where `dor.test_refs` (`:74`) finds one, the `**Gate**` fence via
   `dor.gate_lines` into `gate`, `## History` into `history`, other sections into `prose`,
   `## Children`/`## Backlinks` dropped as derived); normalise the two measured slips (`blockedBy`
   string into a one-element array, `reshape_applied` to the schema's one owner); any key the
   schema does not name into `extra`; round-trip; write.
3. The round-trip is the only proof nothing was dropped (D-0011, invariant I1 at P10): render back to
   markdown, compare with the original normalised for the derived sections, and on a difference
   **stop**, naming the card, the field and the difference — leaving every card it had not reached
   untouched, re-runnable once that one is fixed by hand.
4. Write `<id>.json` through the gate and `<id>.md` through `write_card(..., validate=False)` —
   the first of Task 3's two named waivers — and `git rm` nothing: the old `.md` **is** the view's
   path. `stamp_cards` (`:351`) already stamps every card and `migrate_product` (`:428`) already
   drains sessions and does both roots of `record_dirs` (`:159`). A second run writes nothing.
5. `asf/record/repair.py`: `--to-schema 2` beside `--apply` and `--product` (`:67-74`), keeping the
   dry-run default — the same conversion over the root `cli.resolve_record` resolves, stamping
   nothing, so a **copy** is converted by running it from inside the copy (K7).
6. `sample/backlog` (ten cards and an `index.json`, P15) is converted in this PR by this same code,
   and `tests/test_card_migration.py` pins it byte for byte. Its five readers and
   `tools/quickstart.sh` are in the blast radius, not a fixture left behind — the Gate runs four of
   them. Extend `tests/test_schema_version.py` (48 tests, green, 113 s — K5) for the bump and for
   the refusal `additive=False` buys.
