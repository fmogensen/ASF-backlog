§2.5's stream half and the whole of §2.6. The `sessions` schema gains `model_label`,
`RECORD_KINDS` and `KINDS` gain the kinds the factory actually launches, and the rollup grows one
section and one waste row over the same 7-day window the cost table already reads.

**Files**

- `asf/metrics/metrics.py` — `KINDS` (`:38-39`, P4) and `KIND_PREFIXES` (`:40-46`, P5);
  `RECORD_KINDS` (`:49-50`, §2.5's fence); `SCHEMAS['sessions']` gains
  `'model_label': (('str', 'null'), None)` (`:120-127`); `session_event` copies it (`:908-…`);
  `spend_by_kind_model`, `heavy_share` and `spend_table`; `scorecard_rows`' new keyword and its
  `model spend` row (`:406`); `render_daily`'s single 7-day sessions read and the new section
  (`:502-514`).
- `tests/test_metrics.py` — `SessionKindTests` (new) and `SpendByKindModelTests` (new).

**Steps**

1. `SCHEMAS['sessions']['model_label'] = (('str', 'null'), None)` — null for every event already on
   disk and for one imported from a foreign runner. The unknown-key refusal is unchanged, so an
   event carrying a key neither the schema nor this line names still fails.
2. `RECORD_KINDS` exactly as §2.5 fences it: `coder → code`, `fixer → fix`, and `correct`,
   `adjudicate`, `groom`, `close`, `reshape` each to themselves, beside the nine it maps today.
3. `KINDS` gains `correct`, `adjudicate`, `groom`, `close`, `reshape` (P4 — without this every
   event `RECORD_KINDS` newly maps raises `SchemaError` at `:210`).
4. `KIND_PREFIXES` gains a prefix for each of the five and leaves `job|bounce → other` (P5), so a
   record with no `kind` derives its own bucket instead of `other`.
5. `session_event` adds `'model_label': record.get('model_label')` beside `'model'`. The `launch`
   event is untouched — it keeps carrying the id (§4).
6. `spend_by_kind_model(sessions)` → `{(kind, label or None): {'sessions': n, 'usd': float}}`, pure
   over one window's event list, summing only numeric `usd` and counting every event.
7. `heavy_share(sessions, heavy=HEAVY)` → `(share_pct or None, labelled_usd, unlabelled_usd)`;
   `None` when nothing is labelled. `share_pct = round(100 * heavy_usd / labelled_usd)` (P10).
8. `spend_table(sessions, day)` renders §2.6's section: the window line naming the labelled and
   unlabelled sums, the rows sorted by USD descending with `Share` of **all** spend in the window
   so the column sums to 100 % with the `(unlabelled)` row, then `(unlabelled)` with `—` for its
   model and its share, then `**All**`.
9. `scorecard_rows(ci, sessions, ticks, conv=None, sessions7=None)` (P9): `window = sessions if
   sessions7 is None else sessions7`, and one row appended —
