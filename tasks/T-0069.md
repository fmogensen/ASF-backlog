## Description
stories: S-14301, S-14305, S-14306
writes: asf/metrics/metrics.py, tests/test_metrics.py

Depends on T-14650 (`tokens.meter`, `tokens.of_result`, `tokens.cap_result`). It is disjoint from
T-14651 and T-14653 and runs beside them.

**Files**

- `asf/metrics/metrics.py`: `SCHEMAS['sessions']`, `session_event`, `sessions_from_registry`,
  `_result_line` (deleted, PD8), `compute_costs`, `subtree_cost`, `fmt_tokens`, `cost_table`,
  `scorecard_rows`, `write_costs`, `render_daily`'s caption.
- `tests/test_metrics.py`: `SessionTokensTest`, `ScorecardTokensTest`, `CostBlockTokensTest`.

**Steps**

1. `SCHEMAS['sessions']` gains `tokens_input`, `tokens_output`, `tokens_cache_read`,
   `tokens_cache_write`, each `(('int', 'null'), None)`, beside the keys already there — `session`
   included (PD1). No `tokens` key and no total: `_apply`'s unknown-key refusal
   (`metrics.py:138-143`) rejects one.
2. `session_event(record, result, items=None, by_dim=None)`: when `by_dim` is None it uses
   `tokens.of_result(result)`, so every existing caller keeps working. The four keys are written
   from it, each `int` or `None`. Nothing else in the function changes.
3. `sessions_from_registry`: `m = tokens.meter(logs.get(job) or rec.get('log'))` once per job, then
   `session_event(rec, m.result, items, by_dim=m.by_dim)`. Delete `_result_line` (PD8).
4. `compute_costs`: each bucket gains `tokens: {dimension: int|None}`, four `None`s to start, and a
   session's dimension is added only where it is a number (D4). `subtree_cost` the same, per
   dimension. Nothing in either adds across dimensions.
5. `fmt_tokens(n)` beside `fmt_usd`: `—` for `None`, `f"{n/1e6:.1f} M"` at or above 1 000 000,
   `f"{n/1e3:.1f} k"` at or above 1 000, else `str(n)`.
6. `cost_table`: the header and the separator gain four right-aligned columns, and every row form —
   a Feature's, `(no Feature)`, `**All**` — gains `fmt_tokens` of its four. `in_feature` and `other`
   accumulate per dimension exactly as `usd` does. Sorting is unchanged (USD, then sessions, then
   id).
7. `scorecard_rows`: one row after `agents`, `('tokens', 'in … · out … · cache rd … · cache wr …',
   f'{n} sessions, {capped} capped')`, where `capped` counts the day's sessions whose `result` is
   `failed: token cap`. `·` and not `|`, because `esc` escapes `|` (`metrics.py:386-387`).
8. `write_costs`: `new_cost` gains up to four flat `tokens_*` keys beside `usd`, each omitted when
   its dimension is `None` (D4) — so a card gains no empty keys, and the `it.get('cost') != new_cost`
   comparison still decides correctly. One level of nesting, as `frontmatter` allows
   (`frontmatter.py:1-10`). `spend_usd` is untouched: there is no token equivalent, because there is
   no single number to put there.
9. `render_daily`'s cost-table caption gains one clause: *tokens are four separate numbers and are
   never added together.*
10. The three test classes below, on `tests/test_metrics.py`'s existing `write_registry` /
    `write_results` fixtures.
