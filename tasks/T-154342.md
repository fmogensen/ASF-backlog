**Steps**

1. `asf/record/card.py`: `validate(meta, root=None)` gains its second half (D-0012). With `root`
   given, every field `refs` reports — the properties the schema annotates `"ref": "card"` — is
   resolved against that record, and an id naming no card there is an error at its own pointer:
   `/after/1: T-0412 names no card on the record`. With **no** root it checks shape only and never
   refuses an id, which is what lets the pre-commit's scratch tree and a rootless caller validate.
2. The refusal is the writer's, so `asf set after+=T-0412`, a plan minting a Task, a groom answer
   and a kernel apply all hit the same wall with the same words — Task 3's gate does the raising,
   this Task only gives it the second half of the verdict. A card with several dangling references
   is refused with one error each.
3. A reference onto a **retired** or a **closed** card resolves: the card is on the record. That is
   D-0013's whole premise — the edge is history and is resolved where it stands, never deleted. And a
   card the record holds twice is not read as a resolving target twice.
4. `asf/record/setfield.py`: `_set_only` (`:105`) already validates `parent=` against the record
   before writing it and refuses an id the record lacks (P11) — generalise that precedent to every
   `"ref": "card"` field so `asf set` and `asf new --set` refuse with the writer's own words.
   Adding an id the record lacks to a list field is refused; **removing** an id from a list field
   is never refused for being unresolvable, or a card could not be dug out of a bad state.
5. `asf/record/check.py`: a finding class per unresolved reference, at the card and the field's
   line, reported **once per field entry**. `after:` is checked for the first time (P5 — today
   `record_findings` checks `parent`, `stories` and `blockedBy` and types no other field), and the
   dangling `parent` and `stories` findings it reports today keep reporting.
6. Create `tests/test_card_refs.py` for S-133160's seventeen lines. The three dangling edges §1.1
   measured are the small half; the cases that matter are that a fourth cannot be written, and
   that the no-root path refuses nothing.
