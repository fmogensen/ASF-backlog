**Steps**

1. `RecordPort.unreadable()` (`asf/kernel/ports.py:322-333`) widens from "the parser refused it"
   to "the record cannot use it", keeping the `{item id: why}` shape it already returns: a card
   whose JSON does not parse, or does not validate, reports `<path>: <pointer>: <message>`; a card
   whose reference names no card reports `<field> <id> names no card on the record`. The id is
   still read off the file name, so a card too broken to carry its own `id` is still named.
2. That is the **only** module that changes. `facts.unreadable` already carries the map,
   `decide.limbo` (`asf/kernel/decide.py:2211`) already prints `card unreadable, invisible to the
   kernel: <why>`, `edge_open` already treats a card in LIMBO as holding its dependents, and
   `loop.print_summary`'s `LIMBO n` (`asf/kernel/loop.py:222`) already counts them. The only new
   words are the reason strings (P3).
3. The reason is cut where every other reason is cut, and this is already true twice over:
   `unreadable` caps at `why[:120]` (`:332`) and `decide` caps at `LIMBO_REASON_MAX = 160`
   (`asf/kernel/decide.py:290`, applied at `:2208`). Assert both, do not add a third cut.
4. The reason names the card **file**, so a person can open it — `'%s: %s' % (path, why)` at
   `:332` already does this, and it is why the path is kept rather than the id alone.
5. Nothing becomes parked and nothing is dropped (D-0015): a card in LIMBO is never read as parked and
   never as blocked for good, it still holds the cards that wait on it, it is named on **every**
   tick until it is fixed, and a card fixed between two ticks leaves LIMBO and is an item again. A
   card that does not validate is still absent from the kernel's items, as today — the difference
   is that it is now named rather than silent, which is what made 8 ASF cards disappear.
6. Create `tests/kernel/test_limbo_invalid_card.py` for S-133162's fourteen lines, and extend
   `tests/kernel/test_limbo.py` (53 tests, green at this base — K5) where the widened reason
   changes what it asserts. Include the tick-record cases: one LIMBO entry per invalid card, and
   no such entry on a record with no invalid card.
