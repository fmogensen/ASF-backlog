## Description
stories: S-36502

after: Task 2

The spec's §*The design* §4: `harvest.reads_line(dry_run=False)`, printed once by `lane_pass`.
`lane: reads <g> git, <h> gh, <c> from the pass cache[, <s>s in processes]` — and **no seconds under
a rehearsal**, which is the whole of what this Task is judged on.

The line is why the card's own number can be read next time without `cProfile` against a live
product: when this step is slow again, the next reader needs to know whether it was `git`, `gh`, or a
cache that stopped hitting.

Read **PD10** (only `lane_pass` prints it), **PD11** (`process_s` is summed child elapsed, not wall
clock) and **PD12** (why the counts of a rehearsal and of a live pass differ, and why that is
correct) before starting.

**Files**

- `asf/harvest/harvest.py` — `reads_line(dry_run=False)` beside `read_stats`: the counts always,
  the `, <s>s in processes` clause only when `dry_run` is False. Its docstring names the rule and
  its precedent: a rehearsal's transcript is compared run against run and an elapsed time is the one
  token in it that is not a function of the record (`asf/tick/dry_run.py:53-54`, and
  `product_gate`'s own `timing=False` at **:850**).
- `asf/harvest/lane.py` — one `lane.out(H.reads_line(dry_run=lane.dry_run))` in `lane_pass`, inside
  the window Task 1 opened, after the `try`/`finally` (**:2267**) and before the `ci_queue` pass
  (**:2270**). `gate_pass` prints nothing (PD10).
- `tests/test_lane.py` — `ReadsLineTests` (new; on `LaneFixture`).

**Steps**

1. Write `reads_line`. Read `read_stats()` once, inside the window — the counters are gone when it
   closes.
2. Add the one `lane.out(...)` line to `lane_pass`.
3. Write `ReadsLineTests`: a live pass prints exactly one `lane: reads ` line; it names four numbers
   and ends in `<s>s in processes`; its `git` count equals the number of `git` processes a counter
   around `harvest.sh` saw and its `from the pass cache` count equals `read_stats()['hits']`; the
   same pass with `dry_run=True` prints the line **without** any `s in processes` clause; that
   dry-run line does not match `\b\d+(\.\d+)?s\b` anywhere — asserted here with the same regex the
   rehearsal's own test uses (`tests/test_dry_run.py:83`), so the failure is local instead of
   arriving from another module; and two `dry_run=True` passes back to back over an unchanged origin
   print byte-identical `lane: reads` lines.
4. Run `tests.test_dry_run` and confirm `DryRunReadyPR` and `DryRunReadyFF` are **unchanged and
   green**. They are the fence that decides this Story (P8): `lines1 == lines2` over the whole
   transcript, and no line of it matching `\b\d+(\.\d+)?s\b`, and the `== lane` section of that
   transcript is `lane_pass`'s own output. Do not edit either class.
5. Run the targeted modules, then the fences.
