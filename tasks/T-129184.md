## Description
stories: S-99405
writes: asf/feeder/rows.py, asf/views/status.py, tests/test_cli.py
after: none

`asf retire` took a card off the board and the **Parked** row of `asf status` kept its relaunch-cap
park. The park is not stale — it is a true fact about a run that happened — but it no longer holds
anything back, and `parked_cell` is the one reader of these parks that asks the record nothing: it
folds the ledger, keeps every entry carrying `parked`, and prints it with
`` `asf unpark <item|branch|job>` releases one `` advice that, when the park's job has since been
reused by a run on another item, cannot even reach it. Every other reader already applies a record
rule — the feeder drops the row, health releases the correction, the wave never plans a row it has
not got. This Task gives that rule one name in the feeder and teaches the cell to obey it, so the
two tables can never disagree about the same park.

**Files**

- `asf/feeder/rows.py` — one new function, `closed_ids(items)`, directly above `drop_gone`
  (`:2364`), whose body is `drop_gone`'s own expression moved whole from `:2369-2370`; `drop_gone`
  then calls it. Six added lines, and nothing else in the module. Explicitly **not** touched:
  `correction_rows`' guard (`:1025`), `hold_parks`' guard (`:2340`), `stale_park_cause` (`:2317`),
  `_capped` (`:2386`), `_retired` (`:608`) and `is_open` (`:705`) — the rule is *moved*, not
  changed, and every existing caller keeps the behaviour it has (**PD3**).
- `asf/views/status.py` — one new helper `_closed_items(root)` beside `_stalemate_parks`
  (`:588-597`), and inside `parked_cell` (`:600-622`) one read above the three sources, one
  `if closed is not None:` filter below them, and three sentences added to the docstring. Six added
  lines. Explicitly **not** touched: `_stalemate_parks`' body, the `shown`/`more`/`len(parked)`
  tail (the count leads the cell and must count what it prints, which it already does because the
  filter runs before it), and every other cell in the module. One line is *permitted* and not
  required: the last sentence of `_stalemate_parks`' docstring (`:591-592`) says `parked_cell` has
  no index-dependent contract, which this Task makes untrue — correct it or leave it, but say which
  in the report (**PD12**).
- `tests/test_cli.py` — `ParkedCellTests` (`:594`) has its fixture (`:600-630`) split out into a
  `_ParkedCell` base, the four existing cases (`:632-670`) left in `ParkedCellTests(_ParkedCell)` with their
  names and their docstring unchanged, and the spec's two new blocks added. No landed test is
  edited: `test_with_no_root_reads_exactly_as_today` and
  `test_a_root_with_no_index_json_adds_nothing_and_raises_nothing` are the no-record contract this
