The spec's first two **In** bullets and the `asf/hooks.py — the resolver` block: three routes in
order, `argv[0]` first (D1, D2), the venv script behind the `same_install` guard (D3), `PATH` last
(D4), and the three writers of P2 taking its answer.

**Files**

- `asf/hooks.py` — `ENTRY_POINT_NAME`, `ENTRY_NAME_RE`, `Entry`, `running_asf`, `same_install`,
  `runnable_asf` rewritten over it, `install`'s summary line
- `tests/test_hooks_entry.py` — new module: `RunningAsfLadderTests`, `RunnableAsfRefusalTests`,
  `SameInstallGuardTests`, `WrittenCommandsNameTheRunningInstallTests`
- `tests/test_install.py` — the two summary-line equality assertions (PD8)
- `docs/guide/troubleshooting.md` — the `not on PATH` row at `:43`

**Steps**

1. `ENTRY_POINT_NAME = 'asf'` and `ENTRY_NAME_RE = re.compile(r'^asf[A-Za-z0-9._+-]*$')`, each with
   the comment the spec's design block gives: the declared script name is what a pipx `--suffix`
   install appends to (P3), so both spellings may be written and both must be read back.
   `Entry = collections.namedtuple('Entry', 'path route')`.
2. `running_asf(argv0=None, executable=None, which=shutil.which)` → `Entry` or `None`. `argv0`
   defaults to `sys.argv[0]`, `executable` to `sys.executable`; both are parameters so each route is
   drivable from a test without touching the process. The three routes in the spec's order:
   - `argv0` — made absolute, a bare name resolved through `which`. Counts when its basename matches
     `ENTRY_NAME_RE`, does not end `.py`, and the path is an executable file. The `.py` exclusion
     and the shape test are what keep `pytest`, `run_tests.py` and `asf/cli.py` out (D2, PD7).
   - `venv` — `os.path.join(dirname(abspath(executable)), ENTRY_POINT_NAME)`. Counts when it is an
     executable file, its `#!` line names `executable` or its realpath, **and** `same_install()`.
   - `path` — `which(ENTRY_POINT_NAME)`, made absolute. Counts when it is an executable file.
3. `same_install()` — `importlib.metadata.distribution(drift.PACKAGE_NAME)` (`'asf-factory'`,
   `asf/drift.py:20`), then either its `locate_file('asf/__init__.py')` is the same file as
   `asf.__file__` (`os.path.samefile`, guarded for `OSError`) or its `direct_url.json` is editable
   with a url path equal to `drift.factory_root()` (P17). `False` when the distribution is not found,
   and `False` for a `PYTHONPATH` shadow — which is the snapshot case the guard exists for (P12, D3).
   It raises nothing: every lookup failure is `False`.
4. `runnable_asf(which=shutil.which, argv0=None, executable=None)` keeps its name and its
   `(path, refusal)` contract, so P2's three writers and PD7's twenty-three call sites are untouched
   in shape. It returns `running_asf(...)`'s `path`, or:
   - nothing answered — `NEEDS OPERATOR: this asf install has no entry point to name (argv[0]
     <argv0>, none beside <executable>, none on PATH) — pipx install asf-factory`;
   - a route answered with a path that is not an executable file — today's line, byte for byte:
     `NEEDS OPERATOR: <path> is not an executable asf — no hook is written naming it; pipx install
     asf-factory`. `tests/test_install.py:1270` asserts this one and it does not move.
5. The three writers take the resolved path unchanged: `_git_hook_body`'s `exec "<asf>" redact`, the
   foreign-hook refusal's `add the line: "<asf>" redact …`, and `hook_command`'s `<asf> hook <name>`.
   None of their surrounding text changes — only the first word of the command each writes.
6. `install`'s summary gains the route and the path: `hooks: … ; entry: <path> (<route>)`, the route
   being the `Entry.route` literal (`argv0`, `venv`, `path`). `rc` stays 0/2. The clause is appended
   to the existing string, so `assertIn` on any earlier clause still holds (PD8 is about the two
   `assertEqual`s only).
