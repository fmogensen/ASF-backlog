§2.6: the loop is already unlimited (spec P4) and gains the test that says so; `asf inbox` writes a
`filed:` header, and each minted card emits one `intake` event carrying it — the left-hand end of
the measure Task 7 builds.

**Files**

- `asf/groom/inbox.py` — `INBOX_KV_RE` gains `filed` (`:9`); `cmd_inbox` writes the header (`:84`);
  `process_inbox` gains `event=None` and emits per minted card (`:109`); `parse_inbox_file` reads
  the header and `derive` ignores it (`:53`, `:280`).
- `asf/groom/groom.py` — `cmd_groom` passes its `event` into `process_inbox` (`:718`).
- `tests/test_inbox_shape.py` — `IntakeBatchTests` (new, §3/T7); `InboxCommandTest:444` for the
  stamp.
- `tests/test_groom_shape.py` — `derive` unaffected by the new header.
- `tests/test_groom_every_tick.py` — `ChangedCardsAreReadAgainTests` beside the new class (PD7).

**Steps**

1. `INBOX_KV_RE` gains `filed`, so the line is a header and not the first line of the description.
   `derive` is not given it — it is not one of the shape's inputs.
2. `cmd_inbox` writes `filed: <ISO-8601 UTC>` under the title, beside `parent:`.
3. `process_inbox(…, event=None)` emits, per minted card,
   `event('intake', item=new_id, type=type_, rule=rule, filed=filed_at, waited_min=…)`. `filed_at`
   is the card's `filed:` header, else the intake file's mtime as an ISO-8601 UTC stamp — a card
   filed before this lands has no header. `waited_min` is the difference in whole minutes.
4. `cmd_groom` passes `event=event` through; nothing else in `groom.py` changes.
5. `IntakeBatchTests`: seven cards in the intake directory, one `asf groom`, seven outcomes — every
   card either minted (moved to `done/`, `→ <id>` recorded) or left in place carrying a
   `## Question`; none untouched. One `intake` event per mint, each carrying `filed`.
