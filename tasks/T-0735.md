## Description
stories: S-39051
writes: asf/cli.py, asf/views/status.py, tests/test_views.py
after: Task 1

The reader. One `open` and one subtraction, before anything that could print or raise.

**Files**

- `asf/views/status.py` — `line_text(product_name, now=None)`, `cmd_status_line(args)`.
- `asf/cli.py` — `--line` on `p_status` (`:322-323`), and the short circuit before `:549`.
- `tests/test_views.py` — `StatusLineTests`.

**Steps**

1. `line_text(product_name, now=None)` per §4, with PD9's correction: the `open`, the `read()`, the
   `_HEADER_RE.match` **and** the `strptime` all sit inside one `try`, whose `except` is
   `(OSError, ValueError)` and whose failure path is the single line
   `f"ASF {product_name} · no tick yet\n"`. On success: `age_s = max((now - when).total_seconds(),
   0)`, `stale = ' · STALE' if age_s > int(m.group('horizon')) else ''`, head
   `f"ASF {m.group('product')} · tick {_age(age_s)}{stale}"`, then `lines[1:]` verbatim beneath it.
   `_age` is already there (`:438-445`) and gives `3m ago` / `2h ago` / `1d ago`.
2. `cmd_status_line(args)`: the product is `getattr(args, 'product', None) or
   env.default_product_name()` (`asf/env.py:503`); write with `print(line_text(name), end='')` —
   **not** `sys.stdout.write`, which `asf/views/status.py` cannot call (PD2) — and `return 0`
   always.
3. `asf/cli.py`: add `p_status.add_argument('--line', action='store_true', help=…)` beside
   `--product` at `:323`, with §4's help text.
4. The short circuit goes immediately **above** `if args.command in ('roadmap', 'backlog', …):` at
   `:549` — before `resolve_record`, which prints `record: <path>` on stdout and raises when
   `backlog_dir` is unset (P4, D7):

   ```python
   if args.command == 'status' and getattr(args, 'line', False):
       from asf.views.status import cmd_status_line
       return cmd_status_line(args)
   ```

5. `StatusLineTests`: `snapshot_text` has one header and one `Name: cell` line per `rows()` entry
   and no `|`; a cell containing a newline folds to ` · ` — **stub a cell or `rows()` to inject it**,
   since no real cell produces one (PD1, P2); `line_text` at `ts + 3min` heads
   `ASF sample · tick 3m ago` and carries every body line after it; at `ts + horizon + 1s` the head
   ends `· STALE`; a missing file, an empty file, a file whose first line is not the header, and a
   file whose `ts=` will not parse each give exactly one line, `ASF sample · no tick yet`;
   `cmd_status_line` returns 0 in every one of those cases and prints no `record:` line.
