§2.2 and §2.3: one module, one contract, and the four refusals that make the card's guardrail
mechanical. Both Stories are here because a `take` without `refusals` is a probe that can be aimed
at the live host, and §2.3's whole point is that the refusal comes *before* any subprocess starts
(PD1).

The contract is the third statement of one this tree already carries twice — `rules.run_check`
(`asf/rules/rules.py:140-167`) and `credentials.run_probe` (`asf/credentials.py:269`) — with a
number in the line. Its one hard rule is D4: **broken is not bad.** A probe that timed out, crashed
or printed something unparseable yields *no reading*, never a low one, because a loop that reverts
on a broken probe reverts good changes every time the probe's own dependency wobbles.

**Files**

- `asf/product_loop/probe.py` — `STATES`, `Reading`, `take`, `probe_env`, `refusals`, `_value`,
  `_detail`
- `tests/fixtures/product_loop/signup-ok.sh` — exits 0 printing one `name=number` line
- `tests/fixtures/product_loop/signup-token.sh` — exits 0 printing a token-shaped string on the
  line before a good reading, for the scrub assertion
- `tests/fixtures/product_loop/unparseable.sh` — exits 0 printing prose
- `tests/test_product_loop.py` — `ProbeTests`, `ProbeIdentityTests`

**Steps**

1. `asf/product_loop/probe.py`: `STATES = ('ok', 'broken')` and `Reading` frozen exactly as §2.2
   writes them — `name`, `state`, `value=None`, `detail=''`, `taken_at=''`. The docstring on `take`
   is §2.2's, copied as it stands.
2. `_value(line, name)`: the number out of `<name>=<number>`, or a bare number, tolerating a `%`,
   `ms` or `s` suffix and surrounding space. `None` when the line does not parse. Two readings in
   one line, or a second non-empty line that also parses, is an unparseable answer — a measurement
   that answered twice has not answered once (§2.2's last bullet).
3. `_detail(text, root)`: the last non-empty line of stdout else of stderr, scrubbed with
   `redact.scrub(line, redact.default_patterns(root))` and truncated at `DETAIL_MAX = 160` with the
   ellipsis `credentials._detail` uses (`asf/credentials.py:260-266`) — scrub first, then truncate,
   so a secret cut in half is still redacted whole. `default_patterns(root)`, not
   `default_patterns(None)`: a card carries this line into a record, and the root-aware patterns are
   the ones that know this operator's own names (PD17).
4. `take(measurement, env_map, cwd, timeout, now, run=subprocess.run)`: `shlex.split` the command
   and run it with `cwd=cwd`, `env=env_map`, `capture_output=True`, `text=True`, `timeout=timeout`.
   `rc 0` with a parseable last non-empty stdout line → `Reading(state='ok', value=…)`. **Every**
   other outcome → `Reading(state='broken')` with no `value` set at all: a non-zero rc, rc 0 with an
   unparseable line, rc 0 with no output, `OSError`, `subprocess.TimeoutExpired`, and
   `runtime.AuthEnvError` — the last caught the way `credentials.run_probe` catches it (`:280`), so
   a probe whose account's auth file is missing is broken rather than an exception out of the daily
   step. `taken_at` is `now` rendered `%Y-%m-%dT%H:%M:%SZ`; `now` is a parameter, never a clock read
   inside.
5. `probe_env(settings, cfg, product)`: `credentials.probe_env`'s shape (`asf/credentials.py:202`).
   With `settings.probe.account`, find it in `pool.accounts_from_config(cfg)` and build through
   `runtime.build_env(runtime.Job(product.name, 'product-loop-probe', product.repo_dir, None, None,
   account=acct, product_auth_env=env.product_auth_env(product)))`; with no account,
   `hermetic.worker_base()`. Then, set last and never inherited, §2.3's three:
   `ASF_PRODUCT_PROBE=1`, `ASF_PROBE_BASE_URL=<settings.probe.base_url>`, `GIT_TERMINAL_PROMPT=0`.
