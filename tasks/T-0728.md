## Description
stories: S-38401
writes: asf/capacity.py, asf/workers/pool.py, asf/approvals.py, tests/test_center.py
after: none

PD1 in full, and nothing else. After this Task `capacity.read_demand_record`,
`capacity.inflight_sessions`, `capacity.live_sessions`, `capacity.claim`, `capacity.fair_share`
and `approvals.open_holds` are pure readers: called against a product that has no state directory,
they answer and leave the filesystem exactly as they found it. `capacity.write_demand`,
`pool.append_session` and `approvals.append` each create the directory they write into, which
`env.state_dir` used to create for them.

No line of `asf/center/` lands here — the package does not exist yet. This Task is the floor every
later one stands on, and it is a Task of its own because the correction belongs to three modules
this card otherwise only reads, and because its fence has to run at the moment the correction
lands rather than four waves later.

Read **PD1** before starting and **PD13** before reaching for a fourth helper: `shadow.record_dir`
is deliberately left alone.

**Files**

- `asf/capacity.py`
  - `_demand_path(name)` (`:356-357`) — `os.path.join(env.ASF_HOME, 'state', name, DEMAND_FILE)`,
    the form `scheduler.pause_path` (`asf/scheduler.py:518-519`) already uses. `env.ASF_HOME` is
    read *at call time*, never captured at import: `tests/test_00_home.py:25` patches the
    constant per case.
  - `write_demand` (`:364-378`) — `os.makedirs(os.path.dirname(path), exist_ok=True)` as the
    first statement inside the existing `try`, which already swallows `OSError` with the comment
    *"a write that fails is ignored — a missing record lends nothing"*.
- `asf/workers/pool.py`
  - `sessions_path(product)` (`:220-221`) — composed, keeping the `Product`-or-name argument it
    takes today (`product.name if isinstance(product, env.Product) else product`, the shape
    `env.state_dir` itself uses at `:883`).
  - `append_session` (`:228-231`) — `os.makedirs` before the `open(..., 'a')`, inside the
    `_APPEND_LOCK` it already takes. `update_session` (`:244-251`) calls `append_session` and
    needs no edit.
- `asf/approvals.py`
  - `ledger_path(product)` (`:626-627`) — composed, same argument shape.
  - `append(product, record)` (`:630-632`) — `os.makedirs` before the `open(..., 'a')`.
- `tests/test_center.py` — new: the module docstring and `class ReadersDoNotWrite`. This is a
  class the spec does not name, and PD1 says why: the spec's `WriteScope` digests a *center* pass,
  which cannot exist in wave 1, and the three corrected helpers need their fence at the moment
  they are corrected rather than at the end of the card.

**Steps**

1. `tests/test_center.py`'s docstring first — one paragraph saying what the module fences: the
   cross-product read model, the card's write-scope guarantee, the merged tail, the conversation
   and the wiring, all against a fixture `ASF_HOME` and never a real product tree.
2. `class ReadersDoNotWrite` — a fresh `ASF_HOME` with `products/p-one.yaml` and **no** `state/`
   directory at all. For each of `capacity.read_demand_record('p-one')`,
   `capacity.inflight_sessions('p-one')`, `capacity.live_sessions('p-one')`,
   `capacity.claim('p-one', 3)`, `approvals.open_holds(product)` and
   `capacity.fair_share(product, cfg)` with a fake quota source: assert the answer is the
   documented empty one (`None`, `0`, `[]`, `3`, `[]`, `None`) **and** that
   `os.path.exists(os.path.join(home, 'state', 'p-one'))` is still False afterwards.
