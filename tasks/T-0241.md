§2.1: one new top-level module beside `asf/gitpush.py`'s write half (D1) — `Git(repo, run=…)` with
three named verbs and one failure convention, `FakeGit(answers)` beside it, `hermetic.git_env` for
every invocation and `conventions.git.read_timeout_s` as its one number. Stdlib plus `hermetic`
and `conventions`, no path literal, no product name, no default of its own. Nothing calls it yet —
Task 4 is its first caller.

**Files**

- `asf/gitrun.py` — the module docstring §2.1 prints; `DEFAULT_TIMEOUT_S`; `class Git` with
  `run`, `out`, `ok`; `class FakeGit`
- `tests/test_tick_git.py` — `GitRunnerTests`, `FakeGitTests`, and the module's `Template` fixture

**Steps**

1. The module docstring §2.1 prints, verbatim: the write half named, the one environment, the one
   timeout, the one failure convention, the callers today, and the next callers —
   `asf.harvest.harvest.sh` (§1.3) and F-0010's `LocalGit` (D2), in `asf/proves.py`'s idiom. D2 is
   the reason the docstring names `LocalGit` and this module does not define it.
2. `DEFAULT_TIMEOUT_S = conventions.DEFAULT_READ_TIMEOUT_S` — imported, not spelt (PD16).
3. `Git.__init__(self, repo, run=None, timeout=DEFAULT_TIMEOUT_S)`: `self._run = run or subprocess.run`,
   in `asf/tick/flaky.py:269`'s shape exactly. `repo` may be None (PD6).
4. `Git.run(args, check=False, timeout=None, cwd=None)` — the **only** place in the module a
   process is started: `['git', *(['-C', self.repo] if self.repo else []), *args]`, `text=True`,
   `capture_output=True`, `env=hermetic.git_env()`, `cwd=cwd`, `timeout=` the argument or the
   instance's. Returns a `CompletedProcess`. An `OSError` (nothing to spawn) or a
   `TimeoutExpired` becomes `CompletedProcess(cmd, 1, '', <the reason>)` — never a raise — unless
   `check`, which re-raises as `subprocess.run(check=True)` would and is the one behaviour
   `shadow._sh` keeps (D3). A non-zero returncode under `check=True` raises
   `CalledProcessError`, again as `subprocess.run` does.
5. `Git.out(args, **kw)` → `run(...).stdout.strip()` when it exited 0, else `''` — for any reason,
   including a spawn that never started. `Git.ok(args, **kw)` → `returncode == 0`. Three verbs, so
   the intent is at the call site and every existing `if not x` guard stands (D3).
6. `FakeGit(Git)`: `__init__(self, answers)` with `answers` a `{(verb, args-tuple): value}` map;
   it starts no process and needs no repo. Each verb looks its own key up: a `run` answer is a
   `CompletedProcess` (or an `(rc, stdout, stderr)` triple it builds one from), an `out` answer a
   string, an `ok` answer a bool. An unrecorded key raises
   `KeyError("gitrun fake: no answer for out ('rev-parse', 'origin/main')")` — the verb and the
   argv, so the message names the call to record (D10). No default answer, ever: an empty answer
   for an unasked question turns "the step stopped reading git" into a passing test.
7. `GitRunnerTests` per §3.1, over a `tests/gitfixture.py` `Template` copy (D-preconditions: a
   real origin + clone built once per module, `copytree`d per test):
   `out(['rev-parse', 'origin/main'])` is the clone's trunk sha; `out(['no-such-subcommand'])` is
   `''`; `ok()` is True then False for the same two; `run(['no-such-subcommand'])` is a
   `CompletedProcess` with a non-zero returncode and **no raise**; `run(..., check=True)` raises
   for it. A `run=` that raises `OSError` and one that raises `TimeoutExpired` are both returncode
   1 with the reason on stderr, and `out()` is `''` for both. `cwd=` reads another root. A
   `Git(None)` runs with no `-C` (PD6). Every invocation's `env` carries no member of
   `hermetic.GIT_HOOK`, asserted with all seven set in the base and read off the injected runner's
   recorded kwargs.
