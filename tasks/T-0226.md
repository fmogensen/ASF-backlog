§2.3: the rollup already rewrites each item's `cost:` block at step 0 of every tick, from the
record's own streams. It gains the resolved budget and the verdict, so the feeder, the groom and
the board all read one number that one writer wrote. Plus the one cell of §2.8 that lives in this
file (P6).

**Files**

- `asf/metrics/metrics.py` — `write_costs`'s new `conv` argument and the three `new_cost` keys
  (`:759-792`); `cmd_rollup` passing the conventions it already resolved (`:1449-1455`); the
  `capped` cell (`:569`).
- `tests/test_metrics.py` — `ItemBudgetCostBlockTests` (T3), and the capped cell's case.

**Steps**

1. `write_costs(root, items, all_ci, all_sessions, now=None, conv=None)`; `conv = conv or
   conventions.DEFAULTS` at the top (P13).
2. After the token keys, §2.3's four lines verbatim: `budget_sessions` and `budget_usd` when the
   resolved budget names them, `over_budget` (`'sessions' | 'usd'`) only while the item is over.
   The block is written wholesale, so a raise that puts the item back under its budget removes the
   key on the next tick — no delete path to write.
3. An Epic gets neither key: `budget.of` gives it none (Task 1, step 6), so `spend_usd`,
   `budget_usd` and `cmd_rollup`'s `budget:` lines are untouched and byte-identical.
4. The machine block's key order is unchanged: the new keys go after the token keys, the `cost`
   dict is built in one place and `frontmatter.write_machine` writes what it is handed.
5. `cmd_rollup` passes `conv=_resolve_product(getattr(args, 'product', None)).conventions` — the
   local it already binds at `:1449`.
6. `capped = sum(1 for s in sessions if s.get('result') in ('failed: token cap', 'failed: run
   cap'))` at `:569`, the spec's own literals (P6). Nothing else in `cost_table` moves.
7. `tests/test_metrics.ItemBudgetCostBlockTests`: T3's four sentences — the default budget over a
   Task at 9 sessions / $13.53; `conventions.budget.sessions: 12` writing `budget_sessions: 12`
   and **no** `over_budget`; a card raised by hand losing the key on the next run; the Epic's
   block and `cmd_rollup`'s `budget:` lines unchanged. One more case for the capped cell: a
   fabricated session row with `result: 'failed: run cap'` is counted.
