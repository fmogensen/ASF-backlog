## Description
stories: S-18155
writes: tests/test_workflow.py
after: Task 4

§3.4. The class name, the gate string and the module list are all written twice — once in
`asf/ci.py` and once in the workflow — and this is the test that says so. It reads the class name
from `asf.ci.FACTORY_ONLY` and never writes it (D9), the glob block through
`asf.ci.globs_from_workflow` (PD4), and the module list out of the job's `ASF_GATE_MODULES` (PD5).

This Task's own diff is one file on `FACTORY_ONLY_PATHS`, so the push that lands it is classified
`FACTORY_ONLY` and proves the class on itself: `lint` and `factory-tests` run, `factory-tests`
runs `test_workflow`, and the matrix is skipped.

**Files**

- `tests/test_workflow.py` — `MirrorTests`, beside the trigger tests and Task 4's two classes.

**Steps**

1. `MirrorTests` reads the file once: the raw text for the two block-scalar reads, `env.loads` for
   the job structure.
2. §3.4/1 — every job other than `classify`, `lint` and `factory-tests` carries `needs: classify`
   and an `if:` equal, character for character, to
   `needs.classify.outputs.class != '<asf.ci.FACTORY_ONLY>'`, the name interpolated from the
   module. A new heavy job added later with no gate fails here, which is the point.
3. §3.4/2 — `lint` and `factory-tests` carry no `if:` key at all, and both declare
   `timeout-minutes: 5`. This is the five-minute acceptance in the only form a machine holds.
4. §3.4/3 — `classify` declares `fetch-depth: 0` (PD10) and an output named `class`, and its step
   body calls `asf.cli ci class`: the rule is computed by the factory's own classifier and not
   re-implemented in shell. The test asserts the call is there, not the shape of the whole script.
5. §3.4/4 — the module list both ways: every `tests/test_*.py` entry of `FACTORY_ONLY_PATHS`
   appears as a module name in the `factory-tests` job's `ASF_GATE_MODULES`, and every name in
   `ASF_GATE_MODULES` appears as a `tests/…` entry of `FACTORY_ONLY_PATHS`. The mapping between
   the two spellings — `tests/test_x.py` and `test_x` — is written once in the test.
6. §3.4/5 — `asf.ci.classify` over the tracked files that match `FACTORY_ONLY_PATHS`
   (`git ls-files`, filtered through `asf.ci.matches`) returns `FACTORY_ONLY`; that same set plus
   `asf/env.py` returns `FULL`; and `['.github/workflows/tests.yml']` alone returns `FULL` — D7's
   rule that a workflow edit runs what it edits. This is the acceptance's second row asserted over
   the workflow as it stands, not over a fixture.
7. The two trigger tests (B-0053) and Task 4's two classes are untouched.
