**Steps**
1. `excludes=(asf/conventions.py asf/metrics/import_sessions.py asf/hooks.py)` — the four pending
   entries and the `TODO(B-0020)` paragraph go. The comment above names the three and why.
   `--exclude` stays for an operator's own run.
2. After the pattern file is loaded, and **outside** the `#`-stripping loop (PD10):
   ```sh
   while IFS= read -r line; do
     [ -n "$line" ] && patterns+=("$line")
   done <<< "$(PYTHONPATH="$ROOT" python3 -m asf.conventions --forbidden)"
   ```
   A non-zero exit, or no lines, is `check_conventions: could not read the defaults from
   asf.conventions` on stderr and exit 2 — the check must never pass because its second source
   went missing. `set -o pipefail` is on, so capture the status explicitly rather than relying
   on the `<<<`.
3. The failure text names both sources: `… move it to the product yaml's conventions: block and
   read it through asf.conventions.Conventions — or, if it is the default itself, read it from
   asf.conventions rather than copying it`.
4. `--print-patterns` prints the merged list and exits 0 without scanning.
5. `tools/forbidden-conventions.txt`: the two new sections, byte for byte from the spec —
   `deploy-prod\.yml`, `\bci\.yml\b`, `deploy-dev` under a workflow/job comment; `hotfix-.*-report`
   and `ci-diag-` under a migration-sources comment. The header's "two documented exceptions"
   becomes three and names `asf/hooks.py`; a new paragraph says the path-shaped defaults are
   generated from `asf.conventions` at run time and are deliberately not listed here.
6. `asf/conventions.py`'s module docstring: the parenthesis calling `import_sessions` "the second
   and last exception" names all three adapters instead (PD8). No code change in that file.
7. `.github/workflows/tests.yml`: the `TODO … continue-on-error` comment goes (the step has been
   required since `7bba7a0`), and `- name: check generic / run: bash tools/check_generic.sh`
   joins it as its own step.
8. Tests: `test_the_pattern_list_is_the_cards_inventory` keeps its ten and adds `deploy-prod\.yml`,
   `\bci\.yml\b`, `deploy-dev`, `hotfix-.*-report`;
   `test_the_merged_patterns_include_the_generated_ones` (`--print-patterns` contains every line
   of `forbidden_patterns()`, `['"]### Task\b` among them — PD10);
   `test_only_the_three_adapters_are_excluded` (exactly three entries in `excludes=(`, and none of
   `evidence.py`, `match.py`, `ingest.py`, `stale.py`);
   `test_a_copied_default_fails_the_build` (a temp git repo with `tools/` copied in and one
   tracked `asf/x.py` containing `SPECS = 'docs/specs'` → exit 1, `asf/x.py:1` on stdout);
   `test_a_missing_generator_is_exit_2` (`PATH` pointing at a `python3` stub that exits 1 → exit
   2, `could not read the defaults` on stderr);
   `test_the_whole_package_is_clean` unchanged and now with no per-card exclusion.
