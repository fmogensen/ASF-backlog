## Description
stories: S-37652

after: Task 1, Task 2

The spec's §4. *"Back to its session" never takes effect* because on this path nothing ever calls it:
`_naming_back` is reachable only from a rewrite that cannot be **computed** (P6). A `remote` or a
`stuck` — a refusal that survived `--no-verify` (P12), so the remote's own no — now routes at once:
to `drop_legacy` for a legacy head no card claims, else to `_naming_back`, with the remote's own
words in the correction's text (C7). `lease` and `timeout` stay transient (C5).

Read **PD7** (the one existing test this breaks, and how it is rewritten), **PD11** (why this waits
on Task 2), **PD3** (A3's first fence is keyed by item, not branch) and **PD1** (P7: `NAMING` is
`MECHANICAL`, so the session costs no round; P8: both destinations exist).

**Files**

- `asf/harvest/lane.py` — the deferral block at `:2048-2053`, now a routing block
- `tests/test_lane.py` — A3's two tests in Task 1's class; the rewrite of
  `NamingRewordNeverCostsASession.test_a_remote_refusal_defers_with_its_reason` (`:1815-1826`)

**Steps**

1. After Task 2's `memo_refusal` call, branch on `cause`. `lease` and `timeout` keep their existing
   lines and `return DEFERRED` — a timeout is not a refusal, the remote never answered, and there is
   nothing to tell a session to fix (C5). Only `remote` and `stuck` route.
2. The reaper route first (§4, order 1): `prefix = self.unclaimed_legacy(b, item)`; if it is truthy,
   `return self.drop_legacy(f, why, prefix)` with `why` naming the refusal. `drop_legacy` records
   `STALE` with `harvested=SUPERSEDED` and `correction=None`, closes the PR, deletes the branch and
   logs `superseded {b}: {why} — deleted, not archived (legacy prefix {prefix}, no card claims it)`
   (`:1951-1963`) — all of it existing, none of it changed here. Its returned `rec` is not `None` and
   not `DEFERRED`, so the transition loop's `moved = rec; continue` (`:1792-1794`) re-reads a
   `STALE` `prev`, which is `TERMINAL_STATES` (`:139`) and ends the loop. Note `unclaimed_legacy`
   returns `None` whenever `self.items is None` (`:1942-1943`), so a runner built without `items`
   never reaches the reaper — which is what makes PD7's rewritten test route to a session.
3. Otherwise `_naming_back` (§4, order 2), with the cause in the `why` so the correction's text
   carries the remote's own words and not the symptom (C7):

   ```python
   return self._naming_back(f, f'the remote refuses a rewrite of this ref ({cause}: {text})')
   ```

   `_naming_back` (`:2071-2076`) logs
   `reword {b}: {why} — back to its session (naming, no round)`, which composes to §Records' line
   exactly; it appends `why` to `f['refusal'][1]` and returns `None`. The `None` then falls through
   the transition loop (`:1791-1794` leaves `rec is None` alone) to `hold` (`:2225-2247`), which
   reads `kind, text = f['refusal']` and calls `hold_with_correction` — a `MECHANICAL` kind, so a
   `CORRECT` session and **no round** (`asf/workers/lifecycle.py:2285`, `:2299-2300`). Nothing new is
   written to reach a session: the route already exists and this card only makes a refused push take
   it.
4. If neither applies — no card, no legacy prefix — keep Task 2's memo line and `return DEFERRED`
   (§4, order 3). Task 4's row is what carries it.
5. Rewrite `NamingRewordNeverCostsASession.test_a_remote_refusal_defers_with_its_reason`
   (`tests/test_lane.py:1815-1826`) per **PD7**: `assertIsNone(self.runner().repair_naming(f))`, the
   tip still `old`, and the asserted line the `back to its session (naming, no round)` one, still
   containing `protected branch hook declined`. Keep the test's name or rename it to say what it now
   pins (`test_a_remote_refusal_goes_back_to_its_session_with_its_reason`) — either is fine, but the
   assertion that git's reason reaches a human must stay.
