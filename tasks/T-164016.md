**Files**

asf/logs.py, asf/tick/step_health.py, tests/test_logs_tree.py

**Steps**

1. `asf/logs.py` gains `JOB_LOG_KEEP_DAYS = 14` with the spec's comment: the longest window any
   reader of a job transcript reads over (`metrics.CI_CATCH_UP_DAYS`,
   `asf/metrics/metrics.py:50`), so the reap costs no reader a line it reads today.
2. `reapable_jobs(product, keep_days=JOB_LOG_KEEP_DAYS, now=None, live=None)` → `[(path, why)]`:
   the transcripts under `jobs_dir(product)` older than `keep_days` **and** not a live session in
   the registry. `live` defaults to every session the registry holds without an `ended`, from
   `asf.workers.pool.live_sessions` (`asf/workers/pool.py:275`) imported **inside the function
   body** — the deferred-import shape §1 requires, so the installer, the hook and the clock's exit
   path keep their narrow import.
3. `reap_jobs(product, keep_days=JOB_LOG_KEEP_DAYS, fix=False, out=None, now=None)`: removes what
   `reapable_jobs` names only with `fix`, returns the rows either way, and prints **one** line
   naming the count and the bytes when it removed something — never one line per file, and
   nothing at all when it removed nothing. It never leaves that one product's jobs directory: no
   clock transcript, no rotated generation, no other product's transcripts.
4. `asf/tick/step_health.py` gains `reap_logs(ctx, out=print)` in the shape of `reap_worktrees`
   (`:328-339`) — `try`, the one call, its line, `except Exception` printing
   `logs: skipped — <type>: <e>` so a sweep can never stop a tick — and `run()` calls it on the
   line after `branch_retention(ctx, items, out=out)` (`:303`), before `stale_acts` (`:304`).
5. `tests/test_logs_tree.py` gains `ReapTests` — one case per acceptance line of `S-134158`: what
   is reapable and what is not (the window, the registry's agreement, a live session however old);
   the window being the longest reader window; the dry run naming what it would remove; the fix
   removing exactly that; the one line with the count and the bytes, and silence when nothing
   went; an unreadable directory skipped and raising nothing; nothing outside the product's jobs
   directory touched; the health step calling it after the branch sweep; a raise leaving the
   step's own result unchanged and the tick running; and a scorecard denial row for a reaped job
   counting zero rather than failing.
