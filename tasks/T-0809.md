The spec's `## The design` §3 in full, and A3 whole. Two lines in a brief, both conditional on the
product declaring a sequence (D9: every kind, because a plan books by writing a Task whose footprint
names a number — that is half of F-0208's incident and the reason `writes_bookings` exists).

`after: Task 1` because the reservation line reads `reservations.declared`, which lands there — and
reads it rather than re-deriving it, which is D10's whole point: if the brief named one number and
the check enforced another, the factory would be lying to itself. Its `writes:` is disjoint from Task
2's, so the two run together.

Read **PD5** (`facts['item']` is the item dict — the spec's line is right as written and must not be
"fixed"), **PD6** (preamble does not import `reserve` yet) and **PD7** (`_index_with_writes` does not
exist, and `T-0001` already carries a footprint the helper must replace) before starting.

- `asf/briefs/preamble.py` — `from asf import reserve` beside `from asf import reservations`
  (`:29`); the `Reserved for this card:` line inside `state_lines`' existing sequence branch
  (`:631-638`); `RESERVATION_RULE` and `reservation_rule(product)` beside `PRE_PUSH_GATE_OURS`
  (`:147-151`); one term in the `rules` Section's list (`:766-769`)

   `asf.reservations` — already imported here — imports it anyway.
2. In `state_lines`, inside the `if conventions(product).map_of('sequences'):` branch that is already
   there (`:631`, P13), **above** the existing `Reserved in flight:` lines, exactly the spec's §3
   snippet: `seqs = reservations.sequences(conventions(product))`, `mine =
   reservations.declared(facts['item'], seqs)`, and when `mine` is non-empty one line —
   `'Reserved for this card: ' + '; '.join(f'{name} {reserve.format_number(n, seqs[name][2])}' for
   name, n in mine) + ' — book exactly this; the next free number is not yours to take.'` The
   `snap = facts.get('reservations') or {}` branch below it is unchanged, and the `Section('state',
   …)` it lands in is already untrimmable and absent from `TRIM_ORDER` (`:560`, `:747`), so neither
   line can be cut (P13, P14 — 65 lines of headroom).
3. `RESERVATION_RULE`, modelled on `PRE_PUSH_GATE_OURS` and carried next to it, with the `#:` comment
   block the spec writes: the product's own pre-push check compares the branch against the trunk,
   which is the one place another open claim is not. The text is the spec's, byte for byte.
4. `reservation_rule(product)` → `RESERVATION_RULE` when `conventions(product).map_of('sequences')`
   is non-empty, else `None`. Pure: reads the conventions, never git — the same contract
   `pre_push_rule` has (`:157-164`), and the reason it takes the product and not `facts`.

   `[r for r in (pre_push_rule(facts), HOOK_REFUSAL_RULE) if r]` filter, so a `None` drops out and
   the list is unchanged for a product that declares no sequence. Nothing else in the Section moves:
   `rules_block`, `subject_rule`, `REDACTION_RULE`, `ci_rules` and the order of the rest stay as they
   are.
6. `_index_with_writes(item_id, globs)` in `tests/test_briefs.py` as PD7 specifies — a freshly read
   `index()`, its `items[item_id]['writes']` **replaced**, returned.
