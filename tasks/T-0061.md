## Description
stories: S-14709, S-14710
writes: asf/harvest/refine.py, asf/harvest/harvest.py, asf/conventions.py, docs/products.example.yaml, tests/test_refine.py, tests/test_conventions.py

The seam itself: a spec or plan branch that rewrites the document already on the trunk is held
before it lands, and therefore before any reviewer spends a round on it (D7). Runs after Task 1
(`conventions.py`).

**Files**

- `asf/harvest/refine.py` — new: `ANCHOR_HEADING_RE`, `ANCHOR_ID_RE`, `DEFAULT_REWRITE_RATIO`,
  `anchors`, `verdict`.
- `asf/harvest/harvest.py` — `refine_refusal` beside `lane_refusal`
  (`asf/harvest/harvest.py:725-755`) and one line at the call site (`asf/harvest/harvest.py:1113`).
- `asf/conventions.py` — `DEFAULT_REWRITE_RATIO = 0.5`, the `rewrite_ratio` field, and
  `HARVEST_KEYS['rewrite_ratio'] = 'rewrite_ratio'` (PD3).
- `docs/products.example.yaml` — `conventions.harvest.rewrite_ratio`, commented out at its default.
- `tests/test_refine.py` — new: `VerdictTest`, `RewriteBounceTest` (on `tests/test_harvest.py`'s
  `ProductHarvestTests` fixture).
- `tests/test_conventions.py` — the new `harvest:` key.

**Steps**

1. `anchors(text)` → the normalised `##`–`####` headings plus every `S-`/`T-` id the text names.
2. `verdict(before, after, ratio)`:
   - `before` empty → `None`: there is nothing on the trunk to refine;
   - `lost = anchors(before) - anchors(after)` non-empty → `('rewrite', "<n> anchor(s) the document
     on <trunk> carries are gone: <up to five, quoted> — a request that names an existing document
     refines it and never regenerates it; restore them or say on the card why they are wrong")`;
   - `deleted / len(before.splitlines()) >= ratio`, `deleted` the `-` lines of
     `difflib.unified_diff(before, after, n=0)` → `('rewrite', "<d> of <n> lines of <path> on
     <trunk> are deleted (<pct> %) — that is a regeneration, not a refinement")`;
   - else `None`.
3. `refine_refusal(repo, trunk, branch, item, conv)` exactly as the spec writes it: `deliverable_of`
   names the one document (`asf/harvest/harvest.py:749-755`), `git show origin/<trunk>:<path>` and
   `origin/<branch>:<path>`, either failing → `None`; otherwise `refine.verdict`. `None` for every
   lane that is not `spec`/`plan` — what a coder may rewrite is the plan's business (spec, *Out*).
4. The call site becomes
   `refusal = lane_refusal(repo, trunk, branch, item) or refine_refusal(repo, trunk, branch, item, conv)`,
   so `lane_refusal` still wins a tie and the existing `hold_with_correction` → `FIX → CORRECT` loop
   carries the return leg with no new row kind (`asf/feeder/rows.py:223-249`). `already_on_trunk`
   runs before any refusal (`asf/harvest/harvest.py:1088-1092`), so a branch whose document is
   byte-identical to the trunk's is landed and never reaches the verdict.
5. No bypass: no trailer, no marker, no `--force` on the harvest side (spec, *Out*).
