The spec's fourth `## In` bullet and `## The design` §4: the one place the operator is told what to
run — read-only, idempotent, exiting 1 when any connector needs a human. Plus the one line of
`connectors.findings` that PD16 held back until the command it names exists.

**Two checks, not three** (RD2): *secret reachable* was the `secret:` field's check and leaves with
it. A `cli` connector's credential is the login the tool holds on disk, and `check:` is what proves
it.

Read **RD2**, **RD6** (the surface count literal has drifted — **re-read the line before editing
it**), **PD8** (the count is a literal and P13's fence claim is wrong), **PD12** (`README.md` is in
no footprint and why) and **PD17**.

**Files**

- `asf/connect.py` — **new module**: `cmd_connect`, `register(subparsers)`, the two checks
- `asf/cli.py` — one local-import `register` call in `build_parser`
- `asf/surface.py` — one `COMMANDS` row

- `tests/test_connect.py` — **new module**

**Steps**

1. `asf/connect.py`, usage `asf connect [<name>] --product P [--template <t> --print]`. Per
   connector — all of them when `<name>` is omitted, in the product file's own order — run the two
   checks **in order, stopping at the first that fails for that connector** and printing one line
   for it.
2. Check one, **installed**: `shutil.which(check[0])`. On failure,
   `NEEDS OPERATOR: <name> is not installed — <the catalogue's install line>`. A connector with an
   empty `check:` is skipped, not failed: it declares no probe, so there is nothing to answer.
3. Check two, **authenticated**: `credentials.run_probe(connectors.as_provider(c),
   credentials.probe_env(...), now)` (D1 — no second probe runner). `valid` prints the probe's own
   scrubbed last line as the identity. `invalid` or `broken` prints
   `NEEDS OPERATOR: <name> is not authenticated — run: ! <shlex.join(login)>`. The `! ` prefix and
   `shlex.join` are both asserted by the spec's fence, so build that line from `shlex.join(c.login)`
   and never by hand.
4. Then one line per connector naming what it provides and its session policy, so the operator sees
   the product's whole external surface in one screen. Exit **1** if any connector printed a
   `NEEDS OPERATOR:` line, else **0** (D10).
5. `--template <t> --print` skips all of it and writes the catalogue entry's body to stdout as the
   yaml block to paste under `connectors:`. The spec's fence asserts the emitted block **then
   loads**, so emit it in the shape `env.loads` reads back (RD7) and test the round trip, not the
   string.
6. The command **runs no `login:`, edits no product file, installs no tool and reads no byte of any
   `home:` path** (the spec's `## Out`, first two entries). It prints. No `subprocess` call in this
   module but the probe's, which is `run_probe`'s and is read-only by contract.
7. `register(subparsers)` shaped on `approvals.register`: a positional `name` with `nargs='?'`,
   `--product`, `--template`, `--print`, and `set_defaults(run=cmd_connect)`. Called from
   `cli.build_parser` with a local import, in the block its neighbours use.
8. `surface.COMMANDS` gains, byte for byte from the spec's design:
