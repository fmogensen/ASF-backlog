## Description
stories: S-32556

§2.3 and D3. The constant, `row_names()`, and the test that walks `asf/doctor.py` and refuses a
row the table does not carry. The heading-per-row check is Task 6's, with the page that carries
the headings (PD9).

**Files**

- `asf/doctor.py` — `ROWS`, `row_names()`, and `run` appending by those names
- `tests/test_doctor.py` — `RowNamesTests`

**Steps**

1. `ROWS` — a tuple of `(name, meaning)` pairs, in table order, one line of meaning each, at
   module level above `run`: `config`, `repo`, `backlog`, `scheduler`, `one-factory`, `approvals`,
   `redaction-hooks`, `approvals-hook`, `console permissions`, `worker env`, `worker secrets`,
   `worker push auth`, `clock code`, `drift`, `rule-checks`, `briefs`, `worktrees`, `cli:*`,
   `capacity`, `savings`, `models`, `model table`, `conventions`, `deploy`, `customer content`,
   `token-caps`, `ci pool`, `ci runners`, `cloud lane`, `gate`, `lane pushes`, `ab pairs`,
   `quota lock`, `branches`. That order was read off `run`'s 34 `append` sites in this worktree
   and matches §1.1 exactly.
2. `row_names()` returns the tuple's first column. `run` appends by those names — the 33 literals
   are unchanged text, and the one f-string `f'cli:{…}'` keeps its shape: `cli:*` is the family the
   CLI probe fans out, and the test reads its literal prefix.
3. `RowNamesTests` in `tests/test_doctor.py`: parse `asf/doctor.py` with `ast`, walk the `run`
   function, collect the first element of each `rows.append(...)` call — a `Constant` gives its
   value, a `JoinedStr` gives its literal prefix plus `*` — and assert the set equals
   `set(row_names())`, naming any row in one and not the other. D3's reason is in the test's
   docstring: `run` short-circuits on a bad config and eight of its rows are conditional, so a live
   run can never enumerate the table, and the repository already checks itself this way
   (`asf plugin check`, `check_conventions.sh`).
4. `run` is not otherwise changed: no row is added, removed, renamed or reordered in this Task.

**Gate**

```sh
bash tools/check_conventions.sh && bash tools/check_generic.sh
python3 tools/run_tests.py 2>&1 | tail -3
```

**Acceptance**
