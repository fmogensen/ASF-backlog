## Description
stories: S-8156, S-8157
writes: asf/workers/__init__.py, asf/views/sessions.py, asf/metrics/metrics.py, tests/test_session_identity.py

Depends on T-9452 (`Pool.from_config` with observation) and T-9453 (`render`'s alive path).

**Files**

- `asf/workers/__init__.py`: `cmd_sessions` and its `sessions` leaf; the module docstring's verb
  list.
- `asf/views/sessions.py`: `render(..., cfg=None, session_source=None)`, the **Other** group, the
  header count; the module docstring's group list.
- `asf/metrics/metrics.py`: `session_event` gains `'session'`.
- `tests/test_session_identity.py`: `VisibilityTest`, `HistoryTest`.

**Steps**

1. `cmd_sessions(args)`: `cfg = spawn.load_cfg()`, `accounts = pool.accounts_from_config(cfg)`,
   `observed, why = observe.read(cfg, accounts)`. `why` → print `sessions: unreadable — {why}`
   to stderr and return 2. Otherwise print one line per observed session, in pid order, in the
   spec's three-column form. The account is `—` for None, and the session is `—` for a foreign
   one, with ` (unattributed)` added when the account is None. Then, per account,
   `load: {name} {load}/{cap} (asf {a}, foreign {f})` from `Pool.from_config(cfg, product,
   session_source=…)` (D9). `--json` prints one JSON list of `{pid, account, owner, session}`
   instead, with no `load:` lines. Return 0.
2. `register`: `workers sessions` with `add_product_arg` and `--json`, and help text
   `"every agent session on this machine, and whose it is"`.
3. `render(root, product=None, alive=None, cfg=None, session_source=None)`: load `cfg` if None,
   observe once, and use that read for the alive split (T-9453's helper, given the read) and for
   **Other**. Other holds the observed sessions whose `account` is a pool account and that are not
   this product's (`owner == 'foreign'` or `product != product.name`). It comes after **Dead**,
   with columns `Session | Account | Owner | Pid` and `—` for a missing value, or `Other: none`.
   The header becomes `… · {n} ended · {k} other`. Unreadable observation → Other is `Other:
   unreadable (<why>)`, and the view still renders.
4. `metrics.session_event`: add `'session': record.get('session')` to `ev`. Nothing else in
   `metrics.py` changes (spec Out: per-run history).
5. `VisibilityTest` and `HistoryTest` as below. The CLI test runs `python3 -m asf.cli` with
   `hermetic.build(worktree=<checkout>)` over an env whose `PATH` starts with the stub `ps`
   directory, and with `ASF_HOME` set to the test's temp home, which holds a `config.yaml` and
   `products/a.yaml`.
6. Last Task: run everything, and record the card's final green in the report.
