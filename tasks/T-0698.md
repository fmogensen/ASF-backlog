The spec's §5 and C6. "Logs the reason once" must not become "a branch stops and no one can see it":
a `timeout`, or a routing that found neither a card nor a legacy prefix, leaves a branch waiting with
no session and no hold. One advisory row, in `ref_push_line`'s exact shape (P10), read by both views
from the one function.

Read **PD4** (the fence reads the operator's real state directory unless `env.state_dir` is patched),
**PD5** (the fence's two function names, and the registration no fence asserts) and **PD6** (the line
reads the sessions ledger, not a state file).

**Files**

- `asf/harvest/lane.py` — `reword_refused_line(product)` beside `ref_push_line` (`:2720-2726`)
- `asf/views/status.py` — `reword_refused_row(product)` beside `lane_push_cell` (`:466-470`), and its
  row in the table's tuple (`:534-535`)
- `asf/doctor.py` — `reword_refused_row(product)` beside `check_ref_pushes` (`:1071-1078`), and its
  two lines in `rows` (`:968-970`)
- `tests/test_lane.py` — A4's two tests in Task 1's class

**Steps**

1. `reword_refused_line(product)` in `asf/harvest/lane.py`, directly after `ref_push_line`. It reads
   the memos off the lane records, not a state file (PD6):
   `lifecycle.by_branch(H.sessions_path(env.state_dir(product)))`, each value's `.get('lane') or {}`,
   keep those with a truthy `reword_refused`, take the newest by its `at`, and return
   `f"reword refused: {branch} at {memo['head'][:9]} ({memo['cause']}: {memo['why']}) — waiting for "
   f"the tip to move"` — §5's line byte for byte. Return `None` when no memo stands. Wrap the read in
   `except (OSError, ValueError): return None`, as `ref_push_line` does at `:2723-2724`: both callers
   are views that must not lose their other rows.
2. The docstring says what it is for in `ref_push_line`'s voice — the advisory row while a naming
   reword's refusal stands over an unmoved tip — and names the memo's writer
   (`Lane.memo_refusal`) and both readers.
3. `asf/views/status.py`: `reword_refused_row(product)` with a `from asf.harvest import lane`
   function-local import and a one-line body, exactly as `lane_push_cell` is (`:466-470`). Then the
   row: `('Reword refused', lambda: reword_refused_row(product))` appended to the tuple at
   `:534-535`. The loop's `if text is None: continue` (`:541-542`) is what makes it "a row that only
   speaks up when something is wrong" — no extra guard needed.
4. `asf/doctor.py`: `reword_refused_row(product)` beside `check_ref_pushes`, same function-local
   import and same `try/except (OSError, ValueError)`. Then in `rows`, beside the `refused` block at
   `:968-970`:

   ```python
   stuck = reword_refused_row(product)
   if stuck:
       rows.append(('reword refused', False, False, stuck))
   ```

   The `False` in the second position is *not required* — advisory, like `('gate', …)` and
   `('lane pushes', …)` (C6).
5. A4's two fences, **each with the `env.state_dir` patch** (PD4), copied from `RefPushes.rows`
   (`tests/test_lane.py:1235-1239`):
   `with mock.patch.object(env, 'state_dir', lambda *_a, **_k: self.state_dir):` around the three
   calls in the first and the one call in the second. `env` is imported at `:22`.
6. Confirm the row actually renders, not only that the function returns: after the refusing pass,
   `'Reword refused'` appears in the status table's text and `('reword refused', …)` in
   `doctor.rows(...)`. No fence asserts it (PD5) — check it by hand and say so in the commit body.
