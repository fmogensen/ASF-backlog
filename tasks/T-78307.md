## Description
stories: S-76257

after: Task 1

The spec's §4. It runs before S-76255's Task, not after it, because §2's new report calls this
helper and nothing in §4 needs §2 — **PD1**.

**Files**

- `asf/hooks.py` — a new `which_asf(dispatcher=None, which=shutil.which)` with §4's docstring; the
  inline lambda in `install` (`:673`) and the one in `cmd_hooks` (`:838`) both replaced by a call
  to it; `ensure_account_hooks` (`:791`) takes `which=None` and resolves
  `runnable_asf(which or which_asf())`.
- `tests/test_hooks.py` — `which_asf`'s four states, `ensure_account_hooks`' write, and
  `install`/`plan` agreeing row for row.
- `tests/test_exit_contract.py` — the `unpushed` Stop-gate cases that pass an explicit `which=`,
  asserted still green and unchanged.

**Steps**

1. `which_asf(dispatcher=None, which=shutil.which)`: `dispatcher = dispatcher or
   dispatch.default_path()`; return a `which`-shaped callable naming `dispatcher` when
   `dispatch.is_ours(dispatcher)`, else `which` itself. §4's docstring verbatim. Measured in all
   four states: a dispatcher at the path → the dispatcher's path; a pipx link, a foreign regular
   file, or nothing at the path → the given `which`'s answer.
2. `install`: `which = which_asf(dispatcher, which)` in place of the `if dispatch.is_ours(...)`
   lambda. Pass the `dispatcher` argument the caller already gave and the `which` it already has,
   so with no dispatcher the explicitly-passed `which` is still what answers — the test seam every
   caller in `tests/` relies on is preserved exactly.
3. `cmd_hooks --dry-run`: `which = which_asf(dispatch.default_path(), shutil.which)`, replacing the
   second lambda. `plan`'s own `runnable_asf(which)[0] or 'asf'` is unchanged.
4. `ensure_account_hooks(account, which=None)` and `asf_path, refusal = runnable_asf(which or
   which_asf())`. Its one caller (`asf/workers/spawn.py:1263`) passes no `which` and is not edited:
   that is the whole point — the pre-launch refresh stops resolving `asf` from `PATH` and stops
   moving the account's `approvals` and `unpushed` commands onto the shared install on every
   launch (P6).
5. No new write path: `_write_merged` already returns without writing when `merged == current`
   (measured at `asf/hooks.py:640-642`), so "writes nothing at all when the entry already names
   the dispatcher" follows from naming it, with no extra code.
6. `tests/test_hooks.py`: `which_asf` in the four states above; `ensure_account_hooks(account)` —
   **no** `which` — writes the dispatcher's path into the account's settings where today it writes
   `asf` from `PATH`, and the entry that already names the dispatcher is left byte-identical (no
   write at all, asserted on mtime or bytes); `install` and `plan` name the same asf for every row,
   with and without a dispatcher — the promise `plan`'s docstring already makes, now through one
   helper.
7. `tests/test_exit_contract.py`: the Stop-gate cases that pass an explicit `which=` stay green
   and unedited. If the default change from `shutil.which` to `None` moves any of them, the fix
   belongs in `which_asf`'s fallback, not in the test.
