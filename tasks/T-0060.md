The half of the seam that faces the writer: before the bounce can be fair, the brief has to have
said so. Runs after Task 2 (`build.py`, `tests/test_briefs.py`).

**Files**

- `asf/briefs/preamble.py` — `state_lines` (`asf/briefs/preamble.py:336-358`); `facts` already
  carries `spec_recorded` and `plan_recorded` (`asf/briefs/preamble.py:212-213,233-234`).
- `asf/briefs/build.py` — `context()` gains `'refine'` (`asf/briefs/build.py:194`).
- `asf/briefs/templates/spec.md`, `templates/plan.md` — `{refine}` immediately above the
  DELIVERABLE paragraph.
- `tests/test_briefs.py` — the four remaining `RefineBriefTest` methods (PD7).

**Steps**

1. `state_lines`: when `facts['kind']` is `spec` and `facts['spec_recorded']` (or `plan` and
   `plan_recorded`), one line after the two document lines — the spec's sentence, byte for byte,
   naming the document's path.
2. `context()` gains `'refine'`: the same sentence, or `''` when the document is not recorded.
   `render` ignores a context key a template does not use (`asf/briefs/build.py:137-143`), so every
   other template is unaffected.
3. `{refine}` in the two templates. A Feature with no document recorded renders the empty string and
   the templates read exactly as they do today — which the existing golden assertion in
   `tests/test_briefs.py` keeps honest.
