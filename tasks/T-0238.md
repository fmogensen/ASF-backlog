§2.6's first half and §3.3: the shapes a live product produces — a squash merge whose sha no branch
contains, a doc-lane merge that must not land its Feature (I10), a PR whose title names two ids, a
`CONFLICTING` open PR — with no name in it. A hand-written fixture would only ever contain the shapes
its author already thought of; that is the whole point of recording one (D9). Read PD16 before
starting: this Task's input is not in the repo.

**Files**

- `tests/fixtures/evidence/live/` — `git.json`, `host.json`, `deploy.json`, `product.yaml` (the
  product named `live`), `expected.json` (the machine block ingest derives, whole)
- `tests/test_evidence.py` — `LiveFixtureTests`

**Steps**

1. Record with `asf evidence --json --record tests/fixtures/evidence/live` against a real product
   whose `gh` is authenticated. If none is reachable in the session, print PD16's
   `NEEDS OPERATOR:` line and land nothing — a partial snapshot is worse than none.
2. Scrub: `asf.redact.scrub(text, pats, token)` (`asf/redact.py:235`) over every string of every
   file, with `tools/forbidden-names.txt` and the operator's private list, plus a deterministic
   rewrite of branch names, PR titles, the repo slug and account names into `lane-N`, `item-N` and
   `org/repo` shapes. `tools/check_generic.sh` over the tree is the standing proof the scrub held,
   and it runs in this Task's own Gate before the push. Never a worker account name, never a machine
   path.
3. `product.yaml` names the product `live` and carries only what the replay needs — no path, no
   slug, no host that is not `org/repo`.
4. `expected.json` is the derived `state`/`stage`/`evidence`/`mergeable`/`opened` of every card,
   whole. §1.3's promise is asserted by it: every state rule's vocabulary and every evidence line's
   wording are byte-identical to today's but the one conflict line of §2.4.
5. `LiveFixtureTests`, per §3.3: `ingest` over the fixture with `Recorded` as all three sources and
   no network reachable — the derived block of every card equals `expected.json` exactly; run twice,
   the second run changes nothing (I6's first half); the squash merge lands its Task; the doc-lane
   merge lands its document and not its Feature; the two-id PR title names both; the `CONFLICTING`
   PR's id carries `mergeable: CONFLICTING`. No test in the module patches a private name of
   `evidence` — Task 2 removed the last of them and this Task adds none back.
6. The fixture carries no `schema_version`: it is a test fixture, not a supported interchange format
   (§1.3).
