after: none

The spec's `asf/env.py` and `asf/tick/shadow.py` design section, whole: the non-creating path
function every later Task reads, the two `shadow` helpers that stop creating a state directory as
a side effect of being asked a question, and the one line `sync_operator_checkout` has never
printed when it succeeds. No behaviour changes for any existing caller — `ensure_clone` already
`makedirs` its own parent (P11) — and nothing new is called from anywhere yet.

**Files**

- `asf/env.py` — `state_path(product=None)`; `state_dir(product=None)` delegates to it
- `asf/tick/shadow.py` — `shadow_dir` and `record_dir` become pure path functions;
  `sync_operator_checkout` gains its success line
- `tests/test_env.py` — new `StatePath`
- `tests/test_shadow.py` — new `ClonePathsCreateNothing`, new `OperatorCheckoutSync`

**Steps**

1. `env.state_path(product=None)` beside `state_dir` (`asf/env.py:882`), exactly as the spec's
   block writes it: the `product.name if isinstance(product, Product) else (product or
   default_product_name())` line lifted from `state_dir`, then
   `os.path.join(ASF_HOME, 'state', name)` — and **no** `makedirs`. Its docstring says what it is
   for: a *read* that only wants to know whether something is there uses this one.
2. `state_dir` becomes `path = state_path(product)` plus the `os.makedirs(path, exist_ok=True)`
   and `return path` it already has. Byte for byte the same return value for every caller; the
   `~/.ASF/state/<name>` layout now exists in one function, not two (D14).
3. `shadow.shadow_dir` and `shadow.record_dir` swap `env.state_dir` for `env.state_path`
   (`asf/tick/shadow.py:24,44`). Nothing else in either line changes. Re-verified before the
   swap that every one of the nine call sites of the two either clones into the path — where
   `ensure_clone` does its own `makedirs` (`shadow.py:78-84`) — or reads a file under it; if any
   call site turns out to rely on the directory existing, it gets an explicit `state_dir` call and
   the Task says which, rather than the swap being narrowed.
4. `sync_operator_checkout` gains one line and loses nothing: after the `--ff-only` merge returns
   0, `out(f'record: {repo} fast-forwarded to origin/{trunk}')` immediately before `return True`
   (`asf/tick/shadow.py:227-228`). Every guard above it is untouched — the missing `.git`, the
   `realpath` equality with the clone, the failed fetch, the `behind == 0` silent return, the
   non-trunk HEAD, the dirty tree, the refused merge — and each keeps the line it already prints
   or the silence it already keeps. In particular the *already current* path still returns False
   before the trunk check and still prints nothing.
5. `StatePath` in `tests/test_env.py`: `state_path` returns `<ASF_HOME>/state/<name>` and the
   directory does **not** exist afterwards; `state_dir` returns the same string and the directory
   does; both accept a `Product`, a bare name and `None`; calling `state_path` twice creates
   nothing either time. `ASF_HOME` is pointed at a `tempfile.mkdtemp()` so the assertion on
   non-existence is real and not an accident of the operator's home.
6. `ClonePathsCreateNothing` in `tests/test_shadow.py`: `record_dir(product)` and
   `shadow_dir(product)` both return their paths with no `~/.ASF/state/<product>/` on disk
   afterwards — the side effect the spec's `## Records` says this change removes.
