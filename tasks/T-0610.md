The spec's §2 whole. A head that has had `attempt_limit` review sessions end with no review filed
gets a non-launching `WAITS ON hold` row naming the count instead of another reviewer — and the
count resets to zero the moment the head moves, so the hold is self-healing and can never strand a
branch whose session is doing its job (D4).

Read **PD3** (where `review_attempts` is called from), **PD6** (the row launches nothing, so no gate
sees it), **PD7** (`HOLD` stays where it is), **PD8** (what a review attempt is in the registry's
fields) and **PD9** (`brief_kind='review'` on a row that never launches is precedent) before
starting.

**Files**

- `asf/workers/lifecycle.py` — `review_attempts(path, lanes)` beside `by_branch` (`:488-500`); the
  `attempts` key on `occupancy`'s `review` entries, patched after the fold loop (`:1063-1074`).
- `asf/feeder/rows.py` — the floor guard inside `lane_rows`' `if review:` branch (`:818-826`).
- `tests/test_lifecycle.py` — **new class** `ReviewAttemptsTests`.
- `tests/test_feeder.py` — **new class** `ReviewAttemptFloorTests`.

**Steps**

   docstring — ``{branch: n}`` — ended review runs on that branch started at or after its lane
   record's ``head_at``: how many reviewers this head has already had. Pure over the registry.
   Fold `runs(path)`, **not** `by_branch` (PD8: `by_branch` keeps one run per branch and would cap
   every count at 1). Count a run when its `branch` is truthy, its `kind` is `'review'`, its `ended`
   is truthy, its branch has a `head_at` in `lanes`, and `(r.get('started') or '') >= head_at`.
   A branch whose record carries no `head_at` never enters the map — the guard opens rather than
   holds — and the docstring says so.
2. In `occupancy`, after the `for branch, run in by.items():` loop and before the `corrections`
   filter: `if out['review']:` compute `tries = review_attempts(path, out['lanes'])` and set
   `entry['attempts'] = tries.get(entry['branch'], 0)` on every entry of `out['review']` (PD3).
   Every review entry carries the key, zero included. Extend `occupancy`'s docstring's `review`
   line to `{branch, round, pr, why, attempts}`.
3. `asf/feeder/rows.py`, in `lane_rows`' `if review:` branch, **before** the existing
   `out.append(Row(… PUSHED_REVIEW … action=LAUNCH …))`: read
   `rnd, tries = int(h.get('round') or 1), int(h.get('attempts') or 0)`; when
   `tries >= attempt_limit(product)`, append the spec's row — `kind=PUSHED_REVIEW`,
   `action=f'{HOLD}: {tries} reviewers filed nothing'`, `brief_kind='review'`, `branch=branch`,
   `waits_on='hold'`, `reason=f'{tries} review sessions on this head ended with no review filed: no further reviewer until the head moves'`
   — and `continue`. No `review_round=` on it: the row never launches and no reviewer reads it
   (PD6, PD9). The existing launching row keeps its `rnd`, now read from the shared local.
4. Extend `lane_rows`' docstring with the floor in one clause, in the shape the existing sentence
