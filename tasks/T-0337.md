- `asf/tokens.py` — `Meter` gains `model: str = None` (`:77`). In `meter()`, an `assistant` line
  sets `m.model = rec['message'].get('model')` when it carries one; the `system`/`init` boundary
  clears it with the result, the tally and the turn count (`:117-121`). The four dimensions are
  untouched and nothing is summed. The module docstring's "no fifth number" sentence stands — a

  the new field as a fifth dimension.
- `asf/prices.py` — **new**. `DEFAULT_PATH = os.path.join(env.ASF_HOME, 'prices.yaml')`;
  `load(path=None) -> Table` reading the file through `env.load_file` (PD16 — one yaml reader in
  the package), `[]` when the file is absent, never an error; `rate(table, model, day)` picking,
  among the rows whose `model` matches exactly, else the longest `model` ending in `*` whose stem
  the model starts with, the one with the greatest `from` that is `<= day`, `None` when unpriced;
  `cost(table, model, by_dim, day)` = `sum(by_dim[d] / 1e6 * rate[d] for d in DIMENSIONS if
  by_dim[d] is not None)` rounded to 4 decimals, `None` when the model is unpriced or every
  dimension is `None`. A dimension present in `by_dim` and absent from the rate is a **load-time**
  error naming the row, never a silent zero — so `load` validates every row's `usd_per_mtok`
  against `tokens.DIMENSIONS` and raises with the row's `model` and `from` in the text.
