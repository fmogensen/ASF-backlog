The spec's fifth **In** bullet and `## The design` §4, with PD2's correction to the marker and PD3's
to where the BACK guard goes. `Lane.adopt` learns to take a PR and to stamp the line it writes;
`branch_facts` reads that stamp; one predicate carries it to the five sites that today read
`f['foreign']`; and the two places a BACK is written turn it into a WAITING. No command yet — nothing
writes an `adopted_pr` line until Task 4, so nothing in the product behaves differently.

**Files**

- `asf/harvest/lane.py` — `Lane.adopt(branch, item, kind, correction=None, job=None, pr=None)`;
  `no_session(f)` (module level, beside `is_pr_item`); `f['adopted']` in `branch_facts`; the five
  `f['foreign']` sites; `Lane.enter_back`'s guard; `send_back`'s guard; the `legacy=` on `review_at`
- `tests/test_adopt_pr.py` — new module: `LegacyReviewTests`, `NoSessionOnAnAdoptedPRTests`
- `tests/test_lane.py` — the orphan and `land-spec` cases that pin PD2

**Steps**

1. `Lane.adopt` gains `pr=None`. When given, `f['pr'] = {'number': pr, 'state': 'OPEN', 'head': head}`
   before `self.record(f, PUSHED, 'adopted')` runs, so `record`'s `(f.get('pr') or {}).get('number')`
   (`:1693`) puts the PR on the lane record and `branch_facts`'s `if not prs and rec.get('pr')`
   (`:1269-1270`) finds it without a second host list (P13). The written line also carries
   `adopted_pr=pr` through `write`'s `**fields`, and the record's `reason` is `adopted-pr` rather
   than `adopted` when a PR was given — the Records block's line, byte for byte. With no `pr` the
   method is unchanged in every byte, which is what keeps `asf/tick/land_spec.py:103,111` working.
2. **PD2 is this Task's one correction to the spec.** `branch_facts` sets, beside `f['foreign']` at
   `:1297` and before the run-less early return at `:1298`:
   `f['adopted'] = bool((run or {}).get('adopted_pr'))` — **not** `run.get('adopted')`. The bare
   `adopted:` bit is stamped by `Lane.write` on every synthetic run, including the five repair sites
   and both `land_spec` callers, so reading it would make `no_session` true for every orphan the lane
   picked up and every spec carrier `land-spec` adopted. `adopted:` itself is not touched and
   `tick.summary.credits_landing` keeps reading it (P27).
3. `no_session(f)` at module level, with the spec's docstring byte for byte (§4) and PD2's field
   named in it: `return bool(f.get('foreign') or f.get('adopted'))`.
4. The five call sites, each today's `f['foreign']` (P6, P7, P8):
   `f['review_required'] = no_session(f) or conv.review_required(f['class'])` (`:1341`); the
   `review_waived` shortcut skipped when `no_session(f)` (`:1342`); `lane_refusal` and
   `incomplete_refusal` skipped when `no_session(f)` (`:1347`); and `_repair_naming` (`:1964`),
   `drop_copies` (`:2055`) and `repair_signoff` (`:2152`) each returning `None` at the top for
   `no_session(f)` with one line — `reword <b>: adopted, not the factory's to rewrite`.
5. The review, when the run is adopted, is read with the product's form allowed (`:1359-1362`):

   adopted run — the one the command wrote.
