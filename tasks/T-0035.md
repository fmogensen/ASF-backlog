**Steps**
1. `cmd_new`: the first statement refuses `epic`, `feature` and `bug`. It prints
   `error: <type> is new work — it enters through the inbox: asf inbox --title "…" [--body-file F]; the groom derives its type from the card's shape`
   to stderr, returns 2 and writes nothing.
2. `add_arguments` (PD8):
   - Add `--acceptance TEXT` and `--writes GLOB`, both `action='append'`.
   - Remove `--severity`, `--signature` and `--found-in`, and remove `SEVERITIES` from
     `new.py`.
   - Delete `SETTABLE['bug']`.
   - `cli.py` imports the function by its new alias `add_new_shape_arguments`.
3. `story` with no `--acceptance` → `error: a Story is one PR with one acceptance list — give --acceptance`,
   exit 2. `task` with no `--writes` → `error: a Task is one session with a writes: footprint — give --writes`,
   exit 2. Both checks run after the parent checks that exist today.
4. `story` and `task` are written through `write_new_item` (PD7):
   - A Story gets `shape=('parent-feature', 'story')` and `acceptance=args.acceptance`.
   - A Task gets `shape=('writes', 'task')` and the typed field `writes=args.writes`.
   - Both use `why='new'`.
   - The title overlap refusal (exit 3) and `--force` stay as they are, and the id is still
     printed on stdout.
5. `asf/init.py:82` becomes the two lines the spec gives: `asf inbox --title "…"      file new work (the groom types it)`
   and `asf new story|task …      cut a Story or Task from a spec or plan`.
6. `tests/test_backlog.py`. Seed `E-0001` and `F-0001` with `write_item` wherever a test minted
   them before.
   - `NewCommandTests`: sequential ids, overlap and `--force`, and the skeleton move to
     `new story --parent F-0001 --acceptance x`.
     - `test_missing_parent_refused` becomes `new story --title T --acceptance x` → 2.
     - `test_nonexistent_parent_refused` becomes `new story … --parent F-0009 --acceptance x` → 2.
     - `test_epic_rejects_parent` becomes `new decision --title T --parent E-0001` → 2 (a
       Decision has no parent).
     - `test_wrong_parent_type_refused` adds `--acceptance x` so that it still fails on the
       parent type.
   - `NewSetFieldsTests` uses `new story` and drops `source=review` (a Bug-only field).
     `severity=S1` is still refused.
   - `BugSeverityTests` keeps its two `asf check` tests unchanged. Its three `new bug` tests are
     replaced by `test_new_bug_refused`: exit 2, `enters through the inbox`, and an empty
     `bugs/`.
7. `tests/test_schema_version.py`:
   - Seed `E-0001` and `F-0001` with `write_item`, with `schema_version:` in their machine
     lines.
   - Run `new story --title 'Ship it' --parent F-0001 --acceptance x`.
   - Assert the stamp on `stories/S-0001`. The rest of the test is unchanged.
8. `tests/test_path_resolution.py`:
   - Add a `features/F-0001.md` card under `E-0001` to the fixture.
   - Line 28 and line 141 become
     `new story --title … --parent F-0001 --acceptance x`, and line 141 keeps
     `--product sample`.
9. `NewShapeTest`: every case the spec lists.
