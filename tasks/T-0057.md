foreground, and applies the tree that session wrote. Plus the other writer — `enrich_card` — and the
brief kind both the front door and Task 4's row use. Runs after Task 1 (`asf/idea/*`,
`tests/test_idea.py`).

**Steps**

1. `KINDS`, `DEFAULT_MODELS['idea'] = HEAVY`. `ID_RANGE_KINDS` is untouched: the interrogator mints
   nothing, and `id_ranges_needed('idea')` is therefore False.
2. `templates/idea.md`, the spec's five bullets: `{tree_path}` as the only file to write and the
   grammar as its shape; read the record first, and what it holds; D2 in one line — *never ask —
   propose, and write the proposal as an assumption*; the `{item_id}` paragraph for `--enrich` (one
   node, rooted on that card); and `asf idea apply --tree {tree_path}` as the last act of a
   factory-launched session. Every placeholder must already be in `context()`, or the render raises
   (`asf/briefs/build.py:137-143`); `tree_path` and `item_id` are the two it uses.
3. `Row.tree_file` and `tree_file_for(product, item_id)` → `<state_dir>/idea/<item_id>.tree.md`; the
   `add_dirs_for` grant. No row emits a `tree_file` yet — Task 4's does.
4. `cmd_idea`'s front door: `--tree` defaults to `<state_dir>/idea/<stamp>.tree.md` with `<stamp>`
   `%Y%m%dT%H%M%SZ`. Without `--no-interrogate`, build the `idea` brief, write it beside the tree,
   and run one job — `Job(product, name=f'idea-{stamp}', cwd=<state_dir>/idea/<stamp>/,
   brief_path=…, model=model_for(product, 'idea'), add_dirs=[record_root, dirname(tree)])` —
   through `runtime.from_config(load_cfg()).run(job, wait=True)` (`asf/workers/runtime.py:182`). No
   worktree, no branch. Then Task 1's `apply`, and its printed lines; `--json` prints the `.applied`
   JSON instead.
5. D11 at the seam: a tree file the session left behind is applied whatever the session's result
   was; a missing or unparseable tree is exit 2 with the parser's own line and nothing written.
6. `apply.enrich_card(root, canonical, item_id, node, date)`: append the node's description to
   `## Description`; append its acceptance items to `## Acceptance`, dropping a lone empty `- [ ] `
   line; append its assumptions to `## Assumptions`, creating that section immediately above
   `## Acceptance` when the card has none; set the typed field `enriched: <date>`; append one
   History line `- <date>: enriched (idea) — +<n> acceptance, +<m> assumption(s)`. It writes through
   the `asf set` round trip (`asf/record/setfield.py`): render, re-parse, compare, write only if the
   card comes back as what was asked — otherwise the card is left untouched and the command exits 2.
7. `asf idea --enrich <ID>` refuses a tree of more than one node (exit 2, `--enrich takes one node`)
