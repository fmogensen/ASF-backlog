A rebased branch stopped keeping its approved review, and the verdict was never dropped — it was
never looked up. `Lane.branch_facts` read a branch's review only when the branch's *previous* lane
record was one of `None, PUSHED, BACK, PR_OPEN, REVIEW`, and one pass can carry a branch sitting in
`WAITING_CI`, `GATE`, `WAITING`, `QUEUED`, `MERGING` or `STALE` back through `PUSHED → PR_OPEN →
REVIEW`, because the lane's own rebuild moved its head or its PR reopened. With no `review` fact,
`review_reason` answered `no ASF review yet` — round 1, a fresh review round for code no session
touched, on a review file that was readable the whole time. This Task widens the read to every
state but a landed or reaped one, and teaches the pure table that a review nobody read is not a
review that found nothing.
