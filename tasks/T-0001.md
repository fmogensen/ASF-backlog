- `tests/test_tick_summary.py` — new. The spec's block, verbatim.

**Steps**

1. Write `asf/tick/summary.py` with a module docstring saying what it is: the two tables the tick
   ends with, folded out of the session ledger through `asf.workers.lifecycle` and titled from the
   record clone's `index.json`; best-effort console output that writes nothing to the record and
   never changes a tick's exit code. Imports: `datetime`, `os`, `from asf import env, scheduler`,
   `from asf.tick import shadow`, `from asf.views import index_reader`,
   `from asf.views.sessions import pid_alive`, `from asf.workers import lifecycle, pool`.
   `lifecycle` and `pool` are module attributes, not `from … import runs` — `FailureTests` patches
   `summary.lifecycle.runs`, and a name bound at import time would not see it.

2. The clock and its stamp:
   - `clock(chosen)` → `scheduler.steps_slug(chosen) if chosen else 'all'`. `chosen` arrives from
     `steps.parse_steps` already in manifest order (`asf/tick/steps.py:69`), so the slug pairs with
     the scheduler's log name (`asf/scheduler.py:104`).
   - `stamp_path(product, clock)` → `os.path.join(env.state_dir(product), f'summary-{clock}.stamp')`.
     `env.state_dir` makes the directory; `daily.stamp` is its neighbour and the names do not meet.
   - `read_stamp(product, clock)` → the file's stripped contents, or `None` when it is absent,
     unreadable or empty. `write_stamp(product, clock, now_iso)` writes `now_iso + '\n'`.
   - `window_start(stamp, now)` → `stamp` when there is one, else `now` minus 24 h rendered in the
     ledger's format (`'%Y-%m-%dT%H:%M:%SZ'`).

3. `age(start_iso, end_iso)`: parse both (`datetime.datetime.strptime(s, '%Y-%m-%dT%H:%M:%SZ')`);
   on a missing or unparseable stamp, or a negative delta, return `'?'`. Else, on the total seconds:
   under 60 → `'<1m'`; under an hour → `f'{m}m'`; under a day → `f'{h}h{m:02d}m'`; else
   `f'{d}d{h:02d}h'`. `ClockTests.test_age_buckets` is the whole specification of this function.

4. `titles(product)`: `index_reader.load(shadow.record_dir(product))` → `{id: item['title'] or ''}`;
   `{}` on `OSError`, `json.JSONDecodeError`, `KeyError` or `TypeError` — a missing or malformed
   index is a `—` in a column, never a failed summary. Never calls `ctx.record_root()`: a clock that
   does not run `record` must not clone the record to print a title (the spec's choice), and the
   `FailureTests` fixture hands `run` a context whose `has_record` is False.

5. The rows, both through `lifecycle`:
   - `inflight_rows(product, alive)` → `pool.live_sessions(product)` (which is
     `lifecycle.is_live` over `lifecycle.latest`), each run copied with
     `status = 'working' if alive(run.get('pid')) else 'dead pid'`, sorted by `started`, oldest
     first, missing `started` sorting last.
   - `done_rows(product, since, now)` → every run of every job,
     `[r for rs in lifecycle.runs(pool.sessions_path(product)).values() for r in rs]`, kept when
     `r.get('ended')` and `since < r['ended'] <= now`, sorted by `ended`, oldest first. It is
     `lifecycle.runs` and never `pool.load_sessions`: the latter is `lifecycle.latest`, one run per
     job, and would drop the ended run of a job relaunched inside the window — the run no later tick
     could ever report, because the window has moved past it (B-0041).
