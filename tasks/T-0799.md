**Files**

- `tools/check_factory_only.sh` — new file, executable, the spec's §*The design* §3 block
  verbatim: `set -euo pipefail`; resolves `ROOT` via `git rev-parse --show-toplevel`;
  `PRODUCT_FILE="${FACTORY_ONLY_PRODUCT_FILE:-$ROOT/.asf/product.yaml}"`; exits 2 with a named
  line when that file is missing; forwards every argument, supplying `--files` itself (from
  `git -C "$ROOT" diff --name-only HEAD^1 HEAD`, after a shallow `fetch --depth=2` of
  `GITHUB_SHA`) only when the caller passed none *and* `GITHUB_BASE_REF` is set; exits 2 with a
  named line when that diff cannot be read; otherwise `exec`s
  `python3 -m asf.factory_only --product-file "$PRODUCT_FILE" "${args[@]+"${args[@]}"}"` with
  `PYTHONPATH` set so the package is importable with no install (Task 2's committed file is what
  it reads by default).
- `.github/workflows/tests.yml` — one step, between `actions/setup-python@v5` (**:19-21**) and
  `install with pipx` (**:22-26**):

  ```yaml
      - name: the factory-only merge rule (a hand branch into main is refused)
        run: bash tools/check_factory_only.sh
      ```
  (indented to match the existing steps, a single-line `run:` so `env.loads` can read it — no
  `if:` guard: it runs on every matrix leg, and on a `push` to `main` it prints
  `factory-only: ok — not a pull request`, `GITHUB_BASE_REF` being empty there).
- `tests/test_factory_only.py` — `CiEntryPoint`, a new class: runs `bash
  tools/check_factory_only.sh` as a subprocess (hermetic — `asf.hermetic.build`, the idiom
  `tests/test_hermetic.py` already uses), `--files` always given so no git and no network is
  touched, and asserts return code and the printed line for: `--head feat/round-j --base main
  --files asf/cli.py` → 1, `refused`, `is not a factory branch`; `--head
  fix/exact-path-overlap --base main --files asf/cli.py` → 1, `merge.require_item_id`; every
  prefix of the **committed** file (`worker/`, `fix/`, `spec/`, `plan/`, `cloud/direct-`) with
  `T-0001` after it → 0, `is a factory branch`; `--head release-bot --base main --files
  CHANGELOG.md` → 0, `bot paths`; the same head with `CHANGELOG.md asf/cli.py` → 1; `--ref
  refs/tags/v0.1.214` → 0, `release tag`; `--head feat/x --base next --files asf/cli.py` → 0,
  `not the trunk`; no arguments and no `GITHUB_BASE_REF` → 0, `not a pull request`;
  `FACTORY_ONLY_PRODUCT_FILE` pointing at a missing path → 2, `missing`, never 0.
- `tests/test_workflow.py` — `FactoryOnlyStep`, a new class, read through `env.loads` (a one-line
