stories: S-15602, S-15607

§2.3's second half and §2.6's first half: what a brief *states* about a card, hashed; and the tail
that asks a ruling for its mechanism, with the reader that takes it back.

**Files**

- `asf/briefs/build.py` — `DIGEST_FIELDS`, `card_digest(product, item_id, index)`, `Brief` gains
  `card_digest: str`, and `TAIL`'s report block gains `blocked_on:`, `writes:`, `superseded_by:`
  under the existing `ruling:` line.
- `asf/briefs/templates/adjudicate.md` — one paragraph under "THE RULING GOES TO THE RECORD",
  §2.6's text.
- `asf/workers/report.py` — `FIELDS` and `FIELD_RE` gain the three names; `NONE_RE`;
  `ruling_fields(text)`.
- `tests/fixtures/briefs/golden/*.md` — regenerated (P14).
- `tests/test_briefs.py` — `CardDigestTests`, and the tail/template assertions of T8.
- `tests/test_report.py` — `RulingFieldsTests`.

**Steps**

1. `DIGEST_FIELDS = ('title', 'writes', 'tests', 'after', 'blockedBy', 'decided', 'severity')`.
2. `card_digest(product, item_id, index)`: a `sha256` of a canonical rendering — each
   `DIGEST_FIELDS` key in that fixed order, then `links.spec` and `links.plan`, then (for a
   Feature) the Story ids of its children in id order, then the card's Description / Acceptance /
   Fix / Links text from `preamble.card_sections` (P9) — first 16 hex. Absent keys render as
   empty so a card that gains a field changes the digest and a card that never had one does not.
   `## History` and the machine block (`state`, `evidence`, `stage_since`, `updated`) are not read:
   that exclusion is D4 and is what stops a ruling or an ingest from staling every brief.
3. `Brief` gains `card_digest: str` and `build()` fills it for every kind; no caller unpacks the
   dataclass positionally, so the field goes last and nothing moves.
4. `TAIL`: the three lines exactly as §2.6 fences them, after `ruling:` and before the
   `NEEDS OPERATOR:` line. They render for every kind — the tail is one string — which is what T8
   asserts.
5. `adjudicate.md`: the §2.6 paragraph verbatim, naming `blocked_on`, `writes` and
   `superseded_by`, and saying a paragraph with no field behind it changes nothing.
6. `report.ruling_fields(text)` → `{'blocked_on': str|None, 'writes': [glob, …]|None,
   'superseded_by': str|None}` off the **last** REPORT block (reusing `parse`, never a second
   scanner). `NONE_RE = re.compile(r'^(none|n/a|-|—)$', re.I)`: an absent field and a `none` value
   are both `None` — no claim. `writes:` splits on whitespace. `ruling()` is untouched.
7. Regenerate the goldens: `ASF_UPDATE_GOLDEN=1 python3 -m unittest tests.test_briefs`, then
   `bash tools/check_generic.sh` (P14). Commit the twelve regenerated files with the change that
   caused them, never separately.
8. Tests: `CardDigestTests` — stable across two calls on an unchanged card; changes when `writes:`,
   `after:` or the `## Description` text changes; does **not** change when a `## History` line is
   appended or when the machine block's `evidence`/`state` moves. `RulingFieldsTests` — the three
   fields read, `none`/`—`/absent alike as no claim, `writes:` split, a field outside the last
   REPORT block ignored. T8's assertions in `tests/test_briefs.py`: every kind's brief still ends
   with the tail byte for byte, the tail carries the three names, `adjudicate.md` renders with no
   unfilled placeholder and its text names all three.
