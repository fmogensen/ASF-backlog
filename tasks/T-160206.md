**Files**

asf/kernel/model.py, asf/kernel/ports.py, asf/kernel/settings.py, tests/kernel/test_stacked_builds.py

**Steps**

1. `model.Item` gains `stack: str = ''` — the card's `kernel_stack`, in the form
   `<base-branch>@<fork-sha>`, '' when the card is not stacked (spec §2.1, `D4`). Two pure helpers
   beside it in the same module: `stack_of(item) -> (branch, sha)` and `is_stacked(item)`. Both
   refuse a half-written value: no separator, nothing after it, or a sha that is not hex returns
   `('', '')` / False — a fork point that is not recorded cannot be replayed.
2. `model.PR` gains `base: str = ''` — `baseRefName` exactly as GitHub reports it. `model.Config`
   gains `main_branch: str = ''` (`K1`), `stack: bool = False` and `stack_max_depth: int = 1`.
   `stack` defaults False on the bare model so a unit test opts in, as `escalate_after_h` does; the
   product's documented default is True and comes from the settings.
3. `ports`: add `STACK = 'kernel_stack'` beside `NOTES`/`REBUILDS` and put it in `KERNEL_KEYS`
   (`:80-82`), so `card_fields` round-trips it and a card the kernel no longer stacks does not keep
   a stale key. Read it into `Item.stack` in the `M.Item(...)` build off `machine.get(STACK)`.
4. `ports._open_pr` (`:1417`): one line, `base=d.get('baseRefName') or ''`, from the field
   `PR_FIELDS` already asks for and `change_id` is already hashed from (`:1433`) — no second read.
5. `ports.config_for` (`:2561`): `main_branch=product.main`, `stack=bool(k['stack']['enabled'])`,
   `stack_max_depth=int(k['stack']['max_depth'])`.
6. `settings.SPEC`: a new block `'stack': {'enabled': (True, bool), 'max_depth': (1, int)}`, beside
   `'launch'`. Nothing reads the knob yet — Task 2 does; it lands here because Task 2 and Task 4
   both gate on it.
7. Create `tests/kernel/test_stacked_builds.py` with `class StackFacts`, and give the module the
   fixture helpers the later Tasks extend: a `card(...)` writing a card with a machine block, an
   `item(...)` building a `model.Item`, a `pr(...)` building a `model.PR`, and a `facts(...)`. Cover
   every one of `S-135955`'s ten lines: the four `stack_of`/`is_stacked` readings; `STACK` in
   `KERNEL_KEYS` and returned by a card's kernel-field read; `write_fields` with `{STACK: None}`
   removing the key rather than storing `''`; `PR.base` carried; base-is-trunk not stacked and
   base-is-another-branch stacked, read as `pr.base != config.main_branch`; a reply with no
   `baseRefName` not stacked; and `_open_pr` filling `base` and `change_id` from one reply, asserted
   by counting the port's reads.
