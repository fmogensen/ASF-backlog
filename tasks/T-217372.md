**Steps**

1. `asf/record/archive.py`: `measure(dir_, product)` — §2.11's six rows, each a before-and-after
   pair taken on the same record in the same process, which is what makes a ratio mean anything
   (D-0020). `cards in working set` with its `≤ 50%` target (D-0023); `card files load_items opens` and
   `bytes load_items reads`, both **derived from one ordinary `load_items` call** and not from a
   counter inside it (**PD9**, block M6) — `len(recs) + len(errors)` and
   `sum(len(rec['text']) for rec in recs)`, which is why this Task's `writes:` carries no
   `asf/record/core.py`; `asf check` as `record_findings(dir_)` in-process, so the number is the
   record's cost and not a process start; `facts + decide` as `RealRecord` on `dir_` with every
   network fact stubbed empty, `facts()` then `decide()`, no launches — the pair the card's "tick
   processing time" names; and `references missing` as `audit` on each side, target 0. It refuses to
   run when `dir_` is the product's own `backlog_dir`: it archives, which is a write. Non-zero when
   any target is missed, naming the row that missed it.
2. `asf/cli.py`: `--measure <dir>` wired to it, printing §2.11's header
   (`measuring <dir> (N cards, M markdown files, X MB)`) before it measures anything, the six-row
   table with each row's target beside it, and `ok: every target met` or the row that missed.
3. `tests/test_record_archive_scale.py`: the committed cost test, on `tests/test_registry_perf.py`'s
   pattern (P20) — a record built in `setUp` with today's shape: 639 closed cards aged past
   retention, 835 retired, 1,243 live and parked, the closed ones carrying a `## History` the live
   ones do not, and a reference web across them. Assert the three ratios and the two counts of
   S-211577. **A ratio, never a wall-clock ceiling**: an absolute ceiling is a lint on whichever
   host runs CI, and a before/after ratio measured on one record in one process is the claim the
   card makes (D-0020). Assert, besides: the refusal against the product's own record; the header
   before any measurement; each row carrying before, after, ratio and target; the non-zero exit
   naming the row that missed (force one by capping the retention); the working set after at most
   half the cards before — which is the floor the record's own closed and retired counts set, and
   the one target this spec re-derived from the record rather than taking from the card (D-0023); the
   files and bytes each at least halved; `asf check` and facts-plus-decide each at least twice as
   fast; no id a working-set card references missing after the pass; and that the timings are taken
   in this process.
4. §2.11's own note on why the ratio is reachable at 54% removable goes in the module docstring, in
   the spec's words: the cards that leave are the thick ones — a closed card carries a full
   `## History`, while most of the 1,823 that stay were minted and never moved — so the bytes fall
   faster than the cards, and both `asf check` and the fold are dominated by the bytes they parse,
   not the files they list.
