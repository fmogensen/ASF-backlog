**Steps**

1. `_stalls(data, now)` beside `_phantoms` (`:1207`): the confirmed records off the queue file —
   `passes >= STALL_PASSES` and `last` no older than `STALL_GAP_S`, the same two conditions
   `_phantoms` applies.
2. `stall_text(rec, now)` — §2.6: `run 111 (T-0341) job gate stalled in step "unit tests" for
   12 min`, the minutes measured from the record's `since`, the step's own start (D9).
3. `stall_lines(product, now=None)` — one line per confirmed stall, **longest first** (§2.6 — the
   opposite of `phantom_lines`' oldest-first spelling, which sorts the same way; written as
   `phantom_lines` is written, off `load`, with no `gh` call).
4. `stall_rows(product, now=None)` — §2.6's docstring: `[]` when the queue's mode is `off`; one red
   row per confirmed stall; one red row per `(branch, sha)` at `MAX_STALL_RERUNS` in the `stalls`
   history, naming the branch, the step and the count; and **nothing at all** when neither — the
   group's ok row is the phantom watch's (D15). No `gh` call.
5. `doctor.check_ci_runners` (`asf/doctor.py:955-961`): returns
   `ci_queue.runner_rows(product, now=now) + ci_queue.stall_rows(product, now=now)`, and its
   docstring gains the stall sentence. Nothing else in the file changes.
6. `status_clause` (`:2954-2966`): `stall_lines(product, now)` joins the same `'; '.join` after
   `phantom_lines(product, now)`, and the docstring gains its example clause.
7. The `asf ci queue` command (`:3050`): the stall lines print beside the runner lines, under their
   own prefix (`out(f'stall: {text}')`) — PD13.
8. `RowTests` in `tests/test_ci_step_silence.py`, named as §3.7 names them:
   - `test_a_confirmed_stall_is_a_red_ci_runners_row_naming_the_step`
   - `test_a_sha_at_the_rerun_cap_is_a_red_row`
   - `test_no_stall_adds_no_row_and_the_phantom_ok_row_stands`
   - `test_the_queue_clause_carries_the_stall_line_after_the_phantom_lines`
   - `test_the_rows_make_no_host_call` — a `subprocess.run` patched to raise.
   - `test_an_unconfirmed_record_is_no_row` — `passes: 1` shows nothing.
9. `tests/test_doctor.py`: `class CiRunners` (new — PD7). Its first case is the row that stands
   before this card (`test_no_phantom_and_no_stall_is_one_ok_row`, over `check_ci_runners`), then
   `test_a_confirmed_stall_joins_the_ci_runners_group_red` and
   `test_a_product_with_the_queue_off_has_no_rows`.
