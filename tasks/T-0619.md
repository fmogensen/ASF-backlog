The one matcher, split in two directions and made callable without a product. Nothing outside
`asf/amendable.py` changes, and `reaches`'s contract — the **first** reaching glob or None — is
unchanged for every landed caller (`asf/approvals.py`, `asf/feeder/rows.py` ×3).

**Files**

- `asf/amendable.py` — `reaches` gains `glob_set=None`; new `partition(product, globs,
  glob_set=None)` and `glob_set(product)`, both after `reaches` (`:152`).
- `tests/test_amendable.py` — new tests in `class SetTests` (`:27`), beside `test_reaches`
  (`:88`).

**Steps**

1. Add `glob_set(product)` after `reaches`:

   ```python
   def glob_set(product):
       """``(paths, excluded)`` for ``product`` — what an edge resolves once and threads to a
       product-free reader, as ``footprint.shared_globs`` does for ``conventions.shared_paths``."""
       return (paths(product), excluded(product))
   ```

   Note the order: **set first, exclusions second** (PD5).

2. Give `reaches` the optional pair, as its first statement, leaving `product` first positional:

   ```python
   def reaches(product, globs, glob_set=None):
       import fnmatch
       keep, out = glob_set if glob_set is not None else (paths(product), excluded(product))
       for g in globs:
           if any(fnmatch.fnmatch(g, x) for x in out):
               continue
           if any(_reach(g, s) for s in keep):
               return g
       return None
   ```

   The docstring keeps its existing two sentences and gains one naming `glob_set`. The
   short-circuit on the first hit is unchanged — that is the contract three landed call sites
   depend on.

3. Add `partition` after `reaches`, the spec's body with the pair threaded:

   ```python
   def partition(product, globs, glob_set=None):
       """``(inside, outside)`` — the globs of ``globs`` that reach the amendable set
       (:func:`reaches`'s own two-way test) and those that do not, each in the order given.
       A Task whose ``writes:`` splits non-empty on both sides is *bundled*: the console must
       edit the ``inside`` half and no worker session may, so the ``outside`` half is dragged
       to a writer that should never have had it (F-0232)."""
       gs = glob_set if glob_set is not None else (paths(product), excluded(product))
       inside, outside = [], []
       for g in globs:
           (inside if reaches(product, [g], glob_set=gs) else outside).append(g)
       return inside, outside
   ```

   Resolving the pair once and passing it down is not an optimisation for its own sake: without
   it, `partition` re-reads `conventions.amendable_paths` once per glob, and a product whose set
   changed mid-loop would split against two different sets.

4. Do **not** add `bundled(product, globs)`. §1 says so explicitly: `inside and outside` reads
   plainly at each of the three sites, and a third name over the same two lists is one more
   thing to keep true.
