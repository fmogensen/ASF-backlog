## Description
stories: S-37602

after: Task 2

The spec's §3: `STALLED_CAP`, `stalled_holds`, `stalled_park_text`, and the one guard in `enter`
that both outcomes pass through. `REAPED` is a free state and `BACK` is the feeder's to correct, so
without this Task the mechanism Tasks 1 and 2 build is an engine: the feeder relaunches the card,
the session pushes, a new PR opens, it stales, it is reaped again. The count would sit at 19 and
the factory would pay a session a lap for it.

Read **PD14** (a function of its own, not a branch of `hold` — and why a branch of `hold` could
never fire) and **PD15** (at the cap the outcome does not happen) before starting.

**Files**

- `asf/workers/lifecycle.py` — `STALLED_CAP = 2` beside `INCOMPLETE_CAP` (`:2288`);
  `stalled_holds(path, item)` shaped like `empty_ends` (`:2305-2310`); `stalled_park_text(n, item)`
  byte for byte from §3; `stalled_park(n, item, card, now)` shaped like `blocked_park`
  (`:2339-2346`)
- `asf/harvest/lane.py` — one cap guard in `enter`, above the `REAPED` arm and the `BACK` arm
- `tests/test_lifecycle.py` — `stalled_holds` counts a reap and a `kind=stalled` send-back and
  nothing else; `stalled_park`'s fields
- `tests/test_lane.py` — `StalledCap`

**Steps**

1. `STALLED_CAP = 2` beside `INCOMPLETE_CAP`, with the spec's `#:` comment byte for byte. It is the
   house number: `EMPTY_CAP` is 2 (`:2271`), `INCOMPLETE_CAP` is 2 (`:2288`), `LOOP_CAP` is 3
   (`:2350`).
2. `stalled_holds(path, item)` on `empty_ends`' shape — `sum(1 for r in item_runs(path, item) if …)`
   with the same `if not item: return 0` guard. The predicate is the two outcomes and nothing else:
   a run whose `lane` record reads `state == REAPED`, or one whose `correction` reads
   `kind == STALLED`. Both are on the run line already (the Records table), so this needs no new
   field anywhere. `item_runs` (`:666`) returns the caller's own copies, so read freely.
3. `stalled_park_text(n, item)` byte for byte from §3, and `stalled_park(n, item, card, now)`
   returning `(fields, line)` in `blocked_park`'s exact shape — `{'correction': {'kind': STALLED,
   'text': …, 'at': now, 'parked': True, 'reason': reason, 'card': card}, 'operator_flagged': 1}`
   and `f'parked {item}: {reason}'`. Copy `blocked_park`'s own docstring sentence about why it is
   not a branch of `hold`; here it is true for a second reason as well (PD14).
4. One guard in `enter`, above both overdue arms, so a reap and a send-back are counted and capped
   by the same line: when `lifecycle.stalled_holds(self.path, item) >= STALLED_CAP`, write
   `stalled_park`'s fields through `self.write(f, self.record(f, prev_state, prev_reason), **fields)`
   — the state kept, the outcome not taken (PD15) — print its line, and return. Keep the item's
   current state and reason: a park is not a transition, and the record that says so is the one the
   branch already had.
5. `StalledCap` in `tests/test_lane.py` asserting every clause of A3: the first and second laps
   produce their outcome, the `STALLED_CAP`-th writes the park instead, no third PR is opened,
   `asf unpark <item>` releases it, and `STALLED` is in `MECHANICAL` so the hold spends no round and
   never reaches adjudicate. Build the prior laps as registry lines, not by driving two full passes
   — `stalled_holds` reads `item_runs`, so two run lines with the right `lane`/`correction` fields
   are the fixture, one of each shape so both halves of the predicate are exercised.
