## Description
stories: S-32704
writes: asf/doctor.py, tests/test_doctor.py, tests/test_hook_chain.py
after: Task 1

The spec's ninth **In** bullet and its `asf/doctor.py` block. Accepting the chained hook needs no
code — `is_git_hook_ours` is already true of it (PD6) — so the whole of this Task is one `elif` for
the one failure chaining introduces: the operator's hook silently stopped running.

**Files**

- `asf/doctor.py` — one `elif` in `check_redaction_hooks`, after the `foreign` branch at `:474-475`
- `tests/test_doctor.py` — `test_foreign_pre_push_still_writes_the_approvals_hook_then_needs_operator`
  (`:326`) gains `chain=False`, plus a chained sibling and the broken-chain case
- `tests/test_hook_chain.py` — `DoctorAcceptsTheChainTests`

**Steps**

1. The `elif`, exactly as the spec writes it: a hook whose `hooks.chained_local(text, name)` is not
   `None` and whose named `.local` is not a file in the same `hooks_dir` appends
   `{path} chains {local}, which is not there`. It goes **after** the `foreign` branch, so the
   order of `check_redaction_hooks` stays: missing, then `asf init`'s, then foreign, then broken
   chain. `chained_local` is called once and its answer reused, not called twice in the condition.
2. Nothing else in the function changes. The detail still ends `— asf hooks install --product <p>`,
   which is the right instruction for a missing `.local` too: with it gone, the chained hook is
   what ASF would write anyway, and the operator's own hook is theirs to restore.
3. A `.local` that is **there but not executable** is not a problem (D8): git was ignoring it before
   ASF touched the directory, and the body's `[ -x … ]` guard preserves that. Asserted as a green
   case, not left implied.
4. `DoctorAcceptsTheChainTests`: over a really chained repo (Task 1's fixtures), `check_redaction_hooks`
   is green and says `pre-commit, pre-push in 1 repos`; delete the `.local` and it is red with the
   chain line naming the hook and the `.local`, and the detail still ends with the install command;
   chmod the `.local` non-executable and it is green again; a chained `pre-commit` and a chained
   `pre-push` broken at once give two clauses in one detail; and the row is green for a plain
   unchained ASF hook, for an `asf init` record hook, and red for a foreign one — the three branches
   above the new one, asserted so the `elif` order cannot silently change.
5. `tests/test_doctor.py:326` gains `chain=False` where its point is the refusal and keeps its
   `rc == 2`; a sibling case on the same fixture with `chain=True` asserts `rc` 0, the approvals
   hook still written, and the doctor green afterwards — the card's own before/after in one place.
