**Files**

asf/ci_stall.py, asf/ci_cancels.py, asf/doctor.py, tests/test_clock_injected.py

**Steps**

1. `asf/ci_stall.py`: `_events(product)` (`:201`) becomes `_events(product, now=None)` and its
   `metrics.today()` at `:206` becomes `metrics.today(now)`. `refresh_max(product, data, now,
   events=None)` (`:211`) already holds the instant, so its call at `:216` passes it:
   `events = _events(product, now) if events is None else events`. The stall window end then comes
   from the instant the caller already has, and nothing else in the file moves.
2. `asf/ci_cancels.py`: `cmd_cancels(args, out=print)` (`:345`) becomes
   `cmd_cancels(args, out=print, now=None)`, and `:354` becomes
   `metrics.days_back(metrics.today(now), days)[0]`. The CLI passes nothing and gets the clock
   through `metrics.today`'s own default; a test passes an instant.
3. `asf/doctor.py`: `:2268` becomes
   `metrics.read_stream(root, 'ci', metrics.days_back(metrics.today(now), window_days))` —
   `check_ci_measure(product, now=None, root=None)` (`:2247`) already threads the same `now` into
   `ci_measure.readings` one line below, so there is no new parameter here at all. The other six
   raw reads in this file are not this Story's and are frozen by Task 1's baseline; leave them.
4. Every signature change is additive with the same default, so no existing test module needs an
   edit — measured: `_events` has one caller (`:216`), `cmd_cancels` is reached from the CLI, and
   `check_ci_measure` keeps its signature. If the Gate proves otherwise, the covering module is a
   `needs writes:` line in the REPORT, not a quiet widening of this footprint.
5. Create `tests/test_clock_injected.py` with one case per acceptance line: each of the three
   windows computed from the given instant; each answering what it answers today when no instant
   is given; each answering a window around the given instant **with the wall clock moved**
   (export the shift, or patch `asf.clock`'s reader — the point is that the answer does not move);
   and none of the three reading the clock when an instant is given, asserted through a reader
   patched to raise rather than by comparing values.
