C13, the card's central constraint, as the spec states it: *"no control inversion is a test, not a
sentence."* After this Task a full `asf center`, a `--json` render and a `follow` pass over a
fixture of four products are proved to change **not one byte** anywhere, and `asf center ask` is
proved to change only the addressed product's mailbox. The three `asf/center/` modules are in the
footprint because this is the Task that finds it if one of them reaches somewhere it should not —
and the fix belongs with the finding, not in a follow-up card.

This Task lands last for a reason the spec gives: *"the natural way to add a cell is to call the
function that already computes it, and P3 and P9 are two functions that create a directory on the
way."* Task 1 removed three of those doors; this is the alarm on all of them, and it is what keeps
the guarantee true a year from now.

Read **PD8** before the second fenced assertion — its exact changed-path set is only correct for a
product that names no `deliver`, and the fixture must be built that way and say so — and **PD13**
for the fourth token the `grep`-equivalent assertions must cover.

**Files**

- `tests/test_center.py` — `class WriteScope` completed: `digest_tree`, `changed_paths`, the two
  fenced tests verbatim, and the four assertions beside them.
- `asf/center/read.py`, `asf/center/tail.py`, `asf/center/talk.py` — in the footprint for the
  corrections this Task's fence finds. If it finds none, they are untouched, and that is the
  result.

**Steps**

1. `digest_tree(home)` → `{relative path: (size, mtime_ns, sha256)}` over every file **and
   directory** under the fixture home — the directory entries are what catch a created-and-empty
   `state/<p>/`, which a file-only digest would miss entirely, and which is the exact failure P3
   describes. `changed_paths(before, after)` → the set of relative paths added, removed or
   changed.
2. The two fenced tests, verbatim. The fixture is Task 2's four-product one, with `p-two` given
   **no `center.deliver`** (PD8) and one line asserting that, so a later fixture edit cannot
   quietly widen the expected set.
3. `env.state_dir` monkeypatched to raise, with `read.products`, `read.machine`, `view.render`,
   `view.as_json` and `tail.follow(..., once=True)` all still green — the structural proof of C2,
   and the assertion Task 1's corrections made reachable.
4. A product whose state directory is absent before the pass, still absent after it — asserted for
   the fourth fixture product, the one that has never had a tick.
5. The `grep`-equivalent assertions over `asf/center/read.py`'s source: no `subprocess`, no
   `state_dir(`, no `gh` token — and, per PD13, no `record_dir(` either.
6. Last, the whole suite and the genericity gate, which is where this card ends.
