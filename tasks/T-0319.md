§2.10. The package `spawn` will point `--plugin-dir` at in Task 4, and the four files Task 8's
briefs will cite. The text is **moved**, not rewritten: every character of procedure prose in these
four files comes from `build.TAIL`, `preamble.DEFAULT_RULES` or one of the four templates, so Task 8
can cut its source and the contract a session must satisfy cannot drift from the contract
`asf/workers/report.py` parses. Task 8 does the cutting; this Task only makes the destination exist.

**Files**

- `asf/procedures/__init__.py` — **new**. `plugin_dir()` (the package's own directory),
  `skill_names()` (the four directory names), and nothing else. A one-line docstring naming the
  package as the procedures a brief cites rather than repeats.
- `asf/procedures/.claude-plugin/plugin.json` — **new**, the manifest `--plugin-dir` needs: a name,
  a description, a version. Generic: no product, no account, no path.
- `asf/procedures/skills/review-standard/SKILL.md` — **new**. Frontmatter `name`, `description`,
  `allowed-tools`; the body is the verdict table, the evidence rule and the rounds rule, taken from
  `asf/briefs/templates/review.md`.
- `asf/procedures/skills/pre-push-gate/SKILL.md` — **new**. The coder's gate: what to run, in what
  order, and what a red one means, from `asf/briefs/templates/coder.md`.
- `asf/procedures/skills/spec-shape/SKILL.md` — **new**. Decisions, the design, acceptance, records,
  Stories, from `asf/briefs/templates/spec.md`.
- `asf/procedures/skills/report-shape/SKILL.md` — **new**. The heartbeat, the operator marker and
  the typed REPORT envelope, from `build.TAIL` — the fenced block **byte for byte**, because T12
  asserts exactly that and `workers.report.parse` reads it.
- `pyproject.toml` — one line, in the shape the two data packages already have (lines 27-29):
  `"asf.procedures" = ["skills/*/SKILL.md", ".claude-plugin/plugin.json"]`.
- `tests/test_launch.py` — `ProcedureSkillTests`: the four directories exist, each `SKILL.md`'s
  frontmatter parses and its `name` matches its directory, `plugin_dir()` holds a readable
  `.claude-plugin/plugin.json`, the `report-shape` skill contains `build.TAIL`'s fenced block
  byte-identical, and `workers.report.parse` accepts a report written to the skill's shape.
- `tests/test_install.py` — `PackageDataTests` (**PD11**): a wheel built from this tree and
  installed into a temporary prefix carries every `SKILL.md` and the manifest. The existing
  `PackageTest` is untouched.

**Steps**

1. The package, the manifest, and `plugin_dir`/`skill_names`.
2. The four `SKILL.md` files, each by moving text out of its source file into the skill — the
   source is **not** edited here (that is Task 8), so for the length of this Task the text exists
   twice. Say so in the commit body: a duplicated procedure for one Task is the price of landing
   the destination before the cut.
3. `pyproject.toml`'s package-data line.
4. `ProcedureSkillTests`, with the `report-shape` byte-identity assertion written first — it is the
   one that fails if a character was retyped rather than moved.
5. `PackageDataTests`, over a wheel built into a tmpdir.
6. `bash tools/check_generic.sh` over the new tree: a `SKILL.md` carries no account name, no
   machine path and no product convention, and the four templates it was taken from already satisfy
   that, so a failure here means text was added rather than moved.
