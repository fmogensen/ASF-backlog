after: Task 1

The spec's §2, which is three lines in `decide` and one field on `Plan`. This is the card's own
first acceptance line and the one property the whole stage is allowed to be judged on, so the Task
that carries it touches **nothing** inside `_launches`, `_free`, `_intake`, `_idle` or `limbo`: the
sweep spends the seats that function left, which is stronger than being last in its sort order
(D-0003).

**Files**

- `asf/kernel/decide.py` — four edits, none inside `_launches`. `from asf.kernel import sweep as S`
  beside the other module imports (`:199-207`). `READ_ONLY` gains the kind (`:217`):
  `READ_ONLY = ('review', D.GROOM_FILL, intake.KIND, S.KIND)`. The launch section (`:506-507`)
  keeps the intake's actions in a local and calls the sweep **before** `actions.sort` (**PC3**),
  exactly as §2's fence has it but with the `actions.sort` line left where it is:
  `intakes = _intake(...)`, `actions += intakes`, then `swept, sweep_rec = S.plan(facts, config,
  states, parked_all, unready, free=_free(facts, config) - len(launches) - sum(1 for a in intakes
  if isinstance(a, A.Launch)))` and `actions += swept`. `A.Plan(...)` (`:512-516`) gains
  `sweep=sweep_rec`. `FINISH_FIRST` (`:1742`) and `ORDER` (`:279`) are **not** edited: a sweep is
  an `A.Launch`, already in `ORDER` and already sorted last.
- `asf/kernel/actions.py` — `Plan.sweep: dict = None` after `dor` (`:310`), and the docstring
  sentence §2 writes added where `dor`'s is (`:299-300`): `{'launched': [ids], 'waiting': N,
  'oldest_d': D}`, None while the sweep is off. **No new action class** — the spec says so, and
  `ORDER.index` raises `ValueError` for a class it does not hold, so adding one without registering
  it would break every tick.
- `tests/kernel/test_sweep.py` — `SeatTests`, one method per acceptance line of S-125156, beside
  Task 1's `CandidateTests`. Built on `tests/kernel/test_finish_first.py`'s worlds, which are the
  shipped proof of the ordering this Task must not disturb.

**Steps**

1. `actions.Plan.sweep` and its docstring line first, so `decide` has somewhere to put the record.
   Run `tests.kernel.test_decide` and `tests.kernel.test_loop`: a defaulted `Plan` field changes no
   reader, and that is worth knowing before the next step.
2. `READ_ONLY`, then the import. Then the launch section — and read **PC3** before touching it: the
   sweep's actions go between `actions += intakes` and `actions.sort(...)`, which sit on
   consecutive lines at this base.
3. The seat arithmetic is the one line to get right, and D-0003 writes it out: subtract
   `len(launches)` and then **only the intake's `Launch`es**, counted with `isinstance(a, A.Launch)`
   — an intake `Decide` is code deciding a card, not a session, and costs no seat. `_free` already
   subtracts every live session, including a live sweep, so `sweep_max_concurrent` is a second,
   narrower bound inside `S.plan` and not a term here.
