   `now = measure.table(runs)`; `before` = the last line of `<record>/improve/history.jsonl` or
   `None`.
2. Render `<record>/improve/<date>.md` through `metrics.write_if_changed`, three parts in the
   card's order: **(a)** the §2.1 table, one markdown table per block, the classes table last;
   **(b)** the movement — for every scalar in `now`, `before`'s value, the delta and its sign
   (`35.4 % → 31.0 % (-4.4)`), or `first run — no movement to show` when `before` is `None`;
   **(c)** one block per class over threshold with its sentence, its `excess_usd` and the card it
   proposes (its id once filed, else `— proposed, not filed (<level>)`).
3. Append `now` plus `date`, `product`, `sessions`, `as_of` as one JSON line to
   `<record>/improve/history.jsonl`.

     `core.is_open`; found with `last_seen` today → unchanged; found → `frontmatter.write_typed`
     of `measured`, `last_seen`, `rank` and one `append_history_lines` line
     `- <date> improve: <class> 0.31 → 0.354 (216 sessions)`; not found →
     `ids.mint_id(root, canonical, 'feature')` and `ids.write_new_item(...)` with typed `title`,
     `parent` (`improve.epic`, else `conventions.default_bug_epic`), `source`, `measured`,
     `last_seen`, `rank`, a `## Description` whose first line is the class's sentence with the
     number in it, and an `## Acceptance` naming the number that would close it.
     `index.do_index(root)` once, when anything was filed or bumped.
   - **`groom`** (the default) — one file per proposal in `conventions.intake_dir` as
     `improve-<class>.md`, same body, with a `parent:` header, overwritten each run so the groom
     never sees two. Nothing under `features/`.
   - **`human-now`** — the page and nothing else, one line per proposal:
     `NEEDS OPERATOR: improve proposes <class> (<sentence>) — widen approvals: propose_improvement in products/<p>.yaml`.
