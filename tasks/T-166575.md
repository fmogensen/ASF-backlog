**Files**

asf/kernel/ports.py, asf/kernel/model.py, tests/kernel/test_beat_facts.py

**Steps**

1. `asf/kernel/model.py`: five fields on `Session` — `beat_min` (the interval it was launched
   with, `0.0` without a beat), `beat` (the verdict, `''` when not judged), `quiet_min`
   (`None` when unknown), `beats` (the ledger's `resumes`), `identity` (the opaque string, `''`)
   — each documented in the class docstring where the existing fields are. `Facts.beats_unread`,
   `False` by default: the pass could not read origin at all.
2. `asf/kernel/ports.py`: `RealSessions.sessions()` builds `heartbeat.Beats(self.product,
   runs=[…])` **once** for the tick, over the live runs that carry `heartbeat_min`, and
   `heartbeat.load_state(self.product)` once; each `M.Session` is built in the loop that already
   builds it, with `heartbeat.observe` and then `heartbeat.verdict` on the observation.
3. The observation's `same_tree` is counted in the port and kept in `heartbeat.json` beside
   `shas`/`moved`/`seen`/`zombie`, under the new keys `tree` and `same_tree`. Only a run whose
   **branch head** has not moved for `loop_beats × interval_min` is fetched (`heartbeat.last_beat`)
   to compare its tree with the branch head's; every other run costs no fetch.
4. Any failure to read the beat tree leaves the counter exactly as it was and the verdict `alive`:
   a looping call that cannot be made never ends a session.
5. A run whose state record names a different session starts from a fresh record. A push carrying
   the stalled session's own `ASF-Session` trailer is logged as a zombie push by the code that
   already does it, and is not movement.
6. `beats_unread` is set when the pass read no refs at all; the state file is saved once per tick,
   after the loop, as `sweep` does. A read-only kind carries no beat and is judged as today.
7. Create `tests/kernel/test_beat_facts.py` with one case per acceptance line, driving the port
   against `heartbeat.Beats(…, ls_remote=…)` and a temporary bare repo — the `ls-remote` count
   and the fetch count both asserted on counters, never on a network.
