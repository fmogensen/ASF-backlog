The spec's design §3, **whole** — `unloaded_clocks`, `asf/install.py`'s predicate refactored onto
it, and the install tail's read-back, operator line and `return 1`. The tail lands here and not in
Task 4 because four of S-104407's own acceptance lines are statements about it, and because a trunk
that prints `NEEDS OPERATOR: clock(s) not loaded after install` and still exits 0 is this card with
an extra line of output (**PD2**). This is the card's *"nothing said so"*: the command's two sibling
paths both already look at their own result (`:1473`, `:1504`) and `asf scheduler status` already
exits 1 for exactly the state this install exits 0 on (`:1627-1628`).

**Files**

- `asf/scheduler.py` — `unloaded_clocks(labels, cfg=None)` as §3 writes it, docstring included:
  the one test for *is this clock running under launchd*, with the trap named in it (a paused clock
  is unloaded on purpose and is never counted). Then the install tail (`:1630-1643`): after the
  print loop, `return 3` for a non-launchd kind, else `missing = unloaded_clocks([j['label'] for j
  in jobs], cfg)`, the `NEEDS OPERATOR` line and `return 1` when it is non-empty, `return 0`
  otherwise. `jobs` is what this run rendered and installed, so `--clock <name>` answers for that
  clock and a whole-product install for every declared clock, `ci-queue` and `wave` included; the
  labels `retire_candidates` boots out (`:1637`) are not in `jobs` and are not read back, because
  the product file no longer declares them.
- `asf/install.py` — `_clocks_not_loaded` (`:385-389`) becomes
  `return scheduler.unloaded_clocks(labels)` and **keeps its docstring's reason**. Nothing else in
  the module changes: step 8's own read-back and retry (`:392-430`) stay exactly as they are, and a
  non-zero install rc now makes `:413` return `(1, 'asf scheduler install failed')` one step
  earlier than before, which is the honest answer.
- `tests/test_scheduler.py` — `InstallReadBackTest`, new, for S-104407's ten checklist lines.

**Steps**

1. Write `unloaded_clocks` in `asf/scheduler.py`. Call `status(label)` and
   `pause_record(label, cfg)` as **module globals**, not through an alias — that is what keeps the
   step-8 mocks working, since they patch the attribute on this module object (**PD12**).
2. Point `_clocks_not_loaded` at it. Verify the call order and short-circuit are today's: the
   `status` call first, `pause_record` only when the label is not loaded, so
   `test_step_8_installs_and_reads_back_a_loaded_clock` — which patches `status` but not
   `pause_record` — still never reaches it (**PD12**).
3. Add the tail. The operator line goes to **stdout**, with the rest of the install's output:

   one level up (`asf/install.py:428-429`) is on stderr because `asf install` interleaves eight
