The spec's §2.1 whole: `_glob_hit` becomes public `lane.path_hit`, the docs roots come out of
`landing_class` into `lane.doc_matchers`, and `evidence.doc_dirs`/`docs_only` read both through a
function-local import. After it lands there is **one** answer to "is this path a document", and the
sentence `asf/harvest/lane.py:2918-2921` already makes — *"a document lane is recognised by its
paths instead (`asf.evidence.evidence.docs_only`), which holds as long as it touches only
documents"* — becomes true for a product that declared a doc folder, which is what §1 says it is
not today.

**For every product that has not declared a `doc_path`, this Task changes nothing.**
`doc_matchers` then returns exactly the three trailing-slash roots, and `path_hit` on a
trailing-slash pattern is `path.startswith(pattern)` — the same function `docs_only` is today, path
for path. This repo is such a product; `tests/e2e/product/product.yaml` is the one that is not
(PD5).

**Read PD2 before writing `doc_matchers`** — the `isinstance` guard, and why the spec's literal is
a live hazard once the char-split list reaches `evidence`. Then **PD8** (`_conv`, because one
caller hands in a bare `Conventions`) and **PD7** (`tests/test_lane.py` is a Gate, not a
footprint).

**Files**

- `asf/harvest/lane.py` — `_glob_hit` renamed `path_hit` with the spec's docstring, and its two
  call sites (`landing_class` `:328`, `shared_hits` `:345`) follow; new `doc_matchers(product)`
  directly above `landing_class`; `landing_class` rewritten to the spec's five lines. `DOCS`,
  `CODE`, `shared_hits`'s own behaviour, `_conv` and every other function untouched.
- `asf/evidence/evidence.py` — `doc_dirs` and `docs_only` rewritten as the spec writes them, both
  with a function-local `from asf.harvest import lane`. `item_facts` is **not** edited: `dirs` is
  still computed once at `:1229` and passed to both call sites (`:1238`, `:1257`), which is D5.
- `tests/test_doc_lane_landing.py` — the `product()` helper and five methods on the existing
  `DocsOnlyTests`, plus the one row PD2 asks for. `DIRS` and the three tests that use it stay
  exactly as they are: they are the proof that the default did not move.

   from `conv.get('doc_paths')` only when it is a `list` or `tuple`, else `()`. Keep `_conv`

3. `landing_class` — the spec's body. Note it now matches roots through `path_hit` where it used
