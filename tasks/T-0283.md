§2.3 and §2.4: the only thing there is of why a session died, and the class printed where an
operator can see it — the card's first acceptance line. `stall` returns `Stalled` namedtuples
(D11), so the class is computed once and read by both the print and Task 4's router.

**Files**

- `asf/workers/runtime.py` — `last_beat`, `beat_text`, `beat_signature`
- `asf/workers/stall.py` — `Stalled`, `failure_class`, the class on `stall`'s and `capped`'s lines
- `asf/tick/step_health.py` — `dead_jobs` reading `Stalled` by name
- `tests/test_failure.py` — `StallLineTests`
- `tests/test_workers.py` — the `stall()` unpack at `:1916`
- `tests/test_session_identity.py` — the `stall()` equality at `:578`
- `tests/test_tokens.py` — the two `CAP` line assertions at `:374` and `:525` (PD11)

**Steps**

1. `runtime.last_beat(log_path)` — the same scan `read_result` makes (`asf/workers/runtime.py:410`),
   rewinding the collected records at every `init` line (B-0028), returning the **last parsable
   JSON record of the last run**, or None. A missing log, an empty one and a log of nothing but
   unparsable lines all return None and raise nothing.
2. `runtime.beat_text(rec)` (PD15) — the record's `result`, else its `error`, else the `text` of
   its last content block, else `''`. Its docstring carries the rule: read by `beat_signature`
   and by `headroom`'s reset parse (F-0054 PD14), never printed, never written to the state dir,
   never put in an event.
3. `runtime.beat_signature(rec)` — the `FAILURE_SIGNATURES` name that `beat_text(rec)` carries,
   else `''`. A name, never the text (§2.3): this is what keeps D3 true by construction.
4. `asf/workers/stall.py`: `from asf import failure` — the module, not the function (PD12) — and
   `Stalled = collections.namedtuple('Stalled', 'job state quiet cls why')`.
5. `stall.failure_class(session)` exactly as §2.4 writes it: `read_result`'s signature through
   `runtime_mod.failure_reason` when the session wrote a result, else its last beat's, else
   `work` — one `failure.classify(signature=sig)` either way, so `why` is `signature <name>` or
   `no signature`. A missing, empty or unparsable log returns `(work, 'no signature')` and
   raises nothing.
6. `stall()`: `found.append(Stalled(s['job'], state, quiet, *failure_class(s)))` and the print
   line gains `failure.label(cls, why)` as a two-space-separated suffix. `stall: none` is
   untouched — it is not a failure line and carries no class (§2.4).
7. `capped()`: the `CAP` line (`asf/workers/stall.py:232`) gains the same suffix, with the class
   of its own measure — `token cap` and `run cap` are both `work`, both through
   `failure.of_signature`, so the string is built by `failure.label` here too and not worded a
   third way. `capped`'s return tuple is unchanged; `cap: none` carries no class.
8. `asf/tick/step_health.py:62`: `jobs += [s.job for s in stalled if s.state == 'DEAD']`. The
   `found` comprehension on the line above reads health's own three-tuples and is untouched.
   `asf/workers/__init__.py:92` reads `stall()` for truth only and needs no edit (PD11).
9. `tests/test_workers.py:1915`–`:1922`: the unpack becomes attribute reads
   (`sorted((s.job, s.state) for s in found)`), and the fixture gains the two sessions §3.3
   names — a dead pid whose last beat is an authentication error, and a dead pid whose last beat
   is `connection reset by peer`.
10. `tests/test_session_identity.py:578`: `found == [stall_mod.Stalled('j2', 'DEAD', None, 'work',
    'no signature')]`, which is the same assertion made against the widened shape.
11. `tests/test_tokens.py:374` and `:525`: the expected `CAP` string gains
    ` class work (signature token cap)` and ` class work (signature run cap)` respectively (PD11).
