The spec's design §2 and §3, and its `## In` row 2. `rows.silent_features` names every Feature in
build whose work has no row anywhere, and one `silent work` row in `asf doctor` reports it — off the
same draw of the plan the `pushed work` row already makes (C9). The house precedent is
`orphaned_pushed` with `pushed_work_line`, and both halves sit beside it (C10, P10).

No invariant is added to `asf/invariants.py` (P12, `## Out`): the feeder's invariants judge rows
that exist, and an absent row has no subject. Nothing is refused, held, filed or minted by the new
row — it is a label, `required=False` (`## Out`, `## Records`).

**Read this Task from `docs/plans/f-0274.md`, not from this card** — the record cuts a Task card's
description at 4000 characters and this section is longer. Three decisions bind it and reach no
card: **PD3** (the anchors here are re-read at `080cdf5a6`, not the spec's), **PD6** (P9's live-Task
clause cannot be pinned by drawing the fixture: the Feature keeps a `RESHAPE → REPLAN` row, so
assert it from an empty rows list — step 4) and **PD9** (`check_pushed_work` has one caller and no
test, so the rename is free; `pushed_work_line` is what the suite calls and it does not change).

**Steps**

1. Write `silent_features(index, rows, occupancy, inflight)`. `items = items_of(index)`;
   `occ = occupancy or {}`; `live = live_ids(inflight, occ) | set(occ.get('waiting_landing') or ())`;
   `rowed = {r.item_id for r in rows or ()}`. Walk `ix.of_type(items, 'feature')` for a decided,
   open Feature whose stage word is in `BUILD_STAGES`; skip it when its own id is in `rowed`; take
   its open Tasks (`ix.feature_tasks` + `is_open`); skip when there are none, and skip when any of
   them is in `rowed` or in `live`. Return the rest, sorted. Note in a comment why `live` is built
   that way and not from `occupied` (`:340`): `occupied` is `busy | waiting_landing` and misses

   `waiting_landing` key (C6).
