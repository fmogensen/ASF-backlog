**Steps**

1. Add `--milestone <name>` to `release-readiness`'s parser, mutually exclusive with
   `--known-issues`; `--gate` is ignored with it, because the gate's criteria are not in this
   report (D-0008). The flag is the card's own wording — not a new command and not a gate criterion.
2. In `cmd_release_readiness(args, root)`, one branch before the gate is computed and after the
   `--known-issues` branch it already has: `if getattr(args, 'milestone', None): return
   cmd_milestone(args, root)`.
3. `cmd_milestone(args, root)` reads the declarations from the record root and the items from
   `index.json` through `index_reader.load`, so it sees exactly what every other table sees.
   Import both **inside the function**: `asf/release.py` has no package imports at module level
   and reaches `asf.record.core`, `asf.harvest` and `asf.metrics` function-locally (`:728`,
   `:655`, `:157`) — follow the file's own convention.
4. A name the record does not declare → `release-readiness: no milestone 'v9.9' in milestones.md
   (declared: v0.2, v0.3)`, exit **2**, the shape the command's other refusal already has.
5. Otherwise: every item whose effective milestone is the name (`in_milestone`), plus the retired
   ones that are done (D-0009) — `index_reader.live()` already splits `retired_done` (state in
   `('Resolved', 'Closed')`) from `retired_open` (P11), so a retired-and-done card counts closed
   and a retired-and-open one is in neither column. Bucket `closed` when `state` is in
   `DONE_STATES` and `open` otherwise, group by `epic_of` and order by the Epic's `rank`, with one
   trailing `(no epic)` row for an item with no Epic above it — a Decision, a Rule, a parentless
   Feature.
6. Exit **0** when nothing is open, **1** when something is: the command's own convention, and
   the answer to "is this milestone ready". `--json` prints `{"milestone", "state", "epics":
   [{"id", "title", "open", "closed"}], "open", "closed", "items"}`, carrying the same numbers as
   the text, whose totals equal the sum of its rows. Write nothing: this is a report, and the
   gate's own criteria, evidence and exit code are untouched when the flag is absent.
7. Extend `tests/test_work_item_model.py` with `MilestoneReadiness`, over a fixture record: the
   open and closed counts per Epic and in total, the counts grouped by the Epic above each item
   in those Epics' own order, the `(no epic)` row, totals equal to the sum of the rows, an item
   that inherits the milestone from an ancestor counted, a retired-and-done card counted closed
   and a retired-and-open one left out, exit 1 while something is open and 0 when nothing is,
   `--milestone v9.9` printing the refusal that names the declared names and exiting 2, `--json`
   carrying the text's numbers, and the release gate's own criteria, evidence and exit code
   unchanged when the flag is absent.
