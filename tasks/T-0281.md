- `asf/failure.py` — the module docstring §2.1 gives verbatim; `CREDENTIAL`, `QUOTA`,

  `ACCOUNT_SCOPE_RE`; `of_signature`, `of_text`, `classify`, `retries`, `may_relaunch`, `label`,
  `operator_text`, `account_scoped`
- `tests/test_failure.py` — new module; `ClassTests`

**Steps**

1. `asf/failure.py` with §2.1's docstring copied as it stands, `import re` and nothing else.
   No `Product`, no `os`, no path literal, no product name — `tools/check_generic.sh` and
   `tools/check_conventions.sh` refuse all four, and `asf.size`, `asf.budget` and `asf.tokens`
   are the shape to follow.
2. The four class names and `CLASSES` in §2.1's order; `RETRIES = {CREDENTIAL: 0, QUOTA: 0,
   TRANSPORT: 1, WORK: None}` with §2.1's comment on why `work` is `None`.
3. The four credential patterns, split so `FAILURE_SIGNATURES` can keep its own three names
   (§2.2) and so PD7 holds:
   - `AUTH_RE` — `invalid api key|please run /login|authentication[_ ]error|oauth token`
   - `MODEL_RE` — `issue with the selected model|model .* (?:not found|does not exist)`
   - `PERMISSION_RE` — `permission denied|not permitted to use`, the pattern
     `runtime.FAILURE_SIGNATURES`' `permission` entry carries today, byte for byte
   - `AUTH_ENV_RE` — `auth_env \S+ file .* (?:does not exist|is empty|cannot be read)`
   - `CREDENTIAL_RE` — the union of `AUTH_RE`, `MODEL_RE`, `AUTH_ENV_RE` and
     `not permitted to use`: §2.1's literal exactly, and **not** `permission denied` (PD7). Its
     doc comment says so and names the reason, so nobody widens it back.
   All `re.I`, each with the doc comment §2.1 gives.
4. `QUOTA_RE` and `TRANSPORT_RE` byte for byte as §2.1 writes them — which is byte for byte what
   `headroom.LIMIT_RE` (`asf/workers/headroom.py:41`) and `lifecycle.NETWORK_RE`
   (`asf/workers/lifecycle.py:128`) hold today, so Task 2's rewiring is behaviour-free. Each
   carries the `:data:` cross-reference §2.1 shows.
5. `SIGNATURE_CLASS` exactly as §2.1's dict, thirteen names.
6. `of_signature(name)` — `SIGNATURE_CLASS.get(name)` over a stripped string, None for `''`,
   None, `finished` and any name the table does not hold. It never falls back to `work`: the
   caller's text is read instead, which is what makes an unknown signature safe.
7. `of_text(text)` — `CREDENTIAL_RE`, then `QUOTA_RE`, then `TRANSPORT_RE`, first match wins,
   None when none does. The order is the ranking §2.1 documents and §3.1 asserts.

   `(default, 'no signature')`. Pure, no clock, no io. `why` is built from a pattern or class
   *name* and never from `text` (D3) — that is the invariant, stated in the docstring.
9. `retries(cls)` → `RETRIES.get(cls)`; `may_relaunch(cls, tried)` → True for `WORK` at any
