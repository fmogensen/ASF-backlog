**Files**

asf/record/writer.py, tools/check_card_gate.sh, tests/test_card_write_gate.py, tests/test_record_writer.py

**Steps**

1. `writer.write_card(path, text)` (`asf/record/writer.py:47`) becomes
   `write_card(path, text, validate=True)` and gains four lines and one import: when `validate`
   and the path is a card, parse `text` as a card for that path's extension and run
   `card.validate`; on any error raise `CardInvalid(path, errors)` and **write nothing**.
   `CardInvalid.__str__` is the path, the pointer and the message, one line each, naming **every**
   fault and not only the first.
2. The refused write must leave the target byte-identical, leave no temporary file beside it, and
   leave no file at all where the card did not exist — `write_card`'s write is one `os.replace`
   per call, so validate before the temporary file is created, not after.
3. Nothing else changes at any call site. All 27 of them in 16 modules inherit the gate (K1),
   including `asf/rehearsal.py:470`, which is outside the four areas the spec's P1 names, and the
   two module-local wrappers above the writer — `groom._write_card` (`asf/groom/groom.py:171`) and
   `widen_footprint.write_card` (`asf/tick/widen_footprint.py:364`). The three field-level writers
   go through it too: `frontmatter.write_machine` (`:510`), `merge_machine` (`:582`) and
   `write_typed` (`:635`), each of which writes at `:544`, `:631` and `:697`.
4. The waiver is the named argument and nothing else (D-0006): `validate=False`, allowed from exactly
   `asf/schema.py`'s migration and `asf/record/repair.py`. No environment variable — a switch a
   session could flip is not auditable. A waived write writes the card as given, however invalid.
5. Create `tools/check_card_gate.sh` in the shape of `tools/check_record_writers.sh`: grep the
   tree for `validate=False` against `write_card`, name the two modules allowed it, exit 1 and
   print `file:line` for a third. In this Task neither waiver exists yet, so the lint's allowed
   list is declared and the tree has no waiver — it must pass on the tree as this Task leaves it,
   and fail when a test writes a third waiver into a scratch copy.
6. Create `tests/test_card_write_gate.py` for S-133157's eighteen lines, and extend
   `tests/test_record_writer.py` (16 tests, green at this base — K5) with the two it owns: a write
   of something that is **not** a card is neither validated nor refused, and every existing writer
   still writes the cards it wrote before, unchanged. Cover the two reach cases too: a console
   command whose write is refused exits non-zero with the error on stderr, and a tick whose card
   write is refused leaves a note and does not crash the tick.
