## Description
stories: S-32257

§2.8: the parser the three rule scripts call, and the one check whose answer is local — the lane's
own state and the clone, no network and no host call. Two new files, for the reason PD8 gives.

**Files**

- `asf/security/passcheck.py` — `violations(product, root=None)` (R-0008) and
  `branch_classes(product, branch)` (`asf security paths`)
- `asf/security/cmd.py` — `register(sub)`, `cmd_security(args)`, the four subcommand bodies
- `asf/cli.py` — the parser's two lines
- `tests/test_cli.py` — `SecurityParserTests`

**Steps**

1. `asf/cli.py` gains what `asf/redact.py` has (`:293-294`): `from asf.security.cmd import register
   as register_security` and `register_security(sub)`. No command body in `cli.py` — none of its
   verbs has one.
2. `asf/security/cmd.py`: `register(sub)` builds `asf security` with four subcommands —
   `paths <branch>`, `pass --check`, `alerts --check`, `ports probe|dispatch|--check`, with
   `probe` taking `--json` (PD16). `cmd_security` dispatches; every `--check` prints one line per
   place on stdout and exits **1** when there is one, **0** when clean, and any other exit is a
   check failure the factory owns (P10). `--check` on `alerts` calls `alerts.violations`, on
   `ports` `ports.violations`, on `pass` `passcheck.violations`; `ports probe` calls
   `ports.probe(targets(product), ports)` and `ports dispatch` `ports.dispatch(product)`.
3. `asf/security/passcheck.py`, R-0008's check: over `lane.snapshot(product)`
   (`asf/harvest/lane.py:3678`), for every branch in a live state whose diff against
   `origin/<trunk>` touches a class (`security_paths.touched`), one line when there is no precheck
   of the head, one when its faults against the security dimensions are non-empty (naming the first
   fault, so an unread class row is visible), and one when it holds a blocking row — §2.8's shape
   byte for byte, `sev=S2 sig=unread-<item>`. The precheck file is read at F-0060's
   `precheck_pattern` path; the faults are `precheck_mod.faults(text, level,
   security=precheck_mod.security_dimensions(hit))`. No socket, no `gh` call, no `gh` import.
4. `branch_classes(product, branch)` for `asf security paths <branch>`: the diff's files against
   the trunk, `touched`, printed through `security_paths.describe` — one line, exit 0, and exit 0
   with `nothing sensitive` when the diff touches no class. It is a report, not a check.
5. A product with no `security.paths` violates nothing anywhere: every `--check` exits 0 with no
   line (§1.1's "unset, nothing is sensitive").
6. `SecurityParserTests` per the Story's fence (PD13): the parser accepts each of the four
   subcommands and the flags §2.8 names, rejects an unknown one with exit 2, `--check` exits 1 with
   lines and 0 clean over fakes, `ports probe --json` writes parseable JSON and nothing else on
   stdout, and `paths` prints one line. The exit codes are asserted as the numbers `rules.py` reads,
   not as truthiness.
