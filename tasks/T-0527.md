The spec's last two **In** bullets and `## The design` §3. T-0087's process-wide `time.monotonic`
freeze comes out, the test compares the real transcript, and one `assertFalse` refuses any line of the
rehearsal that carries a duration token — so the eighth occurrence of this mechanism is a named test
failure in the session that introduces it instead of a landing gate red one run in N (D5).

It waits on Task 1 not for a footprint — the two Tasks write disjoint files — but because removing the
pin before the product stops printing the clock is putting the flake back. Verify Task 1 has landed
before starting: `git log --oneline -S'timing=True' -- asf/harvest/harvest.py` must find it.

Read **PD9** before touching the imports: one goes, one is added, and one that looks dead is not.

**Files**

- `tests/test_dry_run.py` — the stdlib import block (`:12-17`); `DryRun.dry_runs` (`:42-66`);
  `DryRun.test_never_touches_real_state_and_is_idempotent` (`:68-83`)

**Steps**

1. Add `import re` to the module's stdlib block, after `import os` (`:13`) — the block is
   alphabetical. **Do not** remove `from unittest import mock` at `:17` (**PD9**): `DryRunHostPressure`
   and `CopyState` both use it and both would go red.
2. In `dry_runs`, delete the function-local `from asf.harvest import harvest as harvest_mod` (`:55`)
   and the `mock.patch.object(harvest_mod.time, 'monotonic', return_value=0.0)` from the `with` at
   `:57`, leaving `with self.f.seams():`. The two are one edit: the import existed only to reach the
   clock (**PD9**).
3. Replace the docstring's last sentence — *"The gate's own elapsed-time line … is pinned so it reads
   the same on both calls — real wall-clock drift between two back-to-back runs is not the thing under
   test here."* — with the spec's §3 replacement byte for byte: *"No clock is pinned: a rehearsal's
   transcript carries no wall clock (:func:`asf.harvest.harvest.product_gate`'s ``timing=False``), so
   two runs a second apart on a loaded host print the same bytes."* The `(before, after1, after2,
   lines1, lines2)` first sentence and the `Factory.seams` clause stay as they are.
4. In `test_never_touches_real_state_and_is_idempotent`, directly under
   `self.assertEqual(lines1, lines2, 'two dry runs printed different things')` (`:79`), add the spec's
   two lines byte for byte — the `# a rehearsal is diffed run against run: no line of it may carry a
   wall clock (F-0159)` comment and
   `self.assertFalse([l for l in lines1 if re.search(r'\b\d+(\.\d+)?s\b', l)], lines1)`. It goes
   **there** and nowhere else (**PD8**): it then runs under both `DryRunReadyPR` and `DryRunReadyFF`
   off the same pair of dry runs, with no second pair.
5. Nothing else in the file changes. The two checksum assertions at `:78` and `:79` are the
   rehearsal's *other* guarantee (P11) and this Task does not touch them; the `INVARIANT` assertion,
   the `feature/T-0001` assertions and all three other classes stay exactly as they are.
6. Run the module **more than once** before committing. The whole point of the change is that it is no
   longer a coin flip, and a single green run is what every one of the seven reviews in the spec's
   opening already had.
