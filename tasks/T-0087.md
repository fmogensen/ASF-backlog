## Description
stories: S-15050, S-15051, S-15052
writes: asf/workers/lifecycle.py, tests/test_lifecycle.py

§2.1, §2.2 and §2.3: one pure function from a run and its evidence to one state, one impure entry
point that gathers no more evidence than the answer needs, and `derive` reading the first instead
of re-testing `ended` and `end_reason` itself. No reader is converted here — this Task adds the
thing the other three call, and the ratchet that will hold them to it.

**Files**

- `asf/workers/lifecycle.py` — the state names and reason texts; `Status`; `classify`; `state_of`;
  `holds_seat`; `seats`; `is_dead_reason`; `LIVE_GROUPS`; `derive` re-expressed
  (`asf/workers/lifecycle.py:493-515`); the module docstring's state list.
- `tests/test_lifecycle.py` — `SessionStateInvariants` (new) and `OneClassifierTest` (new, with the
  ratchet of P4). `StateMachineInvariants` (`:225`) is unchanged and is the regression net.

**Steps**

1. The vocabulary of §2.1, beside the existing `FINISHED`/`DEAD_PID`/`STOPPED`
   (`asf/workers/lifecycle.py:85-89`): `WORKING`, `ENDED_AWAITING_TICK`, `FAILED`, `DEAD`,
   `SESSION_STATES`, `PUSHED_NO_REPORT`, `NO_RECORD`, `STOPPED_BY_OPERATOR`, `DEAD_REASONS`.
   `DEAD_PID` keeps its value and gains the comment of §2.1: read, never written.
   `is_dead_reason(reason)` is true for `DEAD_PID` and for `f'{DEAD}: {NO_RECORD}'` — the one
   place both texts are accepted (P8).
2. `LIVE_GROUPS` per P11 — `(state, table heading, count word)` for the three live groups, in the
   order the views print them.
3. `Status` as §2.1 fences it — `name`, `result`, `reason`, `source`, and the `label` property
   rendering §2.1's table: `working`; `ended, awaiting tick (<result>)`; `finished`;
   `failed: <reason>`; `dead: <reason>`.
4. `classify(run, ev, path=None)`, pure, in §2.1's order:
   - `run['ended']` — `reason = run.get('end_reason') or DEAD_PID` (P6):
     `FINISHED` → `Status(FINISHED, result=FINISHED, source='ledger')`;
     `STOPPED` → `Status(DEAD, result=STOPPED, reason=STOPPED_BY_OPERATOR, source='ledger')` (P7);
     `is_dead_reason(reason)` → `Status(ENDED_AWAITING_TICK, result=judge(run, ev, …), source='report')`
     when `ev.result is not None` (B-0028's re-judge), else `Status(DEAD, reason=NO_RECORD, source='ledger')`;
     anything else → `Status(FAILED, reason=reason, result=reason, source='ledger')`.
   - no `ended`, `ev.alive` → `Status(WORKING, source='pid')`.
   - no `ended`, gone, `ev.result is not None` →
     `Status(ENDED_AWAITING_TICK, result=judge(run, ev, landing=lands(run, path)), source='report')`.
   - no `ended`, gone, no result, `ev.remote_sha` and `ev.has_commits` →
     `Status(ENDED_AWAITING_TICK, result=PUSHED_NO_REPORT, source='branch')`.
   - otherwise → `Status(DEAD, reason=NO_RECORD, source='pid')`.
   No git, no clock, no file: `judge` and `lands` are the only calls, and `path` is passed through
   to `lands` exactly as `derive` passes it today.
5. `state_of(product, run, alive=None, path=None, gather_fn=None)` — §2.2's ladder, in order:
   a recorded run that is not a recorded death classifies against `Evidence()` and reads nothing;
   a recorded death reads the log's result line alone (`runtime.read_result(run.get('log'))`);
   a run with no `ended` whose `alive(run.get('pid'))` answers classifies against
   `Evidence(alive=True)`; only a run with no `ended` whose process is gone calls
   `gather(product, run, alive=alive)`. `alive` defaults to `health.pid_alive`, imported inside
   the function as `gather` already does (`asf/workers/lifecycle.py:400`). `gather_fn` exists for
   the test that asserts git is never reached.
6. `holds_seat(status)` → `status.name == WORKING`. `seats(rows)` counts the rows of an inflight
   list whose `state` holds a seat, and counts a row carrying no `state` as one (§1.4, P14). A row
   may carry its state as a `Status` or as its `name` string; `seats` accepts both.
