§2.5. One row, read from the cache, never a probe — and by construction, because the function has
no `run` to pass (PD9). This Task adds nothing to `asf/credentials.py`, which is what lets it run
beside Task 4.

**Files**

- `asf/doctor.py`:
  - `check_credentials(cfg, product)` → `(ok, detail)`, with §2.5's docstring. Config problems
    from `credentials.config_problems(cfg)` are reported first and red, naming each dotted key,
    before any verdict is computed — a misconfigured section cannot be judged. Then
    `credentials.for_product(product, cfg)` against `credentials.read_cache(product)`, each
    provider's verdict from `credentials.verdict` and `credentials.days_left` with `now` taken
    once: red when any is `invalid` or `expiring`, its detail naming the provider and carrying the
    renew command. A provider with no cache entry reads as `not probed yet` and is not red — the
    doctor is a view, and an empty cache is a factory that has not ticked, not a bad credential.
    `env.ConfigError` from `for_product` is caught and is the red detail. No providers configured,
    or a product that names none: `(True, 'no providers configured')`.
  - The row, appended in `run()` as a required row after `worker push auth` at `:845`:
    `ok, detail = check_credentials(cfg, product)` / `rows.append(('credentials', True, ok, detail))`.
- `tests/test_doctor.py` — new `CredentialsRowTests`, §3's four cases: red when the cache holds an
  invalid provider and when it holds an expiring one, each detail carrying the renew command; red
  on a config problem, naming the dotted key; `(True, 'no providers configured')` for a product
  that names none; and the row runs no probe — a counting fake `run` passed nowhere stays at zero,
  asserted by patching `subprocess.run` in the `credentials` module and requiring zero calls.

**Steps**

1. `check_credentials`, config problems first, then the cache.
2. The row in `run()`.
3. `CredentialsRowTests`, then the whole of `tests/test_doctor.py` — `TestOneFactoryCheck`,
   `TestFormatAndExit` and `TestCmdDoctorSubprocess` all assert over the row list.
