The spec's §1 and §2: the declared scope in the product file, the factory's own scope as a documented
default in the one module allowed to hold such a literal (D1, P20), and `asf/adopt.py` — the only place
in the package where a card is attributed to another product. Pure over the parsed cards and the scopes
it is handed; nothing calls it yet.

**Files**

- `asf/env.py` — `PRODUCT_FIELDS['scope']`, `SCOPE_FIELDS`, `NESTED_FIELDS['scope']`, `Product.scope`
- `asf/conventions.py` — `DEFAULT_FACTORY_SCOPE`, `FACTORY_SCOPE_NAME`
- `asf/adopt.py` — new module: `Scope`, `Match`, `KEPT_LINE`, `scopes`, `hits`, `matched`, `owner`, `flagged`
- `docs/products.example.yaml` — §1's block, where `customer_paths:` sits (`:308-311`)
- `tests/test_adopt.py` — new module: `ScopeTests`, `JudgementTests`
- `tests/test_env.py` — the new key validates, and a bad shape is refused

**Steps**

1. `asf/env.py`: `'scope': _MAP` in `PRODUCT_FIELDS` (`:515-522`), then §1's two lines —
   `SCOPE_FIELDS = {'paths': _LIST, 'terms': _LIST}` with the spec's comment, and
   `NESTED_FIELDS['scope'] = SCOPE_FIELDS` (`:548-551`). `validate_product_text`'s `_shape_ok` checks
   both levels with no further change (P17): a `scope:` that is not a map, or a `paths:` that is not a
   list, is a named problem and the product does not load.
2. `asf/env.py`: the `scope` property beside `customer_paths` (`:817-818`), with §1's docstring —
   `(paths, terms)` as two tuples, both empty when the product declares none or declares `scope:` with
   only one of the two keys.
3. `asf/conventions.py`: `DEFAULT_FACTORY_SCOPE` and `FACTORY_SCOPE_NAME` exactly as §1 gives them,
   comments included. This module is one of `tools/check_conventions.sh`'s three documented exceptions
   (`tools/forbidden-conventions.txt:4-6`), which is why the path literals may be here and nowhere else
   under `asf/` (D1).
4. `asf/adopt.py`: §2's module docstring byte for byte, then `Scope`/`Match` as §2 declares them and
   `KEPT_LINE = "kept as this product's own work"` with its comment (D7). The module imports
   `fnmatch`, `os`, `collections`, `asf.env`, `asf.conventions` and `record.core.tokenize` — and
   nothing from `asf.groom` or `asf.feeder`, which import it.
5. `scopes(product, home=None)`: enumerate `*.yaml` under `os.path.join(home or env.ASF_HOME,
   'products')` the way `product_of_dir` does (`asf/env.py:436-448`) — `env.load_file` per file inside
   a bare `except Exception: continue`, so a broken sibling product is skipped and never raises (P18).
   Drop the file whose name is `product.name`; keep each remaining product that declares a non-empty
   `scope:` as `Scope(name, tuple(paths), tuple(terms))`. Append
   `Scope(FACTORY_SCOPE_NAME, **DEFAULT_FACTORY_SCOPE)` only when no `*.yaml` in that directory is
   named `FACTORY_SCOPE_NAME` (D2) — including the file this product was loaded from, so a machine
   where ASF is itself a registered product gets one scope under that name and not two. Return the
   list sorted by `name`.
6. `hits(rec, scope)` → `(paths, terms)`, both ints (D3, D4). Paths: the distinct globs of
   `scope.paths` that `fnmatch.fnmatch` matches against any entry of the card's `writes:` **or** any
   path-shaped token — a whitespace-free token containing `/` — in the card's title plus its
   `## Description`. Terms: the distinct members of `scope.terms` present in
   `record.core.tokenize(title + ' ' + description)` (P21), compared lowercased.
7. `matched(rec, scope)`: `paths >= 1 or (scope.terms and terms >= min(2, len(scope.terms)))` — a
   scope with no terms is never matched on terms, whatever the card says.
8. `owner(rec, scopes)` → the single best `Match` or `None` (D5): `None` at once when the card's body
   carries `KEPT_LINE` (D7); else rank the matched scopes by `(paths, terms)` descending and return
