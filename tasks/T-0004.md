**Steps**
1. `PRODUCT_FIELDS` gains `'capacity': _MAP`.
2. Add `CAPACITY_FIELDS = {'sessions': _STR, 'ci': _STR, 'batch': _MAP}` beside `CI_FIELDS`.
3. Replace the one-off `ci` nesting in `validate_product_text` (the `elif section == 'ci'` line

   lookup and the `check(…, '<section>.')` call (P2). An unknown `capacity.<key>` is reported with
   its line exactly as an unknown `ci.<key>` is today; `capacity.batch` given a scalar is reported
   as "must be a map" by the existing `_MAP` shape check.
4. `ci:` behaviour is unchanged — `TestProductSchema` passes untouched.
5. `tests/test_env.py`: new class `ProductValidation` with the three tests of spec §3.5.
