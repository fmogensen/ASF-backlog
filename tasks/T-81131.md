## Description
stories: S-80456

after: Task 2

The ask goes where the branch's facts are gathered, under the guard that is already there (PD5).
The hold is an instruction, not a verdict shouted at a session: a session that cannot see the sha
and the command the lane ran cannot reproduce the refusal.

**Files**

- `asf/harvest/lane.py` — one `import`, and the ask in `branch_facts` beside `f['refusal']`
  (`:1887`), inside the `rec.get('state') in (None, PUSHED, BACK) and not f['foreign']` guard
  (`:1885`); plus the `regression:` clause on the branch's tick line. `lane_refusal` (`:1136`) is
  not touched, and neither is `red_tests` (`:5447`) or `_FAIL_RE` (`:5440`).
- `asf/workers/lifecycle.py` — `REGRESSION = 'regression'` with the spec's §4 comment above it.
  `MECHANICAL` (`:2946`) is left exactly as it is (PD10).
- `asf/harvest/regression.py` — `ask(lane, f)` and `hold_text(f)` (PD10).
- `tests/test_regression_gate.py` — `LaneHoldTest`.

**Steps**

1. `ask(lane, f)` → `(state, line)` or `None` while deferred: `gated` first, and when it says no,
   the `why` goes to the tick line as `not gated — <why>` and nothing is held. When it says yes,
   `check` with the trunk sha, the branch sha and the command.
2. In `branch_facts`, beside `f['refusal']`:
   `if not f['refusal'] and conv.branch_kind(b) == 'fix':` set `f['regression']`, and when it is
   neither `proved`, `skipped` nor `waived`, set
   `f['refusal'] = (lifecycle.REGRESSION, regression.hold_text(f))`. An existing refusal wins: the
   cheap pure-git one is not displaced by the heavy one.
3. `hold_text(f)` — four texts, one per state, each naming the test file to write, the pre-fix sha,
   the command the lane ran and the run's last lines: `not-red` says the branch's tests pass on the
   trunk so nothing on it would have caught the defect; `inconclusive` prints the non-zero run's
   tail and says the grafted test did not run as a test on the pre-fix tree (D-0004); `red-both` names
   the cases red on both sides (D-0005). Each closes with the waiver sentence — that a defect which
   genuinely cannot be caught by a test is a decision in the register and a trailer, not a note.
4. The tick line gains the `regression:` clause for a fix branch: the four states, plus
   `deferred — started in the background on <sha>` and `not gated — <why>`.
5. Write `LaneHoldTest` to the seven acceptance lines of S-80456, driving the lane over a stubbed
   `check` so the four states are exercised without a test run (PD11): `→ back` with cause
   `regression`, the text naming file, sha and command verbatim, `rounds` advanced by one and the
   cause not in `lifecycle.MECHANICAL`, a `proved` verdict leaving today's transition untouched, a
   deferred verdict holding nothing and printing the deferral, and `inconclusive` and `red-both`
   each with their own text.
