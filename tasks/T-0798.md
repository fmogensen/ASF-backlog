Read **PD1** again before starting — this Task's own acceptance is why Task 1 had to come first.

**Files**

- `.asf/product.yaml` — new file, at the repository root, exactly the spec's §*The design* §1
  block (reproduced here so the coder copies it verbatim rather than re-deriving it):

  ```yaml
  # .asf/product.yaml — the conventions this repository's CI must read for itself.
  #
  # `conventions.merge.factory_only` is enforced by a CI step (tools/check_factory_only.sh), and a
  # GitHub runner cannot see the operator's ~/.ASF/products/<product>.yaml. So the inputs the rule
  # needs live here, in the repository, and nothing machine-, account- or product-specific does:
  # no repo_slug, no repo_dir, no backlog_dir, no product name. The operator's own product file
  # stays the tick's source of truth for everything else.
  main: main
  conventions:
    branch_prefixes:
      code: worker/
      fix: fix/
      spec: spec/
      plan: plan/
      direct: cloud/direct-
      legacy: []
    merge:
      mode: auto
      factory_only: true
      require_item_id: true
      bot_paths: [CHANGELOG.md]
  ```

- `tests/test_factory_only.py` — `CommittedProductFile`, a new class: reads `.asf/product.yaml`
  from the repository root (`os.path.join(REPO, '.asf', 'product.yaml')`, `REPO` found the same
  way `tests/test_workflow.py:9` finds it — no cwd dependence); `env.load_file` parses it;
  `env.product_problems(text)` is `([], [])` and `env.validate_product_text(text)` is `[]`; the
  file's top-level keys are exactly `{main, conventions}`; `Product('asf', data).main == 'main'`;
  `conventions.merge_factory_only` and `conventions.merge_require_item_id` are both `True`,
  `conventions.merge == 'auto'`, `conventions.merge_bot_paths == ['CHANGELOG.md']`, and
  `conventions.shape_findings() == []`. The drift pin: `conventions.all_prefixes()` built from
  the committed file equals `Conventions.from_mapping({}).all_prefixes()` — a kind added to
  `DEFAULT_BRANCH_PREFIXES` without being added here goes red in this suite rather than silently
  refusing the factory's own new branch kind in CI.
