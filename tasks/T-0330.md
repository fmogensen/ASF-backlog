## Description

after: Task 5

Two tables, both narrower than the coder's, and both are findings in what they do **not** need. The
reviewer reads, runs the gate and writes one review file — it never installs a dependency, never
drives a browser, never binds a port. The prober is read-only, writes the readings file and nothing
else, restarts nothing and reaches only what the brief grants (`asf/roles/asf-prober.md`); D10 says
it is the role the adopting card can act on first, and §2.6 says its table is expected to be the
short one — *and that if it is not, that is the finding*.

**Files**

- `docs/research/sandboxed-worker-shell.md` — §2.7's item 3, the second and third tables, each
  opening with its two control rows.
- `tools/spike/f-0065/**` — PD12.

**Steps**

1. The reviewer: `session.sh reviewer off`, `reviewer bare`, then one `grant-<n>` leg per refused
   probe over `P00`–`P09`. The column that matters is `needed by the role`: a grant the coder
   needed and the reviewer does not is the whole reason the adoption list's first row exists (a
   settings file per role, not per pool — `asf/workers/spawn.py:598-606`).
2. The prober: `off` and `bare` are already in the logs from Tasks 3 and 4. Add a `grant-<n>` leg
   for each of `P07`, `P08` and `P13` if `bare` refuses them. Every egress probe must read
   `not needed` in this table; an egress probe the prober turns out to need is a finding about the
   role, and it goes in the document as one.
3. Generate both tables with `collect.py`. Any row still `unpaired` is work left, not a finding
   (§2.3) — the count goes to the stamp and this Task may end `partial` on a non-zero count as long
   as the stamp carries it (PD12).
4. Update the stamp.

**Gate**

```bash
cd "$(git rev-parse --show-toplevel)"
python3 tools/spike/f-0065/collect.py --role reviewer --require-control
python3 tools/spike/f-0065/collect.py --role prober --require-control
python3 tools/spike/f-0065/collect.py --all --markdown
bash tools/check_generic.sh
python3 -m asf.redact --tree
```

**Acceptance**

```bash
python3 tools/spike/f-0065/collect.py --all --markdown > /tmp/f0065-tables.md
grep -c '^| P' /tmp/f0065-tables.md          # one row per probe per role
python3 tools/spike/f-0065/collect.py --all --unpaired   # prints the count the stamp carries
```

```bash
bash tools/spike/f-0065/session.sh prober bare
python3 tools/spike/f-0065/collect.py --role prober --require-control
# the two control rows read 'refused'; exits 0
python3 tools/spike/f-0065/collect.py --role prober --leg off --require-control; echo "rc=$?"
# the control rows read 'ok' in an unsandboxed leg, so the collector refuses it: rc=1
```
