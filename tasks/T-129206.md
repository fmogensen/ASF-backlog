**S-120856 — the map, the session, the scrub and the secrets row; and unchanged when unset**

```bash
# S-120856 — the map, the session, the scrub and the secrets row; and unchanged when unset
python3 -m unittest -q tests.test_auth_env.GitHubAppIdentity tests.test_auth_env.ProductAuthEnvConfig tests.test_auth_env.ProductAuthEnvRedaction
```

- [ ] a product with no github_app returns exactly the map it returns today, for a product with an auth_env and for one without
- [ ] a product with a github_app but no token minted yet returns exactly the map it returns today
- [ ] a product with a github_app and a minted token gains one entry, naming the token file
- [ ] an empty token file adds no entry, because a named missing file refuses a launch
- [ ] the App's entry replaces a declared auth_env entry for the same variable
- [ ] a declared auth_env entry for any other variable is still returned beside the App's
- [ ] the environment a gh child gets carries the minted token as its code-host variable
- [ ] the environment the security pass builds carries it too, through the same map
- [ ] a launched session's child environment carries the minted token
- [ ] a launched session's git gets its HTTPS credential from the minted token, with nothing written to disk
- [ ] the rate-limit budget is read under the minted token's own key, so the App's remaining calls are not the operator's
- [ ] the redaction gate holds the minted token as a pattern, under the code-host variable's name
- [ ] no part of the minted token reaches the session ledger, the brief or the setup log
- [ ] the worker-secrets row lists the App's token file by variable name and presence only

**S-120858 — the host's two doors, and that a refresh after the ports is too late**

```bash
# S-120858 — the host's two doors, and that a refresh after the ports is too late
python3 -m unittest -q tests.kernel.test_loop.GitHubAppRefresh tests.test_workers
```

- [ ] the kernel tick refreshes before it builds its ports, so the token the port snapshots is the one this tick minted
- [ ] a token minted after the ports are built is not the token that tick's port uses, which is why the door is where it is
- [ ] the kernel tick on a product with no App configured makes no mint call and runs unchanged
- [ ] a kernel dry run mints nothing and prints the would-mint line with the rest of the plan
- [ ] a failed refresh does not fail the tick: one line, and the tick runs on the ambient login
- [ ] a session launch refreshes before it reads the auth map, so the session's token has at least the margin left
- [ ] a session launch on a product with no App configured makes no mint call and launches unchanged
- [ ] a failed refresh at launch does not refuse the launch
