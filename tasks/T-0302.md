## Description
stories: S-30457

after: Task 2

§4 and §3's T8. The operator's memory directory is outside every repo the factory writes (§1.3),
so the product cannot prove that each file there became a pointer — but it can commit the table
that says what each pointer is, and run the check over it. This fixture is that copy, and it is
what makes the second pass cheap: the next six files are found by `asf memory check`, not by
reading a console.

**Files**

- `tests/fixtures/memory/*` — six memory files, one per row of the table below, plus `MEMORY.md`
- `tests/test_memory.py` — `PassOneInventoryTests`

**Steps**

1. One file per row, each carrying the id of the item that made its remembering unnecessary. The
   ids are PD3's positional map, which corrects §4's table (PD4):

   | memory file | points at | once it is code |
   | --- | --- | --- |
   | `groom-epic-assignment-rule.md` | `S-30452` | `conventions.epic_routes` |
   | `groom-inbox-answers-must-carry-no-why.md` | `S-30453` | `parse_answer`'s reason + the groom's line |
   | `validate-plan-dag-with-plan-order.md` | `S-30454` | `asf plan-check` |
   | `verify-spec-preconditions-against-checkout.md` | `S-30455` | `asf spec-check` |
   | `reshape-relaunches-until-record-half-applied.md` | `S-30456` | `split_parts` in the reshape brief |
   | `t-0103-review-self-trigger-loop.md` | `B-0147` | already code — `review.is_current` |

2. Each file is the one-line pointer the card's second acceptance asks for: the id, the one
   sentence of what was remembered, and the name of the thing that produces it now. No console
   path, no account, no host — these files are tracked and `tools/check_generic.sh` reads every
   tracked file (`asf.redact --tree`).
3. `tests/fixtures/memory/MEMORY.md` is the index of one-line pointers,
   `- [Title](file.md) — hook` per row, which is also the form §1.4's second row is about: the id
   rides in the line as prose and `pointer` finds it there.
4. `tests/test_memory.py` gains `PassOneInventoryTests`, §3's T8 assertion by assertion: the
   directory holds one file per row; `asf memory check --dir tests/fixtures/memory
   --grace-days 0` exits 0 and prints `memory: every file carries a card` (PD13 is what makes a
   zero grace check every file, whatever its mtime after a fresh checkout); deleting the id from
   any one file — a copy in a temp directory, never the fixture — makes it exit 1 naming that
   file; and every id the fixture names is one of this spec's Stories or `B-0147`.
5. The `B-0147` row is asserted as the one row that points at something already landed: its
   pointer is the Bug that taught `review.is_current` a named head still stands when the code at
   the tip is the same (`asf/evidence/review.py:218`), held by
   `test_the_review_commit_on_top_of_the_head_it_names_is_current`
   (`tests/test_review_reader.py:179`). Nothing is added there and nothing is re-litigated
   (§1.3).
6. Print the `NEEDS OPERATOR` line §4 carries in the Task's final message: this fixture is the
   committed copy of the table, and replacing the files on the console host, then proving it with
   `asf memory check --product <p>`, is the operator's.
