The spec's §`asf/conventions.py` — the second key — and `Lane.regenerate_shared`, the third instance
of P13's shape. After Task 4 because both edit `asf/harvest/lane.py`, and because a regenerate is
only reachable on a branch the per-path serialisation made wait.

**Read PD4 and PD5 before writing the method.** PD4 fixes what the commit contains; PD5 fixes what
happens on every refusal — one line, nothing pushed, `None`, and the branch takes today's path. No
new correction kind, no new lane state, no new WAITING reason.

**Files**

- `asf/conventions.py` — `DEFAULT_SHARED_REGENERATE = None` beside `DEFAULT_SHARED_PATHS` (`:193`)
  with the spec's `#:` comment; the `shared_regenerate: str = DEFAULT_SHARED_REGENERATE` field
  beside `shared_paths` (`:717`) with its `#:` comment; `validate_mapping` gains the clause
  `worktree_setup` has (`:466-468`) — a command string, not a dict, a list, a bool or blank — and
  the docstring's list of checked keys (`:454`) names it; the module docstring's yaml example
  (`:33`) gains the `shared_regenerate: uv lock` line under `shared_paths`.
- `asf/harvest/lane.py` — `SHARED_REGENERATE_TIMEOUT_S = 900` (the number `worktree_setup` gets, for
  the same reason: an install command over a network); `Lane.regenerate_shared(self, f)` placed
  beside `drop_copies` and `repair_signoff`, carrying the spec's docstring including its list of the
  ten cases that publish nothing; one call in `Lane.advance`, immediately after the `drop_copies`
  call (`:1761`) and inside the same `if self.repo:` block — the slot for *"rewritten by the lane
  with no session, before any refusal sends it back to a session that may not force-push"*.
- `tests/test_contracts.py` — `class SharedRegenerateTests` beside `ConventionKeysParse` /

   existing `assertIsNone(c.worktree_setup)` gets a sibling for `shared_regenerate`, and
   `SharedRegenerateTests` covers the parse and the three refusals (a dict, a list, a blank string
   — each one `conventions.shared_regenerate` problem whose text carries *must be a command string*)
   and that unset is `None` with no behaviour anywhere.
2. `regenerate_shared`'s guards, in this order, each one line out and `None`:
   `not self.repo or not f.get('head')`; no `f['kind']` (under no factory prefix); `f.get('foreign')`

   `drop_copies` refuses on (`:2075-2078`); no `conv.get('shared_regenerate')`; `f.get('live')` (a

   paths that are in both are the ones the branch is behind on. Empty → `None`, **no command run**,

   current trunk this pass and a lockfile it cannot rebase goes back to its session as today (P14) —
