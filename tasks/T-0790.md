The rest of the spec's §2 and all of §4: `f['unlandable']`, the `REAPED` arm, `archive()` serving
both terminal states, `REAPS_PER_PASS`, and `pr_hygiene`'s two new lanes with the two docstrings
that are now false the other way round. `REAPED` has been a defined, listed, tested terminal state
with no writer anywhere in the product; this Task is its first.

This is the Task the card's number turns on. Task 1 sends every overdue branch back to a session,
which is right for a branch that can still land and wrong for one whose card is Closed — that one
should not cost another session at all.

Read **PD5** (a deferred reap writes `STALE` unless `push_or_defer` learns a third kind),
**PD9** (the second unlandable question is unreachable and is dropped), **PD13** (the vocabulary
test asserts *exactly two* lanes and goes red) and **PD10** (`reap: false` sends back instead)
before starting.

**Steps**

1. `REAPS_PER_PASS = 25` with the spec's `#:` comment, and `self.reaps_taken` initialised beside
   `self.orphans_taken` at both `:1375` and `:1419`. The spec's snippet names the counter
   `self.reaped`; use `reaps_taken`, which is the name the bound it copies already uses two lines
   away and which does not read like a boolean.
2. `f['unlandable']` in `branch_facts` — the reason the branch can no longer land, or `None` —
   computed **only when `overdue_s(rec, f)` is not None** (D9). `branch_facts` already has
   everything it needs at that point: `rec` from `lifecycle.lane_of(run)`, and `now`/`stale_after`
   in the literal at `:1467`. Two questions, both lifted from `orphan_facts` with its own wording:
   `superseded_by(self.items, item)` or a `card.get('state')` in `('Resolved', 'Closed')` gives
   `f'{item} is {closed} in the record'` (`:1696-1700`), and `not self.merges_clean(b)` gives
   `f'too far behind {self.trunk} to rebase'` (`:1707`). The third question of the spec's table is
   dropped — PD9 proves it can only answer "no" for a branch a run holds. The gate matters for
   cost: `merges_clean` is a `git merge-tree` per branch and a pass sees every lane branch, so it
   runs only where a decision depends on it. A2 asserts that by mocking `merges_clean` and counting
   calls; write the gate so that assertion can be true.
3. `archive(self, f, why, state=STALE)`: the one `record(f, STALE, why)` at `:2130` becomes
   `record(f, state, why)`, and the two lines that announce the outcome follow the state — the
   printed line reads `reaped {b}: {why} — archived as archive/{b}` and `self.results[b]` stays
   `SUPERSEDED` (it is the harvest field, and the Records table says `harvested: superseded` for a
   reap). `close_pr`'s comment keeps its shape ex
