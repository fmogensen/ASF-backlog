The whole of the spec's `## The design`: `declared_stories` rewritten to read the document itself,
`_fenced` and `_outside` beside it, and one comparison in `check_doc` masked on both sides. No
signature moves and no pattern is edited — `FENCE`, `CODE_SPAN`, `HEADING`, `STORY_DECL` and
`CHECKBOX` stay as they are and are simply run against the document instead of a copy of it.

**Files**

- `asf/record/idcheck.py`
  - `_fenced(text)` and `_outside(spans)`, new, immediately after `_prose` (`:27-28`) — the spec's
    bodies and docstrings verbatim (`## The design`, first block). `_fenced` returns
    `[m.span() for m in FENCE.finditer(text or '')]`; `_outside(spans)` returns the
    `pos -> not any(a <= pos < b …)` predicate. Four lines each, counting the docstring.
  - `declared_stories(text)` (`:99-109`), rewritten to the spec's body verbatim: `outside` from
    `_outside(_fenced(text))`; `bounds` the unfenced `HEADING` starts; each `STORY_DECL` match
    skipped when its start is fenced; the line walk `splitlines(keepends=True)` with a running
    `pos` and `CHECKBOX.match(line.rstrip('\r\n'))`, appending only when `outside(pos)`; the same
    `out.setdefault(…)` with the same `{'title', 'acceptance'}` shape. The docstring is the spec's,
    which states that code spans survive **and** why the fences do not — a reader who changes this
    function next must find which half is deliberate.
  - `check_doc` (`:41-61`), one comparison: the loop body turned inside out so the line fits —
    `if rec is None or not title: continue`, then `was = rec['meta'].get('title')`, then
    `if _norm(title) != _norm(_prose(str(was or ''))):` — with the spec's two-line comment above it.
    `prose = _prose(text)` at `:43` stays, the finding's text at `:49` stays (it keeps printing the
    card's title raw, `{was!r}`), and the claim half below is untouched.
  - **Not edited:** `_prose`, `_norm`, `CODE_SPAN`, `FENCE`, `HEADING`, `STORY_DECL`, `CHECKBOX`,
    `cited_stories`, `phantom_stories`, `task_key`, `duplicate_task`, `session_claims` (`D2`,

    already verbatim (`P6`, **PD2**).
- `tests/test_plan_tasks.py` — two classes appended after `DeclaredAndPhantomStories` (`:117-155`),
  each subclassing `PlanTasksTests` the way that class already does, so each reuses its record

  the minted card back with the module's own `read(self.root, 'story', …)` (`:55-57`):
