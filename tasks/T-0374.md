§2.8's second half and §2.9. Ingest stays the only writer of a card's machine block: it reads the

now has two more arguments. This Task needs no host and no pass — its fixtures write
`metrics/probes/<day>.jsonl` by hand, which is why it runs beside Tasks 5 and 8.

**Steps**

1. `closing.Ev` gains `probe: str = ''`. No rule row reads it: the six rows at
   `asf/evidence/closing.py:107`, `:122`, `:127` and their Story equivalents are untouched, and
   the module stays pure and total (P5). `Ev.in_prod`'s doc comment (l. 70) is widened to name
   the probe as a second way it is true (PD13).
2. `_in_prod(child_ids, task_ev, ev, merged=None, own_sha='', reach=None, probe='',
   customer_facing=False)` becomes §2.9's table, written as data, with the childless branch
   explicit and the two new clauses ordered around it (PD5):
   - **a** the product deploys nothing → True (B-0077, unchanged);
   - **b** no readable `prod_sha` → False (unchanged);
   - **c** the landing sha is not inside `prod_sha` → False (unchanged);
   - **e** `probe == 'fail'` → **False** (new), evaluated before the childless branch, so a
     failed journey stops the close in every mode;
   - the childless branch: `prod_mode == 'auto' and own_sha and reach(own_sha)` (unchanged) —
     and, when that is False, clause **g** still applies;
   - **d** `prod_mode != 'auto'` and every child's pull request is in `checked` → True
     (unchanged) — a human looked, and a human outranks a probe;
   - **f** `prod_mode == 'auto'` → True (unchanged);
   - **g** `probe == 'pass'` and not `customer_facing` → **True** (new) — the card's first
     acceptance;
   - **h** otherwise → False (unchanged). `probe == 'unrunnable'` falls through to **h**: it
     closes nothing and blocks nothing that was not already blocked.

   sha passes `probe=''`, and nothing about it changes.
4. `verdicts` is called once per derive for `ev['prod_sha']`, not once per item.
5. The evidence lines: the four forms of §2.8, rendered into the item's `evidence:` list, plus one

   is written.
6. The `rule:` phrase names what decided — `children-closed (probe: pass at <sha7>)` — so a state
   that changed does not change for no visible reason.
