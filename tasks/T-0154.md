§2.2 and §2.3: `bugs_cell` and `features_cell` on top of Task 2's counts, and the two rows between
`Ready to launch` and `Quota 5h/7d`. Every clause in §2.2's two tables, in that order, with the two
noted omissions and no third.

**Files**

- `asf/views/work.py` — `bugs_cell(root, product, now=None)` and `features_cell(root, product, now=None)`
  added below the counts, each loading the index through `ix.load` and the ledger through
  `lifecycle.runs` once, each returning `status.not_configured('backlog_dir (no index.json)')` when
  there is no `index.json` (§1.4, the same string `ready_cell` uses), and the two "no Bugs / no
  Features in the record" forms. `features_cell` reads the window as
  `product.conventions.get('land_window_days')` (P13) and prints it. Durations render through
  `ix.span` (PD6).
- `asf/views/status.py` — the module docstring's row list grows §2.3's two bullets; `render`'s tuple
  grows `('Bugs', …)` and `('Features', …)` between `Ready to launch` (`:212`) and `Quota 5h/7d`
  (`:213`), the `from asf.views import work` import local to the cells' scope as `ready_cell`'s
  already are. Nothing else in the module changes.
- `tests/test_views.py` — `StatusWorkRows` (new, §3.2), over Task 2's fixture builder with the wall
  clock (PD11) and the existing `rows()` markdown parser.

**Steps**

1. `bugs_cell`: guard the missing `index.json` first, then `ix.load`, `lifecycle.runs(pool.sessions_path(product))`,
   `bugs(items, runs, now or dt.datetime.now(dt.timezone.utc))`, then the clauses joined with ` · `
   exactly as §2.2's table orders them. `total == 0` short-circuits to `no Bugs in the record`.
2. The `· S? n` clause only when non-zero; the ` (S1 B-0091 B-0093)` parenthetical only when
   `in_fix_s1`; `oldest open S1/S2 none` when `oldest` is empty.
3. `features_cell`: the same shape, `median to land <span> (<w>d, n=<measured>)` with
   `median to land unknown` when the median is None, and ` (F-0095)` — the newest — only when
   `landed_today`.
4. Add the two rows to `render`'s tuple and the two bullets to the docstring.
5. Write `StatusWorkRows`: the two exact cells, the `S?` clause absent then present, the `(S1 …)`
   parenthetical absent, `oldest open S1/S2 none`, `median to land unknown (7d, n=0)`, the two
   empty-record forms, the row order off the rendered table's lines, and `land_window_days: 14`.
6. Run the Gate.
