§2.9. Criterion 7 is the card's "first-user docs" bullet read by a machine. It waits on Task 3
because that is when the four pages exist on the trunk and the README links them — landing the
criterion first would print an unmet row for a page nobody has written yet.

**Files**

- `asf/release.py` — `DEFAULTS['doc_pages']`, criterion 7 (`:351-357`)
- `tests/test_release.py` — `DocsCriterionTests`

**Steps**

1. `release.DEFAULTS` gains
   `doc_pages: ['docs/quickstart.md', 'docs/concepts.md', 'docs/operator.md',
   'docs/troubleshooting.md']` beside `readme_sections` (`asf/release.py:42`). It is `release.py`'s
   own default list, read by criterion 7 alone; `conventions.doc_pages` is the page **set** the
   link check walks and the two are not merged — one answers "is the line ready to be released",
   the other "do the docs build".
2. `doc_pages` joins the list-valued overridable keys at `asf/release.py:81` so a product may name
   its own.
3. Criterion 7 requires, beside what it reads today (the `readme_sections` headings and the tag's
   CHANGELOG notes): every `doc_pages` entry present on the trunk, and each one linked from the
   README. Its evidence line names the missing page or the missing link — not a count.
4. Nothing else about the eight criteria changes, and `KEYS` (`:48`) is untouched.
5. `DocsCriterionTests`: unmet with a missing page, unmet with a page the README does not link, met
   when the four pages exist and are linked and the tag's CHANGELOG notes are there; the evidence
   names what is missing.
