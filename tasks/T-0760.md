The spec's In-4 and `## The design` §2: one step in `docs/guide/operating.md`, and the first test
this repo has over that page. Waits for Task 1 — PD8 is why, and it is not the queue.

Read **PD5** (the helper the spec says to copy slices four sections, and the class it names does not
carry it) and **PD6** (the assertions do fail today, and the baseline count) before starting.

**Files**

- `docs/guide/operating.md` — step 3 of *Clearing a card that does not belong* (`:350`), the one
  line on the page that says `asf index` (PD1)
- `tests/test_readme.py` — `HandEditIndexProseTests`, a new class, after `ModelRoutingProseTests`

**Steps**

1. Replace `operating.md:350` with the spec's §2 text, byte for byte:

   > 3. Commit and push the card. The record's pre-commit derives `index.json` from what you staged
   >    and sweeps it into the commit — there is no separate `asf index` step. (In a checkout whose
   >    hooks are not enabled, run `asf index` first and commit both files.)

   Steps 1 and 2 above it are untouched, and so is every other line on the page. The parenthesis is
   not padding: `asf init` enables the hook per record checkout with `core.hooksPath .githooks`
   (`asf/init.py:112`, `:255`), so a checkout that never ran it has no hook and does still need the
   command. A page that claimed the index is always derived would be false there, which is the
   choices table's ruling against deleting the step outright.
2. `HandEditIndexProseTests(unittest.TestCase)` in `tests/test_readme.py`, with a class docstring
   naming `F-0146` and the Story, in the idiom of `ProductResolutionProseTests` (`:482-504`): a
   `_read(self, path)` that opens `os.path.join(REPO_ROOT, path)` — copied from `:486-488`, which is
   all that class carries (PD5a).
3. Its own `_section(self, text, heading)`, **not** the one at `:515-519`. Same first line —
   `start = next(i for i, l in enumerate(lines) if l.strip() == heading)` — and a terminator that
   ends on the next heading of any level:

   ```python
           end = next(i for i in range(start + 1, len(lines)) if lines[i].startswith('#'))
   ```

   with a comment saying why it differs from its two siblings: they slice a `###` subsection of
   `product-config.md`, this slices a `##` section of `operating.md`, and `startswith('###')` here
   runs past three unrelated sections to `:405` (PD5b). Return `lines[start + 1:end]`, as they do —
   the heading line itself is outside the slice, which is fine: every string asserted below is in
   the body.
4. The test, the spec's A3 fence byte for byte:

   ```python
       def test_clearing_a_card_does_not_order_asf_index(self):
           section = '\n'.join(self._section(self._read('docs/guide/operating.md'),
                                            '## Clearing a card that does not belong'))
           self.assertNotIn('Run `asf index` in the checkout', section)
           self.assertIn('pre-commit', section)
           self.assertIn('index.json', section)   # the file is still named, as the fallback
   ```

   The heading string is exact (`operating.md:342`, PD1). The three assertions are the three things
   the ruling has to hold at once: the order is gone, the hook is named, and the file is still named
   for the fallback. PD6 measured that the second one fails today, so the test earns its place.
5. Nothing else in `tests/test_readme.py`, and no other guide page. `README.md` does not carry this
   procedure; `asf index` on `operating.md` occurs only at `:350` (PD1), so there is no second site
   to keep in step.
