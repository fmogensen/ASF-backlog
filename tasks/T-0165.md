## Description
stories: S-16200
writes: asf/conventions.py, asf/briefs/build.py, tests/test_conventions.py, tests/test_briefs.py
after: none

§2.1. `HEAVY`, `LIGHT` and `DEFAULT_MODELS` move out of `asf/briefs/build.py` into
`asf/conventions.py`, where every other documented default lives; `models` and `heavy_share_pct`
become typed fields. `briefs.build` imports them and keeps no copy. Nothing resolves differently
yet — `model_for` still takes a kind — so this Task is the surface the other six stand on.

**Files**

- `asf/conventions.py` — `HEAVY`, `LIGHT`, `DEFAULT_MODELS` (§2.1's fence, thirteen need keys
  including `correct/judgement`), `DEFAULT_HEAVY_SHARE_PCT = 50`; the fields
  `models: dict = field(default_factory=lambda: dict(DEFAULT_MODELS))` and
  `heavy_share_pct: int = DEFAULT_HEAVY_SHARE_PCT` (`asf/conventions.py:129-167`); the module
  docstring's yaml example gains the `models:` block of §4.
- `asf/briefs/build.py` — `HEAVY`, `LIGHT` and `DEFAULT_MODELS` deleted (`:40-41`, `:47-49`) and
  re-exported from `asf.conventions` so `from asf.briefs.build import HEAVY` keeps working;
  `model_for` (`:150-153`) reads the same table through the same `.get('models')`.
- `tests/test_conventions.py` — `DefaultsTests` gains the two defaults;
  `FromMappingTests` gains the partial-table case; `ForbiddenPatternsTests` is unchanged and is
  the regression net for P13.
- `tests/test_briefs.py` — `KindModelGrantTest` (`:432`) extended per §3.1's first two clauses.

**Steps**

1. In `asf/conventions.py`, beside the other documented defaults: `HEAVY = 'heavy'`,
   `LIGHT = 'light'` with §2.1's comment (the operator's two labels; `worker_pool.models` maps
   them to ids in `asf.workers.spawn.model_arg`, so no vendor id is written down here);
   `DEFAULT_MODELS` exactly as §2.1 fences it, with the comment saying a need key is a brief kind
   or `<kind>/<refinement>`; `DEFAULT_HEAVY_SHARE_PCT = 50` with §2.7's sentence about what the
   share is of.
2. The two fields on `Conventions`, in the dataclass's order beside `stage_limits`. `models` uses
   `default_factory` so two instances do not share it — `tests/test_conventions.py:38` already
   asserts that shape for `branch_prefixes` and `stage_limits` and gains `models`.
3. `from_mapping` is **not** touched: a dict field is taken as the yaml wrote it, and the per-key
   fallback lives in the resolver (P12). The docstring of `from_mapping` gains `models` beside
   `branch_prefixes` in the sentence that already explains this.
4. `asf/briefs/build.py` imports `DEFAULT_MODELS`, `HEAVY`, `LIGHT` from `asf.conventions` and
   deletes its own definitions. The names stay module attributes of `build` (the import is the
   re-export), so `asf/briefs/__init__.py:15` and every existing caller are unchanged.
   `model_for(product, kind)` keeps its signature and its body; only where the table comes from
   moves.
5. The module docstring of `asf/conventions.py` gains the `models:` and `heavy_share_pct:` lines
   of §4 in its yaml example, so the one place a product reads what it may set shows them.
6. `tests/test_conventions.py`: `test_every_documented_default_is_what_the_card_says` asserts
   `c.models == DEFAULT_MODELS` and `c.heavy_share_pct == 50`; a new case asserts a product
   writing `models: {correct: heavy}` gets exactly that one key (not a merge) and that
   `heavy_share_pct: 30` overrides; `test_two_instances_do_not_share_their_mutable_defaults`
   gains `a.models['spec'] = 'light'` and asserts `b.models['spec'] == 'heavy'`;
   `test_one_pattern_per_path_shaped_default` keeps its `len(patterns) == 9` untouched (P13).
7. `tests/test_briefs.py`: `KindModelGrantTest` asserts every kind of `briefs.build.KINDS` resolves
   to its documented label, that `correct/judgement` is in the table and heavy, that a product
   overriding one key leaves the other twelve at their defaults, and that `build.HEAVY` is
   `conventions.HEAVY` — one object, one owner.
