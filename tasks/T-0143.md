## Description
stories: S-18152
writes: asf/ci.py, asf/cli.py, tests/test_cli.py
after: Task 1, Task 2

§2.3. The command CI calls, and the only place in this card that touches git. It writes `asf/ci.py`
again (PD7), so it queues behind Task 1 — which it waits for anyway.

**Files**

- `asf/ci.py` — under a `# ---- the command ----` rule: `changed_paths(base, head, cwd)`,
  `cmd_class(args)`, `register(sub)`.
- `asf/cli.py` — `from asf import ci` then `ci.register(sub)` beside `plugin_build.register(sub)`
  (`:180-181`); no arm in `_main`, because `set_defaults(run=…)` is already dispatched (`:384`).
- `tests/test_cli.py` — `CiClassTests`, over a temporary git repository.

**Steps**

1. `register(sub)`: `sub.add_parser('ci', help=…)` with a nested `class` action, the
   `plugin_build.register` shape (`asf/plugin_build.py:163-168`) — a group with room for the next
   question CI asks the factory, per §2.3. Flags: `--product`, `--base`, `--head`,
   `--paths-from`, `--globs-from`, `--json`. `set_defaults(run=cmd_class)`.
2. `changed_paths`: `git diff --name-only <base>..<head>`, or `<base>...<head>` when `--base`
   ends in `...` (D10 — the workflow passes the range it wants, the command does not guess the
   event). A base of forty zeros, an empty base, or a ref that does not resolve: no paths, a
   reason on stderr, and therefore `FULL` (D5) — never a traceback and never exit non-zero.
3. Paths: `--paths-from` wins (a file, or `-` for stdin, one path per line, blanks dropped) and
   git is not invoked at all in that case. Otherwise `changed_paths`.
4. Globs: `--globs-from` wins (a file, or `-`), which is how the runner passes the workflow's copy
   with no operator home. Otherwise the resolved product's `Product.factory_only_paths` (Task 2).
5. Output: the class alone on stdout, one line; the reason always on stderr, §2.3's shape —
   how many paths changed, how many matched, and the paths, with `unmatched` named when the class
   is `FULL`. `--json` puts §2.3's object on stdout instead and nothing else.
6. Exit `0` for either class (D12). Exit `2` only for a bad invocation or an unreadable
   repository, which is the `ConfigError` path `asf/cli.py:257-262` already owns — the command
   raises `env.ConfigError`, it does not print its own operator line.
7. `CiClassTests` per §3.3, over a temporary git repository built with the suite's own fixture
   helpers: a two-point range of documents only → `FACTORY_ONLY`, exit 0; the same range with one
   `asf/` file → `FULL`, exit 0; `--paths-from -` reading stdin with no git call; `--globs-from`
   beating the product's configuration; forty zeros → `FULL` with the reason on stderr; an
   unresolvable base → `FULL`, no traceback; `--json` carrying `class`, `paths`, `unmatched`,
   `globs`, `base` and `head`.
