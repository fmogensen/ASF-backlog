**Files**

asf/logs.py, asf/cli.py, asf/scheduler.py, asf/kernel/host.py, tests/test_logs_tree.py

**Steps**

1. `asf/logs.py` gains `OWN_LOG_VAR = 'ASF_LOG'`, `CARRY` — the seven substrings of §1, each with
   the reader named beside it in a comment — and `_STAMP_RE`, all three as the spec writes them.
2. The same `rotate` grows its `carry=()` parameter: with it, the rotated file's matching lines,
   each preceded by the last ISO stamp line seen before it, are written as the head of the fresh
   live file. Still one function, still never raising; a carried head is itself carried by the
   next rotation.
3. `claim_own()` **pops** `OWN_LOG_VAR` from the environment and keeps the path for this process
   only; `own_path()` returns what it took, or `None`; `rotate_own()` is
   `rotate(own_path(), CLOCK_LOG_MAX_BYTES, carry=CARRY)`, and `None` when nothing was claimed or
   the path is not a regular file.
4. `asf/cli.py`: two calls around the dispatch, in `main` (`:790-805`) — `logs.claim_own()` as the
   first act, before `_main(argv)`, and `logs.rotate_own()` in the existing `finally`, after
   `finish()` flushes, so the run's last line is inside the generation the rename moves. That
   covers every clock command by construction: the product tick (`asf/tick/tick.py:424`), the host
   probe (`asf/tick/network.py:415`) and the kernel's tick and watch all enter here, and a
   hand-run command has no variable to claim and rotates nothing.
5. The scheduler writes the variable where each job's `env_vars` is built —
   `env_vars[logs.OWN_LOG_VAR] = log` in `render` (`asf/scheduler.py:654-655` and `:658`, with
   `log` already in hand at `:646`), in `render_host` (`:728-731`), and in
   `asf/kernel/host.py:84-93` for the two kernel jobs. No connector is touched (`K5`). The
   variable is unlisted in the worker environment, so no session inherits it
   (`asf/hermetic.py:65-67`).
6. `scheduler.smoke` strips it: `job_env.pop(logs.OWN_LOG_VAR, None)` immediately after
   `asf/scheduler.py:866` and **before** the dedupe `key` at `:868`. The pop of step 3 cannot
   reach the smoke — it hands its children `env=job_env` (`:889`), rebuilt from each plist rather
   than from the environment it has — and the smoke runs in-process inside a clock run
   (`asf/tick/tick.py:564` → `asf/upgrade.py:1709`) on a no-op derived from that clock's own plist
   (`noop_command`, `:821-835`). Stripping before the key also keeps two clocks of one product
   whose plists differ only in the transcript path collapsing to one probe, as they do today.
7. `tests/test_logs_tree.py` gains `ClockRotateTests`, `CarryTests` and `SmokeEnvTests` — one case
   per acceptance line of `S-134156`, over a temporary `ASF_HOME` and temporary plists, never the
   operator's home. `ClockRotateTests` takes the rotation and the claim, down to the lines about
   in-place truncation and about what the scheduler writes into each clock's environment;
   `CarryTests` the carry set, with the assertion that every pattern `asf/release.py:99-103` and
   `asf/scorecard/program.py:52` match is still matched by a marker; `SmokeEnvTests` the strip.
