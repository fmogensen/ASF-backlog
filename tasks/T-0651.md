The spec's `## The design` §1 in full, and nothing else. After this lands, an operator can write and
lift a durable, readable, atomically written launch pause for one product, and one function —
`pause.held(product)` — answers *are this product's launches held* from anywhere in the tree with no
import cycle. **Nothing asks it yet:** the tick is untouched, the wave still launches, the status
table says nothing. Tasks 2 and 3 are its only callers.

Read **PD4 first.** `held` is four lines and one of them decides whether three shipped tick suites
keep passing on a coder's own paused machine — resolve the name with `getattr`, never with
`isinstance(product, env.Product)`, and never fall back to a default product. Read **PD15** before
`pause_path`: `env.state_dir` creates the directory it returns, and this path is read once per wave
row. Read **PD9** for the CLI wiring (`set_defaults(run=…)`, so `cli._main` is not touched), **PD8**
for the product resolution, and **PD19** for why the in-flight count lives in `cmd_pause` and not in
`pause()`.

**Files**

- `asf/pause.py` — new. The module docstring the spec prints verbatim (`docs/specs/f-0137.md:117-128`),
  including its last paragraph distinguishing this pause from `asf.scheduler.pause`; top-level
  imports `datetime`, `json`, `os` and `from asf import env`, and nothing else (C2, PD19);
  `PAUSE_FILE = 'paused-launches.json'`; `pause_path`, `read`, `held`, `text`, `hold_reason`,
  `pause`, `resume`; `register(subparsers)`, `cmd_pause(args)`, `cmd_resume(args)`.
- `asf/cli.py` — two lines in `build_parser`'s register block (`:278-298`), beside
  `register_scheduler`: `from asf.pause import register as register_pause` / `register_pause(sub)`.
  `_main` is **not** touched (PD9).
- `tests/test_pause.py` — new. `TheRecord` and `TheCommands`, plain `unittest.TestCase`, each
  patching `env.ASF_HOME` to a `tempfile.mkdtemp` in `setUp` and restoring it in `tearDown` (PD14).

**Steps**

1. `asf/pause.py` with the spec's module docstring and `PAUSE_FILE = 'paused-launches.json'`.
2. `pause_path(product_name)` → `os.path.join(env.ASF_HOME, 'state', product_name, PAUSE_FILE)`,
   copied from `scheduler.pause_path` (`asf/scheduler.py:519-520`) — **not** `env.state_dir` (PD15).
3. `read(product_name)` → the record dict or `None`: `json.load` inside
   `except (OSError, ValueError): return None`, plus `return None` for a payload that is not a
   `dict` (PD16). The docstring's safety clause is the spec's: a pause nobody can read must never be
   able to stop the floor silently.
4. `held(product)` → `read` for a `Product`, a name or a stand-in, per **PD4**:
   `name = getattr(product, 'name', None) or (product if isinstance(product, str) else None)`, then
   `None if name is None else read(name)`. Never raises; never invents a default product.
5. `text(record)` → `paused since <at> (<reason>; by <who>)` — the sentence shape of
   `scheduler.pause_text` (`:566-568`), with its same `or '?'` / `or 'no reason'` fallbacks so an
   incomplete record still renders.
6. `hold_reason(record)` → `launches paused: <reason> (by <who>, since <at>)`. This is the string the
   wave, the rehearsal and Task 2's `waits` lines all print; it is defined once, here.
7. `pause(product_name, reason, by, now=None)` → the lines to print. `at` per **PD17**;
   `os.makedirs(os.path.dirname(path), exist_ok=True)`; `json.dump(rec, f, indent=2, sort_keys=True)`
   to `path + '.tmp'` with a trailing newline, then `os.replace` (PD16). Overwrites an existing
   pause rather than refusing — a new reason replaces the old one and `at` moves.
8. `resume(product_name)` → the lines to print; `if os.path.exists(path): os.remove(path)`, and
   resuming what is not paused is rc 0 with a line, not an error (C7, PD16).
