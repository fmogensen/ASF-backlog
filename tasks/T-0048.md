## Description
stories: S-8154
writes: asf/workers/pool.py, asf/workers/wave.py, tests/test_session_identity.py, tests/test_workers.py

Depends on T-9450 (`live_all`) and T-9451 (`observe.read`).

**Files**

- `asf/workers/pool.py`: `Pool.from_config`, `Pool.take`, `Pool.unreadable`; the module and
  class docstrings.
- `asf/workers/wave.py`: the running set and the D10 line; the module docstring.
- `tests/test_workers.py`: `Home.cfg` gains `'sessions': 'fake'` (D6). No assertion changes.
- `tests/test_session_identity.py`: `PoolAcrossProductsTest`.

**Steps**

1. `Pool.__init__` gains `unreadable=''` and stores it. A hand-built pool is readable.
2. `Pool.from_config(cfg, product, quota_source=None, session_source=None)`: `registered =
   lifecycle.live_all(os.path.join(env.ASF_HOME, 'state'))`, `observed, why =
   observe.read(cfg, accounts, source=session_source)`, then `extra` and `live` exactly as the spec.
   The dedupe keys are `{r['pid'] for r in registered}` and `{r.get('session') for r in registered} -
   {None}`. An observed session is extra only when its `account` is not None and it is in neither
   set. Every other constructor argument stays as it is. Keep the `guards=` line as the file has
   it when this Task starts (D13).
3. `Pool.take(account, model, job='', product=None)` records `product`. `load`, `under_caps`,
   `lane_load` and `pick_account` do not change, and an extra's `model: None` falls out of per-model
   caps as the spec says.
4. `wave`: `running = {(s.get('product') or product.name, s.get('job')) for s in pool.live}` (D5).
   A row waits `already running` when `(product.name, row.job)` is in it. After a launch, the pair
   is added and `pool.take(..., product=product.name)` is called. When `getattr(pool, 'unreadable', '')`
   is set, `out(f'pool: sessions unreadable ({why}) — counting registered sessions only')` runs once,
   before the loop.
5. `tests/test_workers.py` `Home.cfg['worker_pool']['sessions'] = 'fake'` (D6).
6. `PoolAcrossProductsTest` as below. A second product's registry is written with
   `pool_mod.append_session(env.Product('b', …), …)` under the same temp `ASF_HOME`.

**Acceptance**

- `PoolAcrossProductsTest(Home)`
  - `test_other_products_sessions_count`: acct-a `cap: 2`, product `b`'s registry has one live
    run on acct-a, the fake source shows it → `Pool.from_config(cfg, product_a).load(acct_a) == 1`.
  - `test_foreign_session_counts`: no registry runs, the fake source shows one foreign session on
    acct-a (`cap: 1`) → `pick_account` returns `(None, 'pool full')`.
  - `test_no_double_count`: a registered run and its observed process (same pid and id) → load 1.
  - `test_just_launched_counts_before_ps_sees_it`: a registered live run whose pid the source
    does not show → load 1.
  - `test_same_job_name_in_two_products`: product `b` has a live `spec-f-0001` → product `a`'s
    wave launches its own `spec-f-0001` (no `already running`).
  - `test_unreadable_prints_and_counts_registry`: source raises → the wave output has `pool:
    sessions unreadable`, and load equals the registered runs across products.
