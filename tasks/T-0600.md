The spec's `## The design` §§2 and 3 — `lifecycle.RESERVED` joining `MECHANICAL`, the snapshot
written once per pass, the clash taken as `f['refusal']`, and `land_spec.adopt` declining a
clashing carrier. This is the half that acts: from here a plan that books a held number is held
with the holder named, routed to a `correct` session, and its approved document is not landed
while it clashes.

Nothing renumbers. The hold asks a session to re-book and the factory rewrites no file (spec
`## Out`). And nothing here decides: every predicate is `asf.reservations`' (C1).

Read **PD7** before touching `lane.py` — the spec's §2 builds the map in `lane_pass` from
`lane.remote_heads()` and `lane.host.prs()`, which are already made exactly once inside
`Lane.gather`, and a second call is a second `gh pr list` per tick *and* a `{}` pr map in the gate
pass that would overwrite the good snapshot with a rankless one. Read **PD13** for the checks.
