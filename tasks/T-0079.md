## Description
stories: S-15609
writes: asf/metrics/metrics.py, tests/test_metrics.py

§2.7. The card's target is a number nobody can read today. One scorecard row, off streams that
already carry every field it needs.

**Files**

- `asf/metrics/metrics.py` — `ADJUDICATION_TARGET_PCT`, `heavy_model(conv=None)`, `is_heavy`, and
  one `adjudication` row appended in `scorecard_rows` after the `agents` row.
- `tests/test_metrics.py` — `AdjudicationShareTests`.

**Steps**

1. `ADJUDICATION_TARGET_PCT = 10` — the card's number, named once.
2. `heavy_model(conv=None)` per P6: `conv.get('heavy_model')` if set, else `env.load_config()`'s
   `worker_pool.models.heavy`, else `None`; lowercased; a `ConfigError` is caught and read as
   `None`. `is_heavy(s, heavy)` is `heavy is None or heavy in (s.get('model') or '').lower()`, so
   an unresolvable config counts every model rather than nothing.
3. In `scorecard_rows`, after the `agents` row: `adj` = the minutes of the window's sessions whose
   `kind == 'adjudicate'`, `hvy` = the minutes of its heavy-model sessions, `n_runs` the adjudicate
   count. `_pct` already floors on `max(1, b)`, so no heavy session is `0 %` and never a division
   by zero.
4. `n_triaged` — the `triage` events in the same window (Task 6 writes them). `scorecard_rows`
   takes them where the other streams arrive; a caller with no events passes none and the note
   reads `0 ruled out cheaply`. The row is informational: nothing fails on a miss (D13).
5. The row's shape is §2.7's: `('adjudication', f"{adj/60:.1f} h of {hvy/60:.1f} heavy-model h
   ({_pct(adj, hvy)} %)", f"target < {ADJUDICATION_TARGET_PCT} % — {n_runs} runs, {n_triaged} ruled
   out cheaply")`. `render_daily:501` prints it with the rest; no renderer change.
6. Tests: a 7-day `sessions` fixture with adjudicate and other heavy-model sessions → one
   `adjudication` row whose percentage is `adjudicate minutes / heavy minutes`, naming the target
   and the prevented count; no heavy session → `0 %` and no exception; no `worker_pool.models` →
   every model counts (the row is still emitted).
