`scorecard_rows` (`asf/metrics/metrics.py:405`) is untouched: F-0028 owns the daily row, this Task
owns the fact it will read.

**Steps**

1. **The schema** — `'in_tokens': (('int', 'null'), None)` and `'turns': (('int', 'null'), None)`
   in `SCHEMAS['sessions']`. `validate` rejects unknown keys and fills declared ones from a default
   (`asf/metrics/metrics.py:119-125`), so both are additive: an old line re-read still validates
   with `None` in each.
2. **`in_tokens(result)`** — the sum of `usage.input_tokens`, `usage.cache_creation_input_tokens`
   and `usage.cache_read_input_tokens` that are present as numbers; `None` when none is. Cached
   input is re-sent input — counting only the uncached part would report a win the moment the cache
   warms and hide exactly the growth this card exists to stop.
3. **`session_event` fills both** — `in_tokens` from the helper, `turns` from the result's
   `num_turns` when it is an `int`. Both come off the same result record `total_cost_usd` and
   `duration_ms` already come from (`asf/metrics/metrics.py:892-906`), so no new bookkeeping and
   nothing new asked of the runtime's log format.
4. **The before reading comes free.** `cmd_backfill` (`asf/metrics/metrics.py:1044`) re-derives the
   `sessions` stream from the registry and its logs, so once `session_event` reads `usage`, every
   past session whose log still exists is backfilled. No baseline number is typed into a document;
   a number in a document is not evidence.
5. Run the gate, commit with `git commit -s`, push.
