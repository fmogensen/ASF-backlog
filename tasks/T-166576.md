**Files**

asf/kernel/decide.py, asf/kernel/loop.py, tests/kernel/test_beat_decide.py

**Steps**

1. `asf/kernel/decide.py`: `beat_stalls(facts, config)` → `[(session, why)]` — every live session
   whose verdict is `frozen`, `looping` or `no-first-beat`, with the reason as the text §2.4's
   table gives it, and every `alive` one past `config.heartbeat_max_age` (the ceiling), whose
   reason names the ceiling.
2. `judged_by_beat(s, config)` → whether `s`'s age is no longer its judge: a verdict of `alive`,
   `frozen`, `looping` or `no-first-beat`. An `unknown` verdict and a session launched without a
   beat are judged by `session_bound` exactly as before.
3. `_over_age` gains one line — `if judged_by_beat(s, config): continue` — and nothing else.
   `session_bound` and the p90 measurement keep their meaning.
4. The session block at `:433-437` appends `beat_stalls`' `EndSession` actions (`free_worktree=False`)
   before the `_over_age` ones, and `breaches` records the verdict for every live session past its
   old bound, so the tick line says why a session the old rule would have ended still runs.
5. Both new functions are pure: no clock of their own, no port, no file. `decide`'s contract
   ("same arguments, same plan") is asserted, not assumed.
6. `asf/kernel/loop.py`: `save_plan`'s per-session dict gains `beat`, `quiet_min` and `beats`,
   and the top-level data gains `beats_unread`; the breach rows it already writes carry the
   verdict. The `EndSession` reason reaches the ledger as the row's `end_reason` through the path
   that already writes it.
7. Create `tests/kernel/test_beat_decide.py` with one case per acceptance line, over facts built
   with `tests/kernel/builders.py` — including the landed over-age cases re-asserted for an
   `unknown` verdict and for a session launched without a beat, so the fallback is pinned by the
   same module that changes it.
