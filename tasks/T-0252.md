## Description
stories: S-29402
writes: asf/doctor.py, tests/test_doctor.py
after: Task 3

§2.6 and D8. `asf/roles/roles.py:23` has promised "a red gate and a red doctor row" since it was
written, and `grep -rn 'roles.validate' asf/` finds no caller: the nine refusals are run by
`tests/test_roles.py` and by no shipped code path. This Task is the missing half — not a new
surface, and not `plugin/agents/` (§1.3).

**Files**

- `asf/doctor.py` — `check_roles()`, and its row beside `briefs` (`:844`)
- `tests/test_doctor.py` — `RolesRowTests`

**Steps**

1. `check_roles()` with §2.6's docstring copied byte for byte. It loads `roles.load_all()`,
   runs `roles.validate` over each, and returns `(True, f'{n} roles, {k} kinds bound')` when
   every role passes — `n` from `load_all()`, `k` from `len(roles.BINDINGS)`, neither retyped —
   or `(False, '<role>: <problem>; …')` naming each failing role and its refusal.
2. A role directory that will not even parse is a red row with the parse error as its detail, not
   an exception out of `asf doctor`: the row exists to be red, and a traceback is not a row.
3. Register it as `rows.append(('roles', True, ok, detail))` beside the `briefs` row. It takes no
   product and no host, so it sits with the other product-less rows and is `required=True` — an
   invalid role reaches every session of its kind, which is why it is not a `skip`.
4. `RolesRowTests`, §3.7: over the shipped `asf/roles/`, `check_roles()` is `(True, '12 roles,
   16 kinds bound')` with both counts read from `roles.load_all()` and `roles.BINDINGS`; over a
   temp role dir holding one file that breaks each of the nine refusals in turn — the cases
   `tests/test_roles.py` already scripts, reused rather than rewritten — the row is `(False, …)`
   and names the role and the refusal; `asf doctor` against that dir is RED and exits 1, and
   against the shipped dir the row is `ok`; and the row appears for a product whose config does
   not parse, which is what `required=True` and "takes no product" mean together.

**Gate**

```sh
python3 -m unittest -v tests.test_doctor tests.test_roles tests.test_briefs
python3 tools/run_tests.py 2>&1 | tail -3
bash tools/check_generic.sh && bash tools/check_conventions.sh && python3 -m asf.cli plugin check
```

**Acceptance**

```bash
python3 -m unittest -v tests.test_doctor.RolesRowTests tests.test_roles
```
