## Description
stories: S-15603
writes: asf/harvest/harvest.py, tests/test_harvest.py

§2.4, on Task 2's `hold(..., files=…)`. B-0082 put the "not this item's fault" test at the source
for a timed-out gate; this is the same shape for a red that names files the item never touched.

**Files**

- `asf/harvest/harvest.py` — `PATH_RE`, `DOTTED_RE`, `gate_files(text, cap=20)`; `product_gate` and
  `run_gate` return `(ok, line, files)`; `hold_with_correction` takes `files=()` and
  `item_writes=()` and returns `'foreign'` per D8; `land_ff` and `land_combined` pass both through.
- `tests/test_harvest.py` — `GateFilesTests`, `ForeignRedTests`.

**Steps**

1. `gate_files(text, cap=20)`: every repo-relative path-like token matched by `PATH_RE`
   (`.py|.md|.ts|.tsx|.js|.jsx|.sh|.ya?ml|.json|.toml`), plus each `DOTTED_RE` unittest id mapped
   to its module file (`tests.test_feeder.X` → `tests/test_feeder.py`), de-duplicated, first-seen
   order, capped at 20. No failure classification and no owner guessing — the In/Out table.
2. `product_gate(tmp, conv, asf_repo)` → `(ok, line, files)`: on red, `line` is
   `first_failing_line(out + '\n' + err)` as today and `files` is `gate_files` of that same whole
   output (P8). On a timeout, the timed-out line and `[]`. On green, `(True, None, [])`.
   `run_gate(tmp, conv=None)` likewise. Both keep `(ok, line)` as the first two values, so a caller
   that unpacks two is the one breakage the suite catches at once — update every caller in this
   package (`land_ff:886`, `gate_groups:940`, `harvest_branch:490`).
3. `hold_with_correction(state_dir, branch, record, kind, text, out, files=(), item_writes=())`:
   the B-0082 timed-out branch stays first and unchanged; then D8 —
   `if kind == 'gate' and files and item_writes and footprint.overlaps(item_writes, files) is None:`
   print `foreign {branch}: gate red outside its writes: {files[0]} — re-gated next tick` and
   return `'foreign'` before any correction is written or any round is bumped. Otherwise
   `lifecycle.hold(..., files=files)` as today.
4. `land_ff` passes the gate's `files` and `item_writes` — it already has the item id, and takes
   the footprint from the caller's index as a new keyword defaulting to `()`.
5. `land_combined(..., items=None)` and its `hold` closure resolve the footprint per P7;
   `run_product_harvest` passes the `items` it already loaded. No index: `item_writes` is empty and
   the branch is held exactly as today (D9).
6. Tests: `GateFilesTests` — a real unittest failure block yields the module paths it names with
   dotted ids resolved, de-duplicated and capped; `FAILED (failures=1)` alone yields `[]`.
   `ForeignRedTests` — a gate red whose files miss the item's `writes:` returns `'foreign'`,
   appends no correction, bumps no round and prints the `foreign <branch>:` line; an overlapping
   file holds as today; no `writes:` or no `files` holds as today.
