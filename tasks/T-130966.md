- [ ] the move pattern matches a kernel tick process argv

- [ ] the move pattern still matches a 0.1 tick, a ci queue pass, a wave run and a background harvest
- [ ] the move pattern matches a kernel tick run through the suffixed dispatcher entry point

- [ ] a running kernel tick of another product is not this product's busy line

- [ ] a missing kernel lock file is no busy line
