## Description
stories: S-29050, S-29051

after: none

The two pure pieces of §2.1 and §2.2: the four numbers in one place, and the one module that
owns both verdicts — what an item may spend against what its card says it has spent, and what one
run may take against what it has taken. No clock it is not handed, no io, no git. Every later
Task imports this one and adds no copy of a default.

**Files**

- `asf/conventions.py` — `DEFAULT_BUDGET`, the `Conventions.budget` field, `'budget'` in
  `MAP_CONVENTIONS`, `budget_for(conv, key)` beside `savings_for` (`asf/conventions.py:792`), and
  the `conventions:` block in the module docstring's example.
- `asf/budget.py` — new. The module docstring §2.2 fences, the four constants, `Budget`, `Spent`,
  `of`, `spent`, `line`, `run_caps`, `run_over`, `run_cap_text`, `run_cap_result`.
- `tests/test_conventions.py` — `BudgetConventionTests` (T1), including the one-place grep (P8).
- `tests/test_budget.py` — new: `ItemBudgetTests` (T2) and `RunCapTests`' pure half (T7's first
  five sentences). Task 4 extends the same class with the wired half (P4).

**Steps**

1. `DEFAULT_BUDGET = {'sessions': 3, 'usd': 10, 'run_minutes': 180, 'run_turns': 600}` with §2.1's
   comment verbatim, beside `DEFAULT_SAVINGS`; `budget: dict = field(default_factory=lambda:
   dict(DEFAULT_BUDGET))` on `Conventions`; `'budget'` appended to `MAP_CONVENTIONS` so a
   misshapen block is a red doctor row and never a silent default (P7).
2. `budget_for(conv, key)` — one line, `savings_for`'s body: the product's own entry when it named
   one, else `DEFAULT_BUDGET`'s. Every other module in this plan reads the four numbers through it
   and holds no copy.
3. The module docstring's `conventions:` example gains §2.1's yaml block, comments included.
4. `asf/budget.py`: the docstring §2.2 fences, then `SESSIONS, USD, MINUTES, TURNS`, `OFF`,
   `RUN_CAP`, `OVER`.
5. `Budget` and `Spent` as fenced — frozen dataclasses, `Spent.over` the `bool(self.measure)`
   property. `source` is whichever of `default` / `product` / `item` set the **lowest** measure,
   for the groom line to name.
6. `of(conv, item)`: `budget_for` for each of `sessions` and `usd`, then the card's own
   `budget_sessions:` / `budget_usd:` over it, each independently; `off` on either is `None` (no
   limit). An item whose `type` is `epic` gets a bare `Budget()` whatever its `budget_usd` — that
   number is the subtree figure the rollup reports (F-0101), not a stop.
7. `spent(conv, item)`: `cost.sessions` and `cost.usd` off the item's machine block against
   `of()`. `sessions` is judged before `usd`, and `>=` is over — the third session is the last one
   the budget buys. A `None` on either side of a comparison is never over: no `cost:` block is
   nothing spent, and `cost.usd: None` (no log carried a cost) is an unmeasured dollar, not a
   spent one.
8. `line(item_id, s)` — `OVER BUDGET T-0021 — 9/3 sessions, $13.53/$10`, both measures always,
   `—` in place of a cap that is off. One format, no branch (§1.4).
9. `run_caps(conv)` → `(minutes, turns)`, each an int or `None` for `off`. `run_over(elapsed_min,
   turns, caps)` → `(measure, value, limit)` for the first cap exceeded, the wall clock before the
   turns, else `None`; a `None` on either side of a comparison is never over, so a run whose
   `started` the ledger lost is judged on its turns alone.
10. `run_cap_text` and `run_cap_result` exactly as §2.2 fences them — no `duration_ms`, no
    `total_cost_usd`: nothing was measured.
11. `tests/test_conventions.BudgetConventionTests`: the four defaults; `from_mapping({'budget':

    `budget_for` still reading the defaults (P7); `'budget' in MAP_CONVENTIONS`; and the grep case
