## Description
stories: S-81207
writes: asf/channels.py, asf/state/registry.py, tests/test_channels.py
after: Task 1

The spec's **In** 5 and the log half of design §1 (D-0005, D-0011; P17). `state/<product>/channels.json`
is where the 48-hour dwell and the weekly cadence are both measured from, so it lands before the
two rules that read it rather than beside them. A tag's own creation date is never the dwell: a
tag is cut before its suite finishes (P1), and a tag that was never published to edge has no time
on edge at all.

**Read this Task from `docs/plans/f-0308.md`, not from this card** — the record cuts a Task card's
description at 4000 characters and this section is longer, so the card stops before the Acceptance.

**PD9** binds this Task: `tests/test_channels.py` already carries Task 1's `ResolveTest` and the
`tagged_remote` fixture — add to it, and run it whole.

**Files**

- `asf/channels.py` — the log half: `LOG_NAME = 'channels.json'`; `read_log(product)` through
  `asf.state.store.read` (`:251`) with an absent file reading as *no channel published yet* — the
  cold start of D-0005, and the shape every later reader must accept; `write_log` through
  `store.update` (`:371`), read-modify-write under the file's own lock; `note_edge(log, tag,
  commit, at)` setting `log['edge']` and **prepending** one `edge_log` entry, newest first, then
  trimming to `settings['log_keep']`; `note_stable(log, tag, commit, at, rows)` setting
  `log['stable']` with its `promoted_for` list of the row keys it was promoted for. A log the
  store cannot parse is **not** written over: the reader returns the corruption as a detail and
  the caller publishes nothing this run.
- `asf/state/registry.py` — one line, `'channels.json': _s('asf.channels'),`, in the
  *"the clock, installs and upgrades"* group beside `'install.json'` (`:109`). No `ttl_days`: the
  dwell window is read from this file, so the reaper must never age it out.
- `tests/test_channels.py` — `LogTest`, one case per checkbox line of S-81207, and a `log(**rows)`
  helper that builds a log at whatever ages a case needs against a frozen `now`. The registry
  claim is asserted here too, not only in the fence: `registry.spec('channels.json')` with owner
  `asf.channels` and `ttl_days is None`.

**Steps**

1. The registry line first, and the fence's own `python3 -c` check — the store refuses a name it
   does not hold, so nothing else can be tested until the name is registered.
2. `read_log` and the absent-file case; then `note_edge` and the trim at `log_keep`.
3. `note_stable` with `promoted_for`.
4. The corrupt-log case: assert the file on disk is unchanged after the run, not only that the
   call returned a detail.
5. The Gate, in the foreground.

**Gate**

bash tools/check_generic.sh && bash tools/check_conventions.sh
