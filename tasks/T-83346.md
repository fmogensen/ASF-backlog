The feeder reads one new kwarg and tests membership in it — no review, no card, no path, nothing
the feeder's own rule forbids (`asf/feeder/rows.py:8`: "No git, no gh, no filesystem"). Two
branches grow one arm each, one constant is minted, and one word joins the S1 lane's "being
worked" set so a waived S1 does not read as abandoned (**PD12**). `asf/workers/lifecycle.py` is
not touched: `corrections()` reads exactly as it reads today (P19, Out).

**Files**

- `asf/feeder/rows.py` —

    (**PD12**).
  - `correction_rows(items, product, busy, corrections, waived=None)` — the fourth argument, and
    one arm in the `same >= rounds_cap` block (`:1047-1060`), directly after the `c.get('settled')`
    arm and before the STALEMATE one.
  - `_one_feature_rows(items, product, f, busy, running, landed_shas, occupancy, waived=None)` —
    one more condition on the `rnd >= limit` test (`:1506`), per **PD13**.
  - `feature_rows(items, product, busy, running, landed_shas=None, occupancy=None, waived=None)` —
    threads it to both `_one_feature_rows` call sites (`:1477`, `:1479`).
  - `candidates(…, waived=None)` and `plan_rows(…, waived=None)` — one kwarg each, threaded to
    `correction_rows` (`:2556`) and `feature_rows` (`:2581`), the same one-kwarg path
    `adjudicated` already takes.
- `asf/feeder/tiers.py` — `'gate'` joins `WORKED` (`:34`), and its comment names why: the lane's

- `tests/test_feeder.py` — the S-78056 feeder cases. The registry fixture shape is
