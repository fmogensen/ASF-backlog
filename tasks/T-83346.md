branches grow one arm each, one constant is minted, and one word joins the S1 lane's "being
worked" set so a waived S1 does not read as abandoned (**PD12**). `asf/workers/lifecycle.py` is
not touched: `corrections()` reads exactly as it reads today (P19, Out).
