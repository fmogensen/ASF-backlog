## Description
stories: S-18903
writes: asf/metrics/metrics.py, tests/test_metrics.py
after: Task 2

§2.3. One function that turns "this record, plus every other product" into a list of
`(label, root)` pairs and a list of names that could not be read. It opens nothing under
`~/.ASF` at all when no product name is given, which is what keeps every existing caller and the
pinned test home honest (B-0043).

**Files**

- `asf/metrics/metrics.py` — `throughput_records(root, product_name=None)` after
  `record_throughput`; `from asf import schema` beside `from asf import env` (`:34`).
- `tests/test_metrics.py` — `ThroughputRecordsTests` (new).

**Steps**

1. `from asf import schema` at module level (P11: no new module, no cycle — `asf.record.index`
   already pulls it).
2. `throughput_records(root, product_name=None)`: when `product_name` is falsy, return
   `([('this record', root)], [])` immediately — **before** any `env.ASF_HOME` access, so a caller
   that did not ask reads nothing outside `root`. Otherwise start the list with
   `(product_name, root)` — this record is always read from `root`, never from its own
   `backlog_dir` (§1.4), because `cmd_rollup` is writing the file into it and the two must agree.
3. Then, for each `name` in `schema._all_products()` sorted and skipping `product_name`: load it
   with `env.load_product(name)` inside a `try`, catching `env.ConfigError` and `OSError` →
   `skipped.append(f'{name} (config unreadable)')`. A product with no `backlog_dir` or one that is
   not a directory → `skipped.append(f'{name} (no backlog_dir)')`. A `backlog_dir` with no
   `index.json` → `skipped.append(f'{name} (no index.json)')` — the string §3.4 and §2.4 both
   spell for `extra`. A `backlog_dir` whose `os.path.realpath` equals `root`'s is dropped as a
   duplicate and is not skipped either (the rollup run over a checkout rather than a clone).
4. The docstring says what §1.4 decided: a product whose record cannot be read is *named* and left
   out of the Total, because zero is a number an operator will act on and a named omission is not;
   and that a rollup must never fail because another product's checkout is missing. It also carries
   P12: every path here is opened read-only and nothing is written under another product's
   `backlog_dir`.
5. `ThroughputRecordsTests`, all of it under `mock.patch.object(env, 'ASF_HOME', <temp dir>)`
   (P10 — the module attribute, not `os.environ`): write `products/sample.yaml`,
   `products/demo.yaml` and `products/extra.yaml` into that home, give `demo` a `backlog_dir` with
   an `index.json` and `extra` one without. Assert `throughput_records(root, 'sample')` is
   `[('sample', root), ('demo', <demo backlog_dir>)]` with `['extra (no index.json)']` skipped, and
   that `root` is used for `sample` even though `sample.yaml` names a different `backlog_dir`.
   Then: a yaml that will not parse is skipped with its reason and raises nothing; a
   `backlog_dir` that does not exist is skipped; a product whose `backlog_dir` *is* `root` appears
   once. Finally `throughput_records(root, None)` is `([('this record', root)], [])` with
   `env.ASF_HOME` patched to a path that does not exist — nothing outside `root` is opened.
