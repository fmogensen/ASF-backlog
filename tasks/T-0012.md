**Files**: `asf/groom/groom.py`, `tests/test_groom.py`, `tests/test_groom_policy.py` (`UnblockTests`).

**Steps**
1. `ANSWER_UNBLOCK` exactly as §2.4. `_parse_answer` returns `('unblock', '<ID>')` before the fallthrough.
2. `apply_groom_answers`: `unblock` removes the id from `blockedBy` and writes the remainder, or
   removes the field when the list empties. History reads
   `blockedBy → <comma-joined remainder, or (none)>`. An id not in `blockedBy` is a no-op.
3. `POLICY_NAMES` (PD3). The `controller: <policy> <word>` form attributes `(controller, <policy>)` (PD2).
   A bare `controller: <word>` keeps `(controller, starvation policy)`.
4. `ADJUDICATOR_PREFIX` (`adjudicator:`) and a new `apply_groom_answers(..., adjudicator_job=None)`
   parameter. The prefix attributes `(adjudicator, <job>)`.
5. Tests: `AnswerParsingTests.test_unblock`; `UnblockTests` covers removing one of two ids, the
   last id (field gone, `(none)`), twice being a no-op, and an absent id being a no-op; plus one
   test per attribution form.
