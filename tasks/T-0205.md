§2.6 and §3.6: N consecutive ticks that launched nothing while New Tasks waited, filed as one Bug
naming the gate that held them and what the record now holds for it — the 2026-09-23 case reading
itself back as `waits on T-0044 (Closed)`. Then the whole-module test that says all six sources
obey one daily guard and one approval class, and that the three old ones still file `found_in: ci`.

**Files**

- `asf/tick/file_bugs.py` — `idle_wave_signatures`; the third `signatures.update(...)` line in
  `cmd_file_bugs`; the module docstring's last source bullet
- `tests/test_file_bugs.py` — `IdleWaveTests`; the three new signatures in
  `FileBugsIntegrationTests`

**Steps**

1. `idle_wave_signatures(root, canonical, conv)`: `_jsonl_lines(os.path.join(root, 'metrics', 'ticks', '*.jsonl'))`
   in stream order, walked backwards, counting the trailing run of lines where `line['wave']['idle']`
   is true **and** `line['wave']['new_tasks'] > 0`. Any other line ends the run — a launching wave,
   a tick with no `wave` key, an idle wave with no New Tasks. No clock: the streak is the stream's
   own memory (§1.4), so this source takes no `now`.
2. A run of at least `conv.idle_wave_ticks` yields one signature. The gate is the key holding the
   most items summed over the streak's `gates` dicts, ties to the lowest key; a gate that resolves
   to an item in `canonical` is printed with its `state` (`T-0044 (Closed)`), one that does not
   (`trunk`, `operator`, `no row planned`, `held <class>`) verbatim.
3. `signature: f'wave idle: {gate}'` — the gate alone, so the same stall bumps one Bug as it
   lengthens — `severity: 'S2'`, `found_in: 'dev'`, `runs: []`, §2.6's title, and evidence oldest
   first: one line per tick (`tick`, `ts`, `nothing to launch`, the New Task count, the gates with
   their counts), capped at `EVIDENCE_CAP` keeping the newest (PD12), then one
   `New Tasks held: …` line from the newest tick's `new_task_ids`.
4. `cmd_file_bugs`: the third `signatures.update(idle_wave_signatures(root, canonical, conv))`
   line. `canonical` is already loaded there.
5. The module docstring's source list gains its last bullet.
6. `IdleWaveTests` per T6: six tick lines each
   `wave: {'idle': true, 'new_tasks': 12, 'gates': {'T-0044': 9, 'trunk': 2}}` with `T-0044` in
   the record as a Closed Task → one Bug, `signature: wave idle: T-0044`, `severity: S2`,
   `decided: true`, the title naming the gate and `(Closed)`, one evidence line per tick plus the
   New Task ids line. Then: five such ticks → nothing; six broken in the middle by one launching
   tick → nothing; six with `new_tasks: 0` → nothing; six whose newest carries no `wave` key →
   nothing; a streak whose gates are `{'no row planned': 12}` filing with that as the gate,
   printed verbatim.
7. `FileBugsIntegrationTests` per T7: one record triggering all three new signatures plus a CI one
   → `4 filed`; a second run the same day → `0 filed, 0 bumped, 4 unchanged`; with
   `file_bug_level='human-now'` nothing written and one `NEEDS OPERATOR: held file_bug on …` line
   per signature, the three new ones included; the CI, refusal and rule Bugs still carrying
   `found_in: ci` (the module's existing assertion at `tests/test_file_bugs.py:244`, kept and
   widened to the refusal and rule cases).
