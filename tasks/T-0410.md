§2.8: the README's Install section becomes five lines or fewer, and the guide stops opening with
two files to copy by hand.

**Files**

- `README.md` — the Install section
- `docs/guide/getting-started.md` — step 1 loses the two `cp` lines and gains the flag table
- `docs/guide/upgrading.md` — `--to`
- `docs/guide/troubleshooting.md` — the installer's `NEEDS OPERATOR` lines
- `tests/test_readme.py` — `InstallSectionTests`

**Steps**

1. `README.md`'s Install section (`README.md:15-27`) becomes five lines or fewer: the
   prerequisites sentence; one fenced
   `curl … | bash -s -- <product> -- --repo <dir> --record <dir> --scheduler launchd` line; and one
   sentence naming `asf doctor` and the two `/plugin` commands. The two `cp docs/*.example.yaml`
   lines go — that is the zero-state half this card exists to remove.
2. The `/plugin marketplace add` target becomes the written `<ASF_HOME>/plugin` path, not the repo
   slug the README names today, to match what Task 2's tail prints.
3. `docs/guide/getting-started.md`: §1 loses the `cp` block and becomes the flag table —
   `--repo`, `--repo-url`, `--record`, `--record-url`, `--scheduler`, `--account`,
   `--fake-workers`, `--console-permissions`, `--allow-checkout`, `--yes` — each with what it
   does and what it defaults to. §2 becomes the one bootstrap line.
4. `docs/guide/upgrading.md`: `asf upgrade --to <sha|tag>` is the documented spelling, with
   `--ref` named as the accepted alias.
5. `docs/guide/troubleshooting.md` gains the installer's `NEEDS OPERATOR` lines: a missing
   prerequisite, a missing account token (`claude setup-token`), the two `/plugin` commands, a
   clock still not loaded after the retry, and `pipx uninstall asf-factory`.
6. `InstallSectionTests` in `tests/test_readme.py`: the README's `## Install` section is five
   lines or fewer of prose and fence content; it contains no `cp docs/` line; its fenced command
   names the bootstrap and the three flags; `getting-started.md` contains no
   `cp docs/config.example.yaml` and no `cp docs/products.example.yaml`; `upgrading.md` names
   `--to`; and `troubleshooting.md` names each of the five operator lines. Every flag the guide's
   table lists is a flag the parser carries — read from `build_parser`, not from a hand-kept list,
   so the table cannot drift from the command.
