**Steps**

1. `asf/workers/scratch.py`: `SCRIPT_NAME = '.b0000_heartbeat.sh'` — a name `PATHS`' second glob
   already matches, so it needs no new entry anywhere. `heartbeat.NOTES_FILE` becomes an alias of
   `scratch.NOTES_FILE`, so the literal has one owner.
2. `asf/workers/heartbeat.py`: `SCRIPT`'s index file becomes
   `"$(git rev-parse --show-toplevel)/.b0000_heartbeat.idx"` in place of `mktemp`. The lease
   fence, the `ASF-Session` trailer and the exit on a foreign ref are untouched.
3. `heartbeat.brief_lines` gains a third form, `script='<name>'`, whose block is §2.2's four
   bullets verbatim: the interval, the ref, the limit, the one `nohup sh <name> …` command and
   the notes rule. No heredoc, no `git rev-parse --git-dir`, no `--git-common-dir`; every path in
   it is inside the worktree.
4. `asf/workers/spawn.py`: `make_worktree` calls `scratch.exclude(worktree)` after the checkout —
   its first production caller — and a worktree whose exclude cannot be written still launches,
   with one line said about it. `spawn` writes `heartbeat.SCRIPT` to
   `<worktree>/.b0000_heartbeat.sh` (mode 0644) when `beat is not None`, before `runtime.run(job)`.
5. `asf/kernel/ports.py`: `RealSessions._spawn` passes `heartbeat=self._beat_on()` —
   `kernel.heartbeat.enabled`, read through `heartbeat.kernel_settings` — in place of
   `heartbeat=False` at `:2263`, and the comment citing the sandbox refusal is replaced by one
   citing this spec's §2.2.
6. `asf/kernel/briefs.py`: `kernel_push_text` gains a `beat=None` parameter and applies
   `_HEARTBEAT_REWRITES` only when `beat is None` (`K5`); `_FLOOR_REWRITES` is unchanged. Its
   caller passes the launch's beat.
7. Create `tests/kernel/test_kernel_heartbeat.py` with one case per acceptance line, and move the
   `enabled: false` half of `tests/kernel/test_no_heartbeat.py`'s first class into it as the
   beat-off case beside the beat-on case (`K14`). Among them: every path in the brief's block
   matched against the worktree root; `git add -A` in a worktree holding the script and the notes
   file staging neither; the ledger row carrying `heartbeat_min` where it carried `None`.
8. `tests/kernel/test_no_heartbeat.py`: keep `DoneAndPushedMovesOn` whole, drop
   `KernelBriefsCarryNoHeartbeat`, and rewrite the module docstring to say it now owns only the
   done-and-pushed-with-a-question rule.
