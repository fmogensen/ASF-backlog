## Description
The finding path reader still reads 35% of real review findings as a writes request (follow-up to B-211642). Measured on the honest fixture tests/fixtures/review_findings_283.jsonl (harvested from docs/reviews by tests/fixtures/harvest_review_findings.py): 35% requested, 0% routed. Two patterns dominate, and neither is an ask to change a file: a review citing the card's own missing docs/plans/*.md or docs/specs/*.md, and a review citing tools/*.sh or a plan or spec for process reasons. asf/kernel/findings.py `outside_writes` and `_cited` do not yet read a path cited as missing or absent, or cited forward of the claim, as context.

kernel.resolve.finding_writes stays off until this lands.

## Acceptance
- [ ] A path the finding cites as missing, absent or not in the record is not a writes request. — tests/kernel/test_finding_writes.py::OutsideWrites::test_a_path_cited_as_missing_or_absent_is_not_a_writes_request
- [ ] A path cited for process reasons (a check script run or not, a plan or spec compared against) is not a writes request. — tests/kernel/test_finding_writes.py::OutsideWrites::test_a_path_cited_for_process_reasons_is_not_a_writes_request
- [ ] A finding that asks to change or create a file outside the footprint still requests it. — tests/kernel/test_finding_writes.py::OutsideWrites::test_the_paths_a_finding_names_are_read_by_the_reports_own_parser
- [ ] The Replay test on the honest fixture reads under 10% requested and under 2% routed, with no row removed from the fixture. — tests/kernel/test_finding_writes.py::Replay::test_the_measured_review_findings_request_writes_under_10pc_and_route_under_2pc
