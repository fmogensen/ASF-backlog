## Description
`check` validates ids, types, parents, links, staleness of the generated sections and of the index. It never looks at whether the record has the folders the schema names: a backlog missing `inbox/`, `groom/`, `releases/` or any metrics stream passes, and the first tick then fails on a missing directory instead.

## Fix
`check` verifies the layout named in the README and reports a missing folder as a finding with the command that creates it.
