## Description
Small CLI defects found verifying every command on the asf product: `rules` and `stale` take no `--product` (cwd only); one tick makes two commits (`tick: state` then `tick: steps`) where one is expected; `doctor one-factory` flags the asf product's own tests as a second factory copy (its repo IS the factory); `sessions` reads only `metrics/sessions`, not the live `state/<p>/sessions.jsonl` the workers write; `status` prints "—" for every row on a product without the first product's operator state; `prod` prints `?` instead of "no deploy configured".

## Fix
One Story each is overkill: fix all six behind tests in one pass; `--product` on every command that reads a record.
