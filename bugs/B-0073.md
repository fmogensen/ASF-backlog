## Symptom

The tick that started 19:17 hung for over 20 minutes inside its gate and blocked every later tick (launchd runs one at a time). Nine to eighteen nested test suites were running, growing. No tick has run since.

## Cause

Two rules that are fine alone and fatal together:

1. `.githooks/pre-commit` (written by `asf init`) runs the product's whole test command before every commit.
2. A test on `task/T-0027` makes a real commit in its fixture repo *with the repo's hooks enabled*, so the hook runs the whole suite again, whose fixture commits again — unbounded recursion.

`fix(B-0072)` (gate timeout) stops the damage from spreading but does not remove the recursion, and it landed while the hung tick was already running.

## Fix

- Every test fixture commits with hooks disabled: the shared fixture helper (`tests/gitfixture.py`) sets `core.hooksPath=/dev/null` on every repo it builds, and a test asserts no fixture repo has the product's hooks path.
- The hook itself refuses to recurse: `asf hook pre-commit` exports a marker and returns immediately when it is already set (a suite started by the hook never starts another).
- `asf init`'s hook template carries the marker, so every adopted product gets it.

## Tests

`test_fixture_repos_have_no_hooks`; `test_pre_commit_hook_is_a_no_op_when_already_running`.
