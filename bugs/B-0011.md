## Description
The pre-commit hook exports the git directory, work tree and index variables and runs the test suite with them inherited. Any test that spawns version control in a temporary repository therefore ignores its own working directory and operates on the real one: a harvest test's fixture committed six initialisation commits and a whole-tree deletion onto the real worker branch and left forty-seven modified and untracked files behind.

## Fix
The hook runs the suite with those three variables unset, and the harvest tool and its tests strip the same three from their own subprocesses.
