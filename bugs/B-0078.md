## Description

A Feature with no Tasks of its own lands by a commit on the trunk that names it. `ingest` takes
that branch, hardcodes `Resolved` and returns — it throws away the state `match_ids` just worked
out, which under D-0047 is `Closed` when CI is green on that commit. So such a Feature can never
leave `Resolved`, however long the trunk stays green. F-0087 sits there now.

Same rule as B-0077: what "in production" means is the product's own. A product that configures
`deploy_sha` keeps waiting for the deploy and the operator's tick; a product that configures none
has its trunk as production, so the green commit is the close.

## Acceptance

- A Feature with no Tasks, named by a commit on a green trunk, in a product with no `deploy_sha`,
  reads `Closed`.
- The same Feature in a product that configures `deploy_sha` still reads `Resolved`.
- F-0087 reads `Closed` after the next record step.
