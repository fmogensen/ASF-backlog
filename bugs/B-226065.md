## Description
An item whose reviewer fix was judged out of bounds can never leave Stuck when the fix is kept. The kernel records the out-of-bounds fix as a kernel-made changes finding on the reviewer's head (asf/kernel/reviewfix.py, apply.py). If the next build keeps the reviewer's commit and changes nothing (correctly: nothing else was asked), the PR head does not move, so no review launches, the finding stays open, and the item reads "changes requested after N fix rounds" for ever. Seen on T-210362 (PR #1766): five rounds, two of them granted by the console, then a strong-model round that reported "nothing to change".
