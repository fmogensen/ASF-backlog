`asf backlog` (asf/views/board.py) prints every Feature: 89 rows, 73 of them undecided cards. As a box table that is 339 lines and 67 KB. Claude Code truncates it ("Output too large"), so the operator cannot see the board.

Expected: the default fits a console (under about 80 lines for this record). Per Epic, every moving or landed Feature is shown in full. The undecided cards collapse to one line (a count plus the top few by rank), and so do Closed/on-prod Features. `--all` prints the full table. Tests in tests/test_views.py and tests/test_readers.py keep their intent.
