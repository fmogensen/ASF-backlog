## Description
The 142 core Rule cards migrated without their `check:` scripts — the ASF repo has no `rules/` directory and `asf rules check` reports `0 checked, 142 unenforced`. The scripts stayed in the first product's backlog (`tools/checks/rNNNN.sh`) and reference that product.

## Fix
`rules/` in the ASF repo ships the core check scripts, generic (paths from the product yaml, ids from `index.json`); `asf rules check --product <p>` runs core ∪ product checks; a Rule card whose script is missing is a violation of the rule-has-a-check rule, not silently unenforced. Port in batches by area; each batch is a Story.
