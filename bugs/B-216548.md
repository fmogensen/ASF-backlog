## Description
A second landing files no follow-up Bug (follow-up to PR #1735). asf/kernel/decide.py `later_bugs` skips an item once `kernel_later_filed` is set, and `kernel_later_findings` is never cleared. An item reverted off a red main and landed again, or rebuilt by ArchiveAndReset, keeps its old lines; LATER findings raised by re-reviews of the second PR are merged in asf/kernel/apply.py `_keep_later` but never filed.

## Acceptance
- [ ] An item that lands again after a revert, holding LATER findings not yet in its filed Bug, files one more Bug listing only those new findings — tests/kernel/test_rereview_scope.py::FollowUp.test_a_second_landing_after_a_revert_files_one_more_bug_of_only_the_new_findings
- [ ] A landing with no new LATER finding (its later-bug bookkeeping cleared when the prior landing was reverted or rebuilt) files nothing — tests/kernel/test_rereview_scope.py::FollowUp.test_a_landing_with_no_new_later_finding_files_nothing
