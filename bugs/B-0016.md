## Description
Five `git worktree add` calls started within one second in the same repo raced on `.git/config` (`could not lock config file`); two jobs died before their first turn. The pre-asf spawn had no lock; the asf spawn must serialise worktree creation per repo (a lock dir or a per-repo mutex) and retry once.

## Fix
`asf.workers.spawn` takes a per-repo lock around `worktree add`/branch creation; test: N concurrent spawns against one bare repo all succeed.
