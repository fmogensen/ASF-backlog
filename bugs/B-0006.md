## Description
The planned command surface is `init tick new groom status roadmap backlog rules metrics harvest product migrate-epic`, plus `doctor` and `idea`. What exists is the write and derive half. After seeding this record there is no way to read it back other than opening the markdown files, which is exactly the failure the record was built to remove.

## Fix
`status`, `roadmap` and `backlog` print stamped tables from `index.json`; `doctor` prints the health table; `tick` runs the loop.
