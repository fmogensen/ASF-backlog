## Statement

Harvest should gate **once per tick**: rebase every eligible branch in turn onto the growing trunk candidate in the throwaway worktree, run the full gate once on the combined head, fast-forward main once; on a red gate, bisect by re-adding branches one at a time so one bad branch holds only itself. Replaces the interim cap of B-0031.

## Needs a design note first

Ordering and the bisect cost; what a held branch's `correction` (B-0032) carries when it was red only in combination; how the checkout sync (B-0036) and the per-branch `harvested` marks work with one push. Blocked by B-0031 and B-0032.
