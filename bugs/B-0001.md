## Description
The plan gives `asf init` as the adopter that creates a product's record in twenty minutes. The CLI's subcommand list is `new check index ingest migrate groom stale file-bugs rules evidence harvest pr-hygiene`; there is no `init`. This record's folder layout, its README, its pre-commit hook and its empty index were all written by hand.

## Fix
`asf init --product <name>` creates the folder layout (the seven item folders plus inbox, groom, releases and metrics streams), writes the schema README, installs the pre-commit hook, writes an empty index and prints the first roadmap.
