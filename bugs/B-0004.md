## Description
The ruling is that `index.json` and every card carry `schema_version`, and that `asf migrate` upgrades a record when the schema changes. Neither the index writer nor the card writer stamps one, so this record's first commit is already unversioned and a future schema change cannot tell it apart from a migrated one.

## Fix
The index writer and the card writer stamp `schema_version`; `check` fails a card without one; `migrate` reads it.
