## Symptom

`fix/B-0025`, `fix/B-0043` and `fix/B-0016` stay on origin tick after tick although the groom marked all three cards `removed: superseded: … — operator ruling 2026-09-22` (two of them Closed). B-0057's rule — a Closed Bug's branch is archived — never fires for them.

## Cause

`harvest.record_items` read the index through `feeder_rows.items_of`, which drops every card with `removed:` set (right for the feeder: a removed card gets no row). Harvest then found no card for the branch's item and `superseded_by` answered None; the branch was neither landed nor archived.

## Fix

`record_items` keeps removed cards, and `superseded_by` answers `removed` for any card with `removed:` set, whatever its type or state — a removed card's branch is exactly the leftover the rule exists for. The branch is archived as `archive/<branch>` and the run marked `harvested: superseded`, as for a Closed Bug. Test: `tests/test_harvest.py::ProductHarvestTests::test_b0065_a_removed_cards_branch_is_archived_whatever_its_type_and_state`.
