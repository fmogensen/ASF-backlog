## Symptom

CI on main red since `d57e569` on the new step `asf plugin check`: every skill reported `stale` (`plugin: stale — plugin/skills/status/SKILL.md` …). Locally the same command prints `up to date`.

## Cause

`asf/plugin_build.py` resolves the plugin directory from the package's own location (`REPO_ROOT = dirname(dirname(__file__))`). Under the editable install that is the checkout; under CI's plain `pipx install .` it is the venv's site-packages, where no `plugin/` exists — so every expected file reads as missing.

## Fix

The plugin directory is a property of the **checkout**, not the package: default `--dir` to `<cwd>/plugin` when `<cwd>/.claude-plugin/marketplace.json` exists (a checkout), else the package sibling (the editable case), else refuse with one line naming `--dir`. `marketplace.json` is written beside that directory's parent. Test: `check`/`build` against a temp checkout layout from another cwd; the CI-shaped case (package elsewhere, cwd = checkout) passes.

Footprint: `asf/plugin_build.py`, `tests/test_plugin.py`.
