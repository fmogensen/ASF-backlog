## Description
A groom test expects its fixture to mint the first id of a type, but the id minter reads the range from the process environment, so with a job's range exported the fixture mints inside that range instead and the pre-commit hook goes red for every ranged worker. The pass that found it committed with the variable cleared.

## Fix
The fixture tests clear the range variable in their setup, or the minter takes the range as an argument that the command line reads from the environment.
