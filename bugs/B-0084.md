## Description

The typed block of a card is a machine-read format, and it is currently written by hand — by a
session, or by the operator with a text editor. A comment that wrapped onto a second line broke
the parser and cost half an hour of blind ticks and five Opus sessions ([[B-0083]]).

Nothing validated the edit at the point it was made. `asf check` catches it on the next tick,
which is exactly one tick too late, and the pre-commit hook in the record repo runs `asf check`
only over what is staged — this edit was staged and committed by a tool that bypassed the hook.

## Acceptance

- `asf set <id> <field>=<value>` writes a typed field through the parser, so an unwritable value
  is refused at the keyboard rather than discovered by the tick.
- The record's pre-commit hook cannot be bypassed by the factory's own tooling: every commit into
  the record runs `asf check` on the files it touches, including commits made by `asf` itself.
- A card whose typed block does not round-trip through the parser is refused by `asf check` with
  the line quoted — already true — and by the commit that introduces it.
