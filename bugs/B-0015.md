## Description
`asf new bug --title …` writes a Bug card without `severity`, `found_in` or `signature`, and offers no flag for them. The first product's `backlog.py new bug` took `--severity S1|S2|S3` and `--signature`; the port dropped them. Every Bug filed by hand on 2026-09-21 (B-0013, B-0014) had its severity added with an editor afterwards — the record's own check did not complain, so an S1 can sit in the record unranked.

## Fix
`asf new bug` takes `--severity` (required), `--signature`, `--found-in` (default `dev`) and writes them; `asf check` flags a Bug without `severity`. Test: minting a Bug without `--severity` exits 2 with the usage line; `check` on a Bug card lacking `severity` reports it.
