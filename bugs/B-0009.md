## Description
On 2026-09-21 a rebase did not fast-forward and the cleanup loop removed the worktree and the branch anyway; twenty-six rewritten Stories were recovered from unreachable objects. Reaping must be conditional on a successful push.

## Fix
Harvest by code: tests, then rebase, then fast-forward, then push, then reap — each step gating the next. Until it lands, a reap happens only after a fast-forward merge returns success.
