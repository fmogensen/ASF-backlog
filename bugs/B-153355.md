## Description
Bug: a local session whose push is refused leaves its work stranded on a local-only branch, silently. On 2026-10-10/11 the product pin pointed at a CLI with no `pre-push`, so the git hook refused every local push. 17 worker branches held unpushed commits (T-129178 among them), the kernel marked 10 of those items falsely satisfied, and the console recovered them by hand by pushing the branches.

## Acceptance
- [ ] A session that ends with local commits origin lacks gets one push from the kernel (--force-with-lease); a refused push leaves the item Stuck(owner=operator) on the refusal's reason — tests/kernel/test_host_push.py::HostPushApply::test_a_refused_host_push_skips_the_pr_and_is_stuck_on_the_operator
- [ ] A done REPORT whose claimed sha or named commits are not on the freshly-fetched trunk is judged unpushed, never marked done or Satisfied — tests/kernel/test_still_needed.py::FoundDoneJudgedOnTheTrunk::test_the_t_129178_report_is_not_done_its_tests_and_commit_off_the_trunk
