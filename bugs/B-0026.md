## Description
Within a tier the feeder orders rows by id, so the S1 Bugs with the lowest ids take every slot on every wave. When those Bugs are the ones whose fix already landed but whose card has not closed yet (no commit names them), the same four sessions relaunch every wave (`$0.30` each) and a newer S1 never gets a slot — the lane starves on its own leftovers. Seen 2026-09-21 19:35: B-0003/B-0008/B-0014/B-0020 held all four slots; B-0023/B-0024/B-0025 waited.

## Fix
Within a tier, order by attempts ascending (sessions the registry holds for the item, ended or not), then by age of the card descending, then id. A Bug attempted three times without closing is a `STALEMATE → ADJUDICATE` row, not a fourth session. Test: four attempted Bugs and one fresh one, capacity 1 → the fresh one launches; three attempts → the adjudicate row.
