The console operator is never told what a tick did. The tick writes only ~/.ASF/logs/tick-<product>-<clock>.log, and nothing reaches the operator's Claude Code console. The operator asked (2026-09-23) to be informed in the console at every tick, by ASF itself.

Expected:
1. At the end of every tick, ASF appends one digest record (a JSON line plus a one-line human form) to a per-product digest file. It covers the clock, in-flight jobs, launched/landed/done, failures and NEEDS OPERATOR, and the wave verdict ("nothing to launch — N waiting on X"). It is built from the tick's own data (asf/tick/tick.py, summary.py), not by re-parsing the log.
2. `asf watch [--product P] [--all] [--since N]` prints the last N digests, then follows the file.
3. The generated plugin (asf/plugin_build.py) wires `asf watch` into the Claude Code console with a mechanism the plugin docs support (a declared monitor if plugins can declare one, otherwise a SessionStart hook or an /asf:watch skill), so the operator needs nothing beyond /reload-plugins.
