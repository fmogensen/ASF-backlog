## Description
A job's grants were passed comma-separated where the launcher expected spaces; the job ran fenced to its worktree and reported every read as denied, building from the brief alone. The asf spawn takes grants as a list from the product yaml (`job_grants`), so this class of error cannot recur — but the launcher must also refuse a grant path that does not exist, instead of passing it through.

## Fix
`asf.workers.spawn` validates every `add_dirs` entry is an existing directory and refuses with the offending path; test.
