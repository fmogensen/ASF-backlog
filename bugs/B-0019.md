## Description
The pre-asf health pass removed a live job's worktree nine minutes after it opened: its branch had no commits yet, so `git merge-base --is-ancestor <branch> origin/main` was true and the branch read as "merged/gone". The job lost nine drafted scripts. A worktree with a live session, or a branch whose only state is "no commits yet", is never merged.

## Fix
`asf.workers.health` reaps a worktree only when ALL hold: the session record says `ended`, its pid is dead, the branch has ≥ 1 commit not on the base at the time it was pushed (or the session ended with `no change`), and that commit is contained in `origin/<main>` (fast-forwarded) — a fresh branch with zero commits and a live session is kept and listed as `opening`. Test: a worktree with a live session and no commits survives `health --fix`; the same worktree with the session ended and the branch landed is reaped.
