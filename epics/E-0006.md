## Description
Speed and economy (operator-approved list 2026-10-10; items to be groomed into Features under this Epic).

Principles (from the 2026-10-10 review): progress not time (heartbeat), every flow continues (conservation), failure is cheap (resume from WIP commits).

Candidate Features, in rank order:
1. Review and fix loop: code checks (tests, writes scope, conventions) before the LLM reviewer; reviewer blocks only on Acceptance or real defects, everything else becomes a follow-up item automatically; strong model on builder and reviewer from fix round 3. Baseline: review p90 1.2 h; T-80572 took 6 rounds.
2. Tick speed: parallel launches (cloud launches are ~25 s each, sequential) and cheap ticks; target tick under 60 s, reacting within a minute. Baseline: ticks ~4 min vs 120 s interval.
3. Canary: one synthetic Feature flows spec -> plan -> Tasks -> PR -> merge through a rehearsal product on every kernel install (builds on F-0306).
4. Hotspot removal: self-registering commands instead of edits to asf/cli.py; no count asserts in tests/test_surface.py; reduces forced serialization (follow-on to Stacked builds).
5. Cloud heartbeat via refs/asf/hb/<job> (with F-0344 Stage 2).
6. Landing: batched merges; measure main-move cost. Baseline: p90 32 min per move, 46 min for the v0.2.0 merge.
7. Backlog hygiene: parked items untouched 30 days retired automatically with the reason. Baseline: 557 parked, 444 item-h.
8. Cost: cost per Feature (F-0344 Stage 2); cheap models for mechanical work; code first where the plan or record has the answer.
9. Funnel view (spec -> plan -> Tasks -> PR -> merged counts and time per step) on F-0344's metrics.
