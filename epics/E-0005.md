## Description
## Description
Give ASF a third way to decide, between the code it trusts and the sessions it pays for: a
calibrated decision model (jev, TypeSafe AI, via OpenRouter's `/api/alpha/decisions`) that
answers a typed question about the tick's state in ~100 ms for ~$0.0001, with a probability the
tick can threshold. Short-term (0.1) it makes the factory *see* (cost per Feature), *triage* (red
CI) and *stay safe* (approvals as code); long-term (0.2+) it makes the factory *choose* — model,
skill, card, rule.

Research: `docs/research/jev-decision-model.md` in the ASF repo (sections 2–4 hold the scoring
model, the six-area table and the 18 uses scored). Proposal with charts:
https://claude.ai/code/artifact/2564648b-4a57-4767-8f37-b6960d57f105

Shape of the work, as Features once the Epic is decided (score in brackets, research §4):

**0.1 — see, triage, stay safe**
- Judge seam: `asf/judge/` with `NoJudge` default, `FakeJudge` for tests, one OpenRouter adapter
  on `urllib`; `judge:` key per product, off by default; `metrics/judgements` stream with
  `product:`, question id, state digest, model version, probability, threshold, outcome
- Shadow mode: every call site answers into the record only for one week on the first product;
  the calibration table at the first check-in decides what goes live
- Event → item attribution (90): `asf.record.match` falls through to a `choice` over the open
  items in `index.json`; `item_reason` carries the probability
- Red-CI triage (83): `file_bugs` classes a failed run {infra, flaky, test, code, config} before
  it files; infra goes to the groom, not the fixer lane
- Approval-class recognition (83): hooks class a tool call or diff against `approvals:`;
  widen-only — `auto` → `groom` or `human-now`, never the reverse
- Prose rules as checks (83): a `check:` template that asks one `noul` per rule per diff; each
  rule gated by a must-fire / must-not-fire eval task before it files anything
- Tool-call risk gate (80): PreToolUse hook, four `noul`s — protected path, network, secret
  path, irreversible outside the tree

**0.2 — choose**
- Error → failure class (77), inbox type and parent Epic (73), `asf init` adopter typing (70),
  skill and role routing (70), model and effort per job (67), groom answer defaults (67)

## Acceptance
- [ ] `asf/judge/` ships with `NoJudge` and `FakeJudge`; the test suite and the sample quickstart run in CI with no key; `grep -r typesafe asf/` finds only `judge/`
- [ ] `judge:` is a per-product key, off by default, and named in SECURITY.md with what leaves the machine and how to turn it off
- [ ] one shadow week on the first product produces a calibration table from `metrics/judgements`, per question
- [ ] sessions matched to an item: 0 → 90 %+; USD per Feature appears on the scorecard
- [ ] fixer launches on infra-class CI failures → 0
- [ ] rules enforced: 53 → 63+ via jev-backed `check:` scripts, each with an eval task
- [ ] no call site lowers an approval class, merges, closes or acts irreversibly on a probability

## Non-goals
- Redaction or secret detection through jev — the content must not leave the machine
- Backlog priority or rank derived by jev — `priority` is the customer's call, never derived
- Replacing any session role: jev cannot write a spec, a plan, code or a review
- `jev-latest`: the adapter pins `typesafe/jev-1.13`
- A second decision-model vendor in 0.1 — the `Judge` seam is the hedge

## Open before deciding
- Scope: ASF and the first product only, or every product? (the data-leaves-the-machine question)
- TypeSafe: retention, a data-processing agreement, determinism of identical calls
