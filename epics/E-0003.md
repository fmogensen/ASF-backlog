## Description
Humans decide Epics, budgets, the business call to close an Epic, and anything the approval matrix marks `human-now` (money, production credentials, legal, customer data). The factory decides everything else from a card to production, including the production probe as the closing evidence.

Gate: the `human-now` list shrinks only as each class shows a quarter without an incident. Autonomy is reached by removing human gates one at a time, each removal earned by data, never by declaration.

## Acceptance
- [ ] the approval matrix is the only place a human gate is written, and widening or narrowing it is one file change
- [ ] a class leaves `human-now` only with a quarter of incident-free evidence behind it
- [ ] every error is still logged at every stage

## Non-goals
Removing a gate without the data that earns it.
