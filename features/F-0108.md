## Description
Operator, 2026-09-24: "we should release asf soon and get feedback … this requires a general installer and docs". Decided by the operator; rank it right after the waste and speed fixes. It absorbs the installer card (asf install: one command from zero to a ticking factory).

State on 2026-09-24: v0.1.0 is tagged (626fffe cuts releases on its own). tools/install.sh pins `asf-live` from a git ref, installs the hooks and clocks and runs the doctor. The plugin's skills prefer `asf-live`. The README has a 3-line Install section. Missing: the rest below.

## Acceptance
- [ ] **Installer, general:** the operator's config is generated, not copied by hand. `asf-live init-config` asks for (or takes flags for) accounts and repos and writes ~/.ASF/config.yaml and products/<p>.yaml from the schema. It works on a clean macOS and a clean Linux (systemd or cron scheduler kind). A CI job installs into a temp HOME against `sample/` and gets the doctor green. `install.sh --uninstall` removes the jobs and hooks.
- [ ] **Docs, for a first-time user:** docs/quickstart.md (from zero to the sample product ticking and one Task landed, in 15 minutes); docs/concepts.md (the record, Epics/Features/Stories/Tasks/Bugs, the tick and its steps, wave, groom, harvest and gate, approvals); docs/operator.md (every config key, every /asf:* command, costs and quotas, what "dead", "held" and "NEEDS OPERATOR" mean); docs/troubleshooting.md (doctor rows → fixes). The README links them. No operator names and no product names (check_generic).
- [ ] **Release notes:** each release tag gets a CHANGELOG entry generated from releases/<day>-<sha>.md (items shipped), and a GitHub Release with the install line pinned to that tag.
- [ ] **Feedback channel:** GitHub issue templates (bug / idea / install problem). An opened issue becomes an `asf inbox` card on the next tick, linked back to the issue, and the issue gets a comment when its item lands.
- [ ] **Release checklist:** a 0.1.x tag is cut only when the CI install test is green and the docs build with no dead links.
