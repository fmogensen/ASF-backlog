## Description
The 0.4 design, approved by the operator on 2026-10-14. It replaces the console's fix stream of 10-13/14: eight kernel changes designed one by one produced about 20 follow-up Bugs and three incidents caused by rules colliding (reviewer fix x high-risk path x round cap; acceptance wording x satisfied-on-main; beat judge x worker permissions). 0.4 = 24 hours hands-off with the kernel gate green. This Feature is built in the order below, one PR per step, by the factory; the console builds none of it.

## Remove (do not patch)
Reviewer fix and verify review; contradiction escalation; the proof gate; satisfied-on-main, take_done and empty-PR Done as ways to close an item; the beat judge and the p90 age bound as reasons to end a session; operator-granted extra rounds as the way out of the cap.

## Keep, and what each guarantees
- M1 Landing: the kernel merges only when an approve holds for that tree, pinned to the head. No auto-merge. Drop the reraise-only landing clause.
- M2 Review loop: finding keys, scoped re-review, one follow-up Bug for later findings, final review at the cap; plus a self-review step in the build brief (a fresh subagent applies the reviewer's checklist to the diff before the one push).
- M3 Exit ladder: rounds 1-2, the strong round, the final review, one rebuild, then Parked "given up" with every finding on the card. Parked shows in the gate and comes back on an answer or a re-plan. Every session counts toward a per-item budget, free rounds included.
- M4 Red main: blame before revert, trunk-wide hold, a revert counts only once merged.
- M5 Liveness: a session ends only on its own exit, on job-log silence of log_silent_min, or at a 240-minute ceiling.

## Invariants (each with its own test)
I1 nothing lands without an approve at that exact tree. I2 no item is Done without its own merged PR; an empty diff goes back with "add a new test proving the acceptance". I3 no session whose log advanced inside the silence window is ended. I4 no kernel rule makes an item Stuck on the operator, and every Stuck or Park has an action or fact that moves it. I5 every item's sessions are finite. I6 a trunk-wide red gets no revert, charges no round and holds every launch except the cure. I7 the gate fails on any hand-landed PR or install inside the window.

## Steps (one PR each, in this order; new test modules only)
- S1 (after S0, done by the operator config on 10-14): delete asf/kernel/reviewfix.py, the fixed verdict, verify mode and the trailer; a kernel-made "reviewer fix out of bounds" finding becomes an ordinary review of the current head; drop the reraise-only landing clause. Tests: tests/kernel/test_v04_no_reviewer_fix.py Removed.test_oob_fix_finding_launches_ordinary_review, .test_reraise_only_changes_never_merges, .test_approve_merges_pinned_to_head.
- S2 (after S1): remove the satisfied closer, take_done, empty-PR Done and the proof gate; keep the stale-CI cancel. Tests: tests/kernel/test_v04_close_needs_merge.py Close.test_green_named_tests_still_launch, .test_empty_pr_returns_ready_with_new_test_finding, .test_report_done_unpushed_not_done.
- S3 (after S2): the exit ladder; remove EscalateFinding; a per-item session budget; containers do not echo a child's Stuck; later findings filed again after a second landing. Tests: tests/kernel/test_v04_exit_ladder.py Ladder.test_cap_strong_final_rebuild_then_park, .test_no_rule_returns_operator_stuck, .test_free_rounds_bounded, .test_reworded_finding_is_a_round, .test_second_landing_files_later_bug.
- S4 (after S3): the liveness rule; the beat kept as information only; the p90 bound removed. Tests: tests/kernel/test_v04_liveness.py End.test_growing_log_past_p90_not_ended, .test_no_first_beat_growing_log_not_ended, .test_silent_log_ended_once, .test_ceiling_ends.
- S5 (alongside): gate honesty: count each question once per item and reason, leaves only; new rows hand-landed (<= 0), given-up (information), working sessions ended (<= 0). Tests: tests/kernel/test_v04_gate_rows.py ConsoleShare.test_item_counted_once_across_ticks, .test_container_not_counted, HandLanded.test_merged_pr_without_build_session_fails, GivenUp.test_park_is_shown.
- S6 (after S1): the build brief carries the review checklist and a self-review step before the push. Tests: tests/test_v04_build_brief.py SelfReview.test_build_brief_carries_rubric, .test_fix_brief_carries_keyed_findings.
- S7 (alongside): red-main tidy-up (an import failure is not "absent"; the red revert names its check; the incident records its blame kind). Tests: tests/kernel/test_v04_mainline_tidy.py.

Tests: tests/kernel/test_v04_gate_rows.py KernelLines.test_counts_kernel_py_lines_only, .test_row_fails_above_max.
