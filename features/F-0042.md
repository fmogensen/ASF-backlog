## Description
Read-only probes for every command-line tool the factory signs in with: is the session valid, and when does it expire — never printing a token. A rule check raises one needs-operator line with the exact re-authentication command when any is invalid or expires within three days. The credential set is per provider and shared across products; which providers a product needs comes from its configuration. On 2026-09-21 three tools had expired silently and blocked a day's work until it was noticed by hand.

## Acceptance
- [ ] the rule card and its script exist, and run daily and in every tick's rules row
- [ ] an expired session shows as one needs-operator line, never as a failed job
