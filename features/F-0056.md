## Description
Anything the factory relies on an agent remembering is a defect, because a truly autonomous factory runs on code and not on what a model happens to recall. Every remembered process step, tool behaviour or workaround becomes a Story here and is closed when its behaviour is produced by a script or a feeder row; rules become Rule cards, rulings and facts become Decisions.

This is the first of three passes over the same source; merging the three is one parent change per Story, and is a groom question.

## Acceptance
- [ ] every Story here is produced by a script or a feeder row, never by a session remembering it
- [ ] each source memory file is replaced by a one-line pointer to its item

## Non-goals
How the operator wants to be spoken to — style stays memory.
