## Description
At cutover, nothing factory-shaped survives outside the code repository, the operator config and the per-product records. The old tool directories are archived as one read-only commit and then deleted; the product repositories keep only what their own CI needs; the prototype is tagged and made read-only as prior art; the old scheduled jobs are replaced by the scheduler adapter's single job. A core rule enforces it: `asf doctor` fails if a second copy of any factory tool is on the path or inside a product repository.
