## Description
The prototype measured that 93 % of a run's cost was the agent discovering what the runner already knew — one build phase spent 12.3 M input tokens over 96 tool calls doing it. Every brief opens with a **code-generated preamble**: the repository head, the branch state, the card, the files it cites with their line counts, the tests that already exist, and the last report. The session reads; it does not search.

## Acceptance
- [ ] a brief carries a generated preamble, and no session is asked to discover a fact the runner holds
- [ ] input tokens per session fall measurably against the before reading
- [ ] the preamble is generated by code, never written by a model
