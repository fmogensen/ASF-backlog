## Description
A missing credential is not a flaky transport, and retrying it is a promise that something might change. The stall check and the launcher classify a failed launch or session before acting: a credential or configuration failure raises a needs-operator line and is never retried; a quota failure routes to another account of the shared pool; a transport failure gets one retry; only a work failure gets the relaunch we do today. The classification comes from the launcher's own result text and the session's last beat.

## Acceptance
- [ ] the stall check prints a class on every failure line
- [ ] a credential failure produces a needs-operator line naming the product, and zero relaunches
- [ ] relaunches per day fall, per product
