## Description
A request that names an existing document refines it and never regenerates it — the licence to reinterpret ends at the seam. In the prototype one run regenerated a 286-line specification from a single sentence and shed eight named tasks in the process. Here: `asf idea "<text>"` is the interrogator that writes the cards and asks its open questions into the groom; a `CARD → ENRICH` row does the same for a thin card; and a rule states that a brief naming an existing spec or plan says *refine*, with the pre-review bouncing a rewrite.

## Acceptance
- [ ] `asf idea` produces an Epic with Features, Stories and acceptance, plus its questions in the groom
- [ ] a brief that names an existing document and produces a rewrite is bounced before review
- [ ] no question is put to a person that the record could have answered
