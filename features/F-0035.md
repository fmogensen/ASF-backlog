## Description
The controlling session decides and briefs; every watcher, harvest, probe and status loop runs as a tick step. A rule check: when the controlling account passes 60 % of its weekly window, the tick lists the commands it ran in the last day that a script already covers, and files them as a factory Bug. On 2026-09-21 the controlling account reached 70 % doing chores.

The daily jobs — groom, rollup, retro, stale sweep — run on the scheduler rather than inside a session, so they survive a sleeping machine or a killed terminal.
