## Description
Every coder branch gets a mechanical code-review pass, at a level chosen by size class — low for small Tasks, high for medium and large, the deepest level for very large pull requests — run by a cheaper session before the expensive review. Its findings land as a check table on the branch and the expensive reviewer starts from that table: a finding already in it is never raised as new later.

## Acceptance
- [ ] the pass runs for every code row
- [ ] the count of critical findings per expensive review round falls
- [ ] a pull request with an unaddressed high-confidence finding is bounced without an expensive round
