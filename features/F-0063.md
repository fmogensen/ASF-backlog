## Description
A crashed or killed session's work survives on its branch, but the relaunch starts from the original brief and pays the whole context again — the cold-restart cost. Every relaunch brief carries four things: the branch head, the commit list between the main branch and that head, the last writer or review report on the branch, the last progress line from the job's own record, and the instruction to continue from the branch — not to re-cut, not to redo what the log shows done, and to push within fifteen minutes.

Pairs with same-session correction: a live session gets the findings, a dead one gets its branch.
