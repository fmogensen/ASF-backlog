## Description
A harvest step run by the tick: for every worker branch whose job ended cleanly — tests green → rebase on the main branch (the generated index regenerated on conflict) → fast-forward → push → reap the worktree and the branch. A branch that fails any step is left in place with one line in the log and is never reaped. On 2026-09-21 a hand reap after a failed fast-forward nearly lost twenty-six rewritten Stories; they were recovered from unreachable objects. Applies to a product's record and to the worker branches of a product repository, which then open their pull request as they do today.

## Acceptance
- [ ] a green worker branch lands on the main branch within one tick with no operator action
- [ ] a failing branch is left in place and named in the tick's output
- [ ] zero hand merges by the operator over seven days

## Non-goals
Merging pull requests in a product repository — the merge queue owns that.
