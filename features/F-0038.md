## Description
A change to the factory does not have to run the whole CI circuit of the product it serves. A `FACTORY_ONLY` path class in the product's change classifier and its mirror in the CI workflow: a push whose changed paths are all factory scripts, factory process documentation or review inputs (with their tests) runs only lint and a factory-test job — no gate, no end-to-end, no site, no soak jobs. A mirror test asserts that both copies of the class agree. The per-product path list lives in the product's configuration, never in the classifier.

## Acceptance
- [ ] a factory-only push runs exactly lint and the factory tests, in under five minutes
- [ ] a push mixing factory and product paths runs the full matrix as today
- [ ] a test covers the new class in both copies of the classifier

## Non-goals
Moving the scripts out of the product repository — that is a later card.
