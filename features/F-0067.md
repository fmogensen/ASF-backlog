## Description
The concrete re-scoping of the clean-floor Feature: an owner, a registry row and a TTL for every ephemeral thing, one sweep in the tick, and the tooling under version control in its own repository so a tool change is a commit and a mistake is a revert — which also removes the habit of keeping a backup copy beside the file. Includes the floor rule check: counts and TTL violations per class on the health table, the safe classes fixed by the sweep and the rest raised as groom lines.

This card and the clean-floor Feature cover the same ground; folding one into the other is a groom question.

## Acceptance
- [ ] the health table shows a floor row with zero TTL violations after one sweep
- [ ] the tooling directory is a checkout, with no backup copies beside its files
- [ ] a dead job's worktree is gone within a day, with its commits on a hold branch
