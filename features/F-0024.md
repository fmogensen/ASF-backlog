## Description
Self-improvement is postponed; the focus is a working factory. In 0.1 every error is logged for learning — the metrics streams, the bug filer, the incident Bugs — and the factory may **propose** changes to its own amendable set (rule cards, checks, hooks, role agents, briefs, evals) as cards. No session edits the amendable set. The eval-gated loop is the 0.2 Epic, built on a quarter of real data.

## Acceptance
- [ ] the amendable set is named in one place
- [ ] a session that writes to the amendable set is refused by a hook
- [ ] a proposed change arrives as a card with its evidence, and a human merges it
