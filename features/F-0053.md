## Description
A gate returns one check per thing it looked at, not a verdict. Every review — spec, plan or code — ends with a table of check, ok and evidence, written to the path the product's review pattern names; code reviews use the Story acceptance lines as their checklist; the verdict is derived from the checks by ingest and is never typed. The mechanical pre-review's numbered checks are the seed.

Build the review-then-verify pipeline as a scripted workflow with a schema per step, so the check table is typed output rather than parsed prose, and run the mechanical correctness pass before the human-standard review.

## Acceptance
- [ ] review templates carry the check table, and a review without one is bounced by the pre-review
- [ ] ingest parses the table and sets the round's verdict from it
- [ ] a Story acceptance line proven by a code review is ticked with the review path as evidence

## Non-goals
Replacing human judgement in the notes column.
