## Description
Genericity audit before the public release: hardcoded policy values and operator-specific names

A read-only audit of main (a1c4f647c). It covers values a product or operator would need to tune that no config key reads (A), operator-specific names that check_generic misses (B), and gaps between the config registry and its docs (C). The GitHub calls spread across modules, launchd/macOS-only scheduling and the Claude/cux runtime wiring belong to the separate connector-interfaces inbox item (forge, CI, runtime, scheduler, installer, quota and the rest, plus its gh/claude/launchctl/pipx lint), and are only cross-referenced here.
