## Description
Two new rows from the code host's pull-request state. `CONFLICT → REBASE`: an approved pull request whose mergeable state has been dirty for more than one tick gets a rebase session and no review round — the review stands, the rebase pushes, and the pull request's own CI reruns. `STALE → CLOSE`: an unreviewed pull request dirty for more than seven days is closed with a comment naming its Task and the reason, and the Task's recorded pull requests and branches are cleared so the feeder re-queues it. Both rows carry the item id, and the stale-PR rule stops firing for pull requests in either lane.

## Acceptance
- [ ] the feeder prints the two row kinds, the brief generator builds the rebase brief, and the tick performs the close
- [ ] a backlog of conflicting pull requests is either rebased or closed within 48 hours
- [ ] violations of the stale-PR rule trend to zero

## Non-goals
Force-pushing anyone's branch; closing approved pull requests.
