## Description
Read every card of the first product's factory Epic against the multi-product isolation table and re-word the ones that assume one product, one repository, one CI provider, one runner pool or one path, naming the config key the behaviour would read instead. A card that cannot be made product-agnostic stays where it is. The output is the re-worded cards plus one note per card in the groom.
