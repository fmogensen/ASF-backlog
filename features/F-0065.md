## Description
Granting a directory is the only fence today, and it grants write. The question: with the harness's sandbox mode on for a coder, a reviewer and a prober, which of the factory's tools break — version control over https, the code host's API, dependency installation, the browser engine, a product's development server — and what must be granted per role? Output: a table per role of what is needed and the settings that make it work; the launch-path card then adopts it. Throwaway code only.
