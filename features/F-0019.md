## Description
Run the new tick in shadow mode against the first product for three days — reading everything, writing to a shadow clone, diffing its tables against the old tick's tables every ten minutes. When three days show zero unexplained differences, switch the scheduled job to the new tick and archive the old tools. Then run `init` for the remaining products.
