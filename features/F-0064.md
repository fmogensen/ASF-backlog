## Description
The factory's own activity is prose first today — one hand-formatted line per launch, merge, relaunch, refusal, needs-operator and tick — and the tick stream is parsed back out of it, which makes the parser the weak joint. Work: (1) every script that writes a log line appends its event to the metrics stream with the item id instead, and a new events stream holds the one-off kinds with a natural key; (2) a render command prints the human view — today's log format — from the streams, so the log becomes that rendering and the parser is deleted; (3) a session's final beat carries its model and its four token dimensions, and a dated price table turns them into money, so cost stops being null; (4) the needs-operator footer reads the events stream; (5) prompt caching by brief order — the stable text first, the variable row last, so every launch hits the cache, with cache-read tokens per session recorded to prove it; (6) a grant audit: every added directory, every deny-rule change and every secret write is an event with its item id and its account.

Every event line carries its product, and a stream file never mixes products.

## Acceptance
- [ ] no tool writes the human log directly
- [ ] the tick stream's lines match the events stream with no parser between them
- [ ] at least 90 % of sessions carry a non-null cost
- [ ] the rendered log is byte-stable for a fixture day
