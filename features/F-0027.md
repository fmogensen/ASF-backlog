## Description
An option on the reviews-return-checks work: several independent reviewers dispatched concurrently and tallied into one check table; a member that fails abstains on the record; below quorum the phase fails; a split escalates to a single stronger adjudication. In the prototype this caught every real defect on a small number of calls and was cheaper than serial rounds with one strong reviewer.

## Acceptance
- [ ] a panel runs as one concurrent batch and produces one tallied check table
- [ ] a failed member abstains on the record rather than silently vanishing
- [ ] a split escalates to one adjudication, and the cost per approved review falls
