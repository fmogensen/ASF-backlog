## Description
A report as prose is testimony. Every job ends with a typed report — JSON, one schema per job kind — beside its prose; ingest reads the JSON; a parse failure goes back to the same session to be corrected rather than being re-run. The report contract is generated from the schema, so a template cannot invent its own.

## Acceptance
- [ ] every job kind has a report schema and every session emits it
- [ ] ingest reads the typed report, never the prose
- [ ] a malformed report is corrected in the session that produced it
