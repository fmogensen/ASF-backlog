## Description
Standing authority is prose today: money, production, security, customer data, legal and new Epics need a person; everything that cuts errors or time does not. It becomes `products/<name>.yaml → approvals:` — action classes mapped to `auto`, `groom` or `human-now` — read by the hooks (which refuse) and by the tick (which raises the line). A human widens or narrows the factory's authority in one file.

## Acceptance
- [ ] every action class in the matrix is named and mapped
- [ ] a hook refuses an action its class marks `human-now`
- [ ] the tick raises one line naming the class and the item when it is held
