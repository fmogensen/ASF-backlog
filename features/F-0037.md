## Description
A question is blocking only when a launch or a merge waits on it. Everything else — Story questions, groom items, title cleanups, priority calls — is appended to `groom/<date>.md` for one sitting. Writers' question lines already flow there; the health table counts open questions; the tick's reply carries at most one blocking question.

The groom becomes a page that can be answered from a phone only after it has run a week as a file — the sections and the answer syntax settle first.

## Acceptance
- [ ] a rule card and its check: a tick reply with more than one question line is a violation
