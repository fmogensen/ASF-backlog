## Description
Coder briefs already carry the Task id. Each Task's pull-request body carries `Proves: <S-id> line <n> — <test path>` for every acceptance line its tests prove; ingest ticks those lines with the pull request as evidence; a rule check fails a Task pull request that proves nothing; the merge queue refuses it. This is the criteria-have-evidence gate made concrete: a verdict without evidence is an opinion.

## Acceptance
- [ ] the rule card and its check exist, and the merge-queue refusal is wired
- [ ] the coder brief tail requires the proves line
- [ ] ingest ticks Story acceptance lines from pull-request bodies

## Non-goals
Bugs and documentation pull requests, which have no Story.
