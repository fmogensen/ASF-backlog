## Statement
Before fixing a red CI job: read that job's exact statement, and the version of the script that actually ran — a job run from a branch head against a base stack is running two versions at once. Release-mechanism files get a local dry run before they are pushed as part of a train.

## Context
A red was diagnosed from its symptom as one thing and turned out to be version skew between head and base, found by reading the job's log. A release drill then needed three CI rounds, each a template mismatch a ten-minute local run would have shown.
