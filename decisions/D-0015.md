## Statement
ASF does not phone home. Metrics stay in the product's own record. An opt-in anonymised scorecard share is a later card. A security policy and a one-page threat model — what an agent can reach, what a hook refuses, what is never in a repository — ship in 0.1.

## Context
An open-source factory that runs agents with credentials on someone's machine has to say this before it says anything else.
