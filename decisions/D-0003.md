## Statement
Configuration lives in `~/.ASF/`: `config.yaml` (scheduler, worker pool, quota guards, defaults, paths), `products/<name>.yaml` (one file per product), `state/` and `logs/`. It is never in a repository, and it carries several products from the first release — not one product with a second bolted on later.

## Context
Everything that is data belongs to exactly one product; everything that is code belongs to ASF. A convention that lives in code is a convention that cannot serve a second product, and a second product was already in view when the first line was written.
