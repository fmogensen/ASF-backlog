## Decision

**A green run** is the standing definition of done for a stretch of factory work, given by Frank
2026-09-22: *"develop 3 new asf features from backlog running completely green … no dead sessions,
failed CIs … missing or failed pushes or mergers or PRs and a clean factory floor"*, with
*"it's a bug if asf doesn't run automatically"*.

Five conditions, all computed, none judged:

| # | Condition | Read from |
| --- | --- | --- |
| 1 | three or more Features `Closed` since the run began | the record's index |
| 2 | no held item and no lane branch waiting on nothing | index + `origin/<lane prefix>` ahead of trunk |
| 3 | CI green on the trunk's head | the CI provider |
| 4 | zero failed runs on any branch | the CI provider |
| 5 | every worktree belongs to a live run | the worktree list ∩ the session ledger |

The verdict belongs to the floor table, printed with the numbers, so that "is it done" is never a
matter of opinion or of a session remembering what was asked.

## Consequences

- `~/.ASF/bin/floor-status.sh` prints `GOAL MET` / `GOAL NOT MET` with the failing conditions named.
- A goal given in conversation is recorded as a card before work starts on it; an unrecorded goal
  is a defect of the same class as an unrecorded rule (code beats memory).
