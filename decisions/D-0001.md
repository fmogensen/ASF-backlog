## Statement
ASF's code lives in a new repository, public, Apache-2.0, with a fresh history. No product data, no operator secrets and no private history are carried into it.

## Context
The factory that exists today grew inside a product's working tree. Rebasing that history into a public repository would publish the product's data with it; a fresh repository costs one import and settles the question for good.
