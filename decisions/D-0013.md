## Statement
`asf doctor` checks configuration, credentials, runners, the scheduler, whether each product repository is reachable, and the schema version, and prints one table. In 0.1.

## Context
It is the first command a stranger runs when something is off. Without it every failure arrives as a failed job instead of as a named cause.
