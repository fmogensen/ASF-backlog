## Statement
The permission classifier denies every write step of a hosted deploy — creating applications and volumes, setting secrets, deploying, and the database bootstrap — while allowing the read-only calls of the same session. The denial is not worked around; it is lifted by a standing operator decision, and the standing rule since is that the controller does secrets and production itself, through pipes that never print a value.

## Context
The write half of a deploy is exactly the class the approval matrix should mark human-now. What made it visible was a database migration being denied the same way as the deploy commands, which showed the classifier gates the whole write half rather than one tool.
