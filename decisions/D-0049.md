## Decision

For the `asf` product, the factory answers its own groom. No question waits for the operator; every answer is written into `groom/<date>.md` with a one-line reason and applied; the operator is **informed** (the tick's digest, the notifier) and may override any answer within 24 hours by editing the card. Only `human-now` classes stop: money, production credentials, deleting history, releasing to the public, anything that leaves the machine.

## Why

Operator, 2026-09-22 09:40: "I want the asf to develop the asf product autonomously … Why wait for me? Why not answer the questions and just inform me?" The 0.1 plan gave every `decided:` to a human; on the factory's own product that only adds a wait.

## Rules the factory applies (no model)

| Question | Answer |
| --- | --- |
| inbox card typed | `decided: true`; parent = the one open Epic, else the Epic sharing the most title words; Bug severity by signature class (a stopped lane = S1, a wrong table = S2, cosmetics = S3); Feature rank = after the decided ones |
| which Epic? | as above; a card that fits no Epic gets the factory Epic and a `## Note` |
| blocked on a Closed item | unblock |
| near-duplicate titles | the older card stays, the newer gets `merged_into:` and closes by ruling |
| auto-filed Bug not decided | yes |
| Feature without Stories | a spec session, one at a time, in rank order, when a slot is free and no S1 Bug is open |
| undecided > 14 d | decided, rank last |
| anything else | one adjudicate session with the record as context (E-0005, scoped to grooming), whose answer is written like the rules' |

## Consequences

- The feature card carries the implementation (rules → `asf groom --auto`, the digest, the notifier).
- Until it lands, the controller session applies the same rules by hand and reports them — it does not ask.
- Other products keep the 0.1 default (the operator decides) until their own ruling.
