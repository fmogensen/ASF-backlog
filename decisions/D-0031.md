## Statement
Browser control is enabled in a dedicated browser profile per worker account, and to browse as a given account the session must be on that account. A browser tool is never handed to a subagent.

## Context
The extension pairs a browser profile with the account signed into it, so each account's logins and cookies are reachable only from a session on that account. The same pairing decides which account a sign-in command authenticates.
