## Statement
How a session is run is an interface. The agent CLI is the first backend; a `fake` runtime that replays scripted results ships with it, so ASF's own tests and the quickstart run in CI with no model and no account. In 0.1.

## Context
Not every adopter has a pool of subscription accounts, and tests need determinism. The prototype already had three runtime adapters, which is the evidence that one hardcoded runtime does not survive contact with a second user.
