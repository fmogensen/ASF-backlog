## Statement
When a documentation page conflicts between a branch and the main branch, the main branch's version wins and the branch re-applies its change on top.

## Context
Documentation branches are long-lived and a documentation train moves the main branch under them constantly. Resolving the other way silently reverts whatever landed in between.
