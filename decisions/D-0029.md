## Statement
Any repository an agent should be able to query through the memory interface is registered with its remote URL, not only with a local path. Only a URL-registered source is pulled by the index's own daemon; a path-only source never pulls and silently goes stale. Source status reports sync recency, not commit recency, so freshness is checked by comparing the indexed head against the remote's.

## Context
A path-registered source froze at an early commit and drifted nine hundred commits behind the main branch while its status reported no lag at all. An index is only worth a token if it reflects the main branch. Which memory backend is used is operator configuration; the interface is what ASF names.
