## Statement
A product's work-item record is one repository of markdown cards. The vocabulary is Epic, Feature, User Story, Task, plus Bug, Decision and Rule. The id is the filename and the link target, and only one tool mints an id. Markdown is the record; the generated index is the only thing scripts read. Intent is typed — title, acceptance, parent, priority, rank, decided, blocked-by — and state is derived by the tick into the machine block, because a status a human maintains is a status that lies. Specs and plans stay in the product repository and the card links to them.

## Context
All four pains — speed, reliability, cost and control — shared one root: there was no record the factory could trust, so the board re-inferred the hierarchy from hundreds of branches every tick. The record's README is its schema.
