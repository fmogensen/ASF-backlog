## Statement
A dispatch rule phrased as a percentage of a usage window can only be checked if the percentage is readable from state. Where the only source is a status line rendered to a human, the rule is not checkable and a report must say so. The fix is a refresh command that writes the figure to a file the checks read.

## Context
The controller had to apply a stop-dispatching-past-a-threshold rule and found no readable figure anywhere: the status line prints its warnings to the person, not to the process. A usage refresh command and a quota script are the readable figures the quota rules are checked against today.
