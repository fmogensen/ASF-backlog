## Statement
The measure is the speed at which features that hold business value reach users. State is reported as features — what a customer gets, what is one review away, what blocks the next. The scorecard's first tile is features released this week. Every dispatch decision asks whether it ships a feature sooner. Independent work starts the moment its ingredients exist, on any account with capacity. A process rule is dispatched only when it removes a measured loss.

## Context
Everything in between — fixes, CI, pull requests, optimising the factory — is irrelevant to the person paying for it except insofar as it moves that number. A day with twenty-two relaunches and fourteen merges is a bad day however clean the process became.
