## Statement
Every session sharing one configuration directory shares one login, so any switch moves all of them. Only a separate configuration directory per account keeps them apart — which is what the worker account folders are for. A remote-control session belongs to the account that started it and must be restarted after any switch.

## Context
Established by inspecting the account manager and the running processes. The consequence that matters: an automatic rate-limit switch can land the main session on a worker account, so the pool the switcher draws from must be narrowed to the accounts that may hold it.
