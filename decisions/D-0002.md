## Statement
ASF's record is its own repository, separate from the code and public from the first commit. The record is the demo: what the factory is building on itself is the best available argument that it works.

## Context
Keeping the record beside the code would mix a data repository with a code repository and would force every card through the code repository's CI. Keeping it private would hide the one artefact a stranger can evaluate without installing anything.
