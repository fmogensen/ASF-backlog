## Statement
The worker pool takes two kinds of backend behind one quota-guard shape: agent-CLI accounts (today) and API keys through an agent SDK. The interface ships in 0.1; the API-key backend is a card for later.

## Context
Adoption without a subscription plan needs the API-key backend, and so does the hosted service. Shipping the interface now is cheap; shipping the second backend now is not, and nothing yet measures whether it is needed.
