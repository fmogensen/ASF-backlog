## Statement
Findings accumulate into packs rather than a burst of small pull requests: hotfix packs at any time, feature packs only after the product's business trigger. Before that trigger a new capability takes the next milestone code, because a milestone code says this is still first-release work. An open pack lives on its own branch with a ledger; an integrator combines its branches into one head with one CI run and one pull request, and the individual pull requests are closed against it.

## Context
A pack branch may not match the CI workflow's push triggers, so a pack head is mirrored to a triggering branch or the pull request's own run is relied on. The pack mechanics hold whenever a pack opens.
