## Statement
Anything the factory relies on an agent remembering is a defect. Every memory file becomes a card — a Rule with a check, a Story under the factory Epic whose acceptance is that the behaviour is produced by code, or a Decision — approved by the operator in the groom. Only communication style stays as memory. A memory file older than a fortnight with no card pointer is a factory Bug.

## Context
A remembered rule fires when the model recalls it; a check fires every tick. Code beats memory because models forget.
