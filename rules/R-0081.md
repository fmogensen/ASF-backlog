## Statement
Every claim of done, green or verified comes with the command, its output, the commit and the review verdict. A report that states a result without them has not proved anything.

## Why
Two suite runs were reported as real the database when they had silently run on PGlite; the wrapper's own arm line would have said so.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
