## Statement
Two live sessions never write the same file. Tasks whose footprints are disjoint launch in parallel; tasks whose footprints intersect are serialised. A Task with no declared footprint is serialised on purpose.

## Why
Parallelism is the whole speed story, and the only thing that makes it safe is knowing what each task writes.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
