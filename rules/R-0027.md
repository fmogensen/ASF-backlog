## Statement
Every PR gets its own path-scoped CI run green BEFORE it may join a batch: a worker branch is pushed to a CI-triggering branch and the run is read. A PR whose own run is red or absent is not batch material. Batches of one are fine.

## Why
One member PR with no run of its own sinks the whole batch and the whole CI cycle with it.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
