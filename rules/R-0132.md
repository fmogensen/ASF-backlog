## Statement
Write `"${SHA}:refs/heads/<branch>"`, `"${r}:path"`, `"${host}:port"` — always braced. In zsh, `$var:` followed by any
modifier letter (a h t r e l u q s) rewrites the value. Never `git branch -D` a local ref before its push is
verified on origin.

## Why
2026-09-06: three pushes failed with `src refspec <sha>efs/heads/… does not match any` (`:r` strips an extension); the
first was misdiagnosed as "pushes from scratchpad worktrees are silently refused" and that false rule spread into the
goal text. 2026-09-10: `git show $r:a copy file in a customer-facing app` became an absolute path through `:a`. 2026-09-15: bit
again on a worker branch1`.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
