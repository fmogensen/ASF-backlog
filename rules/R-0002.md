## Statement
Right after ci-health, the tick runs the factory health check in fix mode and pastes its table into the reply. Anything it prints as ATTENTION is fixed in the same tick or becomes a NEEDS THE OPERATOR line with the exact command. A RELAUNCH row not launched in the same tick is a tick defect.

## Why
Health that is computed and not read is not health. The safe class (dead sessions, orphan runs, box disk, merged branches) is fixed by the script itself; the rest needs the tick to act on it.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
