## Statement
Every "find/grep X and change it" in a task body resolves to a path in that task's Files list, or the task fails preflight. The reviewer's first check stays touched-versus-listed.

## Why
Two tasks cost a fixer, a review round and a controller decision each because the files they told the coder to find were never listed.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
