## Statement
the code host's pull-request command merge --auto does not mean "merge when green" in this repository: with nothing required to wait for, it merges immediately, ahead of CI. The run is watched, then the merge is made with the gate check.

## Why
Three of the twelve ungated merges in the 2026-09-08 sweep came in exactly this way.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
