## Statement
At most four local agent jobs run at once. Cloud sessions are capped at sixteen, eight per slot. This supersedes the earlier sixteen/eight/eight split for the local half (another rule): the Mac could not carry eight.

## Why
the operator set the number after the third terminal crash; local agents compete for the same disk, the same the database and the same memory.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
