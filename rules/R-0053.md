## Statement
Every fix, rebase, build, review, probe or script-writing job — reds included, however small — is a cloud session on another the account manager account. A fork or a local agent runs on the controller's own account and is allowed only for a read-only look that needs this conversation's context and finishes in minutes. The small-change lane still applies to the controller's own 40-line edits.

## Why
The controller's 7-day window is what keeps the factory dispatching at all; spending it on work stops everything.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
