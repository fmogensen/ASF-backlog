## Statement
Plan-writers and preflight scans run on planning-model at maximum reasoning effort; every review runs on deep-model; implementers run on workhorse-model when the plan carries the code. Transcription tasks are workhorse-model whatever the plan's tag says. Writer and reviewer are never the same model, so the check stays independent.

## Why
A reviewer on the writer's own model repeats the writer's blind spots.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
