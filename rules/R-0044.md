## Statement
the merge queue phase 1 runs a preflight in the batch worktree before the push — migration lint, spec lint, docs check, the rename codemod dry run and the scoped package suites — with `TZ=UTC LANG=C.UTF-8` exported, at CI's own path scope. Any failure aborts the batch and names the member PR whose files the failing suite touches.

## Why
Three batches in one day were spent proving what a six-minute local run already knew; a fourth went red on a suite neither member PR touched because the preflight ran the whole tree in the controller's own timezone.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
