## Statement
A PR whose diff exceeds 40 files (excluding the review directory and `docs/**`) is split at review time rather than merged as one unit. The merge queue refuses such a PR outright with "split at review (rule 2ad)".

## Why
A 119-file PR cannot be reviewed or gated as one thing, so it is re-tipped instead — four full CI cycles in one day.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
