## Statement
Every tick's reply ends with the verbatim output of the tick tables command — the ENV line, ON PROD, ON DEV, NEXT, WORKING NOW, SPAWNING and Needs-you. Nothing in those tables is typed by hand: no rephrasing, no added rows, no ETAs of the controller's own. If a cell is wrong the script is fixed and re-run. A table that only exists in a tool result was never shown. The block is printed even on a no-op tick.

## Why
The tables are how the operator sees the factory. A rephrased table is a table he cannot trust, and a table left in a tool result is one he never saw.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
