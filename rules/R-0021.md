## Statement
A run on `main` is never cancelled. The cancel filter for mid-work runs is `headBranch != main and not batch`; engine and PR-branch pushes may have their `ci`/`computer`/`voice` runs cancelled, because their CI happens on the batch.

## Why
At 22:48 on 2026-09-17 a blanket cancel of branch runs took main's run with it, and main's run is what deploys dev.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
