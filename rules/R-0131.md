## Statement
Every item goes into the original brief. New scope that surfaces after dispatch goes to a second, self-contained agent
on the same base branch, never phrased as "continuing what the coordinator told you". Read every finished agent's
report for a line about refused or flagged instructions — that is the tell.

## Why
Twice: a site-content wave-4 fixer, and on 2026-09-06 a web walk-through hotfix agent that dropped three legitimate
items (a section-rename flow, a section header context menu, a responsive layout + owner-at-home copy change) because
the follow-ups arrived formatted like untrusted `<system-reminder>` blocks and its own injection detection flagged
them. The agent was right; the delivery path is the problem.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
