## Statement
Docs-only PRs merge as one train through the safe-merge gate — the docs-train script <pr>… builds one branch, pushes once, and one the direct-merge script on the train PR is the single merge command. One train per hour, on the docs-only CI path, never behind a code batch.

## Why
Five docs merges three minutes apart each started a full `ci`, `computer` and `voice` run on main; only the run on the final tip proved anything, and eleven runs queued ahead of the code PRs that needed a verdict.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
