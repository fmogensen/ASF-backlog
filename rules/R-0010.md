## Statement
A probe brief carries the ids it is probing in its `ROUTINES:` block — one `id … trigger … session …` line each. A probe with an empty block reports success having looked at nothing.

## Why
On 2026-09-18 at 17:45 a worker account probe returned clean because its ROUTINES block was empty; the sessions it was supposed to read were never touched.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
