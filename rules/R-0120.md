## Statement
Cleanup runs where no permission classifier sits: `.the code host/workflows/branch-sweep.yml` daily at 04:17 UTC, `--apply --only merged,equivalent,closed`. The `input` and `review` classes stay manual-apply-only, because those turn on a content judgement a machine should not make unattended. It never runs in the controller, because the controller is exactly the thing that cannot.

## Why
Thirteen deletable remote branches sat there because the controller could not delete any of them, whoever asked.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
