## Statement
An account listed in `account-hold.txt` never gets a launch, whatever its quota says. the quota reader prints `hold` for it in place of `ok`.

## Why
A held account is held for a reason the quota numbers do not carry — a wedged login, a window about to reset, the operator using it himself.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
