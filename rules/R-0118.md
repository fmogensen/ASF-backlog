## Statement
a per-account launch ledger is a launch ledger whose `status` is never updated; its rows are never read as "running". The in-flight set is `one file in the operator state directory`, written once per session by the dispatch recorder — never in a loop over the ledgers.

## Why
Reading a stale ledger as the live set makes the factory relaunch sessions that are working and ignore ones that are dead.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
