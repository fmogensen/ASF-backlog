## Statement
A review's round 1 lists every Critical finding; a finding visible in round 1's diff is never raised as a new Critical later. Round 3 is the last — the reviewer fixes the residue and approves. Fix rounds are for Critical and Important only; Minors ride the plan-end wave.

## Why
Findings that arrive in round 3 for code that was already in round 1's diff cost two extra sessions and teach nothing.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
