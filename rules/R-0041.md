## Statement
A QUEUE DEEP or RUNNER DOWN finding is reported to the operator in the same tick, with the one command that fixes it. Four or more runs queued for thirty minutes is the line.

## Why
A queue nobody reports is a queue the operator finds himself, hours later, in the Actions list.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
