## Statement
When there is free bandwidth and the build column is empty, adjudicate the stalemates and feed new specs from the parity matrix. The factory never idles waiting for the operator to answer something.

## Why
Bandwidth that waits on a human is bandwidth spent on nothing, and the answer usually was not needed to start.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
