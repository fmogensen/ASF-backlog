## Statement
Before every launch, the account manager usage refresh. The 5-hour window is the hard gate: workhorse-model jobs launch up to 92 %, deep-model jobs up to 85 %, and above 92 % only probes go out. A session that hits the 5-hour cap mid-work dies and its work is lost.

## Why
On 2026-09-18 eight deep-model reviews took a worker account from 0 to 100 % between 17:52 and 18:40; two of them never delivered.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
