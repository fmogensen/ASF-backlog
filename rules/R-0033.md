## Statement
Every commit on a pull request carries `Signed-off-by:` matching its author. The workflow requires the trailer to MATCH the author's name and e-mail, not merely to exist, so a scan for the presence of a trailer misses the case; scan for the pair (`git log --format='%h|%an <%ae>|%(trailers:key=Signed-off-by,valueonly)' origin/main..<head> --no-merges`) and flag any row whose two halves differ. The `dco` check is the gate; a red `dco` is fixed on the branch, never bypassed. A train whose members carry an unsigned or mismatched commit is rebuilt as one `git merge --squash` plus `git commit -s` per pull request on a fresh branch off main — the tree is identical, the history stays on the pull requests, and no branch is rewritten or force-pushed.

## Why
An unsigned early commit fails DCO on a merge train and takes the whole train down with it. Train #277 failed on three early spec commits with no sign-off, and rewriting those branches was refused as destructive; train #492 failed with every commit signed, because two were authored the agent harness (cloud) and signed off as the agent harness.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
