## Statement
When every job of a run fails with no steps and no runner, read the check-run annotation. A billing message means the organisation's Actions billing is blocked: tell the operator once, hold pushes, do not re-run.

## Why
Re-running a billing-blocked workflow burns the tick and changes nothing.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
