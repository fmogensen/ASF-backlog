## Statement
the mechanical preflight <plan.md> checks every Files path, every cited anchor, every declared export and every named table, plus the migration band against main and every live head. The deep-model pass reads that table and spends its budget on cross-task overlaps, ordering and whether a "find X" premise still holds.

## Why
A reasoning model spent on `git cat-file` is a reasoning model not spent on the seams.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
