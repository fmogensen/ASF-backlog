## Statement
Docs, tests, config and front-matter changes of about 40 lines or fewer are done by the controller directly (worktree, run the test, `git commit -s` with a `small-change:` trailer, push) or by a local workhorse-model spawn — never a cloud launch, no brief, no ledger row, no review. Reviews are for specs, plans and code.

## Why
A 12-line docs fix that costs a brief, a launch, a review round and a batch slot costs more than the fix is worth.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
