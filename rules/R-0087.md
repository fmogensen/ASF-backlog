## Statement
When a suite is red on the controller's machine and green on CI, the controller first runs it under `TZ=UTC`, then under CI's node version, then against a fresh install — and only dispatches a fixer once that A/B is written into the brief. Every fixer brief carries the line "Already fixed elsewhere: <PR/branch list or none>".

## Why
Q-4 took a workhorse-model fixer four hours with no push, a second that re-fixed a suite another PR had already fixed, and a deep-model that concluded "not reproducible on UTC" — before the two-minute local A/B found it.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
