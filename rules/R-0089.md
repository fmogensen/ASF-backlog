## Statement
No agent stashes. The stash stack is shared across every worktree on the machine, so a pop can take another session's work. Compare against the base with `git diff` or a detached worktree instead.

## Why
Three cloud implementers did it anyway in one plan; a shared stack plus two sessions is how work disappears.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
