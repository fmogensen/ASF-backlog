## Statement
Work that needs no container and no headless browser is dispatched to the cloud. Merges, container work, the hosting provider driver's live cases and anything needing an operator credential or a human stay local.

## Why
Local seats are the scarce ones; spending one on a task the cloud could take costs a container-bound task its slot.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
