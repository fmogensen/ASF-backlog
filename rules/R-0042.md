## Statement
A run whose head branch has been deleted, or whose PR is merged or closed, is an orphan: it is cancelled. An older main run superseded by a newer one is cancelled too. Both are the safe class the CI health check in fix mode applies itself.

## Why
Orphan runs hold boxes for work nobody will ever read.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
