## Statement
Every coder and fixer brief carries the whole review standard as its own pre-push gate — whole-tree lint, typecheck, docs-check, strings-lint, bands, the touched packages' suites, the site suite when a customer-facing app path is touched, the benchmark when runtime/core/db is touched, no empty generic key in the environment example file, no cwd-built root — and the writer's report pastes each command's last line. A reviewer who finds one of those red bounces the branch back in one line.

## Why
Fixers were the factory's largest cost, and most of what they fixed was something the coder could have run itself.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
