## Statement
After `--finish`, main is fast-forwarded, the batch's build worktree is removed, and the batch branch and its member branches are deleted. A merged batch branch left on the remote is not a record of anything.

## Why
the operator: "I like the factory floor clean". Dead batch branches make every later branch scan slower and every queue read noisier.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
