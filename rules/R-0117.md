## Statement
The product checkout carries `worktrees/smfix` and the worktrees of live jobs, nothing else. A merged branch's worktree is removed and its branch deleted; `git worktree prune` runs after.

## Why
Stale worktrees slow every branch scan and hold branches that should have been deleted. The daily sweep died silently once and nobody noticed for days.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
