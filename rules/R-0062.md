## Statement
Every implementer dispatch carries the task-reviewer rubric verbatim — the spec clause by clause, the Global Constraints as the attention lens, the four self-checks, security first, exhaustiveness on every union, bounded strings, named error classes, no dead strings, anchored test regexes — and the implementer's report ends with a self-review table against it.

## Why
Nearly every task needed exactly one fix round, and most findings were Minor: the implementer had never seen the criteria it was about to be judged by.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
