## Statement
Every instruction in a brief carries its reason and names the document the reason came from — the source register, not a summary of it — so the agent can check it. When an agent pushes back with evidence, the evidence is verified before the instruction is defended.

## Why
On 2026-09-08 the controller told the milestone integrator its migration band `0094`–`0099` was wrong ("seven migrations do not fit six slots") and sent it to `0108`–`0114`. The agent checked: the register says seven files fold to six, a ruling reserves 0094–0099 for a milestone, and the invented band was a milestone's 0110–0119 by a decision row. Acting on it would have recreated a milestone's blocker for the next milestone. The person most likely to be wrong is the one who read the summary instead of the source. Twice that day the agent was right.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
