## Statement
If an agent can fail by not finding something, the brief attaches it or says plainly that it may not exist. A brief that sends an agent looking for a file that is not there spends the session on the search.

## Why
Headless jobs are fenced to their worktree and cannot read the controller's scratchpad; what is not in the brief does not exist for them.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
