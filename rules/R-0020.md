## Statement
A red on main is item 0. Before any batch build, any wave dispatch or any queue grooming, the failing job's own statement is read — the check-run summary and log, never a re-run guess — and one diagnosis is produced within 15 minutes, ending in a hotfix branch or a revert. Nothing else is dispatched from a queue read while main's most recent `ci` run is red and undiagnosed.

## Why
Every plan, task and wave in flight is built on that commit. The next batch inherits the same failure and teaches nothing the first red had not already said.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
