## Statement
An ordinary push to a CI-triggering branch runs only the change classifier, the gate and the test gate; the specialised workflows do not match it at all. Batches, trains and main keep the full matrix.

## Why
A member branch's own run is informational — the batch's run is what gates — yet it was starting the same 90-165-minute matrix on five boxes.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
