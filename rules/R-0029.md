## Statement
A customer-visible hotfix (a `*hotfix*` branch) goes alone and FIRST on the batch stack, with the full CI for that surface. It does not wait for the hourly batching, but it still goes through the merge gate.

## Why
A production-affecting fix that waits behind a stack of feature batches is a fix the customer does not have.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
