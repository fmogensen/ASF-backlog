## Statement
A `--finish` blocked only by a wedged rerun — queued with zero jobs — may go once the sha carries no failed check-run. Re-run the dry check rather than waiting for the code host to unwedge itself.

## Why
A wedged queued run never completes, and waiting for it holds a green batch indefinitely.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
