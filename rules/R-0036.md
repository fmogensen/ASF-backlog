## Statement
Docs trains merge first, then code PRs one at a time; approvals are batched into trains; pushes are held when three runs already occupy the pool.

## Why
A code PR merged first moves main, so every waiting gate must contain the new tip — two gates were invalidated and re-run for it.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
