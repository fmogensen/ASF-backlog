## Statement
A branch's writer, its reviewer and its fixer run on three different the account manager accounts. The review is only independent if the account that wrote the code is not the account judging it.

## Why
A reviewer resumed on the writer's own account reads its own work and approves it.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
