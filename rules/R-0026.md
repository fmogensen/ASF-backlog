## Statement
A PR touching a surface a customer sees (the customer-facing app paths, a package, non-test source) ships ALONE, or only with other customer-visible PRs that already have a green CI run — never beside infrastructure, CI or tooling PRs.

## Why
The sign-in PR sat in six batches that sank on unrelated infrastructure changes. Customer value should not wait on a CI script.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
