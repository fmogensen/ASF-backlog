## Statement
An implementer runs its touched packages' suites, typecheck and lint. The full gate runs once, by the controller, in the background, at the merge onto the plan branch — and again only in CI. A cross-package break then surfaces at the merge, never later than the push.

## Why
Three full gates per task kept the local machine too loaded to run the agents the plan needed.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
