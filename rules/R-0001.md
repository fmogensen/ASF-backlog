## Statement
The tick's first command is the CI health check in fix mode. Exit 1 means findings existed; the tick's reply names each one and what was done about it.

## Why
Stalled and superseded runs held boxes while the operator found them himself. He asked not to: "i don't want to find out by myself".

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
