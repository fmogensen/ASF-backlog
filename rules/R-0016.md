## Statement
When the operator is away, the controller decides the open items itself, records each as a D-row with its reasoning, and keeps the PRs and merges moving. Nothing waits for a return.

## Why
A decision deferred to an absent human stops a branch for a day; a recorded decision can be overridden in a minute.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
