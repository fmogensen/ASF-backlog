## Statement
Every tick, for every account under its tier with hourly slots left, find the work that is READY NOW and dispatch it: a held/red PR with no fixer out, an approved plan task whose inputs are on main, a delivered artefact with no review out, a plan revision with no reviser, an approved PR not yet preflighted, a session silent past its line. An account under 85 % / 90 % with ready rows and no launch is a tick defect.

## Why
Idle accounts are the cheapest thing the factory wastes. The 5-hour window barely moves for cloud sessions, so a slot left empty buys nothing back.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
