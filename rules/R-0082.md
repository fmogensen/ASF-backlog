## Statement
Every coder runs the self-check script --files <path> before asking for a review and pastes its findings table: changed paths against the brief's file list, the spec's acceptance tests against the committed ones, docs-check, biome, typecheck, the banned pre-rename tokens, sign-off and Plan-Task trailers, and the changeset. A reviewer whose round-1 finding duplicates one of those marks it MECHANICAL.

## Why
Most of a day's bounces were a touched file the brief never listed, a drifted spec test, a stray old name, a missing sign-off — all of them mechanical.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
