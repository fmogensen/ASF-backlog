## Statement
Every capacity pass regenerates the queue in a detached worktree of origin/main (`git worktree add --detach worktrees/queue origin/main`, then `node the queue script`), reads the READY rows from that output, dispatches the disjoint ones, and removes the worktree. The committed the queue file is never the source of a dispatch.

## Why
A committed queue file is a status a human maintains, and it lied for three days while thirty ready tasks sat unseen.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
