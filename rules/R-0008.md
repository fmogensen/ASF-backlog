## Statement
Every launch/relaunch/probe job's result is read, not assumed. A launcher whose result carries `not found`, `failed`, `error`, `denied` or `empty` is relaunched THIS tick from the launch directory<acct>/.

## Why
A failed launcher looks exactly like a quiet one. Eight briefs can evaporate and the tick reads as normal.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
