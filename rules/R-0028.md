## Statement
A batch carries five or six PRs, docs-only members first (by the repository's own path classifier, then by PR number). autoBatch groups infrastructure PRs up to eight; customer-visible PRs go alone.

## Why
A batch is the unit that gets re-run when one member is bad. The bigger it is, the more good work a single red costs.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
