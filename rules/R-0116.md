## Statement
The statusline's local count is written, never derived; cloud entries are recorded once per session through the dispatch recorder, never in a loop over the ledgers.

## Why
Derived counts disagree with the ledgers and each other, and the rate-limit percentage reaches only the statusline's stdin.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
