## Statement
Every agent that starts a container removes it before reporting, then prunes containers, images and the builder cache with the label filter that spares the operator's home stack. Never a container system prune -a, never the `infra-*` containers or their volumes.

## Why
The disk is small and a day of containers fills it; a blanket prune takes the home stack with it.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
