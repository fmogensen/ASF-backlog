## Statement
A changeset names only public packages. Every `"private": true` package is ignored by changesets,
and a changeset that names an ignored package beside a public one is a "mixed changeset" that
exits 1 — so a private package never appears in one at all.

## Why
Two batches (B6, B7) were refused by `changeset status --since=origin/main` on 2026-09-19 between
01:00 and 03:40, and the pre-push hook's output does not show the line — only `error: failed to
push some refs`. The refusal costs a full batch attempt for a one-word edit.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
