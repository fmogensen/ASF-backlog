## Statement
`git push --no-verify` is banned, full stop. When the pre-push hook fails on files outside the pushed diff, the sanctioned way through is to commit, then `git checkout --detach origin/main && git push origin <sha>:refs/heads/<branch>`, which makes the hook's own diff empty and takes the docs-only fast path.

## Why
The hook lints the whole checked-out tree, so four sessions with clean, unrelated work were refused because some other file failed — and a cloud session's disk dies with it the moment the turn ends unpushed.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
