## Statement
Every customer-facing PR body written by a coder or a hotfix brief carries a `Try it: <url or click path> → <what you should see>` line. The tick's tables read that line; without it the table has nothing to show the operator.

## Why
The prod/next tables are the operator's window into the factory and they are generated from the PR bodies. A missing line is a blank cell no script can fill.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
