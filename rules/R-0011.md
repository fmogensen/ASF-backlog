## Statement
On every tick, for each account whose 7-day usage is over 90 %, probe ALL of its running sessions regardless of silence. A verdict of failed, idle-without-push or limit means relaunch at once on the account with the most room.

## Why
The cap kills a session the instant it hits; the session's last push can be thirty seconds old, so the 45-minute silence line never fires and the work is simply lost.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
