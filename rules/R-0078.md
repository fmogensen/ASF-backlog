## Statement
Every implementer commit ends with `Plan-Task: <plan>-t<N>`; a fix round on the same task carries the same trailer. It makes a milestone's task count a query on the one record that cannot vanish with a worktree.

## Why
The ledger that used to hold the count lived in a git-ignored directory and was wrong by ten tasks.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
