## Statement
Planners, coders, reviewers and fixers run as their own sessions on their own accounts, never as in-process agents inside the controller. A fork is for a read-only look that needs this conversation's context.

## Why
An in-process agent spends the controller's window and dies with the controller's turn.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
