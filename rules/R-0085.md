## Statement
Builds, browser-test runs and gates are piped to a file and the agent reads the last forty lines; vitest runs with `--reporter=dot` unless a failure is being read. A report never pastes more than the last line of a gate.

## Why
One fix round cost 851,000 tokens, most of it pasted output nobody needed.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
