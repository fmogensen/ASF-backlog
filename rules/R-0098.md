## Statement
This repository and the factory tooling are built by local spawns: the whole gate is `python3 -m unittest discover -s tools -p 'test_*.py'` plus the record tool check, the commit is signed, and it is pushed straight to main. No CI, no pull requests, no review rounds.

## Why
The backlog is the factory's own record-keeping; putting it behind the product's CI would make every schema fix cost a batch slot.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
