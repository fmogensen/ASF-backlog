## Statement
CI creates a database named after the run id in each job's first step and every database suite reads that name. Locally, the test-database wrapper holds a database per branch in the `bsn-test-pg` container, refuses to run when the URL is empty or unparseable, and prints which arm the run took as its first line.

## Why
A shared schema raced across jobs, and an empty `TEST_DATABASE_URL` silently ran two suites on PGlite while their reports claimed real the database.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
