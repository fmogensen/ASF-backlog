## Statement
Every cross-task seam in a plan carries its exact exported signature — types, parameters, names — in prose-free code form. The preflight scan rejects a plan that states an interface in prose.

## Why
Component props two tasks both touched, a shared completion function, a sibling's test mocking a shape that had moved: one Critical per task, nearly all of it seam drift.

## Check
None yet. The source check for this rule sources a shared library bound to one product's repository, state directory, branch naming and scheduled job, so it cannot be carried as it stands. It becomes a check when the rule runner reads those four facts from the product's configuration.
