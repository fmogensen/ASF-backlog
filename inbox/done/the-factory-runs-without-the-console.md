# The factory runs without the console

Type: Epic
Priority: need

## Description
The factory runs without the console. Everything a person at the console still does by hand to keep the factory delivering is moved into code: answering session questions, ruling on review loops, handling a red trunk, installing and restarting the kernel, and keeping seats busy. Thematic and open-ended; the Features under it carry the milestone they ship in.

## Acceptance
- [ ] Each Feature under this Epic names the console work it removes and the number that proves it (measured over a 24-hour hands-off window).
